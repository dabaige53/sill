## 真实浏览器

`npm run test:conversations-browser` 的16组检查全部通过，使用真实 HTTP/MCP 服务验证：

- 仅引用卡片不提交问题；刷新恢复待处理请求，刷新后到达的答案自动显示。
- 相同 MCP 答案重试只保留一条助手消息；多对话分别恢复历史、引用与草稿。
- 旧对话读响应不能覆盖后来打开的对话；断线报告错误且保留草稿。
- 对话创建或问题创建已提交但响应丢失时，使用原载荷/原键重试，不重复写入；期间的新文字和引用保留。
- 延迟创建响应与历史中独立编辑的目标草稿不会互相覆盖。
- 仅引用卡片的草稿可从历史恢复；超长草稿不截断，超限不提交；引用数量上限有明确提示。
- 消息/对话分页保持顺序；读取更早消息和后台刷新保留阅读位置。
- 390px 界面及长标题不横向溢出；无页面异常或外部模型请求。

此前 live/content/settings 三个浏览器联调和 F03 协议宿主模拟器均在最终代码上重新运行通过；共5个真实 Chromium 测试入口通过。原生宿主安装仍未验证。
