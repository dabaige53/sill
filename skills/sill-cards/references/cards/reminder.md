# reminder：提醒

到某个时刻提醒自己一件事。要拆成几步的事用 [task](task.md)。

示例是合成资料，只展示 `sill_createContent` 参数里外层的 `body` 对象，不能当作用户资料保存。通用要求见[类型索引](../types.md)，字段格式见[字段字典](../fields.md)。

## 显示

卡面：来源行（提醒时刻）→ 完成圆圈和标题 → 摘要（没有就不显示）。详情：圆圈和标题、标签、正文、所属项目。

## 填写清单

| 字段 | 要求 | 怎么写 |
| --- | --- | --- |
| `title` | 必填 | 到点要做的那件事，动词开头 |
| `summary` | 必写 | 一句话补充：在哪做、要带什么、为什么 |
| `due` | 必填 | 提醒时刻，13 位 Unix 毫秒；来源只有日期时写当天 09:00，并在正文注明 |
| `project` | 有就写 | 所属项目或清单 |
| `body` | 可选 | 更多细节 |
| `sources` | 必写 | 系统提醒事项写 `reminders` |

## 写法

提醒时间只是记录，Sill 不保证发出系统通知；不要对用户说「已设好提醒」。

正文结构：

```markdown
要做的细节。
```

## 示例

```json
{
  "type": "reminder",
  "title": "提交评审材料",
  "summary": "把定稿的 PDF 发到评审群，并抄送林青。",
  "due": 1793613600000,
  "project": {
    "name": "产品评审"
  },
  "body": "用周四定稿的版本，不要发草稿。",
  "sources": [
    {
      "name": "提醒事项",
      "kind": "reminders"
    }
  ]
}
```

## 写入前自检

- `due` 是 13 位毫秒，换算回来时刻正确
- 标题是一个动作
