# reminder：提醒

到某个时刻提醒自己一件事。需要完成并勾选的事情用 [task](task.md)，即使只有一项也是待办；不要按事项数量或来源程序判断类型。

通用要求见[类型索引](../types.md)，字段格式见[字段字典](../fields.md)。

## 显示

卡面：提醒类型 → 完成圆圈和标题 → 提醒时间 → 卡面摘要（没有就不显示）。详情：提醒类型 → 圆圈和标题 → 提醒时间 → 标签 → 独立概要（有 `summary` 时）→ 来源与所属项目 → 正文。时间固定在标题下，来源名称单独展示，不代替类型。

## 填写清单

| 字段 | 要求 | 怎么写 |
| --- | --- | --- |
| `title` | 必填 | 到点要做的那件事，动词开头 |
| `summary` | 可选 | 默认不写：标题和时间已经说清。需要补充在哪做、要带什么时写进 `body` |
| `due` | 必填 | 提醒时刻，13 位 Unix 毫秒；来源只有日期时写当天 09:00，并在正文注明 |
| `project` | 有就写 | 所属项目或清单 |
| `body` | 可选 | 更多细节 |
| `sources` | 必写 | 系统提醒事项写 `reminders` |

## 写法


正文结构：

```markdown
要做的细节。
```

## 示例

```json
{
  "type": "reminder",
  "title": "提交评审材料",
  "due": 1793613600000,
  "project": {
    "name": "产品评审"
  },
  "body": "用周四定稿的版本，不要发草稿。",
  "sources": [
    {
      "name": "提醒事项",
      "kind": "reminders"
    }
  ]
}
```

## 写入前自检

- `due` 是 13 位毫秒，换算回来时刻正确
- 标题是一个动作
