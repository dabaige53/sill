# Sill Apple

更新：2026-10-20。

一个 Swift Package。`SillKit` 提供卡片校验、本地存储与云端客户端；`macOS/` 是 Mac 应用 `Sill`；`iOS/` 只有共享数据层。

## macOS 应用

### 结构

| 目录 | 内容 |
| --- | --- |
| `App/` | 入口、窗口、菜单命令、退出前写入记录 |
| `Model/` | 状态与写入：`Workspace`、`CardState`、`CardModel`、`WriteQueue`、`ActivityRecorder`、`Feed`、`Reader`、`Selection` |
| `Shell/` | 顶栏、页签菜单、搜索框、AI 框、多选栏、面板、提示条、桌面布局 |
| `Settings/` | 设置窗口与设置控件（开关、分段、按键标记） |
| `Feed/` | 瀑布流、卡片外壳、11 种卡片正文、堆叠 |
| `Reader/` | 阅读浮层、预览、全屏页、工具栏、滚动与手势 |
| `Design/` | 图标、动效、阴影与玻璃、字体、格式化 |

状态规则：

- 每张卡片一个 `CardState`。写入只改这张卡片的状态，只有这张卡片重绘。
- 没有全局忙碌状态。写入只锁这张卡片或发起写入的按钮。版本冲突和未知结果先读取核对，不重发写入。
- 卡片数据先转成 `CardModel` 再交给视图，视图不读 JSON 字段。快照差异在后台线程计算，只更新变化的卡片。
- 打开卡片时的已看、阅读位置和阅读时长是后台记录：不改变被观察的状态，在打开动画结束后或关闭阅读时写入。
- 读完后的已读颜色等阅读浮层关闭后才在信息流中显示。
- 顶栏画在内容区。系统标题栏透明，只保留红绿灯。打开阅读时窗口工具栏不变化，遮罩盖住顶栏。

### 本地运行

```sh
node scripts/macos-demo-data.ts /tmp/sill-demo
npm run build:macos
dist/macos/Sill.app/Contents/MacOS/Sill --data-directory /tmp/sill-demo
```

演示数据来自 Web 的 `SeedCards` 和 `SeedItems`（30 张卡片，覆盖 11 种类型）。脚本不覆盖已有的 cards.json。

## 数据层

- 云端使用既有密码登录、会话、工作区与原子批量接口。会话 Cookie 保存在系统钥匙串，密码不持久保存；固定可信 HTTPS 服务，不自动跟随重定向，不使用 service-role 凭据。
- 邮件登录的 `client=macos` PKCE 回调（`sill://auth/callback`）由应用包注册；这条链路还需要服务端发布并核对 Supabase redirect 配置。
- 卡片写入携带读取时的版本；标签与备注保留打开时的编辑基准，冲突时保留输入。批量操作整批保存。请求结果未知时先读取确认，不重发写请求。待核对请求只在当前进程保留，不是持久执行队列。
- 来源字段只记录出处，不接入来源，不同步外部内容。

## 本地数据兼容

旧数据 `~/Library/Application Support/Sill/` 保持原样，不自动上传。

本地 cards.json 保留 revision/state 结构、未知字段与旧来源迁移。每次写入在文件锁内读取并检查版本，再原子替换；会话持有独占锁，两个进程不能同时编辑同一工作区。锁文件存在不表示正在占用。

## 构建与检查

需要 Apple Silicon Mac、支持 Swift 6 的 Xcode 和 Node 24+。

```sh
node tests/apple/run.ts
```

测试使用临时目录与模拟 HTTP 响应，不访问真实卡片或账号。`DesktopTests/` 用内存中的模拟工作区检查桌面状态：单卡写入不影响其他卡片、写入只锁本卡、失败回到已存值、未知结果只核对不重发、外部修改表现为冲突、后台记录不触发重绘、信息流成员与分页。

类型、文案、图标和设计变量（`AppleMetrics`、`AppleColors`）在构建时由 `Plugins/CardGenerator` 从 `contracts/` 与 `design-system/` 生成。生成器递归检查 `macOS/` 中的文案键，失效引用会阻止构建。新增设计值必须回到设计系统维护。
