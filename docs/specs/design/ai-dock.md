# AI 栏交互

更新：2026-10-29。本文维护 AI 栏的交互要求；各端接入范围见[实现状态](../../implementation/design/ai-dock-status.md)。

**底部 AI 框**

| 部分 | 数值 |
| --- | --- |
| 位置 | 底部居中，离底 28 |
| 尺寸 | 宽 640，高 `rail-row` 60，圆角 30 |
| 材质 | Web：清透玻璃 `glass` 加 `glass-filter`，带亮边和发丝线；macOS 26+ 为原生 regular 玻璃，不叠底色；AI 框、多选条和详情工具条三者相同 |
| 控件顺序 | +、输入、麦克风、发送 |
| 输入文字 | 16px |
| 控件 | 36×36，图标 20，不加底色 |
| 发送 | 32px 圆；不可发送时浅灰底、箭头用次级文字色，可发送时 `ink` 底 |

- 不显示主页 / AI / 搜索导航胶囊。控件和文字共用一条中线。
- 网页向下滚动时，顶栏与底部 AI 框一起收起；向上滚动、停止滚动或到达页面边缘时显示，顶部使用560ms、底部使用420ms（`dur-reveal`），曲线为 `ease-reveal`。搜索栏、AI 输入框聚焦或分栏菜单打开时保持显示；拖动卡片时显示 AI 框。
- 信息流不在最上面时，打开卡片详情、阅读页或照片，顶栏与底部 AI 框一起收起（`dur-tuck` 240ms），即使搜索栏有焦点也收起；停在最上面时保持显示。收起后，关闭卡片时与卡片同一帧开始回来，用同一个卡片弹簧，不延迟。Web 桌面与 macOS 相同，手机保持原规则。

桌面 AI 框上方只提供缩小按钮。鼠标未悬停时隐藏，移入 AI 框或按钮区域时显示；键盘焦点进入时也显示。触屏设备保留可见入口。按住输入框或胶囊空白处直接拖动，只调整水平位置，窗口缩小时保持在可用宽度内；展开时 Alt + 左右方向键也可移动，缩小时直接使用左右方向键。缩小后在输入栏右侧原行显示60×60对话气泡；点击恢复输入框，草稿与上下文保留。位置按当前实际宽度的可用范围限制，窗口变化保留相对位置。外壳裁切收缩260ms、展开300ms，曲线(.32,.72,0,1)，文字和图标不拉伸；旧内容前100ms淡出，气泡最后80ms出现，恢复内容最后120ms出现。图标可左右拖动，拖动结束不触发展开。多选交给 AI 时自动展开。手机保留原入口。

AI 框保留原有鼠标样式，输入区域为文字光标、缩小图标为手形；轻点输入框进入输入。展开与缩小使用上述260/300ms及分阶段内容淡入，键盘操作立即完成。

macOS 的缩小入口统一使用已有 `ai-minimize` 减号。引用的 X 保持12px图标，点击范围30×30；引用行右侧预留52px，避免缩小按钮覆盖引用关闭区。点击移除沿用引用退出和补位动效，输入草稿保留。

展开缩小仅缩放玻璃背景，文字与图标只做位移和淡入，保持原比例。左右拖动直接更新位移，不逐帧重绘组件；到达边缘后反向拖动立即跟随。

## 拖入与多选

Web 主页实际拖动卡片后，底部多选条切换为已有 AI 输入框；长按但未移动不切换。手机及搜索页在原操作胶囊位置显示 AI 输入接收框，拖入后打开已有上下文界面，不自动发送请求。取消拖动恢复操作条。收藏、稍后读与标签批量操作保留选择和胶囊；明确取消或交给 AI 才离开对应流程。

AI上下文使用独立参数：进入位移500ms/透明180ms，移除位移220ms/透明140ms，其余条目补位280ms；Web4px、手机整体8px。导航本身的140/420ms交接保持。Mac 使用相同时长和 ease-reveal，多选交接后引用延后 140ms 进入。
