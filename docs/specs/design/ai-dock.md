# AI 栏交互

更新：2026-10-29。本文维护 AI 栏的交互要求；各端接入范围见[实现状态](../../implementation/design/ai-dock-status.md)。

## 底部 AI 框

| 部分 | 数值 |
| --- | --- |
| 位置 | 底部居中，离底 28 |
| 尺寸 | 宽 640，高 `rail-row` 60，圆角 30 |
| 材质 | Web：独立背景层使用 `glass` 加 `glass-filter`、`glass-edge` 细亮边和 `shadow-float` 柔和阴影，外层不重复叠加模糊；macOS 26+ 为原生 regular 玻璃，不叠底色 |
| 控件顺序 | +、输入、麦克风、发送 |
| 输入文字 | 16px |
| 控件 | 36×36，图标 20，不加底色 |
| 发送 | 32px 圆；不可发送时浅灰底、箭头用次级文字色，可发送时 `ink` 底 |

- Web 桌面底部输入胶囊与搜索框共用材质反馈：精细指针悬停时，`glass-shade`、`line-hover` 贴边细线与 `shadow` 阴影层显示至 35%，内部聚焦时显示至 100%。仅该层 opacity 使用 `dur-hover` 160ms、`ease` 的 CSS 过渡；背景缩放与拖动继续由原动效控制。展开后的对话面板、手机和 Mac 保持原有表现。
- 不显示主页 / AI / 搜索导航胶囊。控件和文字共用一条中线。
- 网页向下滚动时，顶栏与底部 AI 框一起收起；向上滚动、停止滚动或到达页面边缘时显示，顶部使用560ms、底部使用420ms（`dur-reveal`），曲线为 `ease-reveal`。搜索栏、AI 输入框聚焦或分栏菜单打开时保持显示；拖动卡片时显示 AI 框。
- 信息流不在最上面时，打开卡片详情、阅读页或照片，顶栏与底部 AI 框一起收起（`dur-tuck` 240ms），即使搜索栏有焦点也收起；停在最上面时保持显示。收起后，关闭卡片时与卡片同一帧开始回来，用同一个卡片弹簧，不延迟。Web 桌面与 macOS 相同，手机保持原规则。

### 缩小与恢复

桌面 AI 框上方只提供缩小按钮。鼠标移入 AI 框或按钮区域、键盘焦点进入时显示按钮，其余时间隐藏。触屏设备始终显示入口。

缩小后，在输入栏右侧原行显示 60×60 的对话气泡。点击气泡恢复输入框，并保留草稿与上下文。多选交给 AI 时自动展开。手机保留原入口。

外壳收缩用 260ms，展开用 300ms，曲线为 `.32,.72,0,1`。只缩放玻璃背景，文字和图标只做位移和淡入淡出，保持原比例。旧内容在前 100ms 淡出，气泡在最后 80ms 出现，恢复内容在最后 120ms 出现。键盘操作立即完成。

### 水平拖动

按住输入框或胶囊空白处可水平拖动。展开时也可用 Alt + 左右方向键移动，缩小时直接用左右方向键。

位置限制在当前窗口与控件实际宽度允许的范围内。窗口宽度变化时保留相对位置。拖动直接更新位移，不逐帧重绘组件；到达边缘后反向拖动立即跟随。气泡也可左右拖动，拖动结束不触发展开。

### 光标与引用

输入区域使用文字光标，缩小按钮使用手形光标。轻点输入框进入输入。

macOS 的缩小按钮使用已有 `ai-minimize` 减号。引用关闭按钮使用 12px 的 X 图标，点击范围为 30×30。引用行右侧预留 52px，避免缩小按钮覆盖关闭区。移除引用时保留退出和补位动效，以及输入草稿。

## 拖入与多选

Web 主页实际拖动卡片后，底部多选条切换为已有 AI 输入框；长按但未移动不切换。手机及搜索页在原操作胶囊位置显示 AI 输入接收框，拖入后打开已有上下文界面，不自动发送请求。取消拖动恢复操作条。收藏、稍后读与标签批量操作保留选择和胶囊；明确取消或交给 AI 才离开对应流程。

AI 上下文进入时，位移动画为 500ms，透明度动画为 180ms；移除时分别为 220ms 和 140ms，其余条目补位用 280ms。Web 位移为 4px，手机整体位移为 8px。导航交接保留 140ms 和 420ms。Mac 使用相同时长和 `ease-reveal`，多选交接后引用延后 140ms 进入。

## 插件内对话

插件内网页隐藏底部 AI 栏。卡片 AI 操作把标题、摘要和正文作为引用附到宿主输入框，不发送消息。连续操作保留已有引用，宿主移除引用时同步当前内容。独立网页沿用原有 AI 栏；原生端不使用此宿主扩展。
