# 产品行为规范

更新：2026-10-29。本文规定页面与卡片的行为；产品目的见 [PRODUCT.md](../agent/PRODUCT.md)，实际平台支持与验证状态见[功能矩阵](../implementation/feature-matrix.md)。

## 页面

| 场景 | 职责 |
| --- | --- |
| 首次使用与新增 | 按本地或云端入口进入，由助手通过 MCP 创建卡片 |
| 主页 | 阅读信息流、分栏、排序与轻操作 |
| 详情与阅读 | 阅读完整内容、查看关联信息、播放支持的媒体 |
| 搜索与归档 | 查找卡片、查看归档与放回主页 |
| 设置与 AI 入口 | 管理偏好；内置 AI 未接入时只展示已有占位能力 |

桌面与手机的导航、搜索、设置和 AI 入口见 [交互规范入口](DESIGN.md)。现行画板位置见 [设计系统映射](../implementation/design-system.md#画板)。

## 卡片

类型：文章、邮件、笔记、待办、日程、提醒、媒体（播客、视频）、照片、文件、摘要、建议、PR。收藏、稍后读、已读、标签、备注是跨类型的状态，不另做卡片。

卡面用标题、摘要、来源与必要的专属字段帮助用户判断；详情文字统一写入 Markdown body，要点放在正文列表。任务、日程、附件、章节、文字稿和 PR 快照保留各自结构。字段含义与上限见 [跨端数据约定](../../contracts/README.md)，写作规则见 [卡片内容设计规范](design/card-content.md)。

标题、摘要的显示行数与截断规则按卡片类型和平台处理，统一见 [字体](../../design-system/handbook/foundation.md#字体)与[文字长度](../../design-system/handbook/foundation.md#文字长度)。详情保留完整正文。

## 信息流

- 按重要和时间排序：快到时间的提醒（15 分钟内）和日程（30 分钟内）自动上浮。
- 同一来源短时间内的多张卡叠成一摞，可左右切换，单击展开。
- 一次显示 40 张，滑到底继续加载。
- 刷新不强制回到顶部；新内容先提示，点了再插入。
- 读过的卡片可以按设置变淡、到期收起；同一提醒不反复出现。

## 阅读

- 单击卡片打开详情，支持完整阅读的类型可进入放大阅读。
- 桌面与手机的打开、关闭和返回方式见 [预览与叠放](../../design-system/handbook/interaction.md#预览与叠放)。
- 打开过不等于读完；阅读完成、短文计时与关闭手势按 [两端共用规则](../../design-system/handbook/interaction.md#两端共用)和[提交、取消与导航](../../design-system/handbook/motion.md#提交取消与导航)处理。
- 视频根据真实播放状态保存位置；实际播放结束才自动标为已读，拖到结尾不算完成。播客只展示外部收听记录，不提供内置播放。
- 跳出到来源网站需要用户明确操作。

## 轻操作

- 卡片 •••：收藏、稍后读、标签、备注、标为已读、少看这类等。
- 多选操作与卡片拖入 AI 区域使用已有入口；具体行为见 [交互规范入口](DESIGN.md#交互与状态)。拖入仅提供上下文，不因拖动自动发送或执行外部动作。
- 待办可勾选完成，提醒可完成、延后、忽略。
- 阅读、收藏和任务勾选更新 Sill 状态。外部动作的待处理、执行中与完成属于待实现的执行流程；只有取得可信回执后才能表达外部完成。
执行流程见[外部助手回写计划](../plans/external-agent-webhook.md)。

## 设置

设置保留桌面偏好、外观、快捷键、数据与隐私等轻操作。桌面弹窗与手机页面的分组、位置和可用状态见 [设置规则](../../design-system/handbook/web-interaction.md#设置弹窗)与[现行设置画板](../../design-system/README.md#设置)。

## 可访问性

全部操作可用键盘完成；手机触控区域不小于 44px；支持浅色、深色与跟随系统主题；已有系统偏好分支按设计规范保留；纯图标控件都有可访问名称。
