# Sill 交互与无障碍修复验收

本改动承接 Sill 重构（#15），保留其视觉语言。默认本地产品的八项审查问题分别对应：

| 问题 | 修复 | 行为回归 |
| --- | --- | --- |
| 断线重载后草稿不可达 | 操作发出前保存草稿日志；重载恢复；恢复重放校验revision；冲突保留本机版本并提供导出/重试/确认放弃 | 503→新增→重载→恢复；服务端新值不被旧草稿覆盖 |
| 同步重建阅读会话 | 无关卡片更新不重建预览；相关更新保留滚动/焦点/full sheet并重绑监听 | 无关与相关更新、滚动继续 |
| 任务/来源丢焦点 | checkbox原位更新；共享面板重绘保存操作标识和滚动位置 | Space/Tab连续操作与来源开关 |
| 深浅色对比不足 | secondary加深；accent-fill与动作前景色分离 | 四种宽度、深浅主题、feed/search/preview/settings axe |
| 短窗口保存不可达 | panel sheet可滚，按dvh限制最大高度 | 320×225键盘聚焦保存并提交 |
| 空桌面归档消失 | 空态保留归档导航 | 仅剩已读卡片时打开归档并恢复 |
| 导入只能审核前六条 | 完整可滚列表；混合类型明确列出本次不纳入的文件，要求分次导入 | 8条逐项选择，第8项可取消，混合CSV/Markdown说明 |
| 搜索名称/焦点/播报不足 | dialog标题、focus-within、live数量、Esc关闭 | 键盘打开/输入/关闭、可访问名称、axe |

一并修复：可关闭N/R/T单键快捷键、radio方向键和单Tab入口、已读文字/符号标识、头像语义、显式aria-hidden、重复项准确称“跳过”，不同URL同标题不再误去重；系统和应用设置两种减少动态效果均覆盖CSS。

## 测试命令

```
npm test
python3 tests/verify.py
npm run test:browser
npm run test:local-browser
npm run test:accessibility
```

`test:accessibility` 使用隔离临时目录、合成fixture、Playwright及axe-core；已加入CI。浏览器可通过 `CHROMIUM_PATH` 指定已安装Chromium（本地验收151.0.7922.173）。原local-browser测试在本环境使用外部副本，仅调整浏览器路径及import，不改变行为。

移动菜单保持44px测试要求。原失败是菜单进入缩放和父卡片触摸回弹缩小点击区域；移除菜单缩放，并在tools-open时立即停止父卡片transform过渡。测试同时在打开后与240ms稳定后测量，不放宽尺寸阈值。

已读测试旧的“不得出现已读文字”断言改为可见非颜色标识和可访问状态；导入测试使用真正重复URL，不再把不同URL相同标题当重复。上述断言改变是修正产品合同，不是隐藏失败。

## 边界

- Chromium自动化与axe不是读屏认证；NVDA/VoiceOver、WebKit/Firefox、实体触摸板/手机、实际浏览器200%/400%缩放与软键盘仍需人工验收。320×225为400%等效布局视口。
- 旧版本草稿没有revision时不自动重放；保留可见草稿并允许导出，避免盲目覆盖服务端。恢复时遇到任何revision变化也保守保留，尚无逐字段冲突合并界面。
- 混合导入不静默丢弃：本次按首种类型预览，清楚列明其他文件需分次导入；尚不是多类型统一导入事务。
- 退役Host/AI/服务端工作流与设计参考原型不在此次修复范围；没有恢复它们的产品交付承诺。
