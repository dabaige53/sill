# 事项分类标签

状态：现行规则。更新：2026-10-16。

| 技能角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给 Agent |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不安排处理 |

技能提到分类角色时，使用对应仓库标签。保留仓库已有的其他标签。目标仓库与操作规则见 [事项管理](issue-tracker.md)。
