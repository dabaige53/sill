# 功能矩阵

更新：2026-10-29。按当前源码说明平台支持，真实服务与窗口验收单独记录。部署和工具发现以当次回执为准。

| 能力 | Web/PWA | Mac | 云端与接口 |
| --- | --- | --- | --- |
| 卡片与轻操作 | 展示、阅读、收藏、任务、提醒、标签、备注、归档、搜索 | 对应原生界面 | 内容与工作区 HTTP/MCP |
| 内容创建与修改 | 通过助手操作 | 通过助手操作 | 版本保护与原子批量 |
| 账号 | 密码登录；邮件流程由配置控制 | 密码登录、钥匙串会话；邮件流程由配置控制 | 邮件登录默认关闭，实际环境需核对配置 |
| 视频 | 官方 YouTube 播放器 | 官方视频区域 | 宿主是否允许嵌入按协商结果 |
| 播客 | 只读介绍、章节与外部收听记录 | 同类只读内容 | 播放位置作为内容状态读取 |
| 图片与外链 | 内置素材或 HTTPS 图片；宿主使用 openLink | 图片加载与外链失败反馈 | 图片 URL 不携凭据；无文件上传 |
| 备份与恢复 | 设置 → 备份与恢复；独立网页配置 WebDAV/R2，宿主操作已有位置 | 设置 → 备份与恢复；配置与立即备份 | WebDAV/R2、登记快照、恢复预览与原子替换；依赖权限、迁移和加密配置 |
| 系统提醒 | 页面打开时检查到期提醒 | 系统安排已载入提醒 | 设备权限独立保存 |
| PR 卡片 | 展示助手写入的快照 | 对应原生展示 | 数据写入不调用 GitHub 评审 |
| AI 上下文 | 独立网页保留上下文预览；插件内隐藏底部 AI 栏，支持 openai/modelContext 的宿主可附加卡片正文引用，用户手动发送 | 上下文界面 | 直接数据工具可用；内置模型与 Webhook 执行尚未实现 |
| 本地模式 | 本地服务与 CLI 共用 JSON | 独立本地测试工作区 | 与云端账号数据分开 |

原生 iOS 当前提供共享数据层，界面支持尚未完成。具体字段见[共享约定](../../contracts/README.md)，工具权限与限制见[MCP 说明](agent-mcp.md)。
