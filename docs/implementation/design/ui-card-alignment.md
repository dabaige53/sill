# 卡片实现对照

更新：2026-10-29。本文记录卡片在各端的接入范围与差异；交互要求见[设计规范](../../agent/DESIGN.md)，历史窗口验收见[事件记录](../../records/README.md)。源码接入不等于窗口验收。

## 信息流与卡片

| 项目 | 当前实现与差异 |
| --- | --- |
| 布局 | Web 桌面多列，手机单列；Mac 使用原生信息流布局 |
| 首屏入场 | Web 前十张按次序入场，分页不重复首屏动画；入口为 `apps/web/views/app-feed.ts` |
| 已读与完成 | 更新展示状态，主动刷新时再重排；已读样式由共享颜色角色控制 |
| 叠卡 | 同来源、时间接近的未读资讯或媒体按既有阈值聚合；已读卡不纳入聚合 |
| 封面 | 两端支持内置图片和 HTTPS 图片。Web 初始画面和缓存命中不重复图片淡入，新图片加载后可淡入；Mac 使用 AsyncImage，失败时保留背景 |
| 内容日期 | 两端按内容日期格式化，邮件与 PR 保留时分；纯日期不补时分 |
| 菜单 | Mac 提供卡片右键菜单；Web 使用既有轻操作与多选操作条，没有单卡或多选右键产品菜单 |

## 详情与阅读

| 项目 | Web / 手机 | Mac |
| --- | --- | --- |
| 打开与关闭 | 桌面从来源卡片展开；手机使用抽屉 | 原生外框展开，内容不缩放 |
| 关联卡 | 逐层打开与返回，恢复父卡阅读位置 | Reader.Layer 保存各层状态，顶层接收输入 |
| 阅读完成 | 长文按阅读位置、短文按停留时间判断；完成手势按真实写入结果处理 | 同一完成语义，交互由原生手势实现 |
| 照片 | 背景随主题，缩略图与通用操作条 | 背景随主题；PhotoLightbox 的工具条仍读取隐藏操作偏好 |
| 视频 | 支持的来源使用嵌入播放器；不可播放时可打开来源 | 官方嵌入播放器位于受限 WebView 区域 |
| 播客 | 只读介绍、章节与外部收听进度，无内置播放 | PodcastDetail 展示相同内容，无内置播放 |
| 资讯目录 | 桌面右侧显示真实 Markdown 标题目录，点击定位；手机宽度隐藏目录，无展开或收起控件 | 左侧原生目录，圆点动效与 Web 有差异 |
| 放大阅读 | 退出全屏返回同张卡预览；关闭退出详情 | ReaderPage 缩小返回预览 |
| 与助手讨论 | 只在支持消息的 MCP 宿主出现 | 独立应用不提供宿主消息入口 |
| 文字间距 | 使用共享纵向间距变量和阅读偏好 | 使用对应的 Apple 变量和阅读偏好 |

原生 iOS 当前只有共享数据层，没有完整阅读界面。平台能力总表见[功能矩阵](../feature-matrix.md)。

## 卡片类型

Web 与 Mac 均有按类型组织的卡面和详情。来源标记共用素材和匹配规则，未知品牌使用通用标记。摘要卡的概览和正文、任务清单、媒体章节、文件与 PR 字段按[卡片内容规范](../../specs/design/card-content.md)组织。

主要实现入口：Web `apps/web/cards/`、`apps/web/views/reader-layout.tsx`、`apps/web/styles/reader-layout.css`；Mac `apps/apple/macOS/Reader/` 与 `apps/apple/macOS/Reader/PhotoLightbox.swift`。更新时核对对应组件和样式，数值以设计变量与手册为准。
