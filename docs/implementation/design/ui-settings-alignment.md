# 设置实现对照

更新：2026-10-29。本文记录设置和账号入口的平台差异；视觉与交互要求见[设计规范](../../agent/DESIGN.md)。

| 项目 | 当前实现与差异 |
| --- | --- |
| 设置入口 | Web 桌面使用弹窗，手机使用整页；Mac 使用原生设置视图，并支持 ⌘, |
| 外观与排版 | 两端提供跟随系统、浅色、深色及卡片和阅读排版偏好；恢复默认只作用于对应偏好 |
| 归档 | 可查看归档并放回主页 |
| 标签与备注 | 保存使用编辑基准，发生冲突时保留输入并提示处理 |
| 登录 | 两端提供账号密码登录与邀请制说明；邮件开启时提供忘记密码和邮件登录，关闭时提示联系管理员。Mac 通过 `/auth/options` 读取是否开启 |
| 账号操作 | 两端在设置 → 数据提供修改密码、管理插件授权、退出登录、退出所有设备。Web 改密使用独立页面，Mac 使用原生弹窗；管理插件授权在两端都打开网页 |
| MCP 授权 | 云端网页提供授权页面，Mac 独立应用不提供该页面 |
| 性能追踪 | Mac 菜单提供本机诊断工具，Web 不适用 |

主要入口为 `apps/web/interactions/panel-settings.tsx`、Mac `SettingsView` 和 `server/cloud/http.ts`。备份与系统提醒见[对应操作说明](../operations/backup-and-reminders.md)。当前页面不把开发备注或未接入能力作为用户设置项。
