# 备份、提醒与外链实现对照

更新：2026-10-29。本文只记录入口差异；配置、恢复限制和部署依赖见[操作说明](../operations/backup-and-reminders.md)。

| 场景 | Web / 手机 | Mac |
| --- | --- | --- |
| 备份位置 | 独立网页可以配置；MCP 内嵌页面只使用已配置位置，不接收秘密 | 通过账号接口配置 |
| 备份与恢复 | 提供备份、记录、下载、预览和确认；需服务端启用 | 使用相同账号能力 |
| 系统提醒 | 独立网页打开期间检查，受浏览器后台计时影响；内嵌页面不申请权限 | 系统安排已载入提醒，关闭窗口可继续运行，退出应用后不能补排 |
| 外链 | 宿主通过 openLink 打开，独立网页使用浏览器 | 统一外部打开并反馈失败 |
| 无 URL 文件 | 展示文件信息 | 展示文件信息 |

通知权限属于设备，卡片提醒状态属于账号。真实环境是否启用，以该环境配置与当次验证为准。
