# 测试操作说明

更新：2026-10-29。范围与授权由[测试规范](../agent/test.md)管理；可用命令读取 `package.json` 与[测试目录](../../tests/README.md)。

## 动效与计时

动画、滚动、手势的时长与间隔使用合成测试核对，不在浏览器逐帧录制来验证计时规则。获准使用浏览器面板时，先确认面板可见和实际视口尺寸，再判断动效表现。

合成计时器和绘制帧分别推进：`f.flush(undefined, ms)` 推进时间，`f.flush(f.frames)` 推进一帧。检查触发、取消与完成时，应推进对应机制；缺陷回归需确认撤掉修复时失败。

节点身份、旧回调、重复请求与状态保留可用非浏览器测试核对；实际触摸、惯性和视觉交接需要对应环境证据。

## 自动检查

CI 的触发路径、命令和必需条件以[工作流目录](../../.github/workflows)为准。Mac 检查在匹配的 Apple、contracts、design-system 等路径变化时运行；发布工作流按版本 tag 执行对应检查和打包。CI 配置不授予本地界面自动化权限。
