# Sill · 窗台 — 产品需求文档

状态：V1 产品目标，2026-10-13 更新 agent 驱动原则；不是全部已实现的功能清单。页面以 [Sill · 设计画布](https://claude.ai/artifact/487W43yaF9D3Kno8c3ej6b) 为准（本地副本 `design-system/boards/`），交互细节见 [交互规范](INTERACTION-SPEC.md)，取舍原因见 [设计决策](DESIGN-DECISIONS.md)。前一版 Quiet Glass 的需求已被本文取代。

## 1. 产品是什么

一个放在本机的个人卡片窗台。文章、邮件、笔记、待办、日程、提醒、播客、照片、文件都变成卡片，按「现在该看什么」排好。用户主要做两件事：往下翻，点开读。

内容由用户自己的 agent（Codex、Hermes、Claude）持续驱动。页面负责展示状态和表达意图；完成、阅读、同步也是 agent 可处理的输入，不能把用户点击等同于外部执行成功。Agent 使用可用 MCP 工具执行并回写真实结果；仅涉及本地阅读偏好的意图可以本地确认，无需制造外部写入。

当前只有本地命令读写与页面状态更新；目标中的意图队列、执行器与回执关联尚未实现。实现边界以 [Agent 与 MCP](AGENT-MCP.md) 为准。

**两种目标形态：** 内置AI助手的工作台；作为外部MCP服务器供第三方AI助手使用。共用能力层提供产品数据/任务操作、内置助手长任务委托和已安装上游MCP的选择性tools桥接。直接调用工具不强制经过内置LLM；安装不等于公开，按调用方与资源授权。详情见 [两种产品形态](AGENT-MCP.md#两种产品形态与共用能力层目标尚未实现)。

当前仍为本地卡片实现；不是以聊天为唯一入口的产品。内置助手、对外服务及桥接均待实现，本次不决定云端部署方案。

## 2. 视觉原则

1. 默认只有卡片。没有侧栏、顶部导航、欢迎横幅。
2. 安静、可读优先。玻璃只用在浮在内容上的东西：右下角入口、预览、操作条。
3. 颜色只表达状态；已读的卡片变淡但仍可读。
4. 文字和图标只用一种，不重复表达。
5. 桌面和手机行为一致，只是触发方式不同。

具体颜色、字体、间距、动效以 [设计手册](../design-system/README.md) 为准。

## 3. 页面

画布的页面地图共 37 个页面和状态，归成六块：

| 区域 | 内容 | 画板 |
| --- | --- | --- |
| 进来 | 首次打开、选来源、导入文件、收集入口 | 03、24、31 |
| 桌面 | 信息流（桌面 1440、手机 390）、下滑与等待、量大与去重 | 05、06、10、25 |

## 4. 卡片

类型：文章、邮件、笔记、待办、日程、提醒、媒体（播客、视频）、照片、文件、摘要、建议。收藏、稍后读、已读、标签、备注是跨类型的状态，不另做卡片。

每张卡片由同一套积木拼成：头部（来源、时间）、标题、摘要或要点、封面、正文、操作。文字长度上限：

| 部分 | 上限 |
| --- | --- |
| 标题 | 2 行，约 30 字 |
| 摘要 | 3 行；有封面时 2 行，约 60 字 |
| 要点 | 3 条，每条约 18 字 |
| 卡片内正文 | 6 行 |
| 引用 | 4 行，约 40 字 |

超出部分截断，点开看全文。

## 5. 信息流

- 按重要和时间排序：快到时间的提醒（15 分钟内）和日程（30 分钟内）自动上浮。
- 同一来源短时间内的多张卡叠成一摞，可左右切换，单击展开。
- 一次显示 40 张，滑到底继续加载。
- 刷新不强制回到顶部；新内容先提示，点了再插入。
- 读过的卡片可以按设置变淡、到期收起；同一提醒不反复出现。

## 6. 来源与导入

来源按用途分组：

- 读：RSS、Readwise、网页收集、YouTube、推特、播客
- 回：邮件
- 做 · 跟进：提醒事项、Linear、GitHub
- 排时间 · 存档：日历、照片、文件夹

另有速记、Markdown 导入、AI 整理。导入时可以选范围、去重；每个来源可以暂停、移除、调整信任度（例如「少看这类」「不再显示」）。来源分类不是已接入清单。连接优先复用宿主现有 MCP 或成熟开源 MCP；鉴权交由上游 MCP/宿主，不由 Sill 自建。记录引用和实际能力，只有成功检测后才展示已连接；没有合适服务的来源保持未支持。

## 7. 阅读

- 单击卡片直接看全文；「全屏」进入完整阅读。
- 桌面从卡片原位展开；手机从底部升起，往下读铺满全屏。
- 关闭：关闭按钮、Esc、在顶部下拉；读到底继续上推完成阅读并关闭。
- 打开过不等于读完：读到底或短文停留 3 秒才算读过。
- 跳出到原网站要明确点「打开原文」。

## 8. 轻操作

- 卡片 •••：收藏、稍后读、标签、备注、标为已读、少看这类等。
- 拖动卡片到收藏、稍后读、标签；可多选后一起处理。
- 待办可勾选完成，提醒可完成、延后、忽略。
- 本地反馈可以立即出现；涉及外部动作时显示待处理/执行中，收到可信回执后才显示已完成。
- 未派发意图可取消；已派发动作的取消不保证外部撤销。外部撤销若受支持，应成为新的补偿意图，不能承诺所有动作可逆。
- 重复点击不得重复创建外部对象；超时且结果未知时先核对，不盲目重试。目标状态协议见 [Agent 与 MCP](AGENT-MCP.md)。

## 9. 设置

五组：来源、桌面（排序、叠卡、已读变淡、自动收起、快到时间上浮、新内容提示）、外观（主题、密度、减少动态效果、减少透明度）、快捷键、数据与隐私（导出、清空、本地处理）。

## 10. 数据与边界

- 数据保存在本机文件，页面和 AI 共用，修改后自动同步；不需要账号。
- AI 通过本地命令读写卡片，批量操作全部成功才保存。
- 当前页面没有内置助手或外部调用入口；目标中内置/外部agent共用能力层，通过MCP处理外部动作，用户仍可直接阅读卡片、表达意图。
- MCP 连接配置属于目标范围；真实凭据和首次授权在宿主/MCP 中完成。Sill 不建立账号/OAuth体系；云端发布和跨设备同步仍不在本阶段。
- agent 定时或事件驱动运行取决于实际宿主能力；不能把浏览器关闭后的自动执行当作当前已有能力。

## 11. 可访问性

全部操作可用键盘完成；手机触控区域不小于 44px；支持减少动态效果、减少透明度、深色主题；纯图标控件都有可访问名称。
