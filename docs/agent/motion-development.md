# 动效开发与排查

更新：2026-10-29。修改动画、滚动或手势时使用。效果要求见[设计规范](../agent/DESIGN.md)与[动效手册](../../design-system/handbook/motion.md)，参数读取[设计变量](../../design-system/tokens/foundation.json)。

## 1. 固定操作与预期

明确平台、输入方式、入口、连续操作、实际现象和预期结果。区分触控板、鼠标滚轮、按住拖动和触屏手势；口语描述先对应到具体界面。

完成条件：能复现用户操作，或明确标为源码排查；本次目标与保留效果清楚。

## 2. 对照参考与实现

按真实元素、输入触发、运动对象、生命周期、运动计算和平台差异逐项对照。成熟组件的手势、嵌套、模态、滚动锁定与键盘处理优先保留，替换的职责要有明确接管者。

完成条件：每个参考行为都有产品对应元素；采用范围和适配差异有依据。

## 3. 确定控制归属

- 同一元素的同一属性在同一阶段只有一个控制者；外框、遮罩、背景与工具按共同阶段交接。
- 正文滚动优先使用平台行为；应用只在明确的产品手势中接管，并在结束时归还。
- 新操作从当前可见状态接续。取消旧动画时清理临时样式、操作锁与监听，使旧完成回调失效。
- 分别处理触摸、拖动与 wheel。wheel 的静默时间只能估计输入结束，不等于 pointerup。

完成条件：开始、跟手、释放、回位和关闭的控制者明确，反向操作可从当前状态继续。

## 4. 按现象定位

| 现象 | 先检查 |
| --- | --- |
| 距离过大、空白过多 | 可见位移、阻力、惯性累计 |
| 回位或关闭延迟 | 输入结束判断、重复计时、反馈等待 |
| 中途停顿或结束突跳 | 节点重建、布局读写、强制清零与叠加过渡 |
| 前后层不同步 | 控制者、交接进度与取消恢复 |
| 勾选闪白、阅读位置跳动 | 详情节点身份、更新范围与内容变化判断 |
| 用户仍看到旧效果 | 页面来源、工作目录、构建产物与数据后端 |

先确定问题所在层，再调整参数。按角色使用设计变量；保持正文、输入、播放器、焦点、滚动位置和草稿。请求、数据写回、内容运动和反馈展示分别计时。

## 5. 验证与交付

计时与取消测试须推进计时器和绘制帧；覆盖旧回调、重复请求、节点保留及取消清理。真实触摸、系统键盘、惯性与视觉交接需要对应环境的证据。

交付列出平台、入口、触发、运动对象、预期效果与验证结果。每次改动同步维护对应规则、参数和实现状态；当次过程与证据进入事件记录。
