## Platform

Web/PWA 提供共享界面基准，原生端适配窗口、输入和通知。平台支持见[功能矩阵](../implementation/feature-matrix.md)。

## Users

已使用外部 AI 助手的个人用户：让助手整理内容，在 Sill 阅读卡片、查看待办与日程、完成轻操作。

## 产品目的

Sill 是由 AI 助手整理内容的个人卡片工作台。助手创建卡片并更新正文与结构字段，用户阅读卡片、查找内容和完成轻操作。

## Agent 优先与界面边界

- 内容创建、正文与结构字段修改由助手完成，Web/PWA 与 Mac 不提供手动创建卡片入口；产品数据与状态操作应能通过 MCP 执行，与界面共用权限和保存规则。
- 界面提供阅读、收藏、稍后读、任务勾选、提醒、标签、备注、归档、搜索、筛选与设置。保持轻操作，不新增整卡编辑器、复杂字段表单或 JSON 编辑器。
- Sill 内的状态只说明本产品中的操作；外部任务完成必须有真实回执。

## 来源与外部工作

- 来源字段记录内容出处。Sill 不接入外部内容来源，不做来源同步、RSS/OPML 订阅或文件导入。
- 外部助手使用自己宿主的工具操作其他程序，通过 Sill MCP 回写结果。
- 若实施内置助手，其连接器只采用 Composio；禁止自建或自选上游 MCP、桥接上游工具、另建上游 OAuth 或直连外部来源。账号备份属于独立的数据保护能力。

## 数据与授权

修改保留读取基准并检查冲突；原子批量操作全部成功才保存。回执未知先核对，避免重复写入。

发现、调用和结果读取受调用方权限、工具允许列表与资源所有权限制；委托不得提权。秘密保留在安全配置中，禁止进入卡片、模型上下文、浏览器持久化、日志和仓库。执行过程须记录审计信息，并限制循环次数和委托深度。

发布版 Web、PWA 和 Mac 只使用服务器端账号数据。不得提供示例写入、独立本地工作区或失败后转为本地修改的入口。界面轻操作须通过服务器保存；开发测试数据与真实账号隔离。

WebDAV 和 R2 仅用于数据备份，不作为工作区数据源，不参与双向同步。定时备份另行实现。
