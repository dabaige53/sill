# 术语与决策管理

更新：2026-10-29。

## 业务术语

整个项目共用根目录 [GLOSSARY.md](../../GLOSSARY.md)。理解业务、命名或审查前读取相关定义；Issue、代码、测试和文档使用同一称呼。新概念先确认含义，再通过 domain-modeling 更新术语表。

术语表只保存业务定义。实现细节进入实现说明，文档管理规则进入[文件管理规范](file-management.md)。

## 决策记录

需要解释架构或重要设计取舍时，查阅相关 ADR。新决定使用 `docs/adr/NNNN-topic.md`，编号取现有最大编号之后，记录日期、状态、理由、影响与替代关系。

生效要求进入对应现行规范，ADR 保留决定原因。后续改变新增决定并说明替代关系，保留原记录与编号；引用使用完整文件路径。仅在产生实际决定时创建记录，不建立空文档。
