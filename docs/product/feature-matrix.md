用户保留既有新增、速记和轻操作；已有卡片标题、正文和结构字段由助手通过 MCP 修改。阅读、收藏、稍后看与任务打勾保留页面动作。数据层整卡保存携带原卡片条件；备注与标签编辑保留原始字段，冲突拒绝写入并保留草稿。来源授权、RSS URL 订阅和文件导入入口已按 [ADR 0033](../adr/0033-ai-writes-composio-only.md) 删除。云端单卡使用卡片 expectedRevision；工作区批量使用原始 before 或工作区 expectedRevision，失败时整批回滚并保留草稿。工作区接口已发布；检查层次与宿主状态见[发布记录](../records/2026-10-16-cloud-operations/README.md)。旧来源配置、本地状态与刷新都不是外部执行成功的证据。

方向与授权边界见 [Agent 与 MCP](agent-mcp.md)，本地协议见 [本地操作](../guides/local-operations.md)，接口准备边界见 [交接说明](../guides/handoff.md)。既有云端 MCP 不等于已实现拟议的新接口或 Webhook。
