# 功能矩阵

更新：2026-10-16。只记录当前能力；设计不表示已批准实施。Web 本地和云端是不同运行路径，不以云端检查代替本地验收。

| 能力 | Web | Mac | iOS | 云端 |
| --- | --- | --- | --- | --- |
| 卡片展示与编辑 | 已实现 | 已实现（独立本地工作区） | 设计中 | 已实现（鉴权网页与卡片 API） |
| 本地 CLI 读写 | 已实现（共用本地 JSON） | 不支持（不共用 Mac 数据） | 不支持 | 不支持（使用内容 API/MCP） |
| 账号登录与云端卡片 | 已实现（云端网页） | 设计中 | 设计中 | 已实现 |
| 内容 MCP | 不支持（由服务端提供） | 不支持（由服务端提供） | 不支持（由服务端提供） | 已实现（既有云端路径） |
| 外部助手 Webhook → MCP 回写 | 设计中 | 设计中 | 设计中 | 设计中 |
| 内置助手、上游工具桥接 | 不支持（不属当前范围） | 不支持（不属当前范围） | 不支持（不属当前范围） | 不支持（不属当前范围） |
| 持久意图队列与可靠执行器 | 设计中 | 设计中 | 设计中 | 设计中 |

旧版本地原型的正常在线整卡并发覆盖、虚假连接成功两个 P1 尚未修复。云端使用 expectedRevision 和冲突草稿，并不表示旧路径问题已关闭。来源占位、本地状态与刷新都不是外部执行成功的证据。

方向与授权边界见 [Agent 与 MCP](agent-mcp.md)，本地协议见 [本地操作](../guides/local-operations.md)，接口准备边界见 [交接说明](../guides/handoff.md)。既有云端 MCP 不等于已实现拟议的新接口、Webhook 或上游桥接。
