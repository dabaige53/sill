# 功能矩阵

更新：2026-10-16。只记录当前能力；设计不表示已批准实施。Web 本地和云端是不同运行路径，不以云端检查代替本地验收。

| 能力 | Web | Mac | iOS | 云端 |
| --- | --- | --- | --- | --- |
| 卡片展示、速记与新增 | 已实现；已有内容通过 AI/MCP 修改，不提供复杂人工编辑入口 | 已实现（独立本地工作区） | 设计中 | 已实现（鉴权网页与卡片 API） |
| 本地 CLI 读写 | 已实现（共用本地 JSON） | 不支持（不共用 Mac 数据） | 不支持 | 不支持（使用内容 API/MCP） |
| 账号登录与云端卡片 | 已实现（云端网页） | 设计中 | 设计中 | 已实现 |
| 内容 MCP | 不支持（由服务端提供） | 不支持（由服务端提供） | 不支持（由服务端提供） | 已实现；工作区读取与原子批量工具已发布 |
| 结构化卡片字段 | 已实现（任务、时间、来源与展示字段） | 已实现（共享本地结构） | 设计中 | API 与网页已发布；平台刷新后已发现完整工作区工具 |
| 工作区状态、偏好与原子批量 | 已接入并发布云端数据操作 | 独立本地工作区，不自动同步 | 设计中 | 已发布 HTTP/MCP：完整状态、偏好、阅读秒数、条件批量写入 |
| AI 筛选、导出与批量整理 | 通过助手调用内容 MCP | 不自动连接云端 | 设计中 | 新增 getWorkspace / applyOperations；不包含外部执行器 |
| 外部助手 Webhook → MCP 回写 | 设计中 | 设计中 | 设计中 | 设计中 |
| 外部来源接入与同步 | 不做（ADR 0033）；来源面板与授权占位已删除 | 不做 | 不做 | 不做 |
| 文件、Markdown、OPML 导入 | 不做（ADR 0033）；文件导入入口与解析器已删除 | 不做 | 不做 | 不做 |
| 内置助手与 Composio 连接器 | 不支持（远期可选） | 不支持（远期可选） | 不支持（远期可选） | 不支持（远期可选） |
| 上游工具桥接 | 不做（ADR 0033） | 不做 | 不做 | 不做 |
| 持久意图队列与可靠执行器 | 设计中 | 设计中 | 设计中 | 设计中 |

用户保留既有新增、速记和轻操作；已有卡片标题、正文和结构字段由助手通过 MCP 修改。阅读、收藏、稍后看与任务打勾保留页面动作。数据层整卡保存携带原卡片条件；备注与标签编辑保留原始字段，冲突拒绝写入并保留草稿。来源授权、RSS URL 订阅和文件导入入口已按 [ADR 0033](../adr/0033-ai-writes-composio-only.md) 删除。云端单卡使用卡片 expectedRevision；工作区批量使用原始 before 或工作区 expectedRevision，失败时整批回滚并保留草稿。工作区接口已发布；检查层次与宿主状态见[发布记录](../records/2026-10-16-cloud-operations/README.md)。旧来源配置、本地状态与刷新都不是外部执行成功的证据。

方向与授权边界见 [Agent 与 MCP](agent-mcp.md)，本地协议见 [本地操作](../guides/local-operations.md)，接口准备边界见 [交接说明](../guides/handoff.md)。既有云端 MCP 不等于已实现拟议的新接口或 Webhook。
