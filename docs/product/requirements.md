## 1. 产品是什么

一个放在本机的个人卡片窗台。文章、邮件、笔记、待办、日程、提醒、播客、照片、文件都变成卡片，按「现在该看什么」排好。用户主要做两件事：往下翻，点开读。

内容由用户自己的 agent（Codex、Hermes、Claude）持续驱动。Sill 不接入外部来源，不由程序同步内容；已有卡片内容由助手修改，用户保留既有新增卡片、记一笔等轻入口。所有产品数据与状态操作都应能通过 Sill MCP 完成。界面不提供复杂内容编辑器，也不因 Agent 优先而删改其他原有产品设计与轻操作。分工见 [Agent 优先与界面边界](agent-mcp.md#agent-优先与界面边界)。

页面负责展示状态和表达意图；完成、阅读也是 agent 可处理的输入，不能把用户点击等同于外部执行成功。外部助手用自己宿主的工具执行，并通过 Sill MCP 回写真实结果；仅涉及本地阅读偏好的意图可以本地确认，无需制造外部写入。

当前只有本地命令读写与页面状态更新；目标中的意图队列、执行器与回执关联尚未实现。实现边界以 [Agent 与 MCP](agent-mcp.md) 为准。

**两种目标形态：** 内置AI助手的工作台；作为外部MCP服务器供第三方AI助手使用。共用能力层提供产品数据/任务操作和内置助手长任务委托；不桥接上游 tools。内置助手只通过 Composio 连接器操作其他程序。直接调用工具不强制经过内置LLM；安装不等于公开，按调用方与资源授权。详情见 [两种产品形态](agent-mcp.md#两种产品形态与共用能力层远期可选尚未实现)。

当前仍为本地卡片实现；不是以聊天为唯一入口的产品。内置助手与对外服务均待实现，本次不决定云端部署方案。

## 2. 视觉原则

1. 默认只有卡片。没有侧栏、顶部导航、欢迎横幅。
2. 安静、可读优先。玻璃只用在浮在内容上的东西：底部导航胶囊、预览、操作条。
3. 颜色只表达状态；已读的卡片变淡但仍可读。
4. 文字和图标只用一种，不重复表达。
5. 桌面和手机行为一致，只是触发方式不同。

具体颜色、字体、间距、动效以 [设计手册](../../design-system/README.md) 为准。

## 4. 卡片

类型：文章、邮件、笔记、待办、日程、提醒、媒体（播客、视频）、照片、文件、摘要、建议。收藏、稍后读、已读、标签、备注是跨类型的状态，不另做卡片。

每张卡片由同一套积木拼成：头部（来源、时间）、标题、摘要或要点、封面、正文、操作。文字长度上限：

| 部分 | 上限 |
| --- | --- |
| 标题 | 2 行，约 30 字 |
| 摘要 | 3 行；有封面时 2 行，约 60 字 |
| 要点 | 3 条，每条约 18 字 |
| 卡片内正文 | 6 行 |
| 引用 | 4 行，约 40 字 |

超出部分截断，点开看全文。

## 5. 信息流

- 按重要和时间排序：快到时间的提醒（15 分钟内）和日程（30 分钟内）自动上浮。
- 同一来源短时间内的多张卡叠成一摞，可左右切换，单击展开。
- 一次显示 40 张，滑到底继续加载。
- 刷新不强制回到顶部；新内容先提示，点了再插入。
- 读过的卡片可以按设置变淡、到期收起；同一提醒不反复出现。

## 6. 来源

- Sill 不接入外部来源，也不由程序同步内容。不做 RSS/OPML 订阅，不连接 Readwise、邮件、日历、GitHub 等来源，不做文件导入或 Markdown 导入。
- 卡片内容由助手写入：外部助手整理好内容后，通过 Sill MCP 写入和修改卡片。用户保留既有新增卡片与速记入口，界面不提供复杂内容编辑器。
- 卡片的来源字段只记录内容来自哪里（例如某个邮箱、某个日历或写入它的助手），用于显示和叠卡，不表示 Sill 已连接该来源。
- 用户不想看某类内容时，用卡片菜单的「少看这类」「不再提示」表达意图，由助手调整之后写入的内容。
- 连接器只用 Composio，只供远期的内置助手操作其他程序。其他外部工作交给外部助手，用它自己宿主的工具完成。

## 7. 阅读

- 单击卡片直接看全文；「全屏」进入完整阅读。
- 桌面从卡片原位展开；手机从底部升起，往下读铺满全屏。
- 关闭：关闭按钮、Esc、在顶部下拉；读到底继续上推完成阅读并关闭。
- 打开过不等于读完：读到底或短文停留 3 秒才算读过。
- 跳出到原网站要明确点「打开原文」。

## 8. 轻操作

- 卡片 •••：收藏、稍后读、标签、备注、标为已读、少看这类等。
- 多选后长按拖动，把卡片提起成带数量的小摞；松手打开操作菜单，再点按钮执行收藏、稍后读或标签。多选条提供同一个「操作」入口。拖动本身不执行动作，不向 AI 对话或其他页面传送。
- 待办可勾选完成，提醒可完成、延后、忽略。
- 本地反馈可以立即出现；涉及外部动作时显示待处理/执行中，收到可信回执后才显示已完成。
- 未派发意图可取消；已派发动作的取消不保证外部撤销。外部撤销若受支持，应成为新的补偿意图，不能承诺所有动作可逆。
- 重复点击不得重复创建外部对象；超时且结果未知时先核对，不盲目重试。目标状态协议见 [Agent 与 MCP](agent-mcp.md)。

## 9. 设置

五组：添加（记一笔，同一个输入框；键盘 `N` 仍直接打开）、桌面（排序、叠卡、已读变淡、自动收起、快到时间上浮、新内容提示）、外观（主题、密度、减少动态效果、减少透明度）、快捷键、数据与隐私（导出、清空、本地处理）。

## 10. 数据与边界

- 数据保存在本机文件，页面和 AI 共用，修改后自动同步；不需要账号。
- AI 通过本地命令读写卡片，批量操作全部成功才保存。
- 当前页面没有内置助手；底部导航的 AI 格只显示「即将推出」。卡片详情可将当前卡片引用交给支持消息的外部宿主，独立页面则复制给助手；这不代表 Sill 执行了任务。目标中内置/外部助手共用能力层。外部助手用自己宿主的工具处理外部动作，内置助手只通过 Composio 连接器处理；用户仍可直接阅读卡片、表达意图。
- Composio 连接器属于远期内置助手范围；真实凭据和首次授权在 Composio 中完成。Sill 不建立账号/OAuth体系；云端发布和跨设备同步仍不在本阶段。
- agent 定时或事件驱动运行取决于实际宿主能力；不能把浏览器关闭后的自动执行当作当前已有能力。

## 11. 可访问性

全部操作可用键盘完成；手机触控区域不小于 44px；支持减少动态效果、减少透明度、深色主题；纯图标控件都有可访问名称。
