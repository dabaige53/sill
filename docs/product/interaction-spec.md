# Sill 交互规范

更新：2026-10-16。

规则来源：[设计手册](../../design-system/README.md)「动效」「底部轨道与反馈」「搜索与键盘」「图标」各节，画板 16–19（弹出动效、手机交互、下滑与等待、退出交互）与 34（玻璃底栏与工具条，取代前几块画板里的入口球和挂在卡片外的工具条）。本文记录当前实现的行为与数值，改动时两边一起更新。

## 执行语义（目标，尚未落地）

完成、阅读、刷新等动作要成为 agent 可处理的意图；即时动画只反馈输入已被接收，不证明外部完成。Agent 经 MCP 执行并回写可信结果。本地阅读状态与外部状态分开；失败、重复提交、取消和结果未知遵循 [Agent 与 MCP](agent-mcp.md)。以下动效数值描述当前界面；当前按钮仍直接写本地状态，不得据此声称已有意图调度。

## 默认状态

先遵守 [Agent 优先与界面边界](agent-mcp.md#agent-优先与界面边界)：已有卡片内容的修改由 AI 完成，界面不提供复杂编辑器；既有新增卡片、记一笔入口及其他轻操作、布局和动效保留。下述原有交互不因取消内容编辑而被整体删除或重新设计。

页面只有卡片信息流和底部一条玻璃底栏：一个胶囊里放搜索与筛选、记一笔，最右侧是头像，点头像直接打开设置。没有入口球和展开菜单，没有侧栏、顶部导航、顶部头像和欢迎横幅。刷新用下拉或 `R` 键，回到顶部用 `T` 键。手机上胶囊在左、头像在右；桌面上整组在右下角。

信息流一次显示 40 张，滑到底再加载；全部显示完，底部是一条短线，不写「没有更多了」。

## 卡片

- 桌面悬停：卡片上浮 2px，右上角出现 •••。触屏和手机上 ••• 常驻，手机放在右下角，避开时间和数量。
- 按下：卡片缩到 0.97，松手回弹。叠卡不缩。
- 单击：直接打开预览，显示**全部正文**。没有「继续阅读」这一步。
- ••• 菜单：只有文字，展开和收起都有过渡。
- 长按 380ms 后提起选中卡片，拖动时最多三张真实卡片缩略图叠成一摞（第一张选中的在最上面，后两张错开 ±14px、倾斜约 ±6°），角标显示总数。松手后小摞留在原处，240 宽的菜单下方放得下就向下展开，否则向上。拖动不写入状态，也不触发标签、加载、刷新或跨页面传送，不能拖进 AI 对话或其他页面。用户另点「收藏」「稍后读」「标签」才执行现有批量操作。
- 多选条的「操作」按钮打开同一菜单。菜单打开时聚焦首项，Tab 和方向键切换按钮；取消、Esc、点背景、触摸取消或窗口失焦都保留选中并返回焦点。导航会关闭菜单。短按移动保持滚动；有选中项时下拉不刷新。
- 菜单沿用现有可执行动作，不新增分享、AI 对话或删除。原生 Mac 继续使用系统上下文菜单和已有删除确认。

## 叠卡（牌堆）

同一来源短时间内的多张卡叠成一摞：整张卡片叠在一起，顶部一张完整显示，下面露出卡片边缘，头部显示「当前/总数」。

- 左右切换：手指或鼠标横向拖、触控板横滑、方向键。拖的是**整张卡片**，不是卡片里的文字。
- 拖动时这摞卡浮到最上层，被拖的卡从相邻卡上方经过。
- 超过卡宽约三成或快速甩出：卡片飞出（1.15 倍卡宽，倾斜 8°），下一张补上来；不够就弹回。
- 单击：在原位展开成多张卡片；展开后可收起。
- 横向拖动后的那次松手不算单击。

## 预览

### 桌面

- 打开：预览以最终字号淡入并上移 10px，不复制或缩放卡片文字。入场 280ms，背景同时变暗。
- 关闭（关闭按钮、Esc、点背景）：预览在 140ms 内淡出并下移 4px，操作条提前淡出。动画完成才关闭弹层；快速打开另一张卡片时取消旧动画，保留新面板。
- 关闭、全屏是浮在内容右上的白色圆片（桌面 36px，手机 44px），不占一条白带；有封面时压在封面上。
- 底部工具条最多三个图标：收藏、备注与标签，第三个按类型放稍后读、不再提醒或下载日历。工具条在卡片内部底边上方，下面有滚动边缘；去原文、回复、加入、为什么看到放在内容末尾。读到底时内容、备注、标签和文字按钮都在工具条上方。
- 「全屏」进入完整阅读。详情和阅读页里没有头像、设置或底栏。

### 手机（宽度 ≤650px）

预览是从底部升起的面板：

1. 打开：从底部升到距顶部 64px。
2. 往下读（滚动超过 4px）：面板铺满全屏，圆角变直角。
3. 在顶部往下拉：先退回半屏；再往下拉超过 110px，面板滑出屏幕并关闭。
4. 工具条和顶部圆片按下面「工具条收起」一节的规则收起和回来。
5. 拖顶部把手：超过 190px 或快速下甩即关闭，否则弹回。

### 全屏阅读

- 「全屏」打开完整阅读，「退出全屏」回到预览。
- 手机上从左边缘右滑返回。
- 顶部继续下拉可以关闭，规则同预览。

## 读完与关闭

**下拉关闭**（预览和阅读都有，桌面用触控板，手机用手指）：在内容顶部继续下拉，面板跟着手指走，背景同步变淡；松手超过阈值就关闭，不够就弹回。关闭全程不闪：位置、透明度和背景在同一次过渡里完成，结束后才清理。

**读完上推**（ReadEndRing）：读到底时页面上什么都不显示。继续往上推：

- 页面最底部、原来工具条的位置（离底边 28px，含安全区）升起一个 40px 的小圆片，透明度随推动距离增加（推 30px 时完全可见），尺寸从 0.6 倍长到 1 倍（推 60px 时）。
- 圆环随推动填满，推满 120px 完成；触控板的推动量按滚动量的一半计算。
- 正文跟着上移推动距离的 0.35 倍，底部操作条收起。
- 完成：圆片变成强调色，出现白色对勾，弹一下（320ms），460ms 后关闭预览，回到信息流，卡片标为已读。
- 中途松手：圆片和正文回到原位。

正文很短、一屏能读完时，停留 3 秒算读过。

**下拉刷新**：在信息流顶部下拉，信息流跟手下移 0.9 倍（手指按着时没有过渡），玻璃圆环在让出的空隙正中，不压卡片；拉够 64px 松手刷新，圆环转动最长 1 秒，信息流随后回到原位。有选中卡片时不刷新。

## 工具条收起

工作台底栏、预览和阅读页的工具条、顶部圆片用同一条规则，手机和桌面一样：

- 向下连续滚动 28px 后完全收起，不留圆点、胶囊或三个点。
- 向上滚动 14px、停下 0.65 秒、回到离顶部 24px 内或读到离底部 24px 内时回来。小于这些距离的抖动不触发。
- 键盘焦点进入收起的工具条时立即回来；工具条有焦点时不收起。
- 收起：下移淡出 300ms，`--ease`；出现：380ms，`--ease-sheet`。减少动态效果时只淡入淡出。
- 弹层打开、拖动卡片或键盘弹出时，工作台底栏让开。

## 搜索与键盘

- 手机上搜索框在底部，跟着键盘升起；筛选胶囊在输入框上方，结果从下往上排。桌面搜索在顶部，⌘K / Ctrl K 打开。
- 不显示数量：输入框和结果分组都不写张数，数量只交给读屏软件。
- 输入法拼写中不筛选，`compositionend` 后再筛选；结果在 140ms 内更新，不显示加载态。
- 键盘弹出时（`visualViewport` 高度变小超过 120px），记一笔、备注与标签这类要打字的面板停在键盘上方，高度跟着可用空间变。

## 惯性和手势

- 触控板滚动停下后的惯性不算手势。惯性滚到顶部或底部时，不会意外触发下拉关闭或读完上推。
- 判断是否为新手势：距上一次滚动超过 140ms，或连续 4 次滚动量稳定或增大。
- 手势完成后的残余惯性一律吞掉（停顿 200ms 为止，最长 2.5 秒）。
- 内容区关闭浏览器的滚动回弹，避免和自己的手势打架。

## 动效基线

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 手机面板升起、铺满、退回、滑走 | 360ms | `--ease-sheet`：cubic-bezier(.32,.72,0,1) |
| 桌面预览淡入 / 淡出 | 280ms / 140ms | `--ease`，保持文字原始大小 |
| 预览正文、操作条淡入 | 280ms，延后约 200ms | 缓出 |
| 工具条收起 / 出现 | 300ms / 380ms | `--ease` / `--ease-sheet` |
| 读完对勾弹出 | 320ms | 回弹 |
| 卡片按压 | 120ms | 缩到 0.97 |

实现原则：手势只决定目标位置，由 CSS 过渡把元素带过去；手指按住时关掉过渡，让元素紧跟手指。背景暗度注册为可过渡的数值，跟着面板一起变。

系统开了「减少动态效果」或设置里打开同名开关时，所有过渡缩到几乎为零，状态照常切换。

## 提醒

快到时间的事项（提醒 15 分钟内、日程 30 分钟内）在信息流中自动上浮，不弹窗。提醒卡可以完成、延后、忽略，都能撤销。
