# Sill 交互规范

更新：2026-10-19。

规则来源：[设计手册](../../design-system/README.md)「动效」「底部导航与反馈」「搜索与键盘」「图标」各节，画板 16–19（弹出动效、手机交互、下滑与等待、退出交互）与 34（玻璃底栏与工具条，取代前几块画板里的入口球和挂在卡片外的工具条）、35（底部导航胶囊，取代 34 号里的底栏布局）。本文记录当前实现的行为与数值，改动时两边一起更新。

## 执行语义（目标，尚未落地）

完成、阅读、刷新等动作要成为 agent 可处理的意图；即时动画只反馈输入已被接收，不证明外部完成。Agent 经 MCP 执行并回写可信结果。本地阅读状态与外部状态分开；失败、重复提交、取消和结果未知遵循 [Agent 与 MCP](agent-mcp.md)。以下动效数值描述当前界面；当前按钮仍直接写本地状态，不得据此声称已有意图调度。

## 默认状态

先遵守 [Agent 优先与界面边界](agent-mcp.md#agent-优先与界面边界)：已有卡片内容的修改由 AI 完成，界面不提供复杂编辑器；既有新增卡片、记一笔入口及其他轻操作、布局和动效保留。下述原有交互不因取消内容编辑而被整体删除或重新设计。

页面只有卡片信息流和底部居中的一个导航胶囊：主页、搜索、AI、设置四格。主页回到工作台，已在工作台时滚回顶部；设置格显示 Sill 线稿品牌标志，点开设置；AI 格标「即将推出」，打开本地会话占位窗，展示所选卡片引用与可输入但不可发送的临时文字；明确说明尚未连接，不生成回复、不联网、不保存输入或改卡片状态。添加（记一笔）在设置第一组「添加」里，键盘 `N` 和首次打开页仍直接打开记一笔面板。没有入口球和展开菜单，没有侧栏、顶部导航、顶部头像和欢迎横幅。刷新用下拉或 `R` 键，回到顶部用 `T` 键。手机上胶囊不占满一行，按内容宽度居中，只有图标；搜索、AI、设置切换页面，不是弹窗：页面没有把手和遮罩；AI、设置保留胶囊，搜索隐藏胶囊并提供顶部关闭按钮，Esc 回主页。桌面上胶囊居中，图标加文字，AI、设置以面板打开，搜索使用独立页面。AI 用对话气泡图标。

当前一格上有一块透明玻璃镜片。换格时镜片用弹簧曲线 300ms 滑过去，途中横向拉长 5%、纵向压扁 3%。手机上镜片和页面同时换，从主页进入时整页 180ms 淡入，页面之间只淡入新内容、底色不透明；桌面上点开搜索、AI、设置时，镜片与面板同时响应，底栏 220ms 内淡出，面板关上后镜片滑回主页。减少动态效果时镜片直接到位。

信息流一次显示 40 张，滑到底再加载；全部显示完，底部是一条短线，不写「没有更多了」。

## 卡片

- 桌面悬停：卡片上浮 2px，右上角出现 •••。触屏和手机上 ••• 常驻，手机放在右下角，避开时间和数量。
- 按下：卡片缩到 0.97，松手回弹。叠卡不缩。
- 单击：直接打开预览，显示**全部正文**。没有「继续阅读」这一步。
- ••• 菜单：只有文字，展开和收起都有过渡。
- 长按 380ms 后进入选择模式，原卡显示选择边框，其他可见卡片只做一次轻微过渡。随后点选其他卡片；不显示角落选择圈或对号，不提起缩略图，松手不自动弹出菜单。按住前移动仍是正常滚动。
- 多选条直接保留收藏、稍后读、标签和取消图标，不增加省略号、全选或菜单按钮。工具条进入和退出过渡透明度及小幅位移，退出立即禁用点击与聚焦；减少动态效果只淡入淡出。显式右键或键盘菜单继续支持焦点循环与取消，只有明确选择动作才修改数据。
- 多选后底部出现 AI 接收条。拖到接收条内松手，或用键盘激活接收条，打开本地 AI 对话窗口。窗口只展示选中上下文，尚未接通模型，不发送数据或修改卡片；目标外松手与取消均不打开。标签、备注不是侧边拖放目标。
- 搜索与主页共用卡片、长按手势和多选工具条实现，各自保存选中集合和范围起点。搜索内操作只作用于搜索选中项；关闭搜索不改变主页选中项。

读完、完成提醒和勾选待办只更新状态，保留当前信息流成员、顺序、叠卡分组、任务预览与卡片占位；显式切换分栏、筛选或刷新后，再按最新状态计算列表。主页分栏保持可见，不参与手机工具条自动收起。

## 信息密度

卡面预览按密度选择理想列宽，新增列后每列须达到理想宽度，最多五列；紧凑摘要最多两行，其余密度最多三行。摘要卡直接展示写入的摘要与要点，不用全局周统计替换。待办预览优先未完成，最多三项；勾选时保留当前预览行和卡片占位，切换分栏或刷新后再按状态排序。完成后的卡片保留任务清单，不压缩为完成横条。桌面任务文字最多两行。详情保留全部任务、要点与正文，长文字允许换行。

## 叠卡（牌堆）

2026-10-19：键盘方向键立即切换，动画不吞输入。减少动态时保留手势判断，取消位移与旋转，仅70ms淡入。Mac左右拖动与Web方向一致，首尾不循环。桌面详情统一220ms最终字号轻移淡入、160ms淡出；导航与面板同时响应。

同一来源短时间内的多张卡叠成一摞：整张卡片叠在一起，顶部一张完整显示，下面露出卡片边缘，头部显示「当前/总数」。

- 左右切换：手指或鼠标横向拖、触控板横滑、方向键。拖的是**整张卡片**，不是卡片里的文字。
- 拖动时这摞卡浮到最上层，被拖的卡从相邻卡上方经过。
- 超过卡宽约三成或快速甩出：卡片飞出（1.15 倍卡宽，倾斜 8°），下一张补上来；不够就弹回。
- 单击：在原位展开成多张卡片；展开后可收起。
- 横向拖动后的那次松手不算单击。

## 预览

### 桌面

- 打开：桌面预览以最终字号淡入并上移 10px（220ms），工具条同时出现，背景同时变暗。不缩放正文，也不从源卡片放大。
- 关闭（关闭按钮、Esc、点背景）：预览在 160ms 内淡出并下移 4px，操作条提前淡出。动画完成才关闭弹层；快速打开另一张卡片时取消旧动画，保留新面板。
- 关闭、全屏是浮在内容右上的白色圆片（桌面 36px，手机 44px），不占一条白带；有封面时压在封面上。
- 底部工具条最多三个图标：收藏、备注与标签，第三个按类型放稍后读、不再提醒或下载日历。工具条在卡片内部底边上方，下面有滚动边缘；去原文、回复、加入放在内容末尾；Web 与 Mac 不再显示「为什么看到」入口或专属面板，原因和来源数据保留。读到底时内容、备注、标签和文字按钮都在工具条上方。
- 「全屏」进入完整阅读。详情和阅读页里没有头像、设置或底栏。

### 手机（宽度 ≤650px）

预览是从底部升起的面板：

1. 打开：从底部升到距顶部 64px。
2. 往下读（滚动超过 4px）：面板铺满全屏，圆角变直角。
3. 在顶部往下拉：半屏和全屏一样，拉过 110px 或快速下甩后松手，面板滑出屏幕并关闭；没拉够就弹回原尺寸。
4. 工具条和顶部圆片按下面「工具条收起」一节的规则收起和回来。
5. 拖顶部把手：上拖展开；下拖时整面平移，正文高度不变。松手时超过 160px 即沿当前位置关闭（全屏也一样），短下拉仍可收起，取消时恢复原状态。

### 全屏阅读

- 「全屏」打开完整阅读，「退出全屏」回到预览。
- 手机上从左边缘右滑返回。
- 顶部继续下拉可以关闭，规则同预览。

## 读完与关闭

**下拉关闭**（预览和阅读都有，桌面用触控板，手机用手指）：在内容顶部继续下拉，面板跟着手指走，背景同步变淡；松手超过阈值就关闭，不够就弹回。松手从当前绘制位置连续离场，不先回位；位置、透明度和背景在同一次过渡里完成，等待真实动画结束后才清理。触控板输入期间直接跟随，每帧最多绘制一次。

**读完上推**（ReadEndRing）：读到底时页面上什么都不显示。继续往上推：

- 页面最底部、原来工具条的位置（离底边 28px，含安全区）升起一个 40px 的小圆片，透明度随推动距离增加（推 30px 时完全可见），尺寸从 0.6 倍长到 1 倍（推 60px 时）。
- 圆环随推动填满，推满 120px 完成；触控板的推动量按滚动量的一半计算。
- 正文跟着上移推动距离的 0.35 倍，底部操作条收起。
- 完成：圆片变成强调色，出现白色对勾，弹一下（320ms），460ms 后关闭预览，回到信息流，卡片标为已读。
- 中途松手：圆片和正文回到原位。

正文很短、一屏能读完时，停留 3 秒算读过。

**下拉刷新**：在信息流顶部下拉，信息流跟手下移 0.75 倍（手指按着时没有过渡），手机刷新圆环临时替换主页标志，位于分栏上方，不遮挡分栏；完成或取消后恢复标志；拉够 48px 松手刷新，信息流停在让出的位置、圆环在空隙里转动，出现勾后回到原位；请求超过 1 秒时信息流先回位，圆环继续转。触控板拉满后停手或开始惯性才刷新。有选中卡片时不刷新。

## 工具条收起

导航胶囊、预览和阅读页的工具条、顶部圆片用同一条规则，手机和桌面一样：

- 向下连续滚动 28px 后完全收起，不留圆点、胶囊或三个点。
- 向上滚动 14px、停下 0.65 秒、回到离顶部 24px 内或读到离底部 24px 内时回来。小于这些距离的抖动不触发。
- Tab 按下时先唤回收起的工具条，再由浏览器选择焦点；工具条有焦点时不收起。
- 收起：下移淡出 180ms，`--ease`；出现：220ms，`--ease-sheet`。减少动态效果时只淡入淡出。
- 弹层打开、拖动卡片或键盘弹出时，导航胶囊让开。手机上的 AI、设置是页面，胶囊只在键盘弹出时让开；搜索页面始终隐藏胶囊，退出后恢复。

## 搜索与键盘

- 桌面主页分类吸顶，五个分类各自保存滚动位置；重复点当前分类不跳动。搜索和主页分别保存筛选、列表和滚动位置，搜索不改主页显示。两处复用同一卡片组件与卡片实体；阅读和完成状态共用。
- 从搜索打开卡片时，搜索结果留在抽屉下面。关闭详情返回原查询与滚动位置；退出搜索才回主页。浏览器前进与后退遵循同样顺序。

- 手机上搜索是一个页面：输入框在顶部安全区下方，筛选和结果依次向下排列；打开后隐藏底部导航胶囊。顶部关闭按钮或 Escape 退出后恢复胶囊。键盘弹出只缩小结果可滚动区域，不移动输入框。桌面搜索也使用独立页面，输入框在顶部，⌘K / Ctrl K 打开。
- 不显示数量：输入框和结果分组都不写张数，数量只交给读屏软件。
- 输入法拼写中不筛选，`compositionend` 后再筛选；结果在 140ms 内更新，不显示加载态。
- 键盘弹出时（`visualViewport` 高度变小超过 120px），记一笔、备注与标签这类要打字的面板停在键盘上方，高度跟着可用空间变。

## 惯性和手势

- 触控板滚动停下后的惯性不算手势。惯性滚到顶部或底部时，不会意外触发下拉关闭或读完上推。
- 判断是否为新手势：距上一次滚动超过 140ms，或连续 4 次滚动量稳定或增大。
- 手势完成后的残余惯性一律吞掉（停顿 200ms 为止，最长 2.5 秒）。
- 内容区关闭浏览器的滚动回弹，避免和自己的手势打架。

## 动效基线

Web 状态衔接遵循手册「Web 状态衔接」：普通面板有退场；速记、归档、筛选和排序保持卡片位置连续；待办与回写保留阅读位置；多选条和图片翻页支持连续操作。手机抽屉等待实际滑出结束再关闭，不用早于 CSS 过渡的固定计时。此处只约束 Web，macOS 的实现不在本次变更范围内。

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 手机面板升起、铺满、退回、滑走 | 360ms | `--ease-sheet`：cubic-bezier(.32,.72,0,1) |
| 桌面预览从卡片放大 / 缩回卡片 | 320ms / 230ms | `cubic-bezier(.2,.75,.25,1)`；卡片不可见时淡入 / 淡出 280ms / 140ms |
| 手机预览正文 | 与抽屉同时出现，不单独延迟 | 随抽屉 |
| 工具条收起 / 出现 | 300ms / 380ms | `--ease` / `--ease-sheet` |
| 导航镜片换格 | 520ms（桌面面板晚 160ms 打开；手机页面 180ms 淡入） | `--ease-spring` |
| 读完对勾弹出 | 320ms | 回弹 |
| 卡片按压 | 120ms | 缩到 0.97 |

实现原则：手势只决定目标位置，由 CSS 过渡把元素带过去；手指按住时关掉过渡，让元素紧跟手指。背景暗度注册为可过渡的数值，跟着面板一起变。

系统或应用内开启「减少动态效果」时，位移与拉伸直接到位，其余使用 `dur-reduced`（70ms）淡入淡出，状态照常切换；顶部圆片、跟手位移和延时回调同样遵守。触摸取消清理临时样式且不提交读完、刷新或关闭；过时面板与导航的回调不得影响新页面。

系统或应用内减少透明度，以及两种浏览器模糊属性均不可用时，导航、菜单和背景统一回退为实色；增强对比度增加可辨认边界。导航镜片仍标明当前页。仅有实际底部工具条的预览才显示底部渐隐；无工具条详情的末尾动作保持清楚。

卡片末尾的「与助手讨论」按当前宿主能力提供，最多一处，语义见 [Agent 交接](agent-mcp.md#当前卡片交给助手)。独立网页不显示交接入口，不提供复制引用降级；发送回执不表示卡片已修改。

## 提醒

快到时间的事项（提醒 15 分钟内、日程 30 分钟内）在信息流中自动上浮，不弹窗。提醒卡可以完成、延后、忽略，都能撤销。完成、已读、时间经过、延后或忽略都不从主页移走卡片。只有明确归档才移出主页；延后只改下次提醒时间，忽略只停止提醒，不等于归档。旧数据中的忽略状态不自动转换成归档，也不批量恢复已归档卡片。

## 验证

```sh
npm test
node tests/e2e/local-browser.ts
node tests/e2e/browser.ts
npm run test:material-density
npm run test:motion-material
```

浏览器回归覆盖：卡片打开与关闭、全屏、下拉关闭、读完上推、叠卡切换与展开、原位长按多选与显式菜单、导航胶囊与多选条同一行、手机布局与 44px 触控区、键盘操作和减少动态效果。工具条收起、输入法、搜索不显示数量和导航胶囊四格由 `tests/web/chrome.test.ts` 覆盖。

键盘打开搜索、记一笔和详情时立即显示并聚焦，关闭也立即响应。鼠标及触摸保留原空间过渡。短待办、提醒、笔记详情宽度为 560px；长文保持原宽度。可撤销提示累计可操作时间 5.5 秒，普通说明 3.2 秒；页面隐藏、窗口失活、指针停留或焦点进入时暂停，恢复后继续剩余时间。

窄桌面仍在容纳两列最小宽度时保留两列；三列及以上才要求每列达到理想阅读宽度，避免小窗口退成过宽单列。

主页分栏下滑时保持可见。读完、完成提醒和勾选待办只更新卡片状态，保留当前信息流的成员、顺序、分组和占位；切换分栏或主动刷新才应用最新筛选和排序。
