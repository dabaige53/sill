# 真实功能完成清单

更新：2026-10-23。范围以 [ADR 0065](../adr/0065-account-backups-and-device-reminders.md) 为准。下表描述当前工作树的实现，不表示已部署。

| 原检查事项 | 当前实现 | 验证边界 |
| --- | --- | --- |
| 外部备份 | 每位用户在设置中配置 WebDAV／坚果云或 Cloudflare R2；检查连接、更新凭据、手动备份、查看记录和下载快照 | 合成 HTTP、MCP、WebDAV、R2 和数据库检查；真实备份账号未连接 |
| 从备份恢复 | 预览卡片数量及增删范围，确认后原子替换账号工作区；检查版本和备份摘要；结果未知时查询回执或重试原请求 | 已覆盖冲突、账号隔离与幂等；恢复后刷新失败单独提示 |
| 真实图片与封面 | 数据约定、Web、Mac 和数据库接受 HTTPS 图片；保留内置图片兼容，加载失败回落到占位背景 | Schema、SQL 与 Swift 检查；真实图片窗口未验证 |
| 有效示例媒体与链接 | 视频使用 YouTube 官方示例，音频使用 MDN 公开示例；无具体地址的会议、邮件不再链接平台首页 | 示例通过共享卡片校验；真实网络播放未验证 |
| 文件与邮件附件 | 有地址才显示可打开入口；无地址只显示文件信息 | 展示和外链路由检查；不提供文件存储或上传 |
| MCP 内嵌播放 | 声明官方视频框架及当前工作区图片、音频域名；文档内单独限制脚本来源 | MCP 资源读取和权限检查；真实宿主播放未验证 |
| 统一外链与失败反馈 | Web 正文、文件、来源及 PR 链接在宿主中调用 openLink；独立网页使用链接；Mac 统一打开并反馈失败 | 路由与协议检查；真实浏览器、邮件客户端未验证 |
| 播放失败恢复 | Web 音频和 YouTube、Mac AVPlayer 和官方视频均可重试；关闭暂停并保存位置；实际播放结束才记为已读 | 媒体事件及源码构建检查；真实播放器未验证 |
| 到时系统通知 | 设置中按设备启用。网页打开时通知；Mac 已载入提醒关闭窗口后仍调度，点击通知回到卡片；状态改变或退出账号时清理 | 合成通知与调度检查；真实系统通知未验证 |
| 云端保存失败后的本地持久草稿 | 按用户决定取消新增；保留已有内存中的待提交修改、冲突检查和未知结果处理 | 不新增跨重启草稿存储 |

账号云端数据继续共用。本机独立测试工作区不与账号双向同步。Google Drive 已取消；Hermes、原生 AI 配置、AI 对话和绘画暂缓。

备份只包含工作区 JSON，包括卡片、个人状态、偏好、阅读秒数和播放位置；外部图片、音频、附件只保存地址。恢复使用本账号已登记的备份，不扫描网盘文件，不导入任意 JSON，不跨账号合并。设置和使用步骤见[外部备份与设备提醒](../guides/backup-and-reminders.md)。

上线仍需应用两项数据库迁移，配置服务端备份加密密钥并发布 Web／Worker／Mac 构建。真实账号、网盘、播放器、宿主与通知窗口没有在本轮验收；设计材料只在仓库更新，尚未发布到线上设计副本。
