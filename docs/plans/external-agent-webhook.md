# 外部助手 Webhook 方案

更新：2026-10-29。状态：设计准备，尚未实施投递器。产品方向见[路线图](roadmap.md)，已实现数据工具见[MCP 接口说明](../implementation/agent-mcp.md)。

## 目标

Sill 将已确认的事件通知指定外部助手；助手使用自己的工具执行，并经 Sill MCP 回写结果。通知接收与外部任务完成分别记录。

## 待确认输入

- 外部助手的产品、实例、版本与真实可用接口。
- 允许投递的事件、卡片资源与工具权限。
- 通知鉴权、去重、结果查询和失败处理能力。
- 联调账号、数据范围与验收环境。

## 方案要求

1. 通知只携带必要对象引用与事件标识；助手通过获准的 MCP 工具读取内容。
2. 通知凭据与 MCP 调用身份分开，目标地址由服务端受控配置管理。
3. 事件、目标版本、幂等键、投递状态和结果关联持久保存。收到通知的确认仅表示接收。
4. 重复投递和回写去重；未知结果先核对。供应商缺少可靠去重或查询能力时，保留待核对状态。
5. 结果回写校验资源、身份、事件关联和读取版本；冲突保留待处理，不覆盖已确认结果。
6. 助手回写不再次触发同一事件，避免循环。

## 验收

先完成模拟验证，再在明确授权范围联调一个真实助手。覆盖通知、读卡、执行和回写，以及重复、冲突、权限拒绝、超时和迟到结果。完成条件是结果可追溯、状态准确、失败可处理。

接口准备材料位于[共享约定](../../contracts/README.md)。早期供应商核验和候选讨论留在[原始依据](../records/2026-10-29-doc-layers/agent-plan-context.md)，实施时按真实实例重新确认。
