# 产品路线图

更新：2026-10-29。记录已确认方向与待定选择，不承诺未确认的日期。当前能力见[功能矩阵](../implementation/feature-matrix.md)。

| 方向 | 目标 | 状态与前提 |
| --- | --- | --- |

## 推进条件

新增功能先确定用户场景、边界和完成标准，再进入专项计划。实现、部署和用户验收分别跟踪；外部执行方案见[Webhook 专项](external-agent-webhook.md)。

现有阅读、卡片和平台问题按 GitHub Issues 管理。具体修复不在路线图重复维护任务状态。
