# 设计决策记录（ADR）

ADR-01 至 ADR-08 是 Quiet Glass 阶段的决策，保留原文；已被后续决策取代的会注明。ADR-09 起是 Sill 阶段的决策。

## ADR-01：取消侧栏与顶部信息区

原因：用户明确指出收藏、关注、稍后读等都能成为卡片标签与筛选状态，独立侧栏造成重复和注意力分散。结果：默认只显示卡片，筛选按需唤出。

## ADR-02：先做组件实验室，再拼页面

原因：要支持多种卡片来源和交互，不能把全部功能硬编码进单张页面。实施顺序为 token → atoms → card primitives → templates → overlays / motion → feed。

## ADR-03：Liquid Glass 用作交互材料

原因：此前的白色胶囊按钮、大片筛选区被认为像普通 Web UI，缺少 Apple 风格精细感。结果：玻璃材质出现在悬浮 icon、预览和操作层，实体卡片继续保持内容可读。

## ADR-04：按钮图标优先

> 已被 ADR-12 取代。

原因：刷新、筛选、收藏、AI 入口不需要永久文字。结果：操作态出现纯图标，必要时 tooltip，保留可访问名称和触控尺寸。

## ADR-05：拖拽即提问

> 已被 ADR-15 取代：页面不再内置 AI 对话，拖拽只用于收藏、稍后读和标签。

原因：相对于“打开卡片 → 找问 AI 按钮”，用户更希望直接将某张卡片拖至目标自动形成对话上下文。结果：动态出现目标、磁吸、生成引用、聚焦输入，不自动发送。

## ADR-06：状态与类型分离

原因：“收藏”和“稍后读”不应制造重复卡片模板。结果：内容种类与标签/阅读/收藏等状态分别建模。

## ADR-07：提醒自然融入而不是弹窗

原因：整个界面以低干扰阅读为核心。结果：时间敏感事项作为优先卡片注入信息流，具有频率控制与撤销/延后入口。

## ADR-08：原型不等于正式连接

当前演示使用模拟邮件、日程、阅读数据和 AI 回答。正式接入涉及 OAuth、数据权限、同步调度与安全验证，不能以 UI 演示完成推定后端已上线。

## ADR-09：改名 Sill，以设计画布为准

原因：Quiet Glass 的玻璃感压过了内容，用户要的是安静、可读的窗台，而不是一块玻璃。结果：品牌、颜色、卡片积木和全部页面重新定稿在 [Sill · 设计画布](https://claude.ai/artifact/487W43yaF9D3Kno8c3ej6b)，本地副本在 `design-system/boards/`。代码、命令和数据路径暂沿用 `quiet-glass`。

## ADR-10：点卡片直接看全文

原因：「点卡片 → 预览 → 再点继续阅读」多了一步，用户点开就是想看内容。结果：预览直接显示全部正文；需要更大的阅读空间时点「全屏」。原来的「继续阅读」按钮去掉。

## ADR-11：从卡片本身展开

原因：凭空弹出的面板很生硬，看不出和哪张卡片有关。结果：桌面上预览从被点的卡片原位放大，关闭时缩回原卡片。手机上改用从底部升起的面板（见 ADR-13），因为屏幕窄，原位放大反而看不清过程。

## ADR-12：文字和图标只用一种

原因：图标旁再写一遍同义文字是重复表达，让工具条变重。结果：每个控件要么只有图标（含义通用：关闭、更多、收藏、刷新），要么只有文字（动作具体：加入会议、授权、恢复、全屏）。纯图标控件保留可访问名称。规则写在设计手册「图标」一节。

## ADR-13：手机预览是底部面板

原因：参照手机交互原型，读者在手机上的习惯是「往下读就铺满，在顶部往下拉就退回」。结果：面板升到距顶 64px；往下读时铺满；在顶部下拉先退回半屏，再拉才关闭；滚动时底部操作条让开。

## ADR-14：手势只给目标，过渡负责移动

原因：早期用脚本逐帧驱动位置，触控板惯性一来就卡顿、闪烁，和原型的顺滑差距明显。结果：手势只设定元素该去的位置，由 CSS 过渡带过去；手指按住时暂停过渡紧跟手指；惯性不算手势，手势完成后的残余惯性吞掉。读完上推、下拉关闭、下拉刷新都按这个方式实现。

## ADR-15：页面不做 AI 对话

原因：内容的采集、整理和生成由用户自己的 AI（Codex、Hermes、Claude）通过本地命令完成，页面再做一套聊天是重复的。结果：页面只负责看和轻操作；拖拽卡片只出现收藏、稍后读、标签三个接收区。

## ADR-16：叠卡是一摞牌

原因：叠卡里只滑动文字，看起来像一张卡在换字，用户感觉不到「这里有好几张」。结果：叠卡由整张卡片叠成，左右拖动的是整张卡片，被拖的卡从相邻卡上方经过；单击才在原位展开。

## ADR-17：封面用矢量图

原因：原来的封面是小尺寸位图，放大后发虚，还带着截图残留。结果：内置封面改为 1600×900 的矢量图，任何尺寸都清晰，颜色跟随卡片色调。

## ADR-18：数据只在本机

原因：用户的阅读、笔记、提醒是私人数据，第一阶段不需要账号和云端。结果：数据保存在本机文件，页面和 AI 共用并自动同步；云端发布流程不属于当前产品入口。
