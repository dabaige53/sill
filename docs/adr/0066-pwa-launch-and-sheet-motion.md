# 手机 PWA 打开、抽屉开合与下拉刷新

日期：2026-10-23。状态：已采纳。

## 原因

用户要求优化手机 PWA 的性能、动画、界面，以及打开、关闭、下拉加载。核对代码后发现四个问题：

- 云端打开时，首次会话检查要等两次请求返回。返回前主页显示未登录欢迎页和「登录」按钮，已登录用户每次打开都会先看到登录入口，然后卡片从上方一起落下。
- 手机抽屉打开时一边上升一边从透明淡入，遮罩在第一帧就是全暗；按钮关闭时抽屉边滑边淡出，与下拉关闭（不透明滑出）不一致。
- 在主页顶部每次触摸开始，下拉刷新都会读取尺寸并写入圆环位置，普通点按也强制布局一次。
- 动效每次读取时长与曲线都对根节点调用 `getComputedStyle`，常在刚写入样式后触发一次样式重算。

## 决定

- 手机抽屉打开和关闭都只移动、不改透明度，使用 `ease-sheet` 与 `dur-sheet`。遮罩用同一时长淡入淡出；等待首帧时遮罩也保持透明。新的淡入淡出或拖动从当前绘制的遮罩透明度接续。
- 下拉刷新在确认是下拉后才读取尺寸。
- 样式表里的动效变量每页只读取一次；根节点行内覆盖仍即时生效。


## 影响

- 手册：[动效](../../design-system/handbook/motion.md) 的手机抽屉打开、详情下拉关闭，以及「其他组件」的加载与下拉刷新条目。
- 设计印记 `boot-skeleton`；没有新增或更换画板。
- Web：`cloud-entry.ts`、`cloud-workspace.ts`、`cloud-views.tsx`、`cloud.css`、`motion*.ts`、`gesture-pull.ts`、`app-surfaces.ts`。
- Mac 没有手机抽屉和 PWA 打开过程，记为不适用；见[界面对账表](../implementation/design/ui-alignment.md)。
