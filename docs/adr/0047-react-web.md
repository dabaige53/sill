# Web 使用 React、TypeScript 与 Vite

日期：2026-10-19。状态：已接受。

用户确认 Web 改用 React + TypeScript，macOS 保留 SwiftUI。Web 的页面外壳、卡片、搜索、设置、详情和云端速记使用 React 组件；沿用既有设计变量、CSS、文案与产品行为，不因框架迁移重做界面。Vite 与官方 React 插件负责开发服务、Fast Refresh 和生产构建。

本地网页、云端网页与 MCP 内嵌页复用组件。单文件 HTML 是宿主交付要求，由 Vite singlefile 插件处理，不作为开发方式。现有 HTTP、MCP、保存版本、幂等和结果未知处理继续复用；不增加 Next.js 服务端或第二套数据协议。

现有页面控制器保留动作编排、导航、焦点、手势和几何测量，React 管理内容节点；动画与 DOM 测量通过明确的渲染适配边界执行。搜索打开详情时保留整个搜索容器。卡片使用稳定的 key 更新，不通过 HTML 字符串或每次重新挂载来刷新。静态 HTML 导出仅供测试、设计画板及旧调用兼容，运行时直接导入 TSX 视图，不打包服务端渲染器。

组件 TSX 纳入类型与格式检查，Node 测试通过 tsx 加载。迁移须验证交互、窄屏、键盘焦点、搜索返回、并发保存、批量更新和结果未知；本地验证不代表云端发布或真实设备验收。第三方界面库按实际功能逐项接入，不在迁移时整套安装。
