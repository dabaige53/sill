# 动画复核后的加载与操作反馈

日期：2026-10-26。状态：已接受，视觉待用户复核。

用户在第一、第二批实现后反馈：网页刷新仍像刷新动画；拖入 AI 需要在底部切换输入框；批量操作不应关闭胶囊；边缘回弹慢且卡顿；设置开关过快。

决定：首次数据直接整体显示，不复用后续列表入场与下拉刷新动画。批量收藏、稍后读、标签保留选择。拖动时用底部原位置承接 AI 输入接收框，松手只加入上下文，不自动发请求。边缘位移直接跟手并可中断回位，避免每个滚轮事件重复重建动画。开关共享 toggleSpring 的 visualDuration 从 0.2s 调为 0.32s，bounce 保持 0.2，设置立即生效；这覆盖 ADR 0071 的旧时长。

影响：Web/PWA 加载、选择、拖动、开关与 Web 边缘反馈；设计手册和相关组件示例同步更新。Mac 本轮未实施，界面对账登记缺失；iOS 原生界面缺失。设计未发布到线上，构建与非浏览器测试不代表观感通过。
