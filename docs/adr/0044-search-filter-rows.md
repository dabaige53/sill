# 搜索按类型、状态、标签分行

2026-10-19，用户比较真实页面 A 保留一条横滑行与 B 分三行后，选择 B。搜索两端都按类型、状态、标签分行，保持既有文字胶囊、选中状态、动作与筛选范围；标签为空时不显示该行，不新增筛选能力。

每行左侧为 28px 宽的 12px muted 名称，名称与条件之间 8px；条件为独立横滑区域，间隔 8px、内边 2px。行间 8px，整体下边 4px；胶囊尺寸与选中色仍沿用既有规则。条件不加图标，不改通栏列表或通栏标签栏，不新增更多菜单。

每行条件用独立的具名 group，读屏可辨类型、状态和标签。原键盘顺序与按钮名称不变；横滑只影响当前行，不移动整个页面。查询、返回、主页隔离、详情下方保留搜索以及键盘缩小结果区的行为不变。用户可见名称全部来自统一文案文件。

方案与选择见[候选记录](../records/2026-10-19-search-filter-proposals/README.md)，实现与检查另记[搜索分行](../records/2026-10-19-search-filter-rows/README.md)。Mac 未改，线上设计不操作。

筛选重绘后保留每行横滑位置与键盘焦点，后面的条件不能因位置归零而不可见。
