# 卡片与详情按 12 类专用重建，来源改用单色品牌圆标

日期：2026-10-22。状态：已接受，尚未设计与实现。部分取代 [基础与组件](../../design-system/handbook/foundation.md#图标) 中「不用品牌标志；来源用通用图标加来源名表示」一条；不改变 [ADR 0038](0038-keep-original-icons.md) 对控件图标的决定。

## 原因

用户核对现有卡片和详情后指出：

- 详情只有 7 种版式，其中一种由资讯、笔记、汇总、建议和视频共用；放大规则只写在代码里，是一张不可放大类型的黑名单。
- 多个已写入的字段在详情里看不到，例如建议的 `why`、汇总的 `related`、待办的 `due` 与正文、提醒的正文、文件的摘要与正文、照片的 `caption`。
- 信息流卡片不显示作者和发布方，视频看不到频道。
- 来源只用通用线条图标表示：YouTube 与视频类型同一个图标，未列入来源类型的来源（例如 Slack）退回书本图标，用户无法分辨内容来自哪里。

## 决定

### 按 12 类专用设计

- 卡片与详情按 12 类各自设计：资讯、笔记、汇总、建议、邮件、日程、待办、提醒、文件、视频、播客、照片。视频与播客虽同属 `media`，各自设计。
- 不设通用或共用版式。不同类型可以使用相同的积木（例如来源行、要点、工具条），但每类的字段选择、顺序和布局单独确定。
- 卡片与详情同一类一起设计，同一字段在卡面和详情中的位置与称呼一致。
- 写入卡片的字段，详情中都有位置显示；按规则不显示的字段（例如收录、保存、更新时间）须明确列出。
- 能否放大改为按类型列出的允许清单，并以正文超出预览面板为条件；具体清单在设计稿中确定。

### 来源单色品牌圆标

- 卡片头部和详情来源行用单色品牌圆标表示来源，替换来源类型的通用线条图标。
- 圆标只用界面颜色（`ink`、`muted` 等），不用品牌原色；品牌色 `sky` 等的使用范围不变。
- 资讯、笔记、建议、邮件、视频、播客遇到未识别的来源，显示来源名首字的圆标，不再退回书本图标；其他类型按下文改用卡片类型图标。
- 多个来源时最多叠放 3 个圆标。
- 圆标只说明内容来自哪里，不表示已连接、已授权或已同步（[ADR 0033](0033-ai-writes-composio-only.md)）。
- 只限来源圆标使用品牌标志；控件、导航、卡片类型图标仍为现有线条图标。
- 上线前逐个核对各品牌标志的使用规范。

### 圆标与文字的分工

2026-10-22 用户确认：

- 资讯、视频、播客：圆标说明来源，旁边文字写发布方；没有发布方时写作者，再没有时写来源名。作者与发布方都有且不同时写「发布方 · 作者」。图标与文字因此表达两件事，符合手册「文字和图标只用一种」。
- 待办、日程、提醒、汇总、文件、照片：来源可识别为品牌（例如 Linear、Google 日历）时用来源圆标；用户速记或本地创建、来源无法识别为品牌时，继续用卡片类型图标。
- 邮件：发件人行之外，另加所在邮箱的来源圆标。

## 影响

先在 `design-system/boards` 制作 12 类卡片与详情的设计稿；设计稿发布时同步修改手册 foundation 图标一节、FeedCard 组件说明和 interaction 预览与叠放一节。之后修改 Web 与 macOS 的卡片模板、详情渲染和来源图标，并在 [界面对账表](../product/ui-alignment.md) 登记。若改为多个附件，须另行修改卡片约定。
