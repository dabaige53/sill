# 已读只靠卡片颜色

2026-10-16，用户已确认，已实施。取代 2026-10-13 无障碍验收中「已读需有可见非颜色标识」的结论。

卡片上不显示「✓ 已读」等文字或符号。已读卡片只通过颜色变化表示：底色 `card-read`、边框 `line-read`、无阴影、标题 `muted`。日程结束后使用同一套已读色，不显示「已经结束」。

原因：用户要求界面只用颜色表达这两种状态，并明确不以无障碍要求保留文字标记。代价：只看颜色无法区分已读与未读。读屏使用的卡片 `aria-label` 仍带「已读」，本次没有移除。

实现位置：`apps/web/cards/templates.ts`、`apps/web/styles/cards.css`、`apps/web/atoms/primitives.ts`。规则写在 [设计手册](../../design-system/README.md)「颜色」一节。
