# 手机顶行统一，搜索改用分类与 # 标签

日期：2026-10-20。状态：已接受。

用户比较手机端设计稿后确认四项决定。规则先发布到线上 Design System 和设计画布 44 号画板，再同步到[页面与交互](../../design-system/handbook/interaction.md#手机主页)。

1. 主页、AI、搜索共用一种顶行：高 60px，左侧页名 34、700 字重，右侧 36px 圆钮、44px 点击区。主页和搜索右侧为头像；AI 右侧为「历史」和「新对话」，不放头像，设置只从主页和搜索的头像进入。两项 AI 控件接入前保持禁用。
2. 主页分栏改为实心胶囊，与搜索结果的类型胶囊为同一组件：高 32、间距 8、左对齐，放不下时横滑。原分栏按五格平分宽度，文字间距为 38–51 不等，这次一并解决。当前项 `ink` 底；主页其余项 `card` 底加 `line-card` 细边，搜索页其余项 `surface` 底。
3. 搜索参照 Apple Music 的流程，但搜索栏始终在页面上方。搜索首页只有搜索栏和分类卡。点分类卡后，分类成为搜索栏里的 `ink` 底标签；确认输入文字后进入新的结果页，顶部为搜索栏和关闭钮。只有文字时显示类型胶囊，左右滑动结果区切换类型。
4. 取消「筛选」展开区。状态和标签改为在搜索栏输入 # 选择，选中后成为 `accent` 底的 # 标签。状态只沿用现有的未读、收藏、稍后读，不新增筛选能力；标签只列已有标签。

本决定取代 [ADR 0044](0044-search-filter-rows.md) 中「状态和标签放在筛选展开区并分行」的部分；搜索与主页分别保存条件、详情返回原位置、输入法组词不筛选、不显示结果数量等行为不变。

本次只改设计规则和画板，Web 与 macOS 实现尚未修改。Mac 是桌面窗口，不需要手机顶行；实现 Web 时须检查 Mac 搜索是否同样取消筛选展开区并使用 # 标签。
