# 下拉刷新的连续阻力与释放

日期：2026-10-27。状态：已接受，Web/PWA已实施，当前Web手感已获用户确认；PWA观感待确认。

用户指定研究 [ui-lab 下拉刷新](https://github.com/xevrion/ui-lab/blob/main/src/lab/components/pull-to-refresh.tsx)，并要求据此优化。原实现内部48阈值与内容0.75倍率分离，可见位移仅36px就绪；80px处切换阻力，wheel逐事件截断并在单次衰减时提交，造成过轻与提前触发。

决定：Web/PWA刷新使用独立的motion.pullRefresh参数。内容位移为 `y = d × 480 × 0.7 / (480 + 0.7 × d)`，圆环进度共用y，64px可见位移才就绪。鼠标4px启动门槛后重设起点；触摸保留真实touchend。回位使用visualDuration 0.35秒、bounce 0，并接续100ms窗口内的释放速度；重抓从当前绘制位置反算输入基准。仅借鉴参数与手感，圆环样式、原有标题区域锚点和加载布局保持。

释放后内容立即回位，圆环单独表示真实请求，不增加64px加载留白。按钮刷新不拉开内容。保持Sill可见、失败重试与取消不提交，不复制示例布局、加载占位、1200ms模拟请求、模糊入场或取消事件调用end的行为。

范围纠正：首次实施迁移了圆环位置并增加请求期间64px留白，超出用户的参数调整要求；用户反馈后已撤回这两项UI变化，保留连续阻力、可见阈值与回位接续。

反馈时长修正：用户随后反馈只看到下拉圆环，加载和完成勾切换过快。加载反馈至少显示300ms，完成勾显示400ms后再以fast 140ms淡出，避免勾选淡入与整个圆环淡出同时开始。数据请求立即开始、结果立即合入，时长只控制圆环呈现，不延后请求、内容回位或实际数据生效；新下拉可中断已结束请求的反馈。

wheel是额外适配，不声称与参考输入完全相同。首个主动边缘事件只建立起点，后续距离完整累计后走同一阻力，不逐事件截断。单次减速不提交；连续3次衰减且幅度降至本序列峰值的50%才估计进入惯性尾段，或停止输入80ms后释放。重新发力取消释放候选；反向、取消、普通滚动抵达顶部的惯性不刷新。估计参数需真实触控板复核，不作为原生松手证据。

本决定替代ADR 0073中下拉刷新的距离、回位、请求期间内容位置与wheel释放规则。正文边缘回弹、读完完成、抽屉关闭与其他动效保持原范围。Mac继续原生阶段处理，本轮新视觉参数未同步；原生iOS界面缺失。设计未发布到线上，代码检查不代替用户观感验收。
