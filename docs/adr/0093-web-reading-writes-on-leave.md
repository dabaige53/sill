# Web 阅读进度与阅读时长离开时写入

日期：2026-11-08。状态：用户已确认，源码已实现，未部署。取代 [ADR 0067](0067-detail-resize-media-and-progress-writes.md) 中「进度本身最多每 500ms 保存一次」的规定，该 ADR 其余决定不变。

## 原因

- 云端每次保存都会返回整个工作区（全部卡片与正文），服务端还为同一次请求保留 7 天的回执副本，供原幂等键重试时返回。保存次数直接决定下载量、数据库写入量和页面处理整份工作区的次数。
- Web 阅读长文时，进度在滚动中最多每 500ms 保存一次；读完一篇长文可能保存上百次。阅读页打开且有操作时，累计阅读时长每 5 秒保存一次，静止阅读也会持续保存。
- Mac 已把进度和阅读时长留在本机，只在关闭阅读页、窗口失焦或退出时写入（`ActivityRecorder`）。两端的写入结果相同，次数相差很大。
- 定位与测量见[诊断记录](../records/2026-11-07-web-markdown-reparse/diagnosis-reading-writes.md)。

## 决定

- 进度条与圆环仍随滚动逐帧更新。阅读中进度只在本机记录最远位置；打开另一张卡片、在预览与放大之间切换、关闭详情、切到后台或离开页面时保存一次。读完仍立即保存。
- 阅读时长同样只在本机累计，关闭详情、切到后台或离开页面时写入，单次最多一天，余下的留到下次写入。
- 退出或切换账号时丢弃未写入的进度与阅读时长，不计入下一个账号。
- 不改变读完规则、进度含义、保存接口或服务端回执。

## 影响

- 浏览器被强制结束（未触发切到后台或离开页面）时，本次未写入的进度与阅读时长会丢失；与 Mac 退出前的行为一致。
- 手册：[网页阅读](../../design-system/handbook/web-reading.md)阅读进度。
- Web：`app-panels.ts`、`app-capture.ts`、`app-lifecycle.ts`、`app-surfaces.ts`、`cloud-workspace.ts`。Mac 不变。
