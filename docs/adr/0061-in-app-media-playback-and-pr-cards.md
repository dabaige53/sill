# 视频与播客在 Sill 内播放，新增 PR 卡片类型

日期：2026-10-22。状态：已接受，尚未设计定稿与实现。取代 [界面对账表](../product/ui-alignment.md) D14「媒体与播客不提供内置播放，提示前往来源」、[动效](../../design-system/handbook/motion.md#其他组件)中播客无内置播放一条，以及 [功能矩阵](../product/feature-matrix.md)「不提供内置播放」；补充 [ADR 0060](0060-card-rebuild-by-type-and-source-marks.md)，卡片类型由 12 类变为 13 类。

## 原因

用户在重建卡片与详情时确认：视频和播客要在 Sill 内播放；GitHub PR 需要单独设计。现有 PR 只是来源为 GitHub 的资讯卡，没有分支、状态、检查和审阅人等字段，无法表达「等你审阅」。

## 决定

### 内置播放

- 视频在详情中嵌入来源平台的官方播放器（例如 YouTube 使用无 Cookie 域名的嵌入地址）。无法嵌入的平台保留「在来源打开」。
- 播客在详情中直接播放音频地址，播放控件由 Sill 绘制：播放与暂停、后退 15 秒、前进 30 秒、进度条、倍速。
- Sill 只在播放时从来源地址读取媒体，不下载、不缓存、不转码，也不由程序同步内容（[ADR 0033](0033-ai-writes-composio-only.md) 不变）。
- 视频与播客仍不提供 Sill 的全屏阅读；视频全屏使用播放器自身的全屏。
- 卡面不放播放按钮（手册「按钮到点才出现」不变）；封面上的播放标记只表示可以播放，点按仍是打开详情。

### 播放进度

- 新增独立的个人状态字段记录播放位置（秒），与阅读进度 `progress` 分开；下次打开从上次位置继续。
- 卡面用封面底部的细进度条表示已播放比例。

### PR 卡片

- 新增卡片类型 PR，表示一个 GitHub 拉取请求。字段为助手写入时的记录：仓库、编号、状态（草稿、打开、已合并、已关闭）、源分支与目标分支、作者、审阅人及各自结论、检查结果、改动行数与文件数、评论数、是否请求你审阅、改动文件列表。
- Sill 不连接 GitHub，界面标明记录时间，不把记录说成实时状态。
- 请求你审阅时卡面出现「审阅」按钮，打开 GitHub 上的该 PR；不在 Sill 内提交审阅。

## 待定

- 关闭详情后音频是否继续播放；如继续，播放条放进底部轨道并遵守「一格一样」。
- 播放到哪里算看完、听完并写入已读。
- PR 的字段名与校验规则，在修改卡片约定时确定。

## 影响

修改卡片约定（新增类型、媒体音频地址与章节时间、PR 字段）和个人状态（播放位置）；修改手册 motion、foundation、interaction 中媒体与卡片积木的规则，以及 FeedCard 组件说明；更新 [界面对账表](../product/ui-alignment.md) D14 与 [功能矩阵](../product/feature-matrix.md)。设计稿先在 `design-system/boards/CardTypeDetails.dc.html` 中给出，之后实现 Web 与 macOS。
