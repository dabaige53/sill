# Mac 卡片展开改为外框露出

日期：2026-10-21。状态：已接受。部分取代 [ADR 0057](0057-desktop-card-spatial-transition.md) 中 Mac 的内容缩放与收回弹簧。

## 原因

用户在真实窗口中反馈三个问题：

- 展开时文字先大后小。原卡片外观随外框放大，详情正文从缩小状态长大，两者交接时文字尺寸相差约 2.4 倍。
- 关闭时先停顿再跳动。弹簧尾段等待时间长于视觉结束时间；交回真实卡片时，阴影从详情阴影直接换成卡片阴影。
- 关闭、全屏圆片和底部胶囊单独移动，看起来不属于卡片。顶部圆片按中线对齐来源，窄卡展开时圆片落在卡片外。
- 收回时外框下部露出空白底色；收回结束时卡片跳一下。卡片位置从标题栏下方量起，浮层从窗口顶端画起，两者相差标题栏高度。
- 照片卡片有时打开后不可见，需要再点一次。

## 决定

- Mac 卡片展开时只移动并放大圆角外框。详情按最终尺寸布局一次，固定在外框左上角，由外框裁剪露出；正文、原卡片外观、圆片、胶囊和图标都不缩放。
- 关闭、全屏圆片和底部胶囊放进同一个外框，随外框一起被裁剪和露出，不再单独计算位移。原卡片外观与详情仍在几何进度 20%–75% 内交接。
- 外框阴影按几何进度从卡片阴影过渡到详情阴影，收回时反向过渡。
- Mac 收回改用与 Web 相同的定长曲线：`motion.cardReturn` 320ms、`cubic-bezier(0.4,0,0.2,1)`，曲线结束即交回真实卡片。删除不再使用的 `cardReturnBounce` 与 `cardToolsRevealProgress`。
- 卡片位置换算到浮层坐标后再作为起点和终点，展开与收回都落在真实卡片上。
- 详情正文在几何进度 20% 以上保持不透明，压在原卡片外观下面；外框接近卡片大小时才淡出，外框下部不露空白底色。卡片关闭后的已读颜色与高度变化按 `read` 渐变。
- 没有来源卡片可放大的图层（照片、不在视口内的卡片）先挂载，下一轮再显示，插入与淡入不在同一次更新；等待显示期间再打开关联卡片照常叠加。
- 关闭时工具先淡出，收回期间浮层不拦截点击。展开弹簧、键盘即时完成、来源不可见时淡出、手机与照片灯箱保持不变。Web 本次不改。

## 影响

修改 foundation 设计变量 `motionCardReturn`（0.25 改为 0.32）并删除两项变量；修改 Mac `CardFlightSurface`、`PreviewSheet`、`ReaderPage` 与 `Motion.cardReturn`；更新手册 motion。真实窗口中的手感仍需用户确认。
