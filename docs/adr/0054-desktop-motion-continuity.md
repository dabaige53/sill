# ADR 0054：桌面阅读与刷新动效衔接

状态：已接受

## 原因

Mac 阅读完成后直接关闭，手势仅移动正文，遮罩没有跟随距离；主页没有下拉刷新反馈。窗口缩放时，Web 也未调用已有的重排动画，不能将这一项描述为 Web 已完全实现。

## 决定

1. 完成反馈、正文弹簧回位、关闭按顺序执行；失败和失效回调不关闭页面。
2. 将阅读正文偏移与整个表面的关闭偏移分开；遮罩观察同一层的手势状态。
3. 主页下拉刷新使用真实读取结果；取消、等待、成功、失败和重试有独立状态，旧结果不覆盖新状态。
4. Web 尺寸变化启用已有重排与淡入；Mac 补充列数变化过渡与宽度变化淡入。保留布局规则及 6px 外边距。

## 影响

涉及 Mac Reader、Feed、Chrome 和 Web FeedLayout；新增刷新成功停留时长变量，与 Web 现有 480ms 一致。规范见设计手册动效章节。使用非浏览器测试验证状态与回调；实际手势观感仍需真实窗口验收。本地设计未发布线上。
