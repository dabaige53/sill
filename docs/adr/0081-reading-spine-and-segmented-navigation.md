# ADR 0081：右侧章节进度与底部胶囊切换

日期：2026-10-27。状态：已采纳。

用户指定 [Scroll spine](https://lab.xevrion.dev/lab/scroll-spine) 用于文章阅读，并要求目录位于右侧；[Segmented control](https://lab.xevrion.dev/lab/segmented-control) 用于 PWA 底部切换。按公开示例的分段进度和双边弹簧行为实现，沿用 Sill 的颜色、字体、图标与三项目的地。源码参考为对应页面提供的 registry 文件。

目录只映射原文标题，按实际章节长度分配剩余高度，短段与长标题保留完整点击空间。阅读线设在视口 30%，到达文章末尾填满全部段。点击仍立即定位正文，键盘即时定位指示块。手机不增加目录。进度仅表达本地阅读位置，不代表外部操作完成。

目录使用 motion.scrollSpine：前缘 0.24 秒、后缘 0.42 秒、无弹跳；导航使用 motion.segmentedControl：前缘 0.18 秒无弹跳、后缘 0.36 秒 bounce 0.15。双边保留速度，重复点击从当前状态转向；导航通过 clip-path 同步胶囊与选中态图标。不动画化正文宽高。首次显示、导航尺寸变化和键盘输入直接定位。按现有项目规则，不新增减少动态效果分支。

影响：foundation 设计变量、阅读与动效手册、资讯阅读画板、Web ReaderLayout、手机导航。Mac ReaderPage 尚未同步，在界面对账表登记缺失。此决定取代原目录在左侧及底部选中块即时切换的对应规则，其他阅读与导航行为保留。
