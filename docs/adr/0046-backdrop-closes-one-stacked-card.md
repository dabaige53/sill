# 点遮罩每次只关一张叠卡

2026-10-19，用户反馈「关闭一张却一起关闭两张；应一次只关一张」，并在对照 17 号画板「点遮罩，叠放的全部关闭」后确认：保持点遮罩每次只关最上面一张叠卡。

在预览里打开引用卡会叠放。✕、Esc、下拉、点遮罩、读完上推和浏览器返回，每次都只关最上面一张，露出下面那张；关到最后一张后回到信息流。全屏阅读右上角的关闭按钮仍直接回信息流。

本决定取代 17 号画板「点遮罩，叠放的全部关闭」。仓库内 17 号画板与[设计手册](../../design-system/README.md)「预览与叠放」已同步改写；线上 Design System 与设计画布未同步。
