# ADR 0085：资讯正文排版与目录

日期：2026-10-28。状态：已接受。

## 原因

用户希望替换资讯文章的正文布局和目录，并明确要求保留现有字体和字号。

## 决定

- Web 资讯预览与放大页接入 shadcn Typeset 的布局规则，调整段落、标题和列表的间距；字体、字号、文字颜色及阅读偏好沿用 Sill。其他卡片不使用这套文章排版。
- 桌面放大页将目录放在正文右侧，使用参考 shadcn 文档目录的简洁列表；当前章节以文字颜色和字重区分，不再播放圆点和文字揭示动效。
- 桌面放大页内容区居中并限制最大宽度，两侧增加随窗口宽度变化的留白；手机预览的边距不变。页面宽度参考 [GOV.UK 布局规则](https://design-system.service.gov.uk/styles/layout/)，结合右侧目录调整。
- 目录只列真实 Markdown 标题；立即跳转、滚动跟随、键盘操作及短章节的点击选择保留。手机预览不显示目录。
- 此决定替代 ADR 0081、ADR 0082 中与 Web 文章目录位置和选中动效冲突的部分；不改变底部导航动效。

## 范围与验证

涉及 Web 正文与目录、阅读手册和资讯放大页画板。现有字体和字号变量不变。Mac 的对应版式尚未同步，差异记在[界面对账表](../implementation/design/ui-alignment.md)；真实界面与视觉效果未验收，设计在线副本尚未更新。
