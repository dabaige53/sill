# ADR 0053：桌面导航对齐与稳定搜索宽度

状态：已接受

## 原因

Mac 品牌按窗口关闭按钮定位，与卡片左缘不齐。搜索框随聚焦和标签伸缩，导致导航位置变化。两端详情工具栏的透底程度和鼠标反馈也需要统一。

## 决定

- Mac 顶部窗口控制区高 36，产品导航高 64，导航距首排卡片 20；品牌与账户分别对齐卡片区左右边缘。Web 使用相同导航高度和内容间距，不额外加入窗口控制区。
- 桌面搜索宽度以 360 为基准，随窗口空间收缩；聚焦和标签不改变宽度。
- 两端详情工具栏使用 `glass-thick`，保留现有尺寸、动作和阴影。Mac 工具及品牌、账户、分栏按钮使用手形悬停指针，禁用状态保留箭头。
- 卡片内部布局、字号和列数不变。

## 影响

替代此前 Mac 品牌对齐窗口关闭按钮、搜索框随状态伸缩的规则。实现位于 Web 桌面样式与 Mac Shell、Reader、Design；更新 `topBarInset`、交互手册以及 MacChrome、WebChrome 和桌面主页画板。

设计仅在本地更新，未发布线上。浏览器与真实窗口视觉验收未执行。
