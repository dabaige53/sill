# 照片大图页补通用操作胶囊

2026-10-19，用户比较真实页面后选择 B：照片大图页在缩略图下补收藏、标签、稍后读三个通用图标，不新增专属操作或更多菜单。照片继续固定黑底；胶囊复用既有深色变量，不随整页浅色模式变成浅色工具条。遵守现有隐藏偏好，全部隐藏时不留空胶囊。

胶囊参与页面排版，不盖在照片、缩略图或助手交接上。照片仍能翻页、关闭；保存或取消标签后回到同一张照片。收藏、标签、稍后读只改 Sill 的个人状态，不改来源内容。长按、键盘名称、减少透明度和增强对比沿用通用规则。公开参考、候选与验证见[讨论记录](../records/2026-10-19-photo-shared-toolbar/README.md)。Mac 未改。
