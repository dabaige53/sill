# 卡片使用明确字段，不再使用混合补充信息

2026-10-20，用户确认实施，并明确不需要旧数据兼容。卡片约定升级为 3.0.0：删除卡片与文件的 `meta`，不解析、回退或迁移旧字符串。来源、作者、发布方、时间、预计阅读时长和用户备注分别保存。旧值不自动转为备注；本次不读取、转换或删除用户存量数据，也不部署。

卡片沿用公共字段和按类型校验的专属字段；个人状态继续独立保存。预计阅读时长使用秒数、提供或计算依据、全文或已有内容范围；计算值必须说明方法，只有完整正文才允许计算全文时长。正文或完整程度变化后，原计算值失效，调用方须同时提供新估算或移除原估算。原文发布时间、原文修改时间、外部保存时间与 Sill 系统时间分开；日期不补成虚构时刻。未知扩展字段仍原样保留，但废弃字段明确拒绝。

选择直接升级而非长期双写，避免助手继续写入没有确定含义的字符串。各端与 MCP 共用字段约定，读取时不再猜测文案。字段字典见 [跨端数据约定](../../contracts/README.md)。卡片不展示用户备注；预览和放大阅读页末尾显示带「备注」名称的同款边框区。此变更在当前 Codex 仓库内实施；云端设计与数据库发布尚未同步，交付与 PR 须明确说明。
