# ADR 0092：正文内联图片与原文链接

日期：2026-10-31。状态：已接受，待发布。

## 原因

Issue #83 要求文章保留原文图文顺序。ADR 0063 的图片仅显示说明文字规则不再适用；原始 HTML 禁用与正文统一 Markdown 解析的决定保持不变。

## 决定

- 使用现有 Markdown 解析器保留图片位置，不新增卡片字段，不迁移正文，不将正文图片复制到封面区域。
- Web/PWA 和 Mac 仅加载正文中的 HTTPS 图片，拒绝携带用户名或密码的图片地址。相对、HTTP、文件和其他协议不加载，保留说明文字。
- 保留查询参数、锚点、替代文字及重复图片。图片保持比例、适应正文宽度，并提供加载、失败和大图查看。已带链接的图片保留作者指定的链接目的地。
- Web 使用原生图片懒加载及原生模态对话框；Mac 使用正文懒布局、AsyncImage 和原生 sheet。查看大图不替换正文，不改卡片状态。
- 原文只取结构化 `url`。独立 Web/PWA 的原文入口使用原生链接，避免以 `window.open` 的空返回值判断是否打开；插件仍走已有宿主操作及反馈，Mac 走系统打开。
- 数据补录与 Readwise 后续导入不属于本次代码修复，不读取或改写真实卡片。

## 验证边界

合成回归、两端构建由 GitHub Actions 执行。浏览器、真实宿主、Safari/PWA 和 Mac 窗口的体验验收分别记录；代码实现不代表生产已更新。
