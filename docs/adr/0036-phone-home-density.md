# 手机主页参考 X 的密度，仍用卡片

2026-10-18，用户已确认，已实施。部分取代设计手册「产品立场」中「不放常驻导航栏、顶栏筛选」一条（只对手机主页），以及「卡片积木」中提醒卡卡面的「稍后」「完成」按钮。卡片的已读规则（[ADR 0030](0030-read-state-color-only.md)）和底部导航胶囊（[ADR 0035](0035-bottom-navigation-capsule.md)）不变。新规则见设计画布 36 号画板和设计手册「手机主页」一节。

## 决定

- 手机主页仍然是卡片。页边距 8，卡片间距 6，圆角 16，内边距 14；摘要最多 2 行。
- 文章封面改为右侧 76 见方的缩略图；视频和照片保留 2:1 大图。带人像的头部合成一行。附件占满整行，手机卡片不再为更多按钮留空白。
- 日程卡：开始时间放在左侧一列，标题和「至 结束时间 · 共 N 分钟」在右侧；「加入」和参与者同一行，靠右。
- 提醒卡：头部写「提醒 · 来源名」和来源里的提醒时间。卡面去掉「稍后 10 分钟」「完成」按钮，圆圈就是「完成」，用 `accent` 描边。详情里保留「在 Sill 内再提醒」和「完成」。
- 待办卡：每项高 28，不写「另有 N 项」。待办和提醒的勾选只改 Sill 里的状态，不改来源。
- 手机主页顶部：Sill 标志（点它回到顶部）和分栏标签「全部 / 未读 / 待办 / 稍后读 / 收藏」。标签只筛主页。往下滑时顶栏和底部胶囊一起收起。
- 新内容提示移到顶部，写「↑ N 项新内容」，前面最多三个来源类型图标，白色玻璃底。
- `sill`、`mail`、`video`、`folder` 四个图标改得更方正。

## 原因

用户参考 Mobbin 上 X 的 iOS 界面，要求手机首页信息更密，同时保留卡片。效果图比较后，用户选择缩略图版、收紧的间距、顶部分栏标签和居中胶囊。

提醒和待办都由外部来源接入，提醒时间由来源决定。卡面上的「稍后」只改 Sill 自己的状态，却像是在改来源，所以从卡面去掉；Sill 内的完成状态以后由 agent 同步到来源。

## 代价

- 手机待办预览每项高 28，低于 Sill 自定的 `hit-target` 44，只满足 WCAG 2.2 的 24 最小值。
- 桌面仍然没有顶栏和分栏标签；Mac 原生应用没有同步这次的手机改动。
- 「在 Sill 内再提醒」只延后 Sill 内的提醒，不改来源时间；来源同步还没有实现。
- 主页标签和搜索页的筛选是两套状态。
