# 桌面卡片空间过渡与浮层可读性

日期：2026-10-21。状态：已接受。

## 原因

卡片详情只有淡入和位移，不能表达它来自哪张卡。桌面浮动工具过于通透时，背景文字会干扰品牌、输入和操作图标。

## 决定

- 桌面点击卡片时从来源位置和尺寸展开，关闭时返回来源。Web 使用 FLIP 几何测量和 transform，macOS 使用共享 Namespace 的 matchedGeometryEffect。
- 弹簧取用户示例的 mass 1、stiffness 190、damping 25，集中在 foundation 的 cardSpring 与 Apple 指标中。手势回位继续使用原有弹簧参数。
- 来源保留布局位置；取消动画不执行过期关闭回调。来源缺失时使用既有淡出。键盘即时切换、手机抽屉和照片灯箱保持原行为。
- 顶栏增加背景模糊；Mac 顶栏使用原生 regularMaterial，AI 栏与多选栏保留原生 Liquid Glass 并加底色。多选栏按内容收窄，禁用发送图标保持可辨认。

## 影响

修改共享动效变量、Web motion 与详情控制器、Mac Reader 与卡片表面，以及两端桌面浮动工具。规则见设计手册的 motion 与 web-interaction；设计仅在仓库维护，尚未发布线上。

验证采用构建、类型检查及非浏览器回归；真实窗口中的动效手感与玻璃表现不由静态检查确认。
