# ADR 0084：Mac 布局回退、搜索与阅读切换

日期：2026-10-28。状态：已接受。

## 原因

用户反馈叠卡展开后收起没有恢复原布局、AI 引用关闭难点、搜索点击缺少反馈且标签不能删除、详情放大入口缺失、资讯放大缩小闪屏，以及照片关闭位置过高。用户要求 Mac 左右留白增加 50%，AI 缩小使用减号。

## 决定

- 叠卡展开和收起保留同一个列表身份，但使用不同的高度缓存键。卡片完成状态仍保留高度，收起叠卡不保留展开高度。
- AI 引用关闭区为 30×30，图标保持 12。引用行右侧为缩小按钮预留 44 加 8 的空间，两者点击区不重叠。AI 缩小统一使用已有 `ai-minimize` 减号图标，折叠参数保持。
- 搜索的空白背景负责聚焦，分类和条件按钮负责移除。标签显示固定位置的 X；按压只改变透明度，选中类型不改变字重。搜索框宽度保持 315，焦点反馈与正文布局分开。鼠标聚焦允许候选开合动画；键盘保留即时响应。
- 有正文的资讯、笔记、摘要和邮件保留放大入口，不再用是否超过预览高度决定入口；视频保持放大，播客保持只读介绍。
- 预览和全屏使用同一正文和原生滚动容器。切换从当前外框接续卡片弹簧，正文保持可见，不再先归零透明度后延迟出现。资讯右侧正文与目录的滚动条隐藏，滚动和顶部阅读进度保留。
- Mac 主页水平边距 12→18，照片页 20→30，放大阅读页 30→45；预览内部排版、卡片间距与 Web 的边距不在这次调整范围。照片标题与 X 顶部留白 16→40，避开窗口控制区。

## 范围与验证

本次修改 `apps/apple/macOS/`、相关后台回归、Apple 设计变量和 Mac 画板。Web 产品代码不变。具体功能与动效分开记录于[修复记录](../records/2026-10-28-macos-feedback-fixes/README.md)。后台测试和构建不代表窗口观感通过；未启动应用、未执行界面自动化，设计未发布到线上。
