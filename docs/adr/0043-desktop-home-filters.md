# 桌面主页显示左上紧凑分栏


桌面分栏参与正常排版，随页面滚动，不悬浮。顶部 24px，标签高 44px，间隔 24px，字号 14px，当前项用 ink、700 字重和 28×3px 下划线；下方到卡片 16px。既有信息流最大宽度 1640px 提取为共用内部变量，使更宽窗口仍对齐。手机的标志、分栏、密度和收起行为保持原样。

分栏只筛主页，不修改搜索条件、卡片内容或来源。键盘可操作，减少动态效果与主题仍沿用既有规则。方案、前后对照与验证见[记录](../records/2026-10-19-desktop-home-filters/README.md)。Mac 未改。

## 后续细化：2026-10-19

用户在 Web 大屏审查后确认全部优化。保留左上紧凑分类方案，分类改为吸顶；按钮左右内边距 12px、组间距 8px，按实际卡片列左边对齐。五类分别保留滚动位置；增加列数前保证理想阅读宽度。此段替代原先随页面滚动与间隔 24px 的规则，其余视觉方向不变。现行数值见设计手册，42 号画板保留旧截图并新增当前实现截图。

窄桌面仍在容纳两列最小宽度时保留两列；三列及以上才要求每列达到理想阅读宽度，避免小窗口退成过宽单列。
