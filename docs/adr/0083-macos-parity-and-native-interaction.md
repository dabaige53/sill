# ADR 0083：Mac 全量对齐与原生交互边界

日期：2026-10-28。状态：已接受。

## 决定

按用户要求，以当前 Web 的内容、动作和状态为基准补齐 Mac；Mac 窗口、键盘、焦点、原生滚动、通知及对应动效允许优化。本次以 62 项功能/内容/位置清单和 41 项动效清单为范围，保留原审计记录，实施结果另记。源码修复、后台测试、构建、窗口验收分别记录。

- 分类位置、分页、查询回顶、批量状态、提醒动作、任务顺序、阅读进度、内容字段与空值规则对齐。卡片状态改变保留既有最小高度；列宽改变后重新测量。
- 搜索、标签、登录、设置、AI 引用和折叠接入当前 Web 的布局与反馈。参数集中维护于 `design-system/tokens/apple.json`，由生成器导出，不在组件保留另一套时长。补齐搜索、菜单退出、标签、开关、目录、登录、刷新和 AI 交接参数。
- 文章目录使用左侧 Sidebar highlight、32px 紧凑行、15px 普通字重、16px List 图标与最多两级缩进。此前右侧 Scroll spine 规则已由 ADR 0082 的后续决定取代。
- AI 收成输入栏右侧原行的 60×60 气泡，引用始终在输入栏上方；窗口变化按可用水平范围保留相对位置。发送和语音仍未接入服务，不显示完成结果。
- Mac 保留叠卡纯水平平移；卡片展开保留固定字号、移动外框与裁切揭示，按几何进度交接卡面和正文。不能为复制 Web transform 而缩放文字。
- Mac 读完上推统一每事件最多40px再乘0.5、累计120px、离散输入静默320ms。达到条件后，等真实保存成功和原生手势结束再关闭；失败停留可重试。此关闭时机有意区别于 Web 的 wheel 达标后离场。
- 照片触控板滚动和惯性由原生 ScrollView 负责，鼠标拖动从起始页确定目标；键盘即时定位。开关使用 SwiftUI 弹簧、原生焦点和输入，记录引擎差异，不以相同参数声称逐帧一致。密码显隐保留原生安全输入控件切换，恢复焦点并保留输入值。
- 系统通知、原生文件选择器和窗口行为继续保留。来源骨架只在真实来源获取接入时使用，当前不制造加载阶段。

## 影响范围

`apps/apple/macOS/` 的信息流、阅读、搜索、设置与底栏，`SillKit/CloudWorkspace.swift` 的账号展示字段，以及 Apple 设计变量。Web 产品代码只补共享 EyeOff 图标；核心测试中一个等待合成计时器的旧用例改为显式推进时间。产品契约、云端服务和外部执行能力不扩展。

设计手册、AI 栏规则、界面对账表同步；生成图标、组件示例和已有画板通过构建刷新。实施证据见[全量补齐记录](../records/2026-10-28-macos-parity-implementation/README.md)。真实窗口、真实登录/媒体/备份与帧时间尚未验收，设计未发布到线上。
