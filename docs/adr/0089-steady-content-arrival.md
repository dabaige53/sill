# 卡片与搜索结果平稳出现

2026-10-29，已采纳。替代 [ADR 0080](0080-animation-reference-completion.md) 中「首批卡片同时直接显示、取消二次图片淡入、慢请求静态占位」一条，并调整 [ADR 0066](0066-pwa-launch-and-sheet-motion.md) 中占位静止的安排；其余决定不变，历史正文保留。

## 原因

用户反馈卡片加载、搜索内卡片加载没有加载动画，内容一闪一闪地出现。来源有三处：首屏封面从透明直接变为显示，外部封面没有主色，只能先显示灰块，再逐张跳出；占位静止，真实卡片到达时直接替换；搜索每次输入后整个结果列表直接重绘。用户确认方向是让内容平稳地出现，而不是增加转圈；手机试看后认为 140ms 太快、仍像闪烁，改用工具恢复的 420ms 与较缓曲线。再次试看后，用户要求搜索结果跟随搜索栏上移的动画一起显示，卡片本身带显示动画，封面不单独闪现。

## 决策

- 屏幕内新加载的封面以 `dur-reveal` 420ms、`ease-reveal` 淡入，包括首屏；缓存图片，以及在屏幕外或卡片抽屉下方加载的封面即时显示，已读透明度保持原值。手机首次打开卡片时页面缩小，下方懒加载封面曾在抽屉后淡入，看起来像底部卡片闪一下。所在卡片或卡片区仍在显示过渡中时，封面随卡片一起出现，不再单独淡入一次。
- 首次数据读取超过 `delay-loading` 时，卡片区以 `dur-reveal` 420ms、`ease-reveal` 淡入占位，占位以 1.6 秒周期在不透明度 1 与 0.55 之间缓慢呼吸；真实卡片排版后，整个卡片区以同样方式一次淡入，不逐张错峰。读取短于 `delay-loading` 时不显示占位，真实卡片同样一次淡入。
- 搜索输入更新结果时，仍在结果中的卡片保留位置与外观，只有新出现的卡片以同样方式淡入；手机从分类浏览进入结果时（点分类或开始输入），结果区随搜索栏上移，区内可见卡片以 40ms 错开逐张淡入上移（`motion.phoneSearch.resultStagger`、`resultCardFade`），不再整块闪现。滚动加载更多不播放入场。

## 影响

影响 Web/PWA 的 `app-feed.ts`、`app-input.ts`、`motion.ts` 与动效手册。macOS 的首屏与搜索节奏未对齐本决定，按跨端规则另行登记。外部封面的真实主色需要在保存卡片时记录，不在本决定范围内。
