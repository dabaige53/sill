## 决策

- Web 搜索对照 [Combobox 源码](https://github.com/xevrion/ui-lab/blob/main/src/lab/components/combobox.tsx)：列表从顶部以 150ms／100ms、0.97 缩放开合，单一高亮以 180ms 移动；选择项图标从候选进入前置位置，280ms，曲线 0.32／0.72／0／1；前置图标切换 300ms 无回弹。历史、标签、状态均使用同一交接。输入过滤候选，重新打开定位到已选项，保留键盘与输入法行为。只替换示例的人名数据，不改 Sill 搜索、筛选和标签业务。
- Web 顶部栏独立恢复改为 `dur-top-reveal` 560ms，保留现有曲线；停顿等待仍 450ms，收起仍 240ms，底部与详情仍 420ms。关闭卡片带回工具沿用原弹簧。560ms 是本次针对用户反馈的试调，未获手感确认。
- PWA 搜索按用户附件 `apple_music_search_transition.html` 分别使用标题／结果的支撑曲线，以及分类／底栏的 CSS ease；保留 410ms 搜索栏移动和真实系统键盘，不人为延迟实际查询。
- 网页刷新时顶部保持原位；首批数据排版完成后卡片同时显示，取消首屏错峰和二次图片淡入。慢请求的静态占位保留，下拉刷新仍为独立流程，不改其已确认手感。
- 照片采用 [Snap carousel 源码](https://github.com/xevrion/ui-lab/blob/main/src/lab/components/snap-carousel.tsx)的原生滚动吸附与鼠标近期速度采样。保留整张照片、明暗主题、首尾不循环和既有箭头／缩略图；触摸、触控板由浏览器处理滚动，不复制演示卡片缩放和装饰。
- AI、任务／收藏、文章／视频全屏按现有用户要求复查中断及完成交接，保留已确认操作。播客继续待定，iOS 不在此次实施范围。
