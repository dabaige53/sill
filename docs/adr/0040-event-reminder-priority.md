# 显示加入时优先保留忽略提醒

2026-10-19，用户比较真实页面后选择 B：会议快开始且已显示「加入」时，专属操作按「加入、在 Sill 内再提醒、忽略此提醒、下载日程」排序。先排除不可用和被用户隐藏的操作，再取前三个；隐藏忽略或再提醒后，下载仍可补位。没有显示「加入」时维持原顺序，不改变加入的时间条件。

继续采用 [ADR 0037](0037-card-detail-toolbar.md) 的通用与专属两组、只用图标、专属最多三个。复用现有图标与名称，不新增菜单或正文按钮。「忽略此提醒」只停止 Sill 的提醒，不改变来源、日程时间或会议。方案和验证见[讨论记录](../records/2026-10-19-event-action-priority/README.md)。Mac 未改。
