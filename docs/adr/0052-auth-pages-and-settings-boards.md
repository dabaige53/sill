# 登录授权页面与设置画板

2026-10-21，已采纳。

## 决定

- 登录与授权采用现行桌面、手机画板的白底居中布局，输入标签和权限条目左对齐。保留密码登录、邮件登录、密码恢复及真实授权流程。
- 邮件登录与密码恢复共用现有邮件验证接口，以 `setupPassword` 区分意图。不新增认证接口、不改变权限校验。
- 当前账号直接显示，权限使用真实请求，允许与取消沿用原有表单和防重放保护。
- 桌面与手机设置画板从产品组件生成，分组切换仅供展示，不执行产品数据操作。
- 设计印记检查覆盖 `apps/` 和 `server/`，独立认证页面也能反查规范。

## 边界

卡片内部布局、字号、列数与设计材料不在此次修改范围。资讯阅读已采用 B 均衡方案，正文仍为纯文本段落，不新增富文本格式。其他详情页保持原有实现。

## 位置

规范见[网页交互](../../design-system/handbook/web-interaction.md#登录与授权)。认证实现位于 `server/cloud/`，设置画板由 `design-system/scripts/previews.ts` 生成。
