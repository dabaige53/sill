# 手机内容文字起点

日期：2026-10-24。状态：已采纳。

## 原因

用户反馈手机主屏幕应用的默认文字偏小，桌面 Web 合适。手机与桌面原先使用同一组字号：卡片标题 16、摘要 14、头部 12，预览正文 15。iOS 默认的标题、副标题、脚注和正文分别约为 17、15、13、17，手机字号比 iOS 小一档。同一篇文章在手机预览里是 15，放大后是 17。

外观设置（卡片文字大小、阅读文字大小）存在账号里，三端共用。在手机上选「大」会同时放大桌面 Web 和 Mac，不能用来单独放大手机。

## 决定

- 新增设计变量 `text-phone-scale` 1.07。手机宽度下，卡片与详情内容的字号乘以它，和卡片、阅读文字大小设置相乘：手机「小」约 1.0、「标准」约 1.07、「大」约 1.2。
- 手机预览正文使用阅读页正文 `reader-body` 17，放大前后字号一致。阅读页正文不再乘手机倍数。
- 导航、标签页、工具条和按钮不变，保留 320 宽下已调好的工具胶囊。
- 桌面 Web 与 Mac 的字号不变。设置仍是一份，存在账号里，不改数据结构。
- 暂不按设备类型分别保存设置，也不跟随 iOS 系统字号。确有需要时另行决定。

## 影响

- 设计变量 `text-phone-scale`；手册[基础](../../design-system/handbook/foundation.md#字体)「手机起点」与预览正文；设计印记 `phone-text-scale`。
- Web：`tokens.css`、`appearance.css`。摘要仍按行数截断，每张卡显示的字数略少，信息流略长。
- Mac 不使用手机宽度，不适用；原生 iOS 没有阅读界面。见[界面对账表](../product/ui-alignment.md)。
