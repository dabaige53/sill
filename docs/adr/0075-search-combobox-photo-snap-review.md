# 第三批复核：搜索候选、工具栏等待与照片吸附

日期：2026-10-27。状态：已接受，实际效果待用户复核。

## 决定

Web 搜索使用用户指定的 [Combobox](https://lab.xevrion.dev/lab/combobox) 与[公开注册源码](https://lab.xevrion.dev/r/combobox.json)作为交互参考。保留固定 480px 框体、Sill 的会话历史、已有标签与筛选模型，不迁入人名或头像业务。已有查询再次聚焦时仍显示历史和标签，不清空查询。

列表直接开关，候选行高 48px，共用一个高亮背景。方向键与 Home/End 定位候选，第一次 Esc 只收起候选。Tab 只接受已用方向键或指针明确指向的候选，未作选择时离开不自动接受第一项。条件图标从候选位置移入框内图标位，280ms、cubic-bezier(0.32,0.72,0,1)；前置图标切换为 300ms、bounce 0。键盘选择即时，框体、文字和光标不拉伸。这些飞入与图标参数来自公开源码，不宣称完整视觉还原已通过。

工具栏停顿恢复等待按用户要求从 650ms 改为 450ms，使用 `rest-show`。下滚 28px、上滚 14px、收起 240ms、恢复 420ms 不变。该改动用于 Web/PWA 共用工具栏。

照片标题和按钮使用 ink，说明使用 muted，背景使用 canvas，清除覆盖主题的 fixed-white 样式。横向直接跟手、纵向手势放行、首尾不循环。释放时使用最近的指针速度，暂停后不沿用旧速度；快速反向操作依据释放方向吸附。采用项目试验弹簧 `motion.photoSnapSpring`：mass 1、stiffness 300、damping 32。它不是 Motion Carousel 的已核实原始参数；参考案例完整还原仍待用户确认。不按固定时长承诺停止，不横向拉伸图片，不增加付费依赖。

播客仍为待定。本轮不修改播客布局或参数，也不将现有实现标为用户认可。

## 边界与验证

仅修改当前 animation-stages worktree 的第三批范围。Mac 搜索、等待与照片仍为独立旧实现，对账登记缺失和未验证。PWA 搜索采用用户提供的 Apple Music 原型，属于第四批后续任务；本轮不进入第四批。

非浏览器检查覆盖查询保留、键盘选择、图标飞入参数、照片释放速度、取消与中断。构建和静态检查不代替真实窗口、系统键盘或真机验收。设计未发布到线上，未提交、推送或部署。
