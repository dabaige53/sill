# 根目录 DESIGN.md 作为设计入口

2026-10-16，用户已确认，已实施。

根目录新增 `DESIGN.md`，与 `AGENTS.md` 并列。它说明设计依据的位置、改动顺序、禁止事项，以及 Web 与 macOS 保持一致的规则。规则正文仍在 `design-system/README.md`，`DESIGN.md` 不复制手册内容。

原因：设计规则分散在设计手册、设计系统映射、ADR 和线上 Design System 中，agent 改界面前不容易找全；线上版本也曾长期落后于仓库而没有人发现。一个固定的入口文件让 agent 先读规则，并把「合并后同步线上」写成改动顺序的一步。

代价：根目录多一个文件，需要和手册保持不重复。`files:check` 的根目录允许列表和链接检查已包含 `DESIGN.md`。
