# 第四批状态与动画交接

日期：2026-10-26。状态：已接受；实现待视觉复核。

## 决定

- 任务勾选只协调现有详情节点，不重开详情或重播整层淡入。收藏详情内取消收藏时，详情、工具和背景来源卡片保持；关闭详情后再更新列表。提醒完成仍保持详情。
- 下拉达到阈值后等松手请求。请求开始即让内容回位，圆环独立反映真实等待；删除额外的最短加载等待和 1 秒内容停留。成功勾选仍保留 480ms，失败保留重试。手机 Sill 标志始终保留，圆环在其右侧，不替换标志。网页刷新仍直接整体显示。
- 文章和视频在预览与全屏之间切换时，先完成外框 expandedSpring，再让正文布局、目录、播放器占位和工具以 detailFade 120ms 淡入；通过动画完成事件串接，取消时恢复可操作状态。宽屏视频明确使用 Grid 1.6:1 双栏，两个栏分别滚动；没有文字稿时默认展示介绍。播客保持介绍页，不恢复播放或全屏。
- 多选条与 Web AI 框、PWA 导航共享底部位置。旧表面 fast 140ms 淡出并移动 8px，新表面随后 dur-reveal 420ms、ease-reveal 淡入回位；退出期间立即禁止点击和焦点，反向操作从当前帧继续。批量收藏、稍后读、标签保留选择。加入 AI 上下文沿用此节奏，移除用 fast 140ms 淡出，余下条目用现有桌面 FLIP 补位。
- Web AI 折叠改为两个固定尺寸表面的接力淡化，不拉伸宽度。旧表面 fast 140ms 淡出，下移 4px、缩至 0.97；新表面随后 dur-state 220ms、ease-reveal 恢复。不强制气泡吸到边缘，保留拖动位置、草稿和上下文。仅做本地界面，不发送模型请求。
- 手机搜索先展示浏览页。点击输入框时直接获得焦点并请求系统键盘，搜索栏在 dur-reveal 420ms 内移到安全区下方，右侧为「取消」，空框显示本次页面会话历史。取消保存非空查询、收起键盘并恢复浏览。条件更新保留输入节点；历史去重最多 8 条，不写入卡片或账号。Web 顶栏固定 480px 规则保留。

## 范围与验证

仅修改 Web/PWA。Mac 的独立实现缺失，登记在界面对账表；iOS 原生界面缺失。第五批的 Vaul、通知中心和 Mac 实现不包含在内。沿用项目既有键盘与动态偏好规则，不新增配置。

非浏览器检查与构建只检查状态逻辑、节点生命周期和产物。浏览器、真机、视觉流畅度与系统键盘是否弹出仍待用户手动复核。设计未发布到线上。
