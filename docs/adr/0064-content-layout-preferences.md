# 0064 内容排版偏好

日期：2026-10-23。状态：已接受。

## 原因

用户希望在设置中调整字号、留白与间距，不增加玻璃、圆角或动效设置。现有卡片宽度只决定列宽，不能代替这些排版选择。

## 决定

外观增加卡片文字大小、卡片间距、内部留白、阅读文字大小、行段间距、正文宽度与文字加重。采用有限档位，默认保持现有排版，提供恢复默认。设置页仅显示配置项，不放排版示例或说明段落。字体家族选择不在本次范围。

字号与行高联动，保留正文和标题层级。卡片间距改变后重新计算列数与位置；字号或留白改变后重新测量高度。导航和工具尺寸不变。

Web 与 macOS 共用设计变量和偏好字段；MCP 通过已有 preferences.patch 操作写入。恢复默认作为一次偏好写入，保留主题和其他设置。缺少新字段的旧数据继续使用默认排版。

## 影响

- 变量：`tokens/apple.json` 中 layoutText、layoutSpace、layoutLine、layoutReader 参数。
- 手册：基础与组件的「内容排版偏好」。
- 画板：SettingsDesktop、SettingsMobile，由产品组件生成。
- 实现：Web、macOS、共享偏好约定和云端偏好校验迁移。
- 云端发布顺序：先迁移数据库校验，再发布 API 与客户端。此决定不授权发布。

视觉验证状态记录在[界面对账表](../implementation/design/ui-alignment.md)。
