# 账号共用数据、外部备份与设备提醒

日期：2026-10-23。状态：已接受。补充 [ADR 0033](0033-ai-writes-composio-only.md) 的外部服务边界与 [ADR 0061](0061-in-app-media-playback-and-pr-cards.md) 的媒体实现。

本版以登录账号的云端工作区为共同数据源，不提供本机数据与云端的双向同步。每位用户在设置中配置自己的 WebDAV（含坚果云）或 Cloudflare R2，手动保存和恢复工作区备份。用户随后取消 Google Drive 与新增本地草稿保护；AI 对话、Hermes 接入、原生模型配置和绘画均留待后续。


系统提醒由用户在当前设备主动开启。网页仅在页面打开时发送通知；Mac 将已载入的提醒交给系统定时通知，关闭窗口后仍有效。网页不建立后台推送服务。完成、忽略、稍后提醒、删除卡片和退出账号均更新或清理本设备的相关通知。系统权限、通知去重标识属于设备设置，不纳入账号备份；卡片的提醒时间和完成状态仍由账号共用。

HTTPS 图片可直接展示，视频沿用官方嵌入播放器，音频使用卡片的真实地址；打不开时显示可重试状态或提供来源链接。MCP 宿主资源权限由实际卡片使用的域名声明，脚本另限于内置代码和官方 YouTube 脚本。新增媒体域名后可能需要重新打开宿主页面，由宿主最终决定是否允许加载。
