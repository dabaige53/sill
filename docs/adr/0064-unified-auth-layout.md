# 统一登录与授权布局

2026-10-23，已采纳。

## 决定

- Web、手机 Web 与 Mac 登录采用居中应用图标、30 号标题和 352 宽表单。「忘记密码？」「通过邮件登录」依次放在主按钮下方，使用左对齐蓝色文字。沿用密码登录、邮件登录和密码恢复能力。
- 登录标题新增 `auth-title` 设计变量；认证网页直接使用字号变量已有的单位，修复重复拼接 `px` 导致字号失效的问题。
- 独立 Web 首次确认未登录且没有待保存内容时进入现有 `/auth/login`；退出后返回该页。已有草稿、读取失败和 MCP 宿主继续保留原有恢复与连接入口，不自动离开页面。
- 登录与授权画板从现有服务端模板生成，示例回执只在画板中替换。原型不调用登录接口、不发邮件、不更改权限。
- 授权页统一应用图标、账号分隔线及权限在前、范围在后的信息顺序；实际权限、身份和授权提交仍来自现有请求。

## 影响

涉及认证网页、Web 登录入口、Mac 登录视图、认证画板生成、设计手册与界面对账表。不新增认证接口、原生 iOS 登录界面或 Mac 授权页，不改变账号及权限校验。

取代 [ADR 0052](0052-auth-pages-and-settings-boards.md) 中登录布局的对应细节，其他边界不变。
