# 标签浮层与圆润方形操作图标

2026-10-29，用户已确认，已实施。部分替代 [ADR 0037](0037-card-detail-toolbar.md) 中九个操作图标的「线条积木」画法、[ADR 0038](0038-keep-original-icons.md) 中「九个图标保持现状」一条，以及 [ADR 0041](0041-photo-shared-toolbar.md) 中「保存或取消标签后回到原照片」的实现方式；其余决定不变。

## 原因

用户反馈打标签时界面会换掉：手机上关掉当前抽屉再开一个新抽屉，Web 上卡片详情消失、换成标签面板，关闭后再重新打开卡片。标签页本身的内容没有问题，问题在打开方式。用户要求改成浮层，而不是切换。

同时用户比较了操作图标的现状、清晰版和圆润版，选择圆润方向，并要求「看起来是正方形」。

## 决定

- 标签与备注使用独立的浮层，叠在当前内容之上：卡片详情、阅读页、照片、搜索页或主页都保留不动，包括滚动位置和播放器。Web 桌面为居中窄面板；手机为贴底面板，和卡片抽屉一样从底部滑入、滑出，并随键盘上移。手机卡片抽屉（Vaul）会把抽屉外的点按、聚焦和 Esc 当作关闭，浮层打开期间抽屉一律不按「点外面」关闭：抽屉在点击结束后才判断位置，那时添加或移除标签已把被点的按钮重绘掉，按位置判断会把添加标签误当成点外面而关掉卡片。保存、✕、Esc、点暗处只关闭浮层；保存后下层详情原地重绘出新标签和备注。下层关闭时浮层一起关闭。
- 面板内容、输入方式和动效保持不变。
- 收藏、标签、稍后读、回复、去原文、再提醒、停止提醒、加入会议、下载日程九个图标改为圆润方形：外框约 4px 圆角，整体接近方形，不画内部短线，选中填色后形状完整。线宽三档不变，其余图标不动。

## 影响

- Web/PWA：`apps/web/views/app-panels.ts`（`openEditor`、`closeEditor`）、`apps/web/views/shell.tsx`（`#tag-layer`）、`apps/web/views/actions/cards.ts`、`apps/web/views/preview-controller.ts`（`repaintDetail`）、`apps/web/interactions/phone-drawer.tsx`、`apps/web/atoms/icons.ts` 和面板样式。同步与云端写入原先以 `modalKind === "editor"` 判断编辑中，改为判断浮层是否打开。
- Mac 原生应用的标签面板本来就叠在阅读层之上，打开方式与本决定一致；图标从 `design-system/assets/Icons` 生成，下次构建后同步。
- 线上设计系统与设计画布需要另行发布。
