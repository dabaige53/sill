# 卡片来源字段使用第二版数据约定

2026-10-16，已确认并实施代码。依据：GLOSSARY、ADR 0024 与本次全量清理授权。

`contracts/card.ts` 是卡片结构的配置源文件。删除现行类型枚举中的 `insight`；未知卡片类型仍可读取并完整写回，界面采用通用卡片。顶层 `source`、`kind` 改为 `sources`，来源类型 `ai` 改为 `agent`。这是不兼容的字段整理，所以约定版本升为 2.0.0；产品版本不随约定单独变更。

读取旧文件时只转换内存副本，不在构建或启动测试时改写用户文件。邮件原 `source` 是发件人，保留为 `sender`，不作为来源名称。来源中的助手名称保留原值，不能把所有助手都假定为 OpenClaw。

迁移后继续接受全部旧版合法来源：发件人上限 300 字，来源最多 11 个（旧 10 个来源加独立来源）；显式空发件人不被覆盖。两端使用同一份迁移边界样例，不通过截断或丢弃字段绕过校验。

未知字段在卡片和嵌套对象中保留。JSON 字段顺序不代表内容变化，冲突比较采用结构比较，仍拒绝覆盖真正变化的卡片。云端的外部工具名、路径、数据库函数和权限名保持兼容；内部类型统一使用 Card。本次不改线上数据库或 OAuth 配置。

JSON Schema 从 zod 导出；合法、非法样例同时覆盖结构与无法导出的业务规则。设计材料移动到 `contracts/design/`，仍不代表其全部接口已经实现。新增依赖仅用于 TypeScript 检查、JSON Schema 验证和统一格式化，不增加运行时第三方连接。
