# 滚动、完成与回弹的交接

日期：2026-10-26。状态：已接受，Web/PWA第一轮已实施，观感待复核。

用户要求按滚动、完成与回弹方案逐项优化全部参与组件。此前wheel不断重置静默计时、完成前重绘背景与详情整层重建，造成等待和交接不连续。

决定：Web/PWA主动wheel达到刷新或完成阈值即执行，pointer／touch继续使用真实释放；未达标共享40ms释放判断，新序列80ms，重新发力1.25倍且增加2px。关闭后的衰减尾段保护40ms静默解除，最长240ms，新主动输入立即放行。

普通回弹仅移动滚动视口内层，采用用户参考案例的160／0.15阻力与300／34／0.9弹簧、px/s释放速度（±750），restSpeed和restDelta均0.5。关闭使用原有cardSpring，遮罩与回收卡片对齐；背景列表在最终关闭后更新。任务／提醒局部更新，保留焦点、滚动和手势节点。

手势刷新不再强制最短300ms、成功480ms或内容悬停1秒，Sill不隐藏；真实请求与失败反馈保留。650ms工具栏恢复属于独立显示规则，继续保留。

影响：Web/PWA手势、任务与提醒、详情返回、工具栏及叠卡输入；Mac新规则未同步，原生iOS无对应界面。手机抽屉整体迁移Vaul仍为后续工作。本轮不改搜索、AI形态、照片、播客或消息承接。设计未发布到线上；构建与非浏览器测试不代表流畅度或视觉验收通过。
