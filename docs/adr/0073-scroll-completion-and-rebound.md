# 滚动、完成与回弹的交接

日期：2026-10-26；修正：2026-10-27。状态：已接受，Web/PWA第一轮已实施，观感待复核。

下拉刷新的参数、释放与加载空间已由[ADR 0074](0074-pull-refresh-resistance-and-release.md)替代。下文保留第一轮决定的依据；正文回弹、完成与关闭等其他部分继续有效。

用户要求按滚动、完成与回弹方案逐项优化全部参与组件。此前wheel不断重置静默计时、完成前重绘背景与详情整层重建，造成等待和交接不连续。

决定：Web/PWA下拉刷新拉够后释放才执行。wheel每事件最多累计40px输入、以0.5倍率转为内部位移，48为就绪阈值；单次大滚动不能独自达标。开始衰减时估计释放，没有衰减事件时使用40ms静默判断；反向、失焦、打开详情或进入多选取消。pointer／touch继续使用真实释放，不追加等待。

读完上推完成和手机wheel下拉关闭保留达标执行；未达标共享40ms释放判断，新序列80ms，重新发力1.25倍且增加2px。关闭后的衰减尾段保护40ms静默解除，最长240ms，新主动输入立即放行。

修正原因：用户实测反馈「一下拉就刷新」。此前将刷新达标当成提交，单次较大wheel增量可直接请求；现将达标与释放分开，不用恢复180ms等待或延长结果展示掩盖问题。WheelEvent没有原生结束阶段，衰减和短静默属于估计，不等同于真实松手事件。

普通回弹仅移动滚动视口内层，采用用户参考案例的160／0.15阻力与300／34／0.9弹簧、px/s释放速度（±750），restSpeed和restDelta均0.5。关闭使用原有cardSpring，遮罩与回收卡片对齐；背景列表在最终关闭后更新。任务／提醒局部更新，保留焦点、滚动和手势节点。

手势刷新不再强制最短300ms、成功480ms或内容悬停1秒，Sill不隐藏；真实请求与失败反馈保留。650ms工具栏恢复属于独立显示规则，继续保留。

影响：Web/PWA手势、任务与提醒、详情返回、工具栏及叠卡输入；Mac新规则未同步，原生iOS无对应界面。手机抽屉整体迁移Vaul仍为后续工作。本轮不改搜索、AI形态、照片、播客或消息承接。设计未发布到线上；构建与非浏览器测试不代表流畅度或视觉验收通过。
