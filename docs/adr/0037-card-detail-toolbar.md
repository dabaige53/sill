# 卡片详情：操作收进底部胶囊，只用图标

2026-10-18，用户已确认，已实施。取代设计手册「Dialog」中「底部工具条最多三个图标」一条和 [ADR 0036](0036-phone-home-density.md) 中「详情里保留『在 Sill 内再提醒』和『完成』」一条。打开方式（从下往上的抽屉）和关闭圆钮的样式不变。新规则见设计画布 37 号画板和设计手册「卡片详情」一节。

## 决定

- 正文里不再放色块按钮（回复、去原文、加入、在 Sill 内再提醒、完成）。所有操作都在底部玻璃胶囊里。
- 胶囊左边是通用操作：收藏、标签、稍后读，`ink`。竖线之后是这张卡片自己的操作，最多 3 个，`accent`：邮件「回复」；文章、视频、播客「去原文」；日程「加入」（快开始时）、「在 Sill 内再提醒」、「下载日程」；提醒和待办「在 Sill 内再提醒」、「忽略此提醒」。
- 只用图标，不写字。名称写在 `aria-label`；触屏长按显示名称，这次按下不执行；鼠标悬停 0.5 秒显示。
- 提醒详情的「完成」是标题前的圆圈，和卡面同一个控件，只改 Sill。
- 关闭圆钮和来源行对齐，标题占满宽度。没有值的日期不显示，日期和来源备注收成一行。
- 手机上正文最后一行到胶囊 26px，胶囊到底边 `max(8px, 安全区)`。
- 设置「桌面」页新增「卡片操作」开关，可以隐藏任何一个操作；偏好 `hiddenActions` 只影响显示，功能本身和 MCP 不受影响。
- 收藏、标签、稍后读、回复、原文、再提醒、停止提醒、视频、下载九个图标按「线条积木」重画：圆角方块、地平线（窗台）、一小段「窗」短线，线宽不变。

## 原因

原来的详情底部叠了三层：正文里的按钮行、胶囊和安全区，短内容下方留下大块空白；按钮是蓝色或灰色色块，和胶囊的图标是两套语言。用户比较了原地放大、浅蓝主按钮、纯文字、图标加文字等方案后，选择只用图标、按通用和专属分两组，并要求图标有 Sill 自己的样子。

## 代价

- 只用图标需要用户记住图标含义；长按名称和读屏名称是补救。
- `hiddenActions` 是新的偏好字段：本地约定、MCP 说明和云端迁移（`supabase/migrations/20261018060000_sill_hidden_card_actions.sql`）一起改；迁移需要部署后才在云端生效，部署前云端会拒绝含这个字段的偏好写入。
- 邮件只放一个「回复」，它和「打开原邮件」是同一个动作。
- 日程的第四个操作「忽略此提醒」在会议快开始时被挤掉。
- Mac 原生应用没有同步。
