# 搜索、阅读与照片的第三批调整

日期：2026-10-26。状态：已接受；实现待视觉复核。

## 决定

- Web 搜索固定为现有 `search-focused-width` 480px，随可用空间收缩。取消伸缩；空框获得焦点直接显示本次页面会话的搜索历史和真实标签。历史在失焦时记录非空文字，去重保留最近 8 条，不写入卡片或账号数据。
- Web 文章全屏使用独立的目录列和正文列，分别滚动。目录占 160px，两列间隔 40px；正文的来源、标题、标签、封面与段落全部留在正文列。保留即时跳转；PWA 不提供目录。
- 首页、AI 与详情工具沿用同一个滚动触发器，收起 240ms，恢复 420ms 与 ease-reveal。关闭卡片时仍跟随 cardSpring，键盘即时完成，首屏不恢复入场动画。
- 照片按 [Motion Carousel](https://motion.dev/examples/react-carousel) 公开运行代码的按页吸附、横向拖动、前后导航与 `loop: false` 方向实现。使用项目已有 Motion 播放层，不复制付费包。拖动超过宽度 25% 或速度 500px/s 时切换，否则回位；纵向优先时不接管滚动。吸附 260ms，键盘即时定位。背景和工具跟随页面明暗主题，覆盖 ADR 0041 的固定黑底规则。
