# ADR 0081：手机详情抽屉使用 Vaul

日期：2026-10-27
状态：已接入原生 Vaul；窄屏嵌套已验证，PWA 真机手感未验证

## 决定

最新决定：按用户确认，移除自写的滚轮拖动关闭及其停止计时、位移和背景联动。触控板双指／鼠标滚轮不关闭 Vaul 抽屉；手机触摸和鼠标按住拖动使用 Vaul 原生路径。保留 shouldScaleBackground，不实施研究报告中的自写根背景控制器方案；仅根层传圆角 onRelease，避免覆盖 NestedRoot 回位。下文滚轮适配过程已被本决定替代。本次按要求未运行测试、构建或浏览器验证。

按动画清单第五批第 15 项，将窄屏 Web/PWA 的卡片详情接入 Vaul 1.1.2。桌面详情、照片灯箱和设置不使用这一抽屉。按用户最新反馈，打开直接到正文需要的高度，不设置 `snapPoints`，采用 Vaul 的 500ms、`cubic-bezier(0.32,0.72,0,1)`。这些是本次实现参数，不是用户验收通过的参数。

Vaul Root / NestedRoot 控制外层位移、嵌套、背景隔离、滚动锁定与键盘避让；HTML dialog 仅作非模态挂载宿主，Sill 保留历史返回。正文原生滚动，到顶后下拉关闭或回位。底部操作栏保留在可见区域；使用 Vaul Handle，取消自定义把手点击关闭；关闭按钮仍可关闭。底页完整可视区域（顶栏、卡片区、底栏）使用 Vaul 的缩放和圆角联动；颜色、卡片内容、工具和图标沿用 Sill。

## 接入边界

- `phone-drawer.tsx` 包住当前预览，渲染入口复用同一包装。关闭等待退出完成，卸载时取消回调；旧卡片的回调不能关闭新卡片。
- Vaul 详情不绑定旧的把手展开、滚动扩展、下拉关闭与普通正文回弹。旧实现仍服务独立示例和未迁移的其他浮层，不与产品详情同时运行。
- 保留读完上推完成。任务和提醒完成仍保持详情，收藏列表仍延迟到详情关闭后移除背景卡片。
- 手机关联卡片保留历史返回、全屏状态和阅读位置，使用新的抽屉入场，不叠加旧的整层 Motion 位移。桌面关联动画保持。
- 手机详情键盘关闭也走 Vaul 退出；其他浮层键盘规则保持。

## 依据与验证

[Vaul API](https://vaul.emilkowal.ski/api)、[上游源码](https://github.com/emilkowalski/vaul)。本次检查的上游 README 标记项目暂不维护；依赖固定为 1.1.2，不自动追踪升级。

非浏览器回归使用真实 Vaul 与合成 DOM，检查全屏且无停靠点、正文节点、焦点、滚动、退出等待和卸载取消。旧手势、阅读反馈和桌面详情的相关检查一并覆盖。它们不证明 Safari 触摸表现、拖动中间帧或 PWA 真机手感通过；这些仍待用户验收。

Mac `PreviewSheet.swift` 使用居中预览和原生阅读流程，不套用手机抽屉参数；对应手机抽屉不适用，Mac 窗口未验证。iOS 原生对应界面缺失。设计未发布到线上，未部署。

用户随后明确要求直接全屏，取消半屏。当前实现移除 `snapPoints`、展开状态切换、半屏滚动限制和工具栏位置补偿，使用普通 Vaul Content 的默认进入与退出动画。上表停靠相关修正是此前过程，不是当前配置。Sill 保留原生 dialog、底部操作栏、键盘即时响应和已有历史返回。库的 500ms、曲线、默认速度阈值 0.4 和滚动锁定 100ms 与用户提供的源码一致。

源码检查发现的重布局与入场冲突已修正，但尚未进行帧耗时测量；不宣称所有卡顿原因已证实或手感已达到 1:1。后续仍以用户真实操作反馈为准。

## 后续反馈：内容高度与叠层

用户要求优先适配各卡片高度，并保留底部黑色、后层下沉与前层上升的叠层关系。此前统一全屏改为正文自然撑高，最小 70dvh，长内容上限为可视高度减顶部安全区（至少 24px）及底部 12px；超出部分滚动。前层使用完整圆角，底部露出 12px 黑色。正文与底部工具栏共用 Vaul 外层，工具栏改为该外层内绝对定位。

入场保留 Vaul 500ms 曲线，先暂停其 CSS 动画，首帧布局绘制后开始，避免同步加载消耗入场时间。合成 DOM 检查验证暂停与开始时序，不作为卡顿原因已确认或 PWA 手感通过的证据。用户随后澄清第二项指抽屉后面的整页缩小，具体定位见下节。

## 当前预览定位：旧模块未更新

2026-10-27 经用户授权检查 5174 预览：实际 DOM 中标题的父节点为 body，Vaul 标记在 main，整页 workspace-background 容器不存在。对照 HTTP 返回的 shell.tsx 与 phone-drawer.tsx，预览服务仍返回此前版本，与磁盘源码不同；因此标题和 Tab 不在缩放范围内。之前仅以 HTTP 200 确认“预览已更新”不充分。

停止该旧预览进程后，在同一目录和端口重启 Vite，临时开启文件轮询监听。重载并通过卡片标题打开详情后，Vaul 标记位于 workspace-background，包含标题、Tab、main 与 dock。437px 宽的浏览器中，标题宽度从 437px 变为 411px，Tab 从 405px 变为约 380.90px，与背景 0.940503 的缩放倍率一致。标题左侧移入 13px，顶部下移约 13.17px。当前浏览器的整页缩放已核验；未据此认定独立 PWA 或 Safari 真机通过。文件监听此前失效的底层原因未确定。

## 关联卡片叠层与边缘手势修正

手机详情内打开另一张普通卡片时，保留父弹框及其 React 节点、滚动位置，新建子弹框；缩放目标改为父层。返回时等待最上层退出，再恢复原父层，不重新加载父卡片。关闭到首页时清理全部父层。照片灯箱与桌面详情仍沿用各自路径。父层使用独立 id 和标题标识，沿用同一组详情样式。

下拉被拦的源码原因：此前为了露出黑色底边隐藏了 Vaul 的 Content 延伸伪元素，导致库的滚动祖先检查越过 Content，受到根页面滚动位置影响。现保留该延伸区域，只让其透明且不接收指针事件。

用户随后指出底部缺少橡皮筋阻力、到顶后要松手再拉。恢复正文底部原有阻力与回位弹簧，仅作用于正文层；启用连续滚动到边缘的反馈。移除手机抽屉滚轮关闭要求重新起手的判断，将 Vaul 的 scrollLockTimeout 设为 0，取消滚动后的额外拖动等待。关闭触发后屏蔽同一段滚轮惯性，避免连续关闭父层；读完上推完成仍优先于普通底部回弹。

非浏览器检查覆盖父节点与滚动保留、连续到顶后关闭、连续到底后的阻力、退出等待与卸载清理。手机手指在 Safari/PWA 中的连续滚动接管仍须真机确认，不以这些检查替代。

## 当前接入：优先原生 Vaul

按用户确认，使用 Root、NestedRoot、Portal、Handle、Trigger 和 Close。子抽屉保留在父抽屉的 React 上下文内，Portal 将内容挂到各自宿主；父层缩放和拖动联动由 NestedRoot 完成。Sill 的层级记录仅负责路由、宿主和阅读位置。

恢复库默认的 body 处理、滚动锁定和输入框键盘避让，scrollLockTimeout 使用默认 100ms。移除自定义 wheel 关闭、普通正文回弹、入场暂停和退出计时器；退出清理由 Vaul onAnimationEnd 通知。读完上推功能仍独立保留。顶部停靠点不启用；内容自适应高度、12px 黑边、工具栏与整页背景容器继续沿用 Sill 设计。

本地 24 项针对性检查通过，覆盖抽屉、详情动画及工具栏。437px 窄屏浏览器已确认：子层打开时父层由 NestedRoot 缩小并上移 16px；关闭后父节点与阅读位置保留，未观察到控制台错误。Safari/PWA 真机滚动交接和软键盘避让未验证，不能以桌面窄屏结果替代。

2026-10-27 关闭恢复修正：背景固定为一屏时持续裁剪溢出，避免 Vaul 回位起始恢复 overflow 后露出屏外正文。最终关闭先卸载抽屉并恢复正常页面几何，再执行积压的卡片刷新，避免在固定背景中测量列表。Mac 保持现有预览，窗口未验证；iOS 对应抽屉缺失。此修正的 PWA 真机表现待确认。

2026-10-27 补回电脑滚轮关闭：Vaul 原生处理触摸与按住拖动；触控板／鼠标滚轮在正文到顶后继续下滑，抽屉跟随滚轮距离移动，遮罩同步减淡；达到抽屉高度 25% 仅进入可关闭状态，持续输入时保持跟随；滚轮停止输入 80ms 后才从当前位置执行 Vaul Close；退出时长与点击关闭一致，固定为 500ms，使用 Vaul 的 cubic-bezier(0.32,0.72,0,1)，前层、遮罩与后层同步。未达阈值时才在输入暂停 80ms 后以 500ms 回位；点击关闭保持 500ms。反向滚动减少位移；可滚动正文与表单保留自身操作。此项替代此前移除全部 wheel 扩展的规则，滚轮跟随只在输入期间控制位移，退出交回 Vaul；触摸路径保持原生。Mac 窗口未验证，iOS 原生对应抽屉缺失。
