# Web 顶栏搜索与底部 AI 框

日期：2026-10-20。状态：已接受。

用户比较 Web 设计稿后确认以下决定，适用于宽于 650px 的窗口；650px 及以下沿用 [ADR 0048](0048-phone-top-row-and-search-tokens.md) 的手机规则。规则先发布到线上 Design System 和设计画布 45 号画板，再同步到[页面与交互](../../design-system/handbook/interaction.md#桌面顶栏与-ai-框)。

1. 顶栏：左侧为品牌图标和「Sill」，右侧为搜索栏和头像。四者统一 40 高、同一中线；搜索栏和头像用 `card` 底加 `line-card` 细边，与卡片同一材质，间距 8。品牌图标沿用现有应用图标。
2. 搜索放在顶栏，不另开页面。结果在卡片区原地显示，保持多列布局；分类标签、# 条件等规则与手机相同。
3. 主页分栏默认收起，从 Sill 后的 ⌄ 菜单选择，⌘1–⌘5 切换。选中的分栏成为搜索栏里的标签，可以接着输入文字在该分栏里搜。桌面上主页筛选与搜索共用一个状态。
4. 去掉底部的主页 / AI / 搜索导航胶囊，底部轨道只放 AI 框。卡片可以拖进 AI 框作为上下文；有会话时显示会话标题、进行中的多个会话和历史；⋮⋮ 菜单可打开居中的完整视图。
5. 多选条与 AI 框共用底部轨道，同宽同高同位置，一次只出现一样；多选条新增「交给 AI」。

本决定取代 [ADR 0043](0043-desktop-home-filters.md) 的桌面主页常驻分栏，以及 [ADR 0035](0035-bottom-navigation-capsule.md) 中桌面显示底部导航胶囊的部分；手机导航不变。

内置 AI 尚未接入：发送和麦克风保持禁用，不显示运行状态、会话内容或回复，不伪造会话与结果。会话、历史和完整视图在接入后启用。

本次 macOS 未同步，Mac 是否改成相同的顶栏、分栏菜单与 AI 框，待用户确认。
