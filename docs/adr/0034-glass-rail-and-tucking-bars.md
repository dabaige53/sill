# 玻璃底栏取代入口球，工具条滚动时收起

2026-10-16，用户已确认，已实施。取代设计画布 12、15、19、20 号画板和手册旧版中的入口球、展开菜单和挂在卡片外的预览工具条；新规则见 34 号画板。底栏的布局（桌面工具胶囊加头像）后来由 [ADR 0035](0035-bottom-navigation-capsule.md) 的底部导航胶囊取代，其余规则仍然有效。

## 决定

- 工作台底部不再有入口球和展开菜单。底栏是一组玻璃按钮：搜索与筛选、记一笔在一个胶囊里，最右侧是头像，点头像直接打开设置。顶部不放头像或齿轮。以后的功能组（例如助手）各自用单独的玻璃按钮，不并进桌面工具。
- 刷新和回到顶部不放按钮。刷新用下拉或 `R` 键，回到顶部用 `T` 键。
- 详情和阅读页：关闭、全屏是浮在内容上的圆片；底部工具条最多三个图标（收藏、备注与标签，第三个按类型），其他动作是内容末尾的文字按钮。详情和阅读页里没有头像、设置或底栏。
- 工作台底栏、详情和阅读页的工具条、顶部圆片用同一条收起规则，手机和桌面一样：向下连续滚动 28px 完全收起，不留占位；向上 14px、停下 0.65 秒、到顶或到底时回来。
- 玻璃只用于功能层，做成清透镜片（38% 白、blur 12px、saturate 1.9、亮边与发丝线）；遮罩只压暗不模糊；选中状态用墨色，蓝色只给提交动作和开关。
- 多选拖动时叠放最多三张真实卡片缩略图，松手后菜单下方放得下就向下，否则向上。
- 手机搜索在底部，跟着键盘升起；搜索不显示数量；输入法拼写中不筛选。

## 原因

用户要求更接近 Apple 的玻璃质感，去掉不需要的刷新、上移按钮，不用三个点替代，并把头像与设置合并为底部最右的一个入口；阅读时工具条不能遮挡正文、不能留白或留下占位。

## 代价

- macOS 人机界面指南建议不把控件放在窗口底部。桌面 Web 为了与手机保持同一位置和同一套收起规则，仍放在右下角；原生 Mac 应用继续使用系统窗口工具栏，不受本决定影响，只统一用词。
- 刷新没有可见按钮，只能下拉或按 `R`；云端同步仍会自动进行。
- 设计画布中 16、19、20 号可交互原型和 32 号设置画板已于 2026-10-17 按 ADR 0035 重画为导航胶囊。

实现位置：`apps/web/views/app.ts`、`apps/web/interactions/chrome.ts`、`apps/web/interactions/panels.ts`、`apps/web/interactions/drag.ts`、`apps/web/styles/`。规则写在 [设计手册](../../design-system/README.md)「玻璃」「底部轨道与反馈」「搜索与键盘」「预览与叠放」各节，交互数值见 [交互规范](../product/interaction-spec.md)。
