# 登录授权与设置画板交接

## 本地实现

登录和授权按现行画板调整；设置画板复用产品组件，可切换五个分组。画板不执行数据操作。

资讯阅读核对：Web 的 `preview-media.css` 与 macOS 的 `ReaderContent.swift` 已采用标题 22/30、正文 15/25、正文最大宽度 600；两端阅读容器采用桌面留白 32，Web 手机留白 20。本轮保留已符合的实现。正文数据按字符串段落渲染，不新增小节、引用或图注解析。

卡片代码、字号、布局、列数及对应画板未调整。此前差异报告仍只供评估。
