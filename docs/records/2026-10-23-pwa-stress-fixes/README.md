## 流畅度与操作

- 关闭手势等方向明确后才接管动画，普通点击不打断入场。横向代码块和媒体控件保留自身触摸操作。
- 阅读页左右、上下拖动每帧最多更新一次。松手前最后一次位移仍交给退出动画；取消不触发关闭。
- 关闭按钮定位集中读取尺寸后再写样式；值不变时不重复写入。旧面板的回调不能调整新面板。
- 滚动展开不会由普通点击触发；触摸取消、多指、关闭中或被替换的面板不延迟展开。

4 倍 CPU 限速下，展开过程采到 49 帧，最大相邻帧位移约 10.28px，最大采样间隔约 18.9ms；scrollTop 始终为 6。数据说明本机模拟条件下没有原先的 64px 突跳，不代表手机固定帧率。另保存[入场中开始滚动](opening-scroll-cpu4.json)的连续位置记录。

[合成触摸记录](interactions.json)确认按住时抽屉停在 64px；松手后展开到 0 且 scrollTop 保持 80；取消后不展开。5 轮快速关闭、重开后，仍只有最后一次日程详情打开。[横向内容检查](reader-ownership.json)中，宽 346px、内容 805px 的代码块收到横划后，阅读页保持打开且没有位移。
