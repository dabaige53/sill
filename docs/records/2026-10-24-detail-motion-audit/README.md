# 详情开合、滑动与放大的动画和卡顿检查

基准：`be37972`（分支 `claude/pwa-launch-motion`），Sill 1.2.7。决定见 [ADR 0067](../../adr/0067-detail-resize-media-and-progress-writes.md)。

本次只读代码、补非浏览器测试，没有浏览器、真机或帧率录制。下表的「卡顿风险」来自代码路径分析，不是实测帧时间。

## 检查结果

| 操作 | 有无动画 | 发现 | 处理 |
| --- | --- | --- | --- |
| 手机打开详情 | 有：抽屉不透明升起，遮罩同步淡入（上一提交） | 视频播放器框架在升起过程中插入 | 动效结束后再插入，最多等 800ms；封面先占位 |
| 手机关闭详情（按钮、下拉、把手） | 有：沿底部不透明滑出，遮罩同步淡出 | 无新问题 | 不变 |
| 桌面打开、关闭详情 | 有：卡片弹簧展开与收回 | 视频框架同样在展开中插入 | 同上 |
| 详情上下滑动 | 原生滚动；工具条按方向隐藏与恢复 | 每个滚动事件都在整个详情里查询过渡元素；文字稿越长越慢 | 改为只查直接子元素和第一个浮动工具条 |
| 资讯详情滑动（阅读进度） | 进度条、圆环逐帧更新 | 几乎每个滚动事件都保存整个工作区：本地写整份浏览器存储，云端复制并比较整个快照 | 进度最多每 500ms 保存一次；读完立即保存；关闭、后台、离开时补存 |
| 手机滑动后展开到全屏 | 有：停稳后以回位弹簧接续（PR #65） | 无新问题 | 不变 |
| 放大到阅读页（资讯、视频、播客） | 代码有外框弹簧，但看不到 | 阅读页遮罩第一帧就是不透明的页面底色，盖住了长大的外框，看起来直接切成白页 | 放大期间保留预览遮罩，外框铺满后再换底色 |
| 从阅读页缩小 | 有：外框缩回预览尺寸 | 上一提交新增的遮罩处理会让排队的一帧失去遮罩 | 排除放大与缩小 |
| 播客播放中滑动 | 吸顶播放条由滚动位置驱动 | 每次播放位置更新（约每秒 4 次）都重绘整份文字稿和章节 | 列表只在当前行变化时重绘 |
| 视频播放中查看摘要 | — | 每 500ms 重新解析一次 Markdown 摘要 | 正文只在内容变化时解析 |
| 播客封面 | 加载后显示 | 详情封面同步解码 | 改为异步解码 |

## 尚未处理

- 放大或缩小视频、播客时，预览和阅读页各有一个播放器。切换时旧播放器暂停并保存位置，新播放器从该位置开始，但不会自动继续播放；视频框架也会重新加载。要连续播放，需要让同一个媒体元素跨两种布局保留，改动较大，等用户决定。
- 播客吸顶播放条的滚动更新每帧读取一次尺寸。布局未变时开销小，本次未改。
