# 手机主页参考 X 的密度

日期：2026-10-18。范围：Web 本地页面的手机首页（390 宽）。参考 Mobbin 上 X 的 iOS 界面，和用户逐项讨论后定稿，结果写入 [ADR 0036](../../adr/0036-phone-home-density.md) 和设计手册「手机主页」一节。本记录保存讨论时的效果图；效果图是在真实页面上叠加临时样式截得的，不是最终实现。最终截图见设计画布 36 号画板。

## 讨论顺序与决定

| 步骤 | 选项 | 用户的决定 |
| --- | --- | --- |
| 方向 | 只借质感 / 手机改通栏列表 / 整体换成 X | 先讨论手机首页；保留卡片，不改成列表 |
| 卡片 | A 收紧（大图 2:1）/ B 紧凑（缩略图） | 先选 B，改为 A，最后定 B；视频和照片保留大图（`cards-a-b.jpg`） |
| 日程与待办 | 压低高度 | 日程时间放在左侧一列；待办每项 28 高（`event-task.jpg`） |
| 左右平衡 | 右侧留白 | 去掉为已不存在的更多按钮预留的空白，附件占满整行 |
| 提醒卡 | 四种按钮排法（`reminder-buttons.jpg`） | 提醒和待办由外部接入，卡上去掉「稍后」；详情保留「在 Sill 内再提醒」；圆圈在 Sill 内标记完成，以后由 agent 同步（`reminder-rule.jpg`） |
| 圆圈颜色 | 灰 / 蓝 | 蓝色描边 |
| 底部导航 | 居中胶囊 / 加宽胶囊 / 通栏标签栏（`nav-bottom.jpg`） | 保留居中胶囊 |
| 顶部 | 无顶栏 / 标志栏 / 大标题 / 标志加分栏标签（`top-bar.jpg`） | 标志加分栏标签；往下滑时顶栏和胶囊都隐藏 |
| 卡片间距 | 收紧 / 通栏卡片 / X 原样（`card-gap.jpg`） | 收紧：间距 6、页边距 8、圆角 16 |
| 新内容提示 | 文案与颜色（`new-content.jpg`） | 移到顶部，写「↑ N 项新内容」，白色玻璃 |
| 图标 | 偏扁的 4 个（`icons.jpg`） | 改得更方正 |

## 实施与检查

- 规则先发布到线上 Design System 和设计画布（36 号画板，截图来自实施后的页面），再同步回 `design-system/`。
- `npm test` 全部通过。`node tests/e2e/browser.ts` 23 项中 22 项通过；未通过的「Refresh keeps the reading position…」在改动前的基础提交上同样失败（平滑滚动下 50ms 内读到的位置不足 40），不是本次引入。
- 未在真实 iPhone 上检查安全区和键盘；Mac 原生应用未改。
