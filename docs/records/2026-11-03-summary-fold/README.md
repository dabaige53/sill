# 概要展开收起与图标

检查日期：2026-11-03。状态：源码已修复，实际界面待验证。

## 问题与定位依据

用户反馈概要展开、收起没有上下过渡，收起带动上方标题移动，部分概要没有图标；随后要求扩大点击区域，覆盖“概要”文字右侧直到右边缘的全部范围。

- Web `DetailSummary` 通过 `open && …` 立即移除正文，只有箭头旋转；Mac `SummaryOverview` 同样只为箭头添加动画。
- Web 预览窗口使用自动外边距垂直居中，Mac 按内容高度重新计算中心位置。概要变矮会改变窗口上沿，带动上方标题。此为源码定位，未在当前应用窗口复现。
- 两端都只在 `longSummary` 非空时显示图标按钮。只有短概要的卡片此前没有图标，这是原有显示条件。

## 处理情况

- Web 保留概要正文节点，由 Motion 在实际内容高度与零高度之间过渡；长短概要切换也跟随测得高度变化。关闭时正文退出可访问范围，重新展开仍使用原节点。
- Web 在概要首次操作前固定预览当前上沿；后续高度变化只影响下方。展开空间受可视窗口限制，超出后沿用正文滚动。概要所在阅读容器关闭浏览器滚动锚定，避免下方节点带动上方位置。
- Mac 使用原生布局与透明度过渡，首次有效测量后保留带概要的预览上沿。全文模式继续使用整窗布局。Mac 代码按 `write-swift` 技能维护，未构建或运行应用。
- 没有长概要时显示静态 Sill 图标；有长概要时保留图标按钮的长短切换。
- 两端将折叠按钮扩展到“概要”文字右侧整片区域，箭头仍在最右侧。左侧图标及标题文字不承担折叠动作。
- 按后续截图反馈，移除 Web 右侧折叠区域的悬停底色，保留整片点击范围；图标与“概要”的可见距离从 14px 缩至 6px，与 Mac 已有间距一致。图标原有点击尺寸保持。
- 后续截图出现概要正文仅露出一条的裁切。前述 Web 测量使用 `getBoundingClientRect().height`，会包含外层打开及缩小动画的缩放；该值被保存为固定高度后，动画结束并不一定触发布局尺寸观察回调。修正为初次读取 `offsetHeight`，后续使用 `ResizeObserver` 的 `borderBoxSize`，两者都取未缩放的布局尺寸。Mac 使用原生自然布局，没有该处 DOM 测量路径，本次不改。
- 时长及曲线复用 `motion.summaryLength`，键盘操作与已有系统偏好分支保持原行为。
