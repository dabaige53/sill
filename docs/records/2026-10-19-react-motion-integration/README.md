# React 迁移与动效本地整合

记录日期：2026-10-19。范围：主目录 Web 技术栈迁移、动效任务代码核对与本地预览。未部署云端，未进行实体 iPhone / Safari 验收。

## 整合结果

Web 已使用 React + TypeScript + Vite，macOS 保留 SwiftUI。页面、卡片、搜索、设置、详情和云端速记使用 TSX；控制器继续编排动作、导航、焦点与手势。单文件产物继续供本地页面、云端页面和 MCP 宿主使用。


已保留的行为包括：

- 叠卡方向键立即响应；减少动态时取消跟手位移和旋转。
- 桌面详情以最终字号进入和退出；导航面板立即响应；重排只平移位置。
- 刷新圆环临时替换主页标志，不遮挡分栏；主页分栏滚动时保持可见。
- 下滑关闭从当前画面连续离场；把手向下拖动保留正文高度，触控板跟手不等待追赶过渡。
- 读完、完成提醒和勾选待办保留当前信息流成员、顺序、分组及卡片占位；切换筛选或刷新后重新应用状态。
- Web 与 Mac 移除“为什么看到”入口，保留原因和来源数据；Mac 保留已确认的叠卡翻页。
