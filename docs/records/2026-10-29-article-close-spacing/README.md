## 手机搜索反馈

- 现象：输入框移动时光标闪动，搜索编辑期间仍可见底部胶囊，建议列表显示滚动条。
- 源码定位：搜索输入框随头部位移，光标未单独处理；胶囊原来随键盘状态恢复，并存在多选流程写入内联 visibility 的路径；建议列表使用 overflow:auto 未隐藏滚动条。
- 处理：移动期间隐藏光标，保持输入焦点；搜索编辑状态统一隐藏胶囊，移除其键盘出入动画；建议列表隐藏滚动条并保留滚动。仅影响手机 Web/PWA。
- 验证：核心测试、构建及文件检查通过；未做真机或浏览器视觉验收。光标问题按源码路径处理，实际 iOS 键盘表现仍待验收。

## 关闭后外侧轮廓仍出现

- 用户复查：去掉阴影后仍能看到外侧线条，前一轮样式处理未完整解决。
- 源码依据：closeNative 仍无条件恢复 lastFocus 或原卡片焦点；原规则只覆盖卡片和标题按钮，不能消除整个恢复聚焦流程。实际设备上的轮廓来源尚未视觉复现。
- 处理：pointer 关闭后清除浏览器自动恢复到卡片内的焦点，并停止主动恢复卡片焦点；键盘返回保留。
