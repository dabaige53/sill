## 候选修改

- HTTP(S) 正则改用等价的 `^https?:[/][/]`，避免公开 schema 的斜线转义；完整 URL 与协议校验仍在服务端执行。更新自动生成的 schema，不手改产物。
- MCP 错误同时提供文本和结构化 `error`，保留 `isError:true`。输出 schema 增加已有错误对象分支，避免官方客户端把结构化错误误判为输出不合规。
- 修正批量新建示例缺少摘要、遗留速记引导、会议入口 10/15 分钟文档差异。补充精简读取和回执截断后的逐卡核对规则。
- 增加真实失败形态的合成回归：单卡和批量 URL、附件 URL、非法协议拒绝、错误两种表示一致、冲突批次无部分修改、skill 新建示例满足内容规则。
- 将当前已提交但未部署的关键词搜索、精简读取和分类型卡片指引随同版本发布；不能只刷新宿主来代替后端部署。

这不是对连接器内部根因的最终判定。URL 和错误展示是否解决，必须由发布后的原宿主调用确认。大批量完整回执依旧可能很大；没有暗中裁剪正文或改变默认响应含义。
