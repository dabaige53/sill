# iOS 真机准备与阅读抽屉补修

2026-10-26，PR #69 的本地补修与验证记录。设备为 iPhone 12，iOS 18.6.2。测试仅使用内存合成卡片，不读取真实账号、钥匙串或个人内容。

## 已完成

- iOS 阅读只保留抽屉。删除全屏按钮、把手点击切换、上拉展开、滚动自动展开及关联卡片强制放大。照片保留单一独立浏览页，没有放大、缩小状态切换。Web、Mac 的既有阅读展示规则未改。
- 文章预览提供真实 Markdown 目录。入场结束后重建一次正文宿主，修复 UIKit 缓存屏外辅助功能坐标的问题；保留原滚动容器与位置。
- 阅读进度每 500ms 节流保存，后台和离开时补存。时长不重复累加；明确失败保留，未知结果不自动重发。
- 清空卡片发送确认时的工作区版本和卡片 ID，避免把长正文带入删除请求。取消和确认按钮分别验证。
- 工具短按使用系统 Button，长按显示名称并抑制动作；下一次短按可以正常执行。
- 添加原生单元测试与界面测试目标。测试目标只链接 SillMobile，避免共享类型重复链接；Xcode 使用自动依赖排序，编译并发由脚本限制。

## 本地运行方式

```sh
SILL_BUILD_JOBS=1 SILL_APPLE_TEAM=<团队ID> npm run test:ios -- --device <设备ID>
SILL_BUILD_JOBS=1 npm run build:ios -- --archive --unsigned
```

Apple 证书由用户在 Xcode 创建，Team 由用户选择；开发者模式和开发证书信任由用户在手机确认。测试脚本允许 Xcode 为选定团队生成描述文件、注册当前设备。凭据和个人设备标识不写入本记录。

按用户要求，已卸载本机 iOS 模拟器设备与运行时。日常后台测试优先使用 Swift Package；真机测试显式指定设备。脚本降低进程优先级，默认两个编译任务，本次使用一个；并发限制不能保证整机 CPU 固定在某个百分比。Xcode 图形窗口无需保持打开。远端 CI 继续显式使用模拟器，不重新安装本地运行时。
