# Sill Web 改进与 macOS 原生版

本轮交付为本地代码和可运行应用。没有更新线上 Worker、数据库或云端插件包。Mac 版本使用独立本地工作区，尚不连接云端账号。

## Web

- 保留卡片信息流与按需浮现的工具。详情使用更舒展的正文间距；桌面预览保持最终字号，280ms 淡入、140ms 淡出，不叠加或放大文字。快速切换会取消旧动画，减少动态效果仍生效。
- 卡片布局先统一读取高度再写入位置，避免逐张反复触发布局。容器宽度变化会自动重排，适用于嵌入侧栏。初次打开正确跟随系统深浅色，输入法组合期间不抢占快捷键。
- 云端编辑器增加明确的标题、正文区域、字数、固定操作栏和 `⌘/Ctrl + Enter` 保存。关闭后草稿保留在本次窗口；重新打开继续编辑。草稿不写浏览器持久存储，离开页面前触发浏览器离开确认。
- 云端保存期间锁定输入，未知结果继续使用原请求核对；版本冲突保留原始草稿与版本。主动放弃草稿需要确认。刷新失败时保留已有卡片，显示可重试入口；旧读取响应不会覆盖较新的保存结果。
- 云端请求最多等待 20 秒；超时后可核对原请求，不重复创建。登录失效或权限不足时保留可复制的草稿，并阻止草稿写入另一个账号。宿主没有提供稳定账号标识时，失效草稿仅供复制，不自动解锁保存。
- 放弃、删除、退出登录复用现有确认面板，在禁止浏览器原生弹窗的 MCP App 中也可操作；取消确认会回到原草稿。仅改标题时保留正文原有段落数组。
- 本地整卡保存、删除携带编辑前的卡片，创建携带空基准。服务器拒绝旧稿覆盖、重复 ID 创建和已删除卡片复活；不阻止其他卡片的阅读更新。编辑期间的轮询和无关写入响应不替换编辑基准。
- 未实现的系统来源授权不会显示连接成功或编造同步时间；RSS 订阅明确提示尚未保存地址。历史数据不批量迁移，真实外部来源接入仍未实现。

## Mac 原生应用

产物：`dist/macos/Sill.app`。使用 SwiftUI + AppKit，包含卡片桌面、原生搜索、阅读、创建与编辑笔记、收藏、稍后读、本地阅读状态和删除确认。支持 `⌘N`、`⌘F`、`⌘R`、`⌘S`。

应用带有本地运行环境，无需打开终端或安装 Node 才能运行。数据放在 `~/Library/Application Support/Sill/`，不覆盖仓库本地数据。草稿保存到磁盘；并发冲突不覆盖内容。服务使用动态本机端口和内核独占文件锁，拒绝同一数据文件的第二个服务，崩溃后锁自动释放。

本地服务退出时保留卡片和草稿，点击重试重新连接；重复启动合并为一个任务，较旧的读取不覆盖新内容。草稿写入移至后台串行队列。保存响应丢失后只读核对一次，完整内容一致才确认保存；核对失败保留草稿。Edit 菜单提供搜索；未改动的编辑器按 Esc 直接关闭。

构建目标为 Apple Silicon、macOS 14+。采用本机 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证，尚不作为公开发行安装包；最低系统版本未在 macOS 14 实机验收。构建与隔离验收参数见 [macOS 说明](../../../native/macos/README.md)。

## 验证

- 本地数据及插件检查、核心状态检查通过，覆盖原子冲突拒绝、独立阅读状态、迁移和持久化。
- 19 个 Web 浏览器场景通过，覆盖阅读、快速关闭、焦点恢复、键盘、拖动及 320–2048px 布局。
- 13 个无障碍与恢复场景通过，覆盖离线草稿、重试、远端更新、深浅色、减少动态效果与短窗口。
- 新增布局与在线并发检查通过，覆盖仅容器缩放、输入法、行内编辑冲突及草稿重载。
- 云端 HTTP 与 MCP App 浏览器回归通过，使用合成账号及隔离数据库，覆盖创建编辑、丢失响应核对、冲突草稿、关闭后继续编辑和不写浏览器持久存储。云端编辑器另通过深浅色下 1440×1000、390×844、320×225 的无障碍与保存按钮可见性检查。
- 云端恢复检查通过，覆盖 20 秒超时、同请求重试、迟到响应、401/403、账号切换与原账号恢复。该组使用可控 HTTP 测试服务；实际 MCP/SQL 路径另由 MCP App 浏览器检查覆盖。MCP App 测试不授予 `allow-modals`，确认面板仍能完成取消、放弃和删除。
- Mac 编译、签名完整性、Swift 业务自测和随包服务检查通过，覆盖读写、原字段保留、重启、冲突草稿、第二实例拒绝和进程崩溃后重启。
- Swift 业务自测使用真实本地 HTTP 服务注入响应丢失和核对读取失败，确认不重复创建、草稿保留、并发内容不被覆盖。并发启动、服务恢复、过期快照拒绝均通过。
- 真实 macOS 窗口检查已覆盖创建、快捷键保存、阅读、收藏、阅读进入编辑、修改保存、重启持久化、搜索自动聚焦与结果过滤。新增验证覆盖服务停止后保留卡片及点击重试恢复、Edit 菜单搜索、Esc 关闭未修改编辑器、取消放弃后保留修改，以及系统半屏窗口下阅读与编辑按钮可见。测试使用临时数据目录。
- 原生 VoiceOver 人工朗读、深色外观、系统减少动态效果、macOS 14 实机及公开签名分发仍未验收。Web 的深浅色和减少动态效果检查已通过；两者不混用验收结论。

## 布局测量

固定 120 张合成卡片，窗口宽度在 1360px 与 1280px 之间交替 12 次；检查两版均实际渲染 120 张卡片，且容器确实改变宽度。基准为 `af1188dbfce0f3bd2d3f971aa4dd2b8121ea1bac`，通过 Chromium Performance 指标读取布局次数与累计耗时。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 布局计算次数 | 1116 | 48 |
| 布局累计耗时 | 59.621ms | 18.664ms |

这组本机无界面浏览器测量中，布局次数减少约 95.7%。耗时受机器状态影响；本结果不代表固定帧率或所有数据规模下的性能保证。[原始结果](../2026-10-15-local-ux/layout-performance.json)包含容器宽度和计数，可用下列命令复测：

```sh
npm run measure:layout -- af1188dbfce0f3bd2d3f971aa4dd2b8121ea1bac
```
