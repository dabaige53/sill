# 界面备注与无效设置清理

按用户确认的清单，删除界面中与实际操作无关的备注和宣传语，精简存放位置与空状态。

## 改动

| 位置 | 处理 |
| --- | --- |
| Web 与 Mac 的「桌面」设置 | 删除卡片操作列表后的「关掉的操作不出现在卡片详情底部，功能本身不删除。」 |
| 云端「数据与隐私」设置 | 删除安全 Cookie 和当前应用授权的实现说明；存放位置精简为「存放位置：云端账号」 |
| Web 欢迎页 | 删除「把要看的、要做的，放在窗台上」；保留新增与示例入口 |
| 云端空状态 | 「窗台还是空的，从一条笔记开始。」改为「暂无卡片」 |
| Web 本地与 Mac 的「数据与隐私」设置 | 删除「AI 只在本机处理」开关；该开关只保存偏好，未控制实际处理位置 |

同步删除专用的 `settings-hint` 样式和不再引用的文案键，重新生成共享文案、组件示例与设置画板。Mac 没有同一欢迎页，保留其既有完成与筛选空状态。

保留 `aiLocal` 的历史偏好字段和读取兼容，不迁移或删除用户数据。保存失败、未同步、登录恢复、删除确认和卡片中的用户备注保持原样。卡片操作的类型示例保留。
