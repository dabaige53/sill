# 手机 PWA 打开、抽屉开合与下拉刷新优化

基准：`e0fe264`，Sill 1.2.7。决定见 [ADR 0066](../../adr/0066-pwa-launch-and-sheet-motion.md)。

## 改动

| 范围 | 原行为 | 现行为 |
| --- | --- | --- |
| 云端打开 | 会话检查返回前显示未登录欢迎页和「登录」按钮；卡片返回后一起从上方落下 | 300ms 内保持空白；更慢时淡入 6 张卡片形状的占位；卡片返回后首屏按 30ms 错开上浮。未登录时占位保持到跳转登录页 |
| 手机抽屉打开 | 上升同时从透明淡入；遮罩第一帧即全暗 | 不透明上升；遮罩同一时长淡入，排队等待的一帧也不变暗 |
| 手机抽屉按钮关闭 | 默认曲线、220ms 遮罩，边滑边淡出 | 与下拉关闭相同：`ease-sheet`、260ms，不透明滑出，遮罩同时淡出 |
| 遮罩衔接 | 关闭从 1 开始淡出；拖动时会把计时淡入当作拖动轨道调整 | 从当前绘制的透明度接续；拖动先停止计时淡入，再建拖动轨道 |
| 下拉刷新 | 主页顶部每次触摸开始都读取尺寸并写入圆环位置 | 确认是下拉后读取一次 |
| 动效变量 | 每次读取都对根节点 `getComputedStyle` | 样式表变量每页读取一次；行内覆盖即时生效 |
