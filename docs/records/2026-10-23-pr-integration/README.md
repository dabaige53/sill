## 修复

- 同时保留阅读目录与排版偏好、媒体重试与简化提示、旧 MCP 页面地址与动态媒体权限。
- AI 输入框仍在缩小按钮之前获得 Tab 焦点。
- 示例封面用精确 URL 的合成响应隔离；测试仍拒绝其他意外外网请求。
- 本地同步测试补齐运行时需要的 `queueMicrotask`。
- 滚动渐隐测试在页面内记录中间帧，避免固定等待错过动画。
- 触控板关闭测试从输入前开始记录帧，避免 120ms 松手判定后才读取已经清空的位置；继续检查跟手误差、连续退出与实际关闭。
- 云端测试在登录页跳转完成后继续；欢迎页验证账号密码登录与默认隐藏的邮件入口。
- 修复 Web「退出全屏」误走返回历史的问题：缩小恢复同一张卡，保留父卡；新增非界面回归在修复前失败、修复后通过。Mac 原有行为一致。
- 详情切换测试只匹配实际页面内容，避免把 Shadow DOM 中不可交互的动画副本当成第二个按钮。
- 超大代码、测试、手册与发布记录按职责拆分。原型的 Motion bundle 生成到 `dist/`，发布准备包携带实际脚本，源码不保存该大包。
