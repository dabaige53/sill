## 定位依据与处理

### AI 输入框与抽屉

- [页面滚动锁定](../../../apps/web/views/app-surfaces.ts) 原来只在 `lockedScroll` 非零时固定背景卡片区域。从主页顶部进入 AI 页时，长信息流仍占据文档高度，输入聚焦可以继续改变页面位置。现在手机从顶部进入也固定背景，并将文档位置归零；离开时恢复原阅读位置。
- [输入聚焦](../../../apps/web/views/app-lifecycle.ts) 原来只为手机搜索框使用 `focus({ preventScroll: true })`。现在搜索框和 AI 输入框共用该处理；已经聚焦的输入框继续由浏览器控制光标与文字选择，草稿保留。
- [抽屉背景](../../../apps/web/interactions/phone-drawer.tsx) 原来保留整篇文档高度和外层滚动位置。Vaul 1.1.2 的 `shouldDrag` 会因可滚动祖先不在顶部而拒绝下滑。现在抽屉打开时只保留一屏文档高度，原阅读位置由固定背景中的卡片位移表示；文档归零，关闭后恢复原位置。
- 合成 DOM 中已检查：从滚动过的信息流打开抽屉，向下拖动 300px 后触发关闭。iPhone 系统键盘造成的实际位移仍需设备验证，不能将合成拖动等同于真机手感验收。

### 搜索导航胶囊

- [挂起搜索](../../../apps/web/views/app-panels.ts) 原来无条件解除导航禁用，再把搜索页改名为 `search-background`；原隐藏样式只匹配 `modal` 与 `phone-layer`，没有覆盖挂起状态。返回搜索时也未恢复导航禁用。
- [页面状态标记](../../../apps/web/interactions/status-bar.ts) 现在统一标记仍在展示的搜索编辑状态，包括抽屉下方保留的搜索页；[隐藏样式](../../../apps/web/styles/search-suggestions.css) 使用该状态，覆盖胶囊子元素，避免多选交接留下的内联 `visibility: visible` 让胶囊重新出现。
- [搜索动效清理](../../../apps/web/interactions/phone-search-motion.ts) 区分挂起和退出。卡片上方保留搜索的导航状态，返回时重新恢复；从搜索进入 AI 整页则归还底部导航，保留返回搜索的能力。
- 回归覆盖连续两次打开卡片并返回、取消搜索后恢复导航，以及进入 AI 再返回搜索；保留搜索节点、查询和滚动位置。

### 本地 PWA

- 实测开发服务的 `/manifest.webmanifest` 与 `/assets/sill-icon.png` 原来都返回 `200 text/html`，实际是 Vite 的页面回退，不是应用清单与图标。
- [Vite 配置](../../../apps/web/vite.config.ts) 已添加这两项开发资源的服务入口，直接使用现有 manifest 和品牌图标，不复制或修改发布文件。
- 重启同一局域网预览后，manifest 返回 `200 application/manifest+json` 且 `display=standalone`，图标返回 `200 image/png`；页面及修改后的源码模块均返回 200。
- iPhone 安装使用 Safari 分享菜单中的“添加到主屏幕”；有“作为 Web App 打开”选项时保持开启，见 [Apple 操作说明](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios)。本地 HTTP 页面不具备安全上下文中的 Service Worker 等完整能力，不将本轮资源修复称为 HTTPS 或离线能力验收。

### 录屏后的第二轮处理

- [手机页面布局](../../../apps/web/styles/phone-search.css) 原来将整页底边设置为 `--kb`，键盘收起而该值尚未归零时，页面不能覆盖下方主页。现在外框保持整屏，只有页内面板按键盘高度缩小。AI 输入框下方的导航间距随键盘高度连续收回、恢复，移除 `keyboard-open` 阈值触发的整段间距切换。
- [键盘状态](../../../apps/web/views/app-lifecycle.ts) 原来在剩余高度降到 120px 时就解除 `keyboard-open`，使胶囊在键盘尚未离开时出现。现在仍以大于 120px 识别键盘首次打开，但打开后直到高度归零才归还导航。小幅视口变化本身不会被当成键盘。
- 搜索编辑状态在当前页与 `search-background` 上统一取消导航占位，只保留实际键盘高度。结果区域移除 `height: 0`，由剩余页面空间中的一个 Grid 行分配高度，滚动和底部安全间距留在结果列表内部。搜索建议原有左右伸展保持不变。
- [手机抽屉布局](../../../apps/web/styles/phone-overrides.css) 改为一个受外框限制的 Grid 行；预览表面继续将高度分配给正文滚动区，去掉表面与滚动区重复的最大高度。保留内容决定高度、原有 70dvh 最小高度、顶部间距、Vaul 手势和底部工具栏。
- 后两项是对源码中的嵌套尺寸约束作针对性修正，尚未用真实 WebKit 布局确认能消除用户截图的截断和留白，不将其记为真机已修复。
- 本轮未更换节点或数据，也未修改桌面布局和 Mac 原生实现。手机设置页与 AI 页共用的整页外框同样持续覆盖背景，页内内容继续为键盘让位。
- 扩展现有键盘回归检查，覆盖剩余高度 120px、70px、1px 到 0px 的关闭序列：旧代码在首个关闭帧断言失败，修改后通过；另检查独立 70px 视口变化不会触发键盘状态。
- 本轮四份针对性测试 59 项全部通过：前三份与 `tests/web/chrome.test.ts`。Biome 检查无错误，保留原有警告；本地 Vite 已重新启动，确认两个修改后的 CSS 模块返回 200 且包含最新规则。未运行发布构建、浏览器自动化或真机操作。

## 用户追加：主页双击回顶与刷新

- 入口：手机底部导航主页图标。单击保留回顶动作并改为动画，300ms 内双击在回顶完成后刷新；已在顶部则直接刷新。其他页面第一次点击先返回主页，第二次点击从恢复的阅读位置开始回顶。
- [导航动作](../../../apps/web/views/actions/navigation.ts) 用 Motion 数值动画控制文档滚动，第二次点击只登记刷新，不重启动画。回顶完成后调用已有 `Gestures.refresh()`，沿用当前读取、失败重试和顶部指示器，不另建刷新请求。
- 使用 `motion.homeReturn` 设计变量：220ms 起，每屏增加 60ms，上限 500ms，远距离平均速度提高，不叠加文字模糊。参数已从 `design-system/tokens/foundation.json` 生成到 `design-system/tokens.json`，规则原位更新到交互与动效手册。
- 中途触摸内容、滚轮、键盘操作、切换页面或浏览器历史变化会取消当前回顶及待刷新动作；取消后旧完成回调不改变新页面。不更换正文节点，不修改当前主页筛选。
- `tests/web/navigation.test.ts` 的 7 项检查覆盖单击、双击、慢速两次点击、连续点击、已经到顶、远距离时长上限、中途触摸、页面切换及从 AI 返回。连同已有刷新结果和反馈检查，10 项通过；再检查搜索状态及页面工具条，40 项通过，本轮累计 50 项。
- 设计数据生成检查、Biome 检查、文件管理与差异检查通过；Biome 保留原有 3 条字符串模板提示，无新增错误。本机 IP 变化后重启同一隔离预览，首页与最新导航模块均返回 200。
