# 手机底部显示问题

2026-10-29，已修复待设备验证。

用户截图：搜索分类在第二行被截断，下方大片空白；文章抽屉底部露出背景卡片。

源码依据：phone-overrides.css 将抽屉底部抬高 12px，且底边使用透明阴影。现改为贴底、底部直角和实色底边，保留顶部圆角与手势。搜索页为嵌套结果容器明确高度基准，避免 WebKit 按内容分配后裁切滚动区；这一原因尚需真机验证。

改动限于手机 Web CSS，Mac 原生不受影响。构建与核心测试结果见本次交付。未运行浏览器自动化或真机验证，未部署。后续检查搜索分类完整显示、可滚动，以及抽屉打开和关闭时底部覆盖。

## 搜索筛选后底部空白（复发）

用户截图：搜索页选「媒体」分类后，第三张卡被拦腰截断，下方一片空白。原因：手机搜索页底部为导航胶囊预留 `rail-bottom + rail-row + 16px`；进入编辑状态（显示「取消」）后胶囊隐藏，预留空间未收回，结果区在其上沿截断。处理：[phone-search.css](../../../apps/web/styles/phone-search.css) 在编辑状态且键盘未弹起时取消该预留，结果区延伸到屏幕底部，滚动内容底部留安全区。键盘弹起时沿用原让位规则。已修复待真机验证。
