# 手机详情动效修复

规则见 [ADR 0070](../../adr/0070-phone-detail-expansion-and-reading.md)。范围为手机 Web 与主屏幕 PWA 的详情展开、关联卡片、取消拖动、读完关闭和背景主页更新；桌面详情的来源卡片收回规则保持不变。

## 修复结果

- 正文上滑后松手即开始展开。外框使用现有回位弹簧，由浏览器播放位移和圆角裁剪；内容按目标尺寸布局，正文、把手与顶部工具只平移、不缩放。安全区变化用内容位移接续，不写入滚动位置。
- 展开与收起从当前可见边界接续；完成或取消后清除临时尺寸和裁剪，旧回调不清理新的过渡。
- 手机关联卡片保持不透明，取消拖动时遮罩从当前透明度恢复。
- 手机读完确认后，工具持续隐藏，正文不先回弹。已读状态立即保存，背景主页在退出动画结束后更新一次。
