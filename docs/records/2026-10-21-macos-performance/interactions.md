# 无窗口交互性能基准验证

日期：2026-10-21。范围：后台测试；未操作真实 App 窗口或用户数据。

命令：`npm run perf:macos -- --output /private/tmp/sill-background-interactions-verified-1021`。
结果：退出码 0；八项 XCTest 场景通过，每项预热一次、测量十次，提取 48 组官方指标。原始结果见 [interaction-benchmark.json](interaction-benchmark.json)，原始日志保留在上述临时目录。

| 场景 | 一轮工作量 | 平均耗时 |
| --- | --- | --- |
| 卡片指令，300 张 | 50 轮打开、全屏、关联卡片、返回、关闭 | 0.228 ms |
| 卡片指令，3000 张 | 同上 | 0.244 ms |
| 分栏切换，300 张 | 五个分栏各一次 | 1.865 ms |
| 分栏切换，3000 张 | 同上 | 21.619 ms |
| 滚动与分页，3000 张 | 1000 次普通位置更新、10 次接近底部加载、返回顶部 | 59.493 ms |
| 设置面板指令 | 100 轮打开与关闭 | 0.065 ms |
| 搜索，300 张 | 四个搜索条件 | 20.820 ms |
| 搜索，3000 张 | 同上 | 167.545 ms |

这些是整轮同步指令与状态处理时间，不是用户单次操作到显示完成的延迟。无窗口的关闭完成回调可能立即执行；用例在每步检查全屏、关联卡片返回和关闭状态，不假定关闭后仍保留视图层。异步写盘、实际绘制、左右手势、延时恢复不计入此基准。

内存指标来自整个 XCTest 测试进程，包含合成数据、框架及此前场景的分配；本次最高约 5.23 GB，不能直接当作 Sill App 日常内存，也不能据此判定泄漏。该观测需要后续按场景隔离进程分析。当前未设性能发布门槛，单次结果不证明实际动画流畅。

测试开发时修正了 XCTest 手动停止计时选项遗漏，以及无窗口关闭后的错误状态断言；均为测试代码修改。类型检查、三项报告解析测试、文件管理检查另行验证。人工补测步骤见 [性能指南](../../agents/macos-performance.md)。
