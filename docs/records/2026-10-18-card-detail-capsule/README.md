# 卡片详情：操作收进底部胶囊

日期：2026-10-18。范围：Web 的卡片详情窗口（手机 390 宽为主，桌面预览同一组件）。参考 Mobbin 上的 X、Apple Mail、Things 3、Pocket、Spark、Atoms 等界面，和用户逐项讨论后定稿，结果写入 [ADR 0037](../../adr/0037-card-detail-toolbar.md) 和设计手册「卡片详情」一节。本记录保存讨论时的效果图；效果图是在真实页面上叠加临时样式截得的，不是最终实现。最终截图见设计画布 37 号画板。

## 讨论顺序与决定

| 步骤 | 选项 | 用户的决定 |
| --- | --- | --- |
| 现状 | 窗口高度随内容、右上两个 44px 圆钮挤标题、操作分在正文按钮和底部胶囊三处（`before.jpg`） | 正文里的「回复」「在 Sill 内再提醒」「去 YouTube」色块按钮难看 |
| 打开方式 | 卡片原地放大成浮卡（`zoom-in-place.jpg`）/ 保留从下往上的抽屉 | 应该从下往上；原地放大没有原来的高级感（`bottom-sheet.jpg`） |
| 主操作样式 | 黑色小胶囊 / 浅蓝底 / 纯文字，多个操作收进「⋯」（`primary-pill.jpg`） | 黑色太大，「⋯」难看；一张卡片最多 3 个操作 |
| 图标加文字 | 三种颜色（`icon-label.jpg`） | 全用图标，不要文字 |
| 分组 | 通用操作（深色）｜卡片自己的操作（蓝色，最多 3 个），中间竖线（`grouped.jpg`） | 采用 |
| 留白 | 正文到胶囊 52→26，胶囊到底边 16→8（`half-gap.jpg`） | 再减一半 |
| 图标品牌化 | A 线条积木 / B 积木加浅色底（`icon-directions.jpg`） | A；九个图标定稿（`icons-a.jpg`） |
| 多余操作 | 邮件「打开原邮件」、日程「下载日历」是否保留 | 都保留，设置里可以隐藏 |

## 实施时的取舍

- 邮件的「回复」和「打开原邮件」都是打开同一个来源链接，实现时只放一个「回复」。
- 提醒完成后，恢复由标题前的圆圈负责，胶囊里不再重复「恢复提醒」。
- 日程最多 3 个自己的操作，顺序是「加入」（会议快开始时才有）、「在 Sill 内再提醒」、「下载日程」、「忽略此提醒」，超出的不显示。
- 手机底边间距写成 `max(8px, 安全区)`：有手势条的 iPhone 仍按安全区留白，没有安全区的设备是 8px。
