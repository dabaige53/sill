按版本记录产品变化与重要维护调整。各端发布范围以对应事件记录为准。

## Unreleased

- Web 搜索、卡片阅读时长和概要不再反复解析正文；卡片多时刷新单张卡片不再逐张扫描。见[性能排查](2026-11-07-web-markdown-reparse/README.md)。
- Web 阅读进度与阅读时长改为离开时保存（打开另一张卡片、预览与放大切换、关闭详情、切到后台或离开页面），读完仍立即保存，与 Mac 一致。见 [ADR 0093](../adr/0093-web-reading-writes-on-leave.md)。
