## 1.2.18 — 2026-10-30

发布范围：云端 Web/PWA 与 MCP 页面，附 Mac arm64 内部测试包。检查、部署和回退标识见[手机交互与发布记录](2026-10-30-phone-page-lifecycle/README.md#1218-发布结果)。未更新插件技能包。

### Added

- 手机底部主页图标支持双击：带动画回到顶部后刷新；长距离回顶加快，中途触摸可取消。

- 搜索卡片抽屉返回后保持导航胶囊隐藏，修正结果列表底部截断与留白。
- 修正卡片抽屉外层滚动干扰下滑关闭，以及正文滚动区的重复高度限制。
- 本地开发预览正确提供 PWA 应用清单与图标。

## 1.2.16 — 2026-10-29

发布范围：云端 Web/MCP 服务及 Mac arm64 内部测试安装包。检查和部署证据见[按钮审查与发布记录](2026-10-29-interface-hardening/README.md#1216-发布结果)。Mac 包未经 Apple 公证；未更新插件技能包。

### Fixed

- Web 与 Mac 多选稍后读支持再次点击取消；Web 搜索多选栏不再被 AI 输入框遮挡。
- 手机搜索候选获得键盘焦点后保持显示，可用空格选择标签。
- Web 日历下载转义标题、地点中的特殊字符，并使用标准行结束符。
- Web 保存反馈使用服务端回执；备份保存期间禁用输入，避免完成时清除新输入。
- 安装线上工作区条件读取函数，修复刷新所需接口缺失。

### Added

- 增加错误记录规范和症状索引，可查询定位依据、处理情况与验证结果。
- 增加产品版本变更日志。
- 增加 LICENSE 版权声明，署名 wuwenyuan，保留所有权利，暂不开放授权。

### Changed

- 邮件卡面不再显示附件，附件只在详情中列出；发件人与日期按文字基线排成一行。
- PR 卡面按设计稿显示分支、增删数与文件数，检查只显示勾号与通过数；没有分支时计数靠左。
- 文件列表恢复为只在相邻行之间画细线，并压缩上下间距。
- 仅资讯与摘要显示预计阅读时长。
- 手机卡片抽屉首次打开时下半部分不再晚一步显示。
- 文档按项目准则、产品与设计规范、实现说明、决策与任务材料分层管理；合并重复正文，更新引用。
- AGENTS.md 直接维护通用开发、优化、授权与交付要求，专题细则按需读取。
