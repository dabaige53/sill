# 合并前文件拆分

用户要求将当前项目改动合入main；提交钩子因Swift源码、测试、Web素材、手机CSS与生成预览超限而拒绝。用户随后授权解决，并确认可以拆分Swift。当前分支为 `codex/macos-parity-feedback`，基准 `f285b0af`。

## 处理

- AI状态、引用条从AIDock拆出；同一Swift target自动编译，环境对象和操作保持。
- WorkspaceTests按已有套件分为独立文件，共用合成后端、样例与观察辅助集中到WorkspaceTestSupport。没有删除测试。
- 四张WebP素材按图分为模块，assets保留公开入口和URL规则。
- 手机CSS按页面导航、详情设置、搜索、最终覆盖拆开，清单保留层叠顺序；画板副本由生成流程更新。
- 组件预览将内嵌图片原样导出为共享WebP，保留图片与HTML内容；生成检查核对图片字节。

## 验证

- Swift后台测试45项共享层、111项桌面层通过，跳过性能基准。
- Web核心461项通过；Web构建与TypeScript检查通过。
- 拆分前后CSS逐规则比较：选择器、声明、媒体条件及顺序相同。四份素材字符串与导出字节相同；FeedCard解析图片引用后HTML与拆分前相同。
- 超限文件拆分后均低于20,000bytes；没有修改限制或跳过钩子。真实窗口未操作，既有视觉待验项保留。
