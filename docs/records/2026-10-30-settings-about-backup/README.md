# 设置关于与备份页面完善

2026-10-30。源码已实现，构建与真实界面待验证。

## 关于

- Web 和 Mac 均在设置分组末尾新增「关于」，显示当前版本和仓库、版本下载、使用说明、问题反馈入口。
- Web 读取根 `package.json` 的版本；Mac 优先读取当前安装包的版本和构建号，SwiftPM 调试环境使用从根版本生成的值。
- 链接和图标名统一维护于 `design-system/product-links.json`，Mac 构建插件生成 `ProductInfo`。四个 GitHub 目标在本次检查中均返回 HTTP 200。
- 关于页不受工作区载入状态禁用，不触发账号写入。

## 备份与恢复

- 两端沿用设置卡片、分隔线、字体与留白，分为配置位置、手动备份、备份记录和恢复确认。
- 使用共享 Lucide 图标表达创建备份、检查备份、历史与恢复；保留图标旁的文字，不改成需要猜测的纯图标按钮。
- Web 备份方式改为设置分段控件；输入字段使用统一边框、底色与圆角。手机字段上下排列，按钮可换行，输入字号至少 16px。
- 历史记录独立成卡，创建时间和状态在首行，预览、核对、下载在操作行。空记录保留操作说明。
- 备份请求、幂等键、恢复预览、确认范围和未知结果核对逻辑不变。宿主仍不提供凭据表单；不新增自动备份或数据源。
- 设置画板增加关于与无账号的备份配置展示。没有连接真实账号，没有执行备份或恢复。
