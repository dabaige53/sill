# 手机标签面板卡死与重做

## 问题与状态

手机端点「标签」后页面卡住，面板加载异常，打开和输入时卡顿明显。状态：1.2.29 已上线；1.2.30 修复录屏中的剩余问题，待真机验证（2026-11-02）。

## 环境与触发

- 平台：Web/PWA 手机宽度，入口为卡片或详情里的「标签」。
- 触发：点「标签」打开面板。
- 预期：面板从底部滑入，键盘不弹出。
- 实际：面板一边滑入，一边弹出键盘，页面卡住。
- 用户在真机上报告；本地未复现，也未做真机或浏览器测试。

## 定位依据

- 观察：`openEditor`（`apps/web/views/app-panels.ts`）在面板 `translateY(100%)` 升起动画开始的同一帧聚焦 `#tag-new`，手机因此立刻弹出键盘。
- 观察：`syncKeyboard` 在键盘动画的每一帧写入 `--kb` 和 `--visible-height`。标签面板用这两个值决定底边和最大高度，所以升起动画期间面板每帧都要重新布局。`--visible-height` 即使数值没变也会重复写入。
- 观察：点候选标签或删除标签后，`editorTag` 会把焦点放回 `#tag-new`，手机键盘会再次弹出。
- 推测：键盘弹出、面板随键盘上移、系统把输入框滚进视野，三者和升起动画同时发生，造成卡死和加载异常。未在真机上证实。

## 1.2.29 上线后的录屏问题

- 点输入框弹键盘时，面板和背后的页面先后跳两次：iOS 先把锁定的页面滚上去，`--kb` 下一帧才更新。
- 打开面板时关闭按钮显示蓝色焦点框。
- 拼音未上屏（如 `djqm`）时点「保存」，未上屏的字母被存成标签。
- 新加的标签与「添加标签」占位文字重叠。
- 底部仍显示「保存到当前账号」。
- 从备注页返回后，背后的页面停在上移的位置，露出黑色条带。

前两项与最后一项同一根因：iOS 聚焦输入框时滚动被锁定的页面，事后不复位。

- 手机打开面板时不聚焦，点标签输入框才弹键盘；点候选或删除标签时，只有输入框原本有焦点才把焦点放回。
- 键盘高度和可见高度没变化时不再重复写入。
- 去掉卡片标题和操作提示两行副标题，Mac 同步去掉标题。
- 1.2.30：页面锁定期间，`syncKeyboard` 在手机上把被系统滚动的页面立即复位，并监听滚动事件补一次同步。
- 1.2.30：手机打开时把焦点放在面板本身（不显示焦点框），不再落到关闭按钮。
- 1.2.30：输入法组合期间点「保存」不收录未上屏的文字。
- 1.2.30：新标签加入时，输入位淡入，不再滑动穿过新标签。
- 1.2.30：去掉底部「保存到当前账号」，Mac 同步去掉。
- 备注不再折叠：桌面直接在面板内输入；手机显示为一行输入框，点按后打开独立的备注页，「完成」返回，「保存」一起写入。
