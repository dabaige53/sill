# Web 改动分析与 Mac 适配

日期：2026-10-28。基准为当前工作树提交 `f285b0af`（产品 1.2.8），实现为该提交上的本轮未提交变更。用户要求先分析 Web 的改动，再从当前版本适配 Mac；未要求发布、安装或窗口自动化。

## Web 改了什么

以当前源码为依据。`ui-alignment.md` 的旧章节包含已被替代的试验记录，不能把其中每个参数同时当成现行要求。

| 范围 | 当前 Web 行为 | Mac 原有缺口 |
| --- | --- | --- |
| 产品入口 | 取消记一笔、N 快捷键和专属流程；设置保留桌面、外观、快捷键、数据四组；卡片动作不再受旧隐藏偏好控制 | 仍有设置添加页、N 面板、桌面粘贴创建及隐藏动作设置 |
| 搜索 | 固定宽度；普通输入列出最多 8 张匹配卡片，`#` 提供状态和标签；方向键、Enter、Tab、Esc 操作候选 | 搜索框伸缩；只有 `#` 列表，普通输入没有卡片建议 |
| 首屏与工具 | 首屏卡片同时出现；顶栏不重复入场；停顿恢复等待 450ms，桌面顶栏恢复 560ms | 卡片错峰、顶栏首次滑入、旧等待时间 |
| 轻操作 | 批量收藏/稍后读/标签保留选择；全部已收藏可取消；任务和提醒在详情原位更新 | 批量动作立即清空选择，完成提醒关闭阅读层 |
| 播客 | 封面与标题并排、介绍、只读章节、前 5 条文字摘录、节目资料；收听位置由外部写入 | AVPlayer、播放控制、页签和吸顶播放器 |
| 视频与阅读 | 媒体预览宽 860；视频无文字稿时显示介绍；放大与缩小使用卡片弹簧，保留播放器；文章左侧常驻紧凑目录 | 旧宽度、播放器随布局重建、可隐藏目录与平滑跳转 |
| 照片 | 主题背景，横向滚动并按页吸附，首尾不循环 | 固定黑底、切图淡入和循环前后翻页 |
| 刷新 | 连续阻力，位移渐近上限 100px，可见位移 64px 就绪；松手发请求并立即回位；加载反馈至少 300ms，成功勾 400ms | 原距离计算、48px 门槛、慢请求停留和 480ms 成功反馈 |
| AI 栏 | 缩小、恢复、水平移动；保留临时输入与上下文；与多选条先退出后进入 | 缺少缩小和拖动；旧上下文时序与工具切换 |
| 设置与登录 | 开关底色随滑块变化；登录浮动标签、密码可见性和真实请求反馈 | 开关底色突变、标签固定 |
| 手机专有 | Vaul 抽屉、页面背景缩放、软键盘、安全区、状态栏及底部导航 | Mac 使用桌面布局，不复制手机抽屉与导航 |

主要代码依据：`apps/web/views/app-feed.ts`、`home-search.tsx`、`interactions/panel-settings.tsx`、`cards/podcast-detail.tsx`、`interactions/refresh-input.ts`、`motion-panels.ts`、`styles/reader-layout.css`。近期合并包含 #76、#77、#78；最后的 `f285b0af` 主要处理手机行为，不代表每项都要移植到桌面。

## 本轮 Mac 修改

- 移除手动记录入口、实现和对应退役测试；保留标签/备注、归档、导出、清空与账号功能。旧 `hiddenActions` 数据保持兼容，界面不再用它隐藏动作。
- 固定搜索宽度，接入匹配卡片、条件候选、键盘选择及输入法组词保护；保留分栏与类型筛选。
- 批量操作保留选择，收藏按钮反映整组状态；提醒动作保留阅读层和滚动位置。
- 首屏直接显示；顶栏、工具恢复、菜单内缩、头像按压和多选栏交接对齐现行规则。
- 播客改为介绍页，不创建本地音频播放器；视频播放器由阅读层保留，预览/全屏切换复用，关闭阅读层时才停止并保存。
- 文章目录常显，紧凑行、List 图标、当前章节圆点与文字移动，点击即时定位；放大/缩小使用卡片弹簧与内容交接。
- 照片跟随主题，原生横向分页，按钮/键盘有首尾边界，缩略图定位同一页。
- 刷新采用现行连续阻力和门槛，保留 AppKit 的真实 ended/cancelled/momentum 阶段；请求期间内容立即回位，反馈时长与请求分开。
- AI 栏支持缩小/恢复、水平移动与键盘移动；草稿和引用保留，仍不连接模型或发送。引用进入、退出、补位分别使用共享参数。
- 设置开关增加拖动与同进度底色；登录标签随输入或聚焦移动，密码显隐保留焦点，按钮只反映真实请求。

## 检查范围

本轮覆盖 C01–C05、L01–L04、M01–M04、R01–R06、G01–G04、N01–N06、P02 的相关改动。G05 保留手册规定的 Mac 平移叠卡差异；P01 为手机专有。所有真实窗口视觉均为未验证，后台测试不能代替手感验收。

独立只读审查发现 Enter 首项选择和 Esc 后方向键重开缺失，均已修正。后台测试覆盖批量取消收藏、筛选后建议、AI 输入保留、刷新取消/反向/重复释放/旧回执，以及既有写入冲突、未知结果、账号切换和阅读层状态。

本地验证：

| 检查 | 结果 |
| --- | --- |
| `node tests/apple/run.ts` | 通过：SillKit 45 项、Mac 100 项 |
| `npm run lint:apple` | 通过 |

应用产物为 `dist/macos/Sill.app`。首次打包的图标转换受沙盒限制；同一图标集在沙盒外转换成功，随后使用原脚本完成打包，无需修改图标或构建脚本。签名为本地 ad hoc 签名，不是公证发布。

没有执行浏览器、e2e、Apple 窗口自动化、真实账号登录或网络媒体播放。设计未发布到线上；没有部署、安装或修改用户数据。
