# 内容排版偏好浏览器验收

使用 Codex 应用内 Browser，在隔离的本地服务中操作设置。数据来自 30 张合成卡片，不使用线上账号或真实卡片。构建为本次工作区的 `dist/web/index.html`。

## 结果

实际点击「设置 → 外观」的选项，并读取渲染后的字号、内边距、卡片位置和正文尺寸。三个档位都已检查，浅色与深色均有截图。

| 项目 | 默认 | 小／紧凑 | 大／宽松 |
| --- | --- | --- | --- |
| 桌面卡片标题字号 | 16 px | 15.04 px | 17.92 px |
| 桌面卡片间距 | 24 px | 18 px | 30 px |
| 桌面卡片内部留白 | 18 px | 13.5 px | 22.5 px |
| 文章正文字号 | 15 px | 14.1 px | 16.8 px |
| 文章正文行高 | 25 px | 21.15 px | 31.36 px |
| 文章段落下间距 | 16 px | 12 px | 20 px |

- 正文宽度：窄为 640 px，标准为 800 px，铺满使用可用宽度；窄屏继续适应窗口。
- 文字加重：正文从 400 到 500，标题从 600 到 700。
- 保存完成后刷新，七项新偏好及主题仍保留。
- 「恢复默认排版」将新偏好和卡片宽度恢复默认；深色主题保持不变。再次刷新后，实际尺寸仍为默认值。
- 1440、390、320 宽度下，25 个卡片／叠卡容器无重叠或越出视口。390 与 320 宽的设置行无横向溢出；可滚动到恢复默认按钮。
- 按用户要求，Web、macOS 设置中删除排版示例与说明段落，包括「留一点空间，读得更清楚」。浏览器确认外观页仅保留配置项和恢复默认。

数据见 [测量结果](measurements.json)。

## 范围与发现

关闭阅读后立即刷新，曾出现一次「版本已变化」同步提示。核对本地服务文件后，排版偏好已经保存；通过既有的「使用服务端版本」恢复测试环境，随后在保存完成后刷新通过。通用同步逻辑未修改；本次没有证明刷新中断时的阅读记录草稿能够自动恢复。

手机检查使用浏览器视口模拟，未在手机真机验收。macOS 只完成源码同步、编译与 AppearanceTests 两项后台测试，未启动真实窗口。未部署云端迁移或发布设计。

本次补充检查：Web 构建、类型检查、设计 build/check、Swift AppearanceTests、文件规范检查和 `git diff --check` 通过。
