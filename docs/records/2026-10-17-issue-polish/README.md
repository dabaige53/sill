## 删除与恢复

删除桌面底栏重复文字、AI 预告及教学说明、缺失时间占位行、数字拖影样式、短卡定时自动已读及全局点击屏蔽。用户卡片、来源备注、原有轻操作、AI 输入区保持不变。恢复基准是本地标签 `sill-before-issue-polish-20261017`；可用 `git show <标签>:<文件路径>` 查看删除前实现，不需要恢复用户数据。

规范已同步到仓库设计手册和 SelectionBar 说明，组件包已重新生成。按本次 Codex 内处理约定，未同步 claude.ai 线上设计。Mac 使用独立原生工作区，未将 Web/PWA 专项交互改动扩展到 Mac，也未宣称原生视觉通过。
