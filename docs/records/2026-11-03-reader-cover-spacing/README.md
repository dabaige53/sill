# 放大阅读页封面顶部留白

检查日期：2026-11-03。状态：源码已修复，实际界面待验证。

用户截图中，资讯放大阅读页的封面上方留白过大。源码定位发现，`reader-layout.css` 原来的 `.reader-workspace > :is(.gesture-content > .reader-body, .reader-body)` 无法匹配实际嵌套的正文节点：正文位于 `.gesture-content` 内，并不是 `.reader-workspace` 的直接子节点。因此 16px 顶部内边距没有生效，正文沿用了旧的 88px。

修正为分别匹配嵌套正文及直接正文，顶部内边距恢复为既有 `space-16`，减少 72px 留白。共用规则放在桌面资讯专属规则之前，保留桌面封面与正文列同宽、手机左右 20px 的布局。顶部工具栏仍保留原占位，目录与封面使用同一顶部间距。Mac 已使用顶部占位加 16px 的正文间距，本轮不改。

本轮仅做源码定位、局部格式、差异及文件检查，并重新生成受影响的设计画板。未执行浏览器自动化、程序测试、Web 构建、Mac 构建或发布；截图对应运行版本及实际窗口效果未验证。
