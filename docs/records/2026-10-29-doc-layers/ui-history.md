## 2026-10-29 桌面 Web 卡片展开结束闪屏

电脑浏览器的打开卡片在动画结束后保留独立绘制层，关闭后释放；不调整展开速度、布局或手机抽屉。针对结束时 transform 从单位矩阵恢复为 none 的交接做修正。浅色和深色桌面截图布局正常，455 项 Web 核心测试通过；自动化环境未提供可用的绘制层采样，用户原浏览器的瞬时闪屏尚待复核。Mac 未改动。

## 2026-10-29 Web 发布回归修复

手机 Web：抽屉收到系统取消手势时回位，旧关闭回调不再关闭新卡片；滚动后打开 AI 或搜索仍可点击底部导航；设置关闭先恢复主页可见状态，再把键盘焦点放回账户按钮。无背景模糊支持时，多选栏和 AI 栏使用实底。以上为 Web 适配，Mac 原生窗口不使用这些路径。

浏览器回归覆盖真实触摸取消、连续开关、导航返回与焦点恢复；既有搜索、多选、照片测试按现行入口更新。Mac 本次未改动，窗口手感仍按上次记录标为未验证。

## 2026-10-28 搜索与 AI 栏补充修复

Mac：AI 栏拖动使用窗口坐标直接跟手，最小化向所在侧收起；搜索使用 regular 原生玻璃，状态胶囊文字随底色配对，输入行高度固定，删除手势直接归属条件按钮；分栏吸收相同的状态条件；搜索结果增减沿用现有入场和重排动画；设置开关使用手形指针。对应 N01、N02、L02、L03、M01、M03。Web 本轮未改动。真实窗口点击、暗色可读性、动画及拖动手感未验证，不能视为跨端验收通过。保留原有 reduceMotion 分支，本轮未新增分支。
