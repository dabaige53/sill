## 真实前后与行为

改前六图见候选记录的 A；改后六张真实页面见 [43 号画板](../../../design-system/boards/SearchFilters.dc.html) 与 [来源元数据](after.json)，没有临时样式。每行左侧为类型、状态、标签，右侧原文字胶囊独立横滑。查询、卡片、主页、详情返回与输入法处理不变；空标签不显示空行，名称全部来自统一文案。

[新增专项在基础先失败](before.log)：没有三个具名组。实现后 [7/7](browser-after.log) 覆盖 320/390/1440 浅深与 390×430 可用高度，检查键盘类型/标签、收藏状态、焦点可见、详情返回、主页隔离、来源卡片不变，无页面异常、外部请求或横向溢出。空组、转义及各行横滑恢复连同原状态单测 [13/13](unit.log)。

首次新增脚本只等查询字段更新，结果断言 [9 对 1 失败](first-query-wait.log)；随后检查发现 [小屏键盘标签焦点不可见](focus-before.log)。按要求先对基础 323a108 原来源构建并实测，[基础观测](baseline-probe.json) 同样先有 9 个结果、140ms 防抖后为 1，且 320 标签重绘后横滑归零、焦点在屏幕外。前者改为等待原结果更新，保留相同结果断言；后者在 repaintSearch 中保留各行 scrollLeft 和焦点，修复已有键盘问题，没有修改搜索范围或等待时长。[实现后七组全部通过](after.log)。
