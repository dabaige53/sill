## 优先对齐顺序

| 顺序 | 项目 | 直接影响 |
| --- | --- | --- |
| 1 | U01、F01–F05、U07、C05 | 引用挡住输入；分类不恢复位置；查询后不回顶；回顶清筛选；状态更新和任务勾选导致内容/位置变化 |
| 2 | C03、C14–C17、C20–C22、U09 | 来源无法打开、文字稿跟随不同、依据被截断、来源/关联标题显示不对、标题/代码/会议内容排版不同、标签保存值不同 |
| 3 | F07、F11–F15、F18、U08 | 提醒后详情/选中不一致、阅读进度未恢复、焦点/计时/键盘链路缺口 |
| 4 | A06–A09、A12、A16–A18、A26、A36 | 动画中反向操作、阅读开关、读完上推、刷新和照片分页的时序或接手不同 |
| 5 | U02、U05/U06、U11–U17/U19、A13/A20/A29–A35/A38/A39 | 尺寸、文案、控件、搜索等待、转速、开合及标签动画的确定差异 |
| 6 | U20/U21、A24/A40/A41及其余待核实项 | 窗口边缘、主题、菜单遮挡、实际掉帧和逐控件反馈需要对应证据 |

各阶段以同数据、同场景逐项验收。页面跳动先区分成员变化、顺序变化、高度变化、滚动位置变化和动画中断，不能用统一延长动画掩盖错误状态。
