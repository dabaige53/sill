# Web ↔ Mac 动效验证清单

本清单独立保留，不并入功能勾选表。基准：2026-10-28工作区（`f285b0af`加未提交修改），当前桌面Web实现与Mac源码；旧文档中的已撤销参数不作为当前要求。

所有项目的窗口实测和性能测量均为**未执行**。“确定差异”指触发、参数或机制不同，不表示已经观察到每一种跳动。ms为毫秒；curve四个数表示贝塞尔曲线；spring的m/k/c表示质量/刚度/阻尼。Web的CSS像素和Mac的逻辑点按同等内容区域对照，不直接比较截图物理像素。

每项核对：触发动作→变化对象→起止位置→等待/时长→曲线或弹簧→取消/反向→最终状态。键盘、鼠标拖动、离散滚轮和触控板分别记录。相同参数不等于同一帧率或手感；原生输入阶段不是缺陷。A04为明确保留的平台差异，A07有设计依据冲突。

功能、内容及页面位置见[功能验证清单](function-checklist.md)；优先级、统计及依据冲突见[总览](README.md)。
