# 卡片重建：本地界面接入

状态：字段与播放器已接入；实际页面布局已补改，真实窗口未验证。未部署，设计未发布到线上。更新：2026-10-22。

此前以字段接入和编译通过判断全部界面完成，不成立。用户指出实际 Web 页仍是旧布局后，核对真实入口 `app-feed → feed → CardView` 和 `preview-controller → PanelViews`，发现旧文章字号、手机缩略图、详情顺序及媒体外观仍在使用。本记录区分源码修改、构建产物和真实窗口验收。

## 范围

Web 桌面、手机 Web 与 Mac 同步接入来源圆标、发布方与作者、汇总摘要及正文列表、任务与日程字段、多个邮件附件、文件链接、独立 PR 卡片。12 个卡片类型中，媒体区分视频和播客，共 13 类布局。界面状态见[界面对账表](../../product/ui-alignment.md)。

来源圆标共用 `design-system/assets/source-marks/marks.json` 的 SVG 路径与身份匹配规则。当前收录 YouTube、Gmail、Google Calendar、Linear、Slack、Google Drive、GitHub、Apple Podcasts 和 X；未收录或身份不明确时用通用图标，不把普通邮件、日历或播客来源当成某个品牌。

Web 播客使用 HTML audio，Mac 使用 AVPlayer，点击播放前不加载音频。两端支持播放、暂停、后退 15 秒、前进 30 秒、进度、倍速、章节与文字稿。预览中的播客播放区滚出后显示收起播放条；文字稿默认跟随，手动滚动停止跟随。桌面放大页为两栏，手机保留抽屉。

视频使用官方 YouTube IFrame API。Mac 仅此播放区域使用 WKWebView，其余仍为原生界面。不可嵌入的平台或播放失败时保留来源打开。媒体读取仍受来源可用性、嵌入许可及浏览器混合内容规则限制。

用户确认的行为：关闭详情暂停并保存 `playbackPosition`；只有实际结束事件才能自动标为已读。正文滚动不记为媒体播放；跳转结尾不作为完成。尚未开始播放的播放器关闭时保留旧位置。

PR 展示助手写入的仓库、编号、状态、分支、审阅、检查、改动与记录时间；请求审阅时跳到来源。不连接 GitHub 或提交审阅。附件显式空数组不回退旧附件标签。

| PR | 状态标签、分支与增删统计、审阅头像/状态、检查数量和审阅入口；详情按记录事实显示 | 同样使用状态标签、分支行、增删统计、审阅区与文件列表 |

以上是源码核对，不是视觉验收。未在真实窗口检查遮挡、滚动、窄屏布局或联网媒体；不能据此声称与画板完全一致。设计生成器仍有既有 React key 警告。来源图库只涵盖上述九个已收录品牌，未知品牌仍使用通用图标。

## 官方播放器来源身份

按 [YouTube 客户端身份要求](https://developers.google.com/youtube/terms/required-minimum-functionality#embedded-player-api-client-identity)，Web 在嵌入 iframe 单独设置 `strict-origin-when-cross-origin`，不改变全站策略。按 [IFrame API 的预建 iframe 方式](https://developers.google.com/youtube/iframe_api_reference#Loading_a_video_player)，先声明来源策略与 origin，再交给 API。Mac 本地 HTML 的 baseURL 使用已安装应用的 Bundle ID；开发运行回退为打包标识 `app.sill.native`。
