# 跨端性能优化

状态：源码、远端程序检查与构建通过；性能收益未测量。日期：2026-10-29。

## 定位与处理

- Web/PWA 可见页面每 5 秒读取工作区。新增带版本号的读取；数据库先检查权限和工作区版本，未变化时不聚合卡片正文。保留旧读取接口；MCP 和 Mac 现有读取调用不变。迁移须先于新服务端部署。
- 保存差异比较改用已有结构比较，避免为每个字段分配 JSON 字符串；没有操作时保留基线，跳过全量复制。有操作时仍保存独立基线，并复制队列中的操作，避免后续编辑改变待重试内容。仍会遍历卡片，不属于按卡片追踪变更的实现。
- Mac 瀑布流缓存当前宽度的测量结果；仅布局位置变化时复用，子视图更新或宽度变化时失效。没有替换列表、删除离屏视图或改变分页；长列表常驻视图的内存增长尚未解决。
- PWA 与 Web 共用单文件 HTML，新增内容摘要 ETag 和 private/no-cache。浏览器每次校验版本，未改变返回 304，新版本返回完整页面；账号 API 与登录页仍 no-store。不提供离线账号数据或 Service Worker 页面缓存。

## 验证

新增条件读取、授权、页面版本校验、无变化保存与重试内容不可变的回归测试。程序测试与构建按项目规则由 GitHub Actions 执行。

本地 `npm run files:check` 和 `git diff --check` 通过。未执行浏览器、Mac 窗口或真实账号测试。没有测得耗时、帧率或内存收益，不声称四项瓶颈已全部消除。

## 性能验收

使用相同 Release 构建条件和合成数据，优化前后交替至少五次，报告中位数、范围、完成次数与错误数。分别测未变化轮询的传输字节、单卡保存全过程、Mac 长列表布局与内存、PWA 再次打开；单独采样定位瓶颈，采样运行不计入成绩。差异小于波动时报告无可测差异。
