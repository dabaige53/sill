# 卡片状态闪屏与网站图标发布

日期：2026-10-29。

范围：现有 Cloudflare Worker 的 Web 热修复，产品版本 1.2.8。不创建新 tag，不重建 Mac 安装包，不更改数据库或插件身份。

## 闪屏诊断

**状态：已验证共用刷新链路修复并发布。最近检查：2026-10-29。** 本次补录依据同一聊天中的实际排查和发布回执，没有重新执行界面测试；不等于所有平台、所有闪屏现象均已消除。

### 环境与触发

电脑浏览器云端 Web。打开卡片后，在展开结束附近闪一下；待办打勾后也闪。收藏、稍后读等操作共用保存路径。预期只更新对应状态，当前详情、焦点、滚动和媒体实例保持不变。

### 定位依据与已证实原因

隔离云端数据探针观察到：打开详情、待办打勾、收藏、稍后读四种操作，每次保存返回后均发生一次列表刷新和一次详情替换。后三项操作前后详情节点不是同一个节点。打开详情也会写入 seen 状态，因此网络返回时机解释了“展开结束后再闪一下”。

1. [adoptWorkspace](../../../apps/web/cloud-workspace.ts) 原先将完整云端卡片参与 drawnState 比较，包含 state、revision、updated_at 等。乐观更新只改本地个人状态；服务器更新版本号、时间或嵌套状态后，即使画面已显示正确结果，也被判为内容变化。
2. 该判断触发 paintRecords 刷新列表，并无条件更新当前预览；其他卡片的变化也会影响正在阅读的详情。
3. [replacePanelContent](../../../apps/web/views/app-capture.ts) 原先调用 renderContent。[React 渲染入口](../../../apps/web/views/react-renderer.ts) 会先 root.render(null)，再以新 key 挂载，丢弃原详情节点。
4. 详情正文 innerHTML 不同还会触发 [MotionEngine.fade](../../../apps/web/interactions/motion.ts)，新节点从 opacity 0 淡入到 1，造成整块内容短暂消失。HTML 比较也会受局部控件和临时样式影响。
5. 全部待办完成时，服务端会派生 done，并在工作区状态投影中返回 reminderDone；只排除版本号仍不足以避免多余刷新，须按卡片类型比较实际显示的状态。

### 处理及排除的错误方向

最初怀疑展开结束时 transform 清除造成绘制层切换，增加了 will-change: transform。该阶段没有获得有效的浏览器绘制层证据，用户随后报告打勾仍闪，说明该补丁没有处理共用保存刷新链路；不能将它记为已证实根因或完整修复。

最终通过 [cloudViewCard](../../../apps/web/services/cloud-view-state.ts) 排除保存元数据、统一派生状态，并单独比较当前卡片。无可见变化的保存回执不刷新；无关卡片变化不重建当前详情；真正的当前卡片变化使用保留节点的 React 更新，保持相同组件结构，并取消该更新路径的整块淡入。修复提交为 `80a78da00783c1e11a48a23564512afe4ba41ba2`。

### 验证范围与复发排查

- 修复后原探针的打开、打勾、收藏、稍后读均不再触发多余详情替换或列表刷新；状态操作保留详情节点。
- [针对性浏览器回归](../../../tests/e2e/helpers/cloud-stable-detail.ts)覆盖部分完成、全部完成、取消勾选、收藏与取消、稍后读与取消，以及无关卡片和当前卡片的真实远端修改。此前测试主要检查保存值，没有检查回执到达后的节点身份，这是漏检原因。
- [状态比较回归](../../../tests/web/cloud-view-state.test.ts)覆盖保存元数据、完成派生状态、真实内容变化及删除。检查数量和部署证据见下文。
- 浏览器证据来自隔离数据；未在生产账号重复写入卡片，未对 Mac 原生窗口作同等闪屏验收。
- 若复发，先核对运行提交，再区分点击瞬间、保存返回、真正远端内容变化三个时点；统计详情替换和动画目标，检查节点身份、整块 opacity 动画及组件结构。不要仅凭“闪一下”再次认定 GPU 或绘制层问题。

## 手机抽屉闪烁

手机主屏幕 Web App 打开卡片，抽屉升到位时闪一下，与上述保存回执无关，见[手机抽屉打开结束闪一下](diagnosis-phone-drawer.md)。

## 内容

- 保存确认忽略版本与更新时间等非内容变化；统一待办与提醒派生状态。
- 其他卡片更新不重建当前详情；真正的远端内容变化保留详情节点，不重播整块淡入。
- 登录页和工作台引用现有 Sill PNG 作为浏览器标签图标。
