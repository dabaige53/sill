## 已出现的问题与本次确认

- 现象：大力下拉时卡片下降过多，松手仍有向下动量，空白过大；随后试调又出现回零生硬。
- 调整路径：下拉渐近上限由 480px 收紧至 120px，再由用户指定为 100px；回位由固定视觉时长改为物理弹簧；不再将释放速度全部清零。
- 当前确认参数：刷新可见阈值 64px；渐近位移上限 100px（不是手指移动 100px）；阻力系数 0.7；弹簧 stiffness 300、damping 34、mass 0.9；restDelta 0.1px、restSpeed 1px/s。保留向上释放速度，向下释放速度最多 60px/s。
- 触控板释放估计：连续 3 次衰减且幅度降至峰值 50%，或静默 80ms；这属于输入判断，不是新增动画停顿。真实触摸／指针松手不套用这一等待。
- 加载至少显示 300ms，成功反馈停留 400ms；保留圆环、完成图标、卡片随动及 Sill 标题原有设计。
- 普通 Web 滚动使用浏览器原生回弹；自定义下拉刷新期间暂时接管位移，回位结束后归还，避免两套反馈叠加。上述参数只属于下拉刷新，不能批量覆盖其他模块。
- 用户在关联任务反馈“可以了！提交git”。该轮按用户要求未跑测试，已重建后供用户手动确认。

参数源：`design-system/tokens/foundation.json` 的 `motion.pullRefresh`；实现：`apps/web/interactions/gesture-refresh.ts`。详细构建与历史方案见[优化方案](optimization-plan.md)。
