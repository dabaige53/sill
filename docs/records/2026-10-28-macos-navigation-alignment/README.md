# Mac逐步对齐：输入栏与信息流位置

2026-10-28。基于当前工作区，保留上一轮适配代码与独立的[功能清单](../2026-10-28-macos-parity-audit/function-checklist.md)、[动效清单](../2026-10-28-macos-parity-audit/animation-checklist.md)。本批先处理输入遮挡与导航位置，不将全部清单标成完成。

## 适配原则

用户确认：适合Mac的部分可以优化，其他部分逐步对齐。共同的卡片内容、文案、动作含义与状态结果以当前Web为对照；Mac窗口、快捷键、焦点、原生滚动、通知及相应动效允许按平台优化。信息结构和既有轻操作保留，具体平台差异分别记录。

该原则已写入[交互手册](../../../design-system/handbook/interaction.md#两端共用)和[设计工作规则](../../agent/DESIGN.md#跨端规则)。不由此推导重做界面、恢复已取消流程或增加内置助手能力。

## 本批修改

| 清单编号 | 改动 | 当前证据与边界 |
| --- | --- | --- |
| U01 AI引用条重叠 | 引用条与输入表面改为垂直布局，间距8；引用换行向上占位，输入栏底边保持在原轨道。水平移动作用于共同容器，引用随输入栏移动 | 已修改源码；用户截图中的实际窗口场景尚未重新验证 |

| F02 查询及条件改变后的位置 | 查询、类型、#状态/标签的增删统一重置到第一页并请求回顶 | 验证查询、类型及状态条件变化；窗口焦点与可见帧仍待验证 |
| F03 品牌回顶误清筛选 | 品牌和T统一走仅回顶命令，保留分类、查询、类型、状态和标签；保留已加载成员 | 原先清筛选发生在品牌入口；旧审计将T也归为清筛选，范围过宽。T原先是独立滚动调用，本批统一入口 |
| A21 回顶等待 | 上述回顶和分类恢复即时定位，不附加260ms滚动 | AppKit单元验证包含顶部安全区换算；真实滚动手感待验证 |
| A02 导航时额外入场（部分） | 位置恢复请求期间禁用卡片入场与重排动画，避免新列表恢复位置同时播放另一段位移 | 本批仅覆盖分类/条件导航；分页等其余触发继续留在动效清单 |

`Feed`保存分类位置与恢复请求；已有`ScrollProbe`只负责把恢复请求送给`NSScrollView`。它等待当前布局更新，不加固定延时，不每帧重建界面。恢复中的旧滚动通知不会覆盖新分类位置；快速切换时仅应用最后一个请求。

对应源码：

- `apps/apple/macOS/Model/Feed.swift`：分类位置、分页与筛选后的恢复目标。
- `apps/apple/macOS/Shell/Chrome.swift`、`Feed/FeedView.swift`：原生滚动桥接与导航期间动画范围。
- `apps/apple/macOS/Shell/DesktopView.swift`：滚动位置回传、回顶入口与加载下一页的衔接。
- `apps/apple/macOS/Shell/AIDock.swift`：引用条与输入表面的布局。

## 验证场景

| 场景 | 期望 |
| --- | --- |
| 全部加载80张，滚到中段→未读滚到另一位置→切回全部 | 恢复80张和原位置，再回未读恢复它的位置 |
| 长列表中提交查询、切类型或增删#条件 | 新结果从第一页顶部显示，不沿用旧结果的中段位置 |
| 同时带分类、文字、类型、状态和标签→点品牌或按T | 条件和卡片集合保持，只回到顶部 |
| 快速切换分类，旧布局发送滚动变化 | 旧位置不覆盖最新目标，只完成最后一次恢复 |
| 原生顶部安全区100、恢复逻辑距离640 | clip原点为540，逻辑距离仍为640；工具重新显示 |
| 引用1条、3条、两行；缩窄窗口及水平移动AI栏 | 引用位于输入栏上方8，输入不被遮挡，底边固定；此项待窗口实测 |
