## Delivered behavior

The cloud build calls the original welcomeHTML, retaining its Sill icon, typography, spacing and tagline. The login form lives in the welcome flow. An authenticated empty account gets a first-note action; actual authorized records use the existing cards, reader, stack gestures and glass dock. Account actions use the same design tokens. No sample cards or fictitious source connections are injected.

Note-body clicks, edit buttons and the capture keyboard shortcut open the same cloud editor. Unconfirmed writes retain their idempotency key and block navigation/search from replacing the editor. Late list responses cannot repopulate a logged-out page. Unsupported local-only actions do not claim cloud persistence; settings describe cloud storage and unconnected sources correctly. Browser callback failures return to a recovery message without clearing or replacing existing session cookies. The UI offers a 60-second resend countdown; this is a UI guard, not a substitute for the production server's rate controls.
