# Mac 用户反馈修复

本轮根据用户三张截图与文字反馈处理 Mac。用户进一步确认：收起失败指叠卡展开后没有回到原布局。由主代理单独完成，未委派执行任务。

## 范围

- [功能验证清单](function-checklist.md)：叠卡回退、关闭命中、搜索条件、放大入口、阅读和照片位置。
- [动效验证清单](animation-checklist.md)：搜索点击、引用移除、叠卡收起和预览/全屏交接。
- [ADR 0084](../../adr/0084-macos-feedback-layout-and-reader.md)：本轮尺寸与结构决定。

原[62项功能状态](../2026-10-28-macos-parity-implementation/function-status.md)与[41项动效状态](../2026-10-28-macos-parity-implementation/animation-status.md)保留。本轮清单是增量纠正，不把旧记录改成新一轮验收结果。

## 原因与处理

1. 展开叠卡与收起叠卡使用同一个高度缓存键。展开高度被当作最小高度保留，收起仍占大块空间。现保留列表身份，分开两种布局的测量键。
2. AI引用的X原点击区只有18×18；缩小按钮在引用行右侧的覆盖区域也可能接收点击。现关闭区30×30，右侧预留52，缩小统一使用已有减号。
3. 搜索整区聚焦手势与内部按钮重叠；鼠标请求聚焦也运行禁用动画的事务。现只有空白背景处理聚焦，标签有固定X，鼠标开合可动画。按钮按压只改变透明度，类型选中不再切换字重。
4. 详情放大额外要求内容高于预览。现按Web规则：有正文的资讯、笔记、摘要、邮件显示放大；视频保持，播客不增加入口。
5. 预览与全屏原来替换整个正文根节点，并将新正文透明度先设为零。现共用正文滚动容器，保持内容可见；外框仍从当前绘制位置使用卡片弹簧过渡。
6. 资讯正文与目录隐藏右侧滚动条；顶部阅读进度保留。照片标题和X顶部留白改为40。主页、照片、放大阅读页水平边距分别12→18、20→30、30→45。
