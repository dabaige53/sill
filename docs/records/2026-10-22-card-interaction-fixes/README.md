# 卡片内跳转、详情切换与播客吸顶修复

本轮针对用户提供的三张截图修复五处问题。先核对原 HTML 参考稿、Web 与 Mac 源码，再查看本地界面。范围为 Web 桌面、390 × 844 手机 Web 视口及 macOS；iOS 原生不在范围内。

## 修改

| 问题 | 修改后的行为 |
| --- | --- |
| 正文中的卡片链接新开页面 | 已存在于当前工作区的 Sill 卡片链接走内部详情；关闭或返回恢复上一张卡片。普通外部链接仍打开原地址。 |
| 详情放大缩小没有尺寸过渡 | Web 从当前面板边界启动既有卡片弹簧；Mac 记录当前边界与圆角，挂载目标布局后执行边界过渡，保留同一详情层与阅读位置。 |
| 播客小播放器覆盖大播放器 | 滚动到切换位置后隐藏大播放器，小播放器占据吸顶区域；页签固定在小播放器下方。点击小播放器标题返回完整播放器。 |
| 标题与正文之间的通栏横线 | 按用户确认删除；原 HTML 桌面、手机、阅读参考稿与 Web、Mac 同步。页签下划线、播放进度条及内容内部行分隔保留。 |
| PR 审阅按钮置灰 | 有真实 PR 地址时保留外部入口；没有地址的示例卡片可打开本地 PR 详情。此操作不提交 GitHub 审阅。 |

## 界面检查

| 检查 | 结果 |
| --- | --- |
| Mac 汇总正文「笔记」链接 → 笔记 → 回到上一张 | 仍在 Sill 窗口内；返回后显示原汇总卡。 |
| Web 汇总正文「笔记」链接 → 笔记 → 回到上一张 | 当前标签页地址变化，标签页数量保持 1；返回原汇总卡。 |
| Web 与 Mac 点击卡面「审阅」 | 按钮可用，打开本地示例 PR 详情。 |
| Web 与 Mac 标题区分隔线 | 笔记、汇总及 PR 详情中已移除。 |
| Mac、Web 桌面及手机 Web 播客滚动 | 大播放器退出显示；小播放器与页签吸顶，继续滚动时文字稿从页签下方经过。 |
| Mac 与手机 Web 点击小播放器标题 | 返回完整播放器，小播放器退出显示。 |
| Web 与 Mac 放大、缩小 | 两个方向都到达正确布局；自动截图只抓到结束状态，未获得连续中间帧，不能据此认定动画流畅度已验收。 |

界面对账状态为「待确认」。本轮修正了此前仅凭收起条出现就认定吸顶通过的检查范围；旧记录保留，不能代替本轮的切换与占位检查。
