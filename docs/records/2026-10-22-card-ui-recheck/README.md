## 逐模块源码检查

下表每行均核对了卡面、详情、适用的阅读页与手机规则。此处的“修改”只表示代码已修改，窗口结果另列。

| 模块 | 修改前 | 修改后及保留的行为 |
| --- | --- | --- |
| 共用结构 | 桌面卡面额外叠加 4px / −2px 边距；Mac 详情把来源、标题、标签平铺在 20px 间距中 | 卡面内容块统一 8px；详情头部单独分组，来源后 6px，标题到标签 16px；章节和正文保留自己的间距 |
| 资讯 | 详情来源和标题间距叠加；Mac 标签颜色、备注框与 HTML 不同 | 两端统一头部分组；预览封面在前，阅读封面在标题区后；保留 220 / 200 / 340px 的封面高度规则和正文阅读字号 |
| 笔记 | 卡面缺少已有发布日期；Mac 备注有灰底和过大内边距 | 来源行使用明确的发布日期；备注改为 14px 圆角细边框、12px / 14px 内边距；保留短笔记窄预览及长内容放大条件 |
| 汇总 | Mac 详情来源、标题和标签分散 | 将日期范围、数量与标题放入同一头部分组；正文后保留关联列表；不重复显示覆盖时段 |
| 建议 | 卡面关联入口的底色和间距不同；Mac 原因、依据散布在外层间距中 | 卡面关联行使用 surface、12px 圆角和 6px 行间距；详情原因、依据独立分组；保留两条卡面关联入口及窄详情 |
| 邮件 | 卡面头像 28px、来源显示泛称；Mac 附件为分散的普通行 | 头像 32px；使用来源名称和发送时间；附件为可换行的静态标签；手机超过两件显示数量；详情附件格式与大小在右侧 |
| 日程 | 卡面时间 34px、缺少时间区分隔线；详情时间 52px | 卡面时间 28px、右侧 2px accent 分隔线；详情时间 44px、手机 40px；保留会前加入条件及地点、参会人、议程 |
| 待办 | 只有 Mac 详情使用灰圈绿勾，卡面仍蓝色；“另有”缩进 | 两端统一灰圈、绿色完成态、完成文字删除线；卡面圆圈 18px、详情 20px；截止字段用警示色，更多项左对齐；清单操作仍只修改 Sill 状态 |
| 提醒 | 卡面圆圈 22px，摘要缩进 34px | 卡面圆圈 18px，摘要缩进 28px；详情圆圈 24px；44px 操作区域保留；正文后保留项目 |
| 文件 | 数量没有单位；文件标签过厚；Mac 详情文件行之间另有大间距 | 数量带单位；静态标签 6px / 10px 内边距、10px 圆角、左对齐；详情保留格式、大小、修改时间及真实链接 |
| 视频 | 播放符号为轮廓；缺时长时卡面重复显示破折号；无封面时整个播放区消失 | 使用 44px 圆片和实心播放符号；底部轨道与时长并列，未知时显示“时长未知”；无封面保留播放区域；详情保留官方播放器与阅读页内容区 |
| 播客 | 缺章节时当前章节区域消失；小播放器不显示总时长；Mac 无音源时连返回播放区也被禁用 | 保留“暂无章节”；小播放器显示章节序号与播放位置 / 总时长；仅禁用不可用的播放操作；Mac 使用无系统外框的轨道，保留拖动和辅助功能调节 |
| 照片 | 三张以内不显示数量；缩略图是 48px 方块；Mac 说明居中 | 来源行保留照片数量；缩略图为 44×32px、间隔 6px；说明左对齐；保留黑底查看器、左右切换和手机滑动入口 |
| PR | 分支为比例字体；审阅状态微小；Mac 禁用按钮叠加系统外框，检查展开箭头在左 | 分支使用 12px 等宽字体；24px 头像与 12px 状态角标；审阅按钮使用 plain 样式；Mac 检查展开改为整行与右侧箭头；保留真实统计、检查结果和文件路径 |
