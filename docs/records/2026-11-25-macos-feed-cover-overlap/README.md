# Mac 信息流宽封面撑大卡片外框

2026-11-25 已修复并通过离屏 SwiftUI 回归检查。截图对应的应用版本和窗口尺寸未确认。

## 定位依据

- 截图中的中间卡片左缘约为 240 px，右缘约为 1002 px。按相邻列约 49 px 的正常间距推算，卡片右缘应在 921 px 附近。外框宽出约 81 px，其中约 32 px 伸进了右列。绿色封面约为 730 × 365 px，显示比例接近 2:1。
- [Mac 信息流布局](../../../apps/apple/macOS/Feed/MasonryLayout.swift#L115)按统一列宽放置卡片。[卡片封面](../../../apps/apple/macOS/Feed/CardBodies.swift#L48)给图片提供 16:9 的排版尺寸，但[图片组件](../../../apps/apple/macOS/Feed/CardParts.swift#L438)让 `.fill` 图片参与容器测量。较宽的图片按高度填满后仍可把封面和卡片外框一同撑宽。按截图推算，列宽扣掉两侧封面留白后约为 650 px，16:9 的高度约为 366 px。按 2:1 填满这个高度，宽度会增至约 732 px，与截图吻合。
- [Web 信息流](../../../apps/web/interactions/layout.ts#L90)直接设置卡片宽度。[Web 封面](../../../apps/web/styles/cards.css#L257)在已有尺寸的封面容器内用 `object-fit: cover` 填充和裁切。从当前源码看，图片尺寸不会沿同一路径撑宽卡片。

## 处理与验证

Mac 卡片封面容器先按列宽确定 16:9 的尺寸，图片在其上填充并裁切。

离屏检查使用修改前后的 `CardCover` 和现有的 `CoverImage`，分别渲染无图和已有 640 × 320 合成图两种状态。旧实现加载后把 340 pt 列内的卡片撑到 380.5 pt。修复后，340 pt 和 400 pt 两种列宽下，卡片宽高在图片加载前后相同。封面边缘、列间距和右侧卡片的像素检查通过。网络下载和真实应用窗口未实测。
