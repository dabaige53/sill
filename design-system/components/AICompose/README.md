# AICompose

参照 [X 应用内 AI 对话](../../references/README.md)，使用浅灰圆角输入容器和黑色语音胶囊。

- 容器左右外边距 12px、圆角 24px、内边距 12px；Web 当前高度 96px。
- 上排输入区高 36px，字号 17px、行高 24px、内边距 2px 4px。
- 下排放附件、发送和语音控件，间距 12px。附件按钮 32×32px，发送圆钮 24×24px，语音胶囊高 32px、最小宽 84px；语音文字 17px、500 字重。
- 附件使用竖向 paperclip 图标，发送使用向上箭头，语音使用 audio-lines。沿用现有图标资源。
- 颜色使用 `ai-composer`、`ai-control`、`ai-ink`，亮暗主题取值由[颜色变量](../../tokens/color.json)维护，不另写一组颜色。
- 已选卡片显示为上下文；空白内容区留白，不显示引导句、功能说明或「输入不保存」等备注。
- 当前附件、发送和语音未接入，控件禁用；草稿在当前页面会话内保留，切换导航后回来仍可继续输入。不伪造回复或执行结果。
- 手机输入框跟随软键盘上沿，键盘出现时底部导航让开。

页面行为见[页面与交互](../../handbook/interaction.md#底部导航与反馈)。
