已并入待办：提醒是带到期时间的单项待办。

- 改用 CardBlocks 里的「待办·提醒」预设：来源头部「提醒 · 来源名」，提示位写来源里的提醒时间（到点 `alert`，未到点 `muted`）+ 勾选圈 + 标题 + 摘要。
- 卡上没有按钮。勾选圈用 `accent` 描边，点它在 Sill 里标记完成（`complete-reminder`），完成后再点恢复（`restore-reminder`）；读屏读作「完成」「恢复」。这只改 Sill 的状态，不改来源。
- 详情里保留「在 Sill 内再提醒」（`snooze`，10 分钟后在 Sill 里再提醒，不改来源时间）和「完成」。
- 和清单共用同一个勾选圈，一眼就能认出是待办。
