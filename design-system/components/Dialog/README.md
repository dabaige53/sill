# Dialog

对话框与面板：快速预览、完整阅读、筛选、编辑、设置都用同一个 `dialog` 外壳。

- `card` 底、`panel-radius`、`shadow-sheet`；遮罩 `dim` 只压暗、不模糊。搜索和多选菜单用 `frost` 磨砂。
- 预览：关闭、全屏是浮在内容右上的白色圆片（`card`、`shadow-float`），不占一条白带；有封面时压在封面上。底部工具条最多三个图标，在卡片内部底边上方，下面有滚动边缘。往下读时圆片和工具条一起收起，停下时回来。
- 手机变为底部抽屉；要打字的面板停在键盘上方。设置整页一层 `canvas` 底、白色分组，选中分类是浮起的白行。
- 面板标题 `panel-title`；字段标签 12px/500 `muted`。关闭后恢复原阅读位置。详情和阅读页里没有头像、设置或底栏。
- 系统取消触摸时，未提交的下拉、侧滑和上推恢复表面、遮罩和工具条，不执行关闭或完成。打开与关闭可以中断；被取消的开场回调不能重新显示正在退出的抽屉，旧面板的延迟关闭不能影响后来打开的面板。
- 减少动态效果时，表面保留当前位置，手势进度仍可通过淡入和圆环反馈；顶部圆片与底部工具条都用 `dur-reduced` 淡入淡出。搜索磨砂在减少透明度或不支持模糊时改用 `canvas` 实底。
- 底部滚动渐隐与工具条预留空间只用于带悬浮操作栏的预览。摘要等没有操作栏的详情保留普通留白，正文末尾和交接按钮不能被渐隐覆盖；手机半高抽屉仍为屏幕外的 64px 保留滚动空间。
- 照片详情的交接按钮排在缩略图之后，用白字和至少 44px 的触控高度，并留出底部安全区。复制不可用时，完整引用留在原详情内的只读文本区，可以选中和滚动；文本选择与文本区滚动不触发页面关闭或读完收起。
