# SearchField

参照 [Apple Music 搜索](../../references/README.md)。手机和桌面均将搜索栏放在页面顶部，桌面 ⌘K / Ctrl K 打开搜索。

- 搜索页使用 `card` 实底；顶部标题 17px、600 字重，右侧头像进入设置。手机左右边距 20px。
- `.search-pill` 高 44px、胶囊圆角、`surface` 浅灰实底，不加玻璃阴影。左侧搜索图标，输入文字 17px；有输入时显示清除按钮，空输入时显示尚未接入的语音控件。
- 无查询、无筛选时，搜索栏下方间隔 16px 展示两列分类卡：16:9、间距 12px、圆角 12px，使用既有封面与分类名称，不加说明、数量或虚构热门搜索。
- 输入或选择分类后展示结果，按正常阅读顺序从上到下排列。类型选项常驻一行；状态和标签收进「筛选」，选中条件在收起后仍可见。
- 输入法组词时不筛选，确认后更新；本地搜索不显示加载动画或结果数量。
- 搜索与主页分别保留查询、筛选及滚动位置。从结果打开详情后返回原位置；筛选重绘保留展开状态与焦点。
- 软键盘缩小可用内容区，不移动顶部输入框；底部导航暂时隐藏。

页面行为见[页面与交互](../../handbook/interaction.md#搜索与键盘)。
