# SearchField

参照 Apple Music 搜索，但搜索栏始终在页面上方。手机和桌面一致，桌面 ⌘K / Ctrl K 打开搜索。

- 搜索首页使用 `card` 实底；顶行与主页相同：左侧「搜索」34px、700 字重，右侧 36px 头像进入设置。搜索栏左右边距 16px，下方不放筛选。
- `.search-pill` 高 44px、胶囊圆角、`surface` 浅灰实底，不加玻璃阴影。左侧搜索图标，输入文字 17px；有输入时显示清除按钮，空输入时显示尚未接入的语音控件。
- 无查询时，搜索栏下方间隔 16px 展示两列分类卡：16:10、间距 12px、圆角 12px，使用既有封面与分类名称，不加说明、数量或虚构热门搜索。
- 确认输入或点分类卡后进入结果页：顶部为搜索栏和 44px 圆形关闭钮，不显示顶行。分类以 `ink` 底标签放进搜索栏；输入 # 选择的状态和标签以 `accent` 底标签放进搜索栏。标签可与文字同时存在，删除键从后往前逐个删除。
- 只有文字时，搜索栏下方显示一行类型胶囊，与主页分栏同一组件（高 32、间距 8、选中 `ink` 底）；左右滑动结果区切换类型，没有结果的类型不显示。
- 输入法组词时不筛选，确认后更新；本地搜索不显示加载动画或结果数量。命中词加粗，不加底色。
- 搜索与主页分别保留查询、条件及滚动位置。从结果打开详情后返回原位置。
- 软键盘缩小可用内容区，不移动顶部输入框；底部导航暂时隐藏。

页面行为见[页面与交互](../../handbook/interaction.md#搜索与键盘)。

## 桌面（宽于 650px）

- 搜索栏在顶栏头像左侧，宽 280（有标签时 360，聚焦时 480）、高 40、圆角 20，`card` 底加 1px `line-card` 内描边；⌘K 为 13px `muted` 纯文字。⌘K / Ctrl K 聚焦。
- 不另开搜索页：结果在卡片区原地显示，保持多列布局。有文字且没有分类标签时，顶栏下方显示一行类型胶囊。
- 主页分栏从 Sill 后的 ⌄ 菜单选择，选中后成为搜索栏里的 `ink` 底标签；主页分栏与搜索在桌面共用一个状态。Esc 先清文字，再清标签。
