# CardBlocks

卡片积木：卡片由 6 组、29 块积木按固定顺序拼成，类型只是预设的配方。

| 组 | 积木 | 限额 |
|---|---|---|
| 头部 | 来源、人、状态、提示 | 1 |
| 媒体 | 封面、原图、拼图、节目条、文件条、地图、波形 | 1 |
| 文字 | 标题、摘要、要点、金句、正文、代码 | 2 |
| 数据 | 大数字、趋势线、进度条、时间段、航段 | 2 |
| 列表 | 勾选清单、引用卡、附件、参与者、检查项、时间列表 | 1 |
| 动作 | 按钮（一个或两个） | 1 |

- 顺序：贴顶媒体 → 头部 → 主角 → 文字与数据 → 条状媒体 → 列表 → 动作。总共不超过 6 块。
- 积木之间间距 `block-gap`；封面贴顶，内缩 `cover-inset`；按钮前多留 6px。
- 文字行数见 `lines-*` 令牌。
- 写入格式：`{ type, preset, blocks: [ ... ] }`。AI 只需要写用了哪几块积木、各自填什么内容。
