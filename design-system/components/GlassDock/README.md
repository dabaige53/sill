# GlassDock

底部居中的玻璃胶囊，固定三项：**主页 / AI / 搜索**。设置从页面右上头像进入。

- 胶囊高 `rail-row` 60px，每格 `nav-tab` 76px，内边距 4px；手机离底 16px 加安全区，桌面离底 28px。
- 手机与桌面均只显示居中的现有 Mono24 图标，不显示文字。当前项使用 `ink`，其余使用 62% 的 `ink`。
- 保留透明镜片标出当前项。切换立即更新，不拉伸、不弹跳，页面不播放整页过渡。保留镜片的决策见 [ADR 0039](../../../docs/adr/0039-keep-navigation-lens.md)；导航项以当前三项规则为准。
- 主页、AI、搜索均为页面，底部导航常驻；软键盘出现时让开。设置保留返回按钮，不将镜片移动到第四格。
- 玻璃使用既有 `glass` 材质和边缘、阴影变量；浏览器不支持模糊时使用既有实底回退。
- 随主页滚动自动收起与恢复，具体阈值和时长统一见[动效](../../handbook/motion.md)。键盘聚焦时恢复工具条。
- 搜索存在筛选时显示 5px 小点，不显示数量。手机多选条与胶囊共用轨道，多选时隐藏胶囊；详情遮罩覆盖背景工具条。
- AI 页面及输入状态见 [AICompose](../AICompose/README.md)，搜索见 [SearchField](../SearchField/README.md)。记一笔保留在设置的「添加」组，快捷键 N 保持可用。

页面结构见[页面与交互](../../handbook/interaction.md#底部导航与反馈)，来源见[设计参考](../../references/README.md)。
