# GlassDock

底栏：右下（手机为整行）的一组玻璃按钮。桌面工具在一个胶囊里，头像单独一颗放在最右，点头像打开设置。

- 胶囊 `.rail-tools.glass`：搜索与筛选、记一笔，只用图标，按钮 44×44，行高 `rail-row` 52。没有入口球，也没有展开菜单；刷新靠下拉，回到顶部用键盘 `T`。
- 头像 `.account-button.glass`：40px 头像圆，有账号名时显示首字，没有时显示通用人像（`person`）。
- 以后的功能组（例如助手）各自用单独的玻璃按钮，放在胶囊和头像之间，不并进桌面工具。
- 手机：胶囊靠左、头像靠右；桌面：整组在右下角。离边 `rail-edge` 28（手机 16）。
- 材质：`glass` + `glass-filter` + 左上 `glass-edge`、右下 `glass-shade`、外圈 `glass-rim`、`shadow-glass`。减少透明度时改用 `card` 实底加描边。
- 向下滚动 28px 完全收起（`dur-tuck`），停下 `rest-show`、向上滚、到顶或到底时回来；弹层打开、拖动或键盘弹出时让开。
- 筛选进行中，搜索按钮带 `glass-press` 浅底。下拉刷新时圆环出现在页面让出的空隙里，不在底栏上。
