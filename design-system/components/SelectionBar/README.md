# SelectionBar

多选与批量操作：选中卡片后出现在底部轨道上、入口球左边的玻璃工具条。

- `.glass` 胶囊，高 56px，与入口球同一底边；依次是选中数量、「全选」、「操作」、分隔线、✕。
- 出现时「↑ 3」「未连接」提示让开；手机宽度下占满整行，入口球暂时隐藏。
- 进入方式：⌘/Ctrl 点选、Shift 连选、手机长按后松手、卡片菜单「选择」。已有选中时轻点卡片即切换。「操作」打开分组菜单；菜单内 Esc 只关闭菜单并保留选中，回到入口焦点。菜单外 Esc 或 ✕ 退出选择。
- 选中的卡片右上角显示选择圈，内容不移动。拖动时隐藏。

长按拖动只显示选中卡片小摞与蓝色数量角标，松手打开同一操作菜单。背景磨砂，菜单项复用现有图标，文字左、图标右，按「收藏」「稍后读」「标签」才执行批量操作。取消、点背景、触摸取消和失焦都不修改卡片。删除与外部传送不是当前批量菜单能力。

用户确认的局部设计例外：此上下文菜单采用约 240px 宽度与右侧现有图标；卡片小摞保留真实卡片 DOM 的图片、正文与排版缩略图（不可交互、移除重复 ID/ARIA 引用）。菜单锚定松手位置，根据上下可用空间翻转并限制在视口内；键盘入口以按钮位置为锚点。
