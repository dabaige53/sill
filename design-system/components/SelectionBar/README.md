# SelectionBar

多选与批量操作：选中卡片后出现在底部轨道上的玻璃工具条，和导航胶囊同一行。

- `.glass` 胶囊，高 `rail-row` 60，在导航胶囊左侧；依次是选中数量、「全选」、「操作」、分隔线、✕。
- 出现时「↑ 3」「未连接」提示让开；手机宽度下占满整行，导航胶囊暂时隐藏。向下滚动时与导航胶囊一起收起。
- 进入方式：⌘/Ctrl 点选、Shift 连选、手机长按后松手、卡片菜单「选择」。已有选中时轻点卡片即切换。「操作」打开分组菜单；菜单内 Esc 只关闭菜单并保留选中，回到入口焦点。菜单外 Esc 或 ✕ 退出选择。
- 选中的卡片在「…」的位置显示选择圈（桌面右上、手机右下），内容不移动。拖动时隐藏。

长按拖动时，最多三张真实卡片缩略图叠成一摞：第一张选中的在最上面，后两张错开 ±14px、倾斜约 ±6° 露出来，蓝色角标显示总数。不把卡片换成图标。松手后小摞留在松手位置，操作菜单下方放得下就向下展开，放不下就向上；横向跟着指针并限制在视口内。背景磨砂，菜单用 `glass-thick`，文字左、图标右，按「收藏」「稍后读」「标签」才执行批量操作。取消、点背景、触摸取消和失焦都不修改卡片。删除与外部传送不是当前批量菜单能力，也不能拖进 AI 对话或其他页面。

用户确认的局部设计例外：此上下文菜单宽 240px，右侧用现有图标；卡片小摞保留真实卡片 DOM 的图片、正文与排版缩略图（不可交互、移除重复 ID/ARIA 引用）。键盘入口以按钮位置为锚点。

菜单与工具条共用材质回退：系统或应用内减少透明度、浏览器不支持模糊时，菜单使用 `card` 实底与 1px 描边，背景使用 `canvas` 实底。增强对比度时描边用 `ink`，同时减少透明度时仍保持实底。
