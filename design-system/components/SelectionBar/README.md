# SelectionBar

多选条：选中卡片后出现在底部轨道上，依次是数量、收藏、稍后读、标签、交给 AI、分隔线、取消。只用图标。

- 桌面与 AI 框同高同位置同材质，宽度按按钮内容收窄，一次只出现一样；「交给 AI」把所选卡片放进 AI 框。手机与导航胶囊同一轨道，出现时胶囊隐藏。
- 进入：⌘/Ctrl 点选、Shift 连选、手机长按后松手。已有选中时轻点卡片即切换。Esc 或取消退出。
- 选中只画卡片边框，不加角落对号，不提起卡片，不改卡片内容和位置。
- 出现和退出只过渡透明度与轻微位移；退出时立即不可点击。
- 手机长按后拖向 AI 接收条，松手在目标内才打开 AI 窗口；接收框仅实际拖动时在原操作胶囊位置显示，取代操作按钮，结束或取消即隐藏。键盘通过多选条「交给 AI」按钮操作。
- 主页和搜索各自保存选中集合。

实现：`apps/web/atoms/selection.tsx`。示例由 `design-system/scripts/previews.ts` 从产品代码生成，不手改。

Web/PWA 不提供多选条右键菜单。全部选中卡片均已收藏时，收藏按钮为蓝色，名称为「取消收藏」，点击批量取消；混合状态仍批量收藏。收藏、稍后读与标签操作保留选中卡片和操作条，明确取消选择时退出。
