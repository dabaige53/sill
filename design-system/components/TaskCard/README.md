# TaskCard

待办卡：标题 + 最多 3 项 CheckItem + 进度计数；全部完成后折叠为完成态。

- 计数 `.task-count`：12px/500 `ink` + 「/ 总数」 `muted`，tabular-nums。
- 超过 3 项显示「另有 N 项，打开查看」。
- 完成态：32px `surface` 圆底 + `success` 勾 + 「已完成」 eyebrow + `muted` 标题。

## 预览顺序

卡面最多显示三项，未完成事项排在已完成事项之前，各组保留原顺序。数量按全部事项计算，详情保留完整清单。没有子任务的卡片展示标题与摘要，不显示「全部完成」。只调整视图，不改写任务顺序与状态。
