> 东西在光里，安放一会儿。

Sill（窗台）是一个本地优先的卡片工作台：文章、消息、笔记、媒体、待办、日程、工单、项目、指标和 AI 整理，都以卡片的形式放在同一张桌面上。内容在不透明的白色表面上，半透明玻璃只属于按需出现的工具。中性白灰、石墨文字，只有一种蓝色动作色。

组件脚本的全局名是 `Sill`（`window.Sill`）。

## 产品立场

- Agent 优先：已有卡片的正文和结构化内容由 AI 修改；所有产品数据与状态操作须能通过 MCP 完成。不新增复杂人工编辑器，不把接口字段逐项搬到界面。
- 用户保留既有新增卡片、记一笔等轻入口，其他原有产品设计与轻操作保持不变。取消内容编辑不授权删除阅读、收藏、任务勾选、提醒、归档或设置等功能。具体边界见 [产品约定](../docs/product/agent-mcp.md#agent-优先与界面边界)。
- 信息流就是入口：不放常驻导航栏、侧边栏、顶栏筛选、横幅或统计面板。
- 工具按需出现：靠近、选择、提起卡片时才浮现，用完就退场。
- Agent 驱动内容与执行；卡片展示状态、收集意图。涉及外部动作时由 agent 通过 MCP 执行并回写，不逐按钮直连外部应用；打开原文仍可作为显式导航。
- 本地反馈与外部完成分开：待处理、执行中、失败和结果未知必须可辨认，不能只用动效或颜色暗示成功。意图调度尚待落地，见 [架构边界](../docs/product/agent-mcp.md)。
- 新内容不插队：正在读的位置不动，新卡在顶部等着。
- 本机是默认：卡片状态保存在本机；agent、模型与 MCP 的实际执行位置取决于宿主和上游配置，不承诺所有 AI 处理都在本机。
- 退出不用找 X：点外面、按 Esc、下拉、读完上推都能离开。

## 文案

- 简体中文，短句，陈述事实，不感叹，不用 emoji。
- 按钮写要去做的事：「加入」「审阅」「回复」「值机」「放回桌面」「撤销」。
- 不写状态句：「已是最新」「加载中」「到底了」「已读」「已经结束」都不说，交给动作和颜色。
- 每个图标按钮都有中文 `aria-label`。

## 颜色

- 页面底色用 `canvas`，卡片和弹层用 `card`。内容卡片不换底色，也不加彩色左边条。
- **已读未读只靠卡片颜色**：未读是 `card` 加 `shadow`，在背景上浮起来；已读退成 `card-read`，边框换成 `line-read`，去掉阴影，标题换成 `muted`，封面降饱和到 0.6，过渡 `dur-read`。不加蓝点，不写「已读」，也不加「✓」等符号；这条取代 2026-10-13 无障碍验收中「可见非颜色标识」的结论，见 [ADR 0030](../docs/adr/0030-read-state-color-only.md)。只有资讯、消息、笔记、媒体、整理五类分已读未读。日程结束后同样退成已读色，开始时间也换成 `muted`，不写「已经结束」。待办、工单、项目、指标一直是白卡。
- 文字：标题和正文用 `ink`，摘要和元信息用 `muted`（三种底上都过 4.5:1）。`secondary` 只给图标和分隔符用。
- `accent` 是唯一的动作色。一个区域里只出现一个 `accent` 实心按钮。
- 状态胶囊：琥珀用 `alert-soft` 底配 `alert` 字，完成用 `success-soft` 底配 `success` 图标。
- 遮罩：预览和抽屉用 `dim`（压暗）；搜索和筛选用 `frost`（磨砂，不压暗）。
- 品牌色 `sky`、`sky-soft`、`ledge`、`ledge-deep` 只用于图标、封面和启动画面，不进界面。

## 玻璃

- `glass` 配 blur(20–24px) saturate(1.2) 和 1px rgba(255,255,255,.72) 描边，阴影用 `shadow-glass`。
- 只用于入口球、阅读胶囊、提示胶囊（「↑ 3」「未连接」）、选择条和 Toast。卡片菜单盖在卡片文字上，用 `card` 实底，不用玻璃。
- 系统开启「减少透明度」或浏览器不支持时，回退到 `card` 实体底。

## 字体

- 系统字体栈 `sans`；数字统一用 `rounded`（圆体）并开启 tabular-nums。
- 字号在 CSS 中写作 `--text-<样式名>`，例如 `--text-card-title`、`--text-meta`。`caption` 12、`meta` 13、`control` 14、`body` 15 同时充当小字阶梯：数值相同的文字直接用它们，不另写像素。
- 卡片：`card-title` 17/600 最多 2 行，`summary` 15 最多 3 行（有封面时 2 行），`meta` 13。
- 主角数字：`figure` 34，详情页用 `figure-xl` 44，航段用 `figure-route` 28。
- 金句：`quote` 21/500，最多 4 行。
- 阅读：`reader-title` 30，正文 `reader-body` 17/1.9。

## 卡片积木

卡片由 6 组、29 块积木拼成，类型只是配方。

| 组 | 积木 |
|---|---|
| 头部 | 来源、人、状态、提示 |
| 媒体 | 封面、原图、拼图、节目条、文件条、地图、波形 |
| 文字 | 标题、摘要、要点、金句、正文、代码 |
| 数据 | 大数字、趋势线、进度条、时间段、航段 |
| 列表 | 勾选清单、引用卡、附件、参与者、检查项、时间列表 |
| 动作 | 按钮（一个或两个） |

- 顺序固定：贴顶媒体（封面、原图、拼图）→ 头部 → 主角 → 文字与数据 → 条状媒体 → 列表 → 动作。
- 只有一个主角：标题、金句、大数字、时间段、航段里只能有一个最大。
- 限额：头部 1、媒体 1、文字 2、数据 2、列表 1、动作 1，总共不超过 6 块。
- 按钮到点才出现：会议开始前 10 分钟出现「加入」，PR 等你审阅时出现「审阅」；平时卡面上没有按钮。
- 窄于 300px 时收起：摘要变 1 行，参与者只留头像，双按钮上下排。
- 10 类、32 种预设，见设计画布第 21–23 块。

## 文字长度

- 卡上按行数截，写入时按字数限（`lines-*` 令牌）。截断统一用「…」。
- 总结过长时不在卡上堆一段话，改写成「一句结论 + 最多三条要点」，完整内容在点开后看。

## 间距与尺寸

- 卡片内边距 `card-padding` 18，积木之间 `block-gap` 8，封面内缩 `cover-inset` 8。
- 信息流间距：手机 `gap-sm`、中等宽度 `gap-md`、桌面 `gap`；页边距对应 `margin-sm`、`margin-md`、`margin-lg`。
- 列宽在 `col-min` 到 `col-max` 之间，理想 `col-ideal`，1–5 列。
- 所有可点击元素不小于 `hit-target`。
- 圆角：卡片 `card-radius` 22、封面 `cover-radius` 14、弹层 `sheet-radius` 28、面板 `panel-radius` 24、控件 `control-radius` 12、胶囊 `pill-radius` 999。CSS 变量与令牌同名，例如 `--cover-radius`。

## 动效

- 只有三种：跟手、落下、淡入。曲线 `ease`，手机抽屉用 `ease-sheet`。
- 桌面预览以最终字号淡入并上移 10px（280ms），关闭时淡出并下移 4px（140ms）；不复制或缩放文字。手机预览保留跟手抽屉。菜单 `dur-menu`，抽屉 `dur-sheet`。
- 只有首屏卡片入场：上浮 10px，间隔 `stagger`。滚动中出现的卡片不动。
- 等待短于 `delay-loading` 不显示任何加载态；骨架按真实高度；封面先给主色块，进入视野后再清晰淡入。
- 读完：读到底时什么都不显示。继续上推，底部浮出 40px 白色圆片，从 0.6 倍放大到 1 倍，蓝色细弧随推的距离填满；正文带阻尼跟着上移，工具胶囊淡出让位。填满后变成蓝底白勾，弹到 1.2 倍再落回（320ms），约 460ms 后收回卡片，卡片转为已读色。推一半就松手，圆片消失、正文回弹，什么都不发生。
- 下拉关闭：内容已在顶部时继续下拉，弹层和工具胶囊一起跟手下移，遮罩随距离变淡。拉过弹层高度约五分之一（或快速一甩）就滑出屏幕关闭，不再缩回卡片；没拉够就回弹。全屏阅读下拉、右滑都直接回信息流。
- 惯性不算手势：滚轮或触控板一路惯性滚到底部或顶部时，不触发收起和关闭。必须在边缘停一下，或者持续用力推拉，才开始计数。
- 被拖走的弹层离开屏幕后就保持离开，等关闭完成后再清理，中途不能复原，否则会闪一下。
- 跟手的做法（照 MobileProto）：手势只负责设目标位置，过渡交给 CSS（抽屉曲线 `ease-sheet`，360ms）。滚轮一格一格来也会连成一条线，中途改方向从当前位置接着走，不会跳。手指按在屏幕上时关掉过渡，让表面严格贴手。惯性只会让边缘轻轻让一下，不会关闭。
- 手机预览是抽屉：从底边升起，停在离顶 64px；往下读就铺满全屏、圆角收起；在顶部下拉先退回半屏，再拉 110px 才关；Esc、点遮罩、拖把手过 190px 都是滑回底边关闭。往下读时底部胶囊让开，往回翻或读到底再出现。电脑上使用轻量淡入淡出。
- 按下卡片时缩到 0.97（120ms），表示它可以被拿起。
- 关掉了就停下：收起或关闭之后，触控板残余的惯性不再滚动信息流。弹层内关闭浏览器自带的回弹，只留自己的跟手。
- 系统开启「减少动态效果」时，所有动效改为 `dur-reduced` 淡入淡出。

## 底部轨道与反馈

- 底部只有一条轨道，以右下角入口球为锚点。所有底部浮层与入口球同一底边、同一行高 56、同一种玻璃，排在入口球左边。
- 入口球左边一格同一时间只放一样：多选条，或「↑ 3」「未连接」提示。多选时提示让开。手机宽度下多选条占满整行，入口球暂时隐藏。
- Toast 只在两种情况出现：可以撤销的操作，以及失败或需要人处理的事。单张卡的收藏、稍后读、已读不弹 Toast，卡片自己的变化就是反馈。
- 可撤销的 Toast 5.5 秒后淡出，普通说明 3.2 秒后淡出；失败提示一直留着，带关闭按钮。Toast 在入口球左边；那一格被占用或弹层打开时，升高一行，不叠在别的浮层上。
- 拖动时底部不放任何东西。收藏、稍后读、标签三个目标出现在拿起卡片的位置下方，不挡住上面正在看的内容；下面放不下（靠近底边）时才放到上方。目标离指针一拳；靠近 28px 内自动吸附。
- 多选：电脑上 ⌘/Ctrl 点选、Shift 连选；手机上长按卡片不移动就松手即选中。已有选中时，轻点卡片就是选或取消，不再打开。多选条有「全选」，按 Esc 或 ✕ 退出。
- 选中时每张卡右上角的「…」换成选择圈：空圈未选，蓝底白勾已选。卡片内容不移动。
- 刷新：入口球外一道细弧转动；完成后细弧闭合，球上短暂出现勾（约 0.9 秒）再消失。不写「已是最新」。

## 预览与叠放

- 同一张卡在信息流和预览里用同一个头部和同一套动作文案。具体动作（「稍后 10 分钟」「完成」「恢复」）在两处都是文字按钮，放在内容下方；通用动作（收藏、标签、不再提醒、关闭）在预览工具条里用图标。
- 提醒没有时间时，头部只写「提醒」，不显示 `meta` 等状态文字。关联卡下面列出了引用卡，头部不再写「来自 N 张卡片」。
- 在预览里打开引用卡时叠放：新卡盖在上面，下面那张露出顶边，点顶边回到下面那张。
- ✕、Esc、下拉、浏览器返回每次只关最上面一张；点遮罩一次全部关闭。

## 量大与时间

- 同一来源一小时内超过 5 张，自动叠成一摞，像一副牌：一篇一张完整的卡，位置写在每张卡右上角（「2/6」）。左右翻看时移动的是整张卡，不是卡里的文字：最上面一张跟手走、带一点倾斜，下一张从下面浮起；松手过三分之一或快速一甩，上面那张整张飞出；往右拖是上一张从左边盖回来；不够就弹回。手指、鼠标拖动、触控板横扫、方向键都可以。卡在手里或飞出时压在旁边的卡上面。点按或回车才在原地展开整摞，拖动结束不算点按。
- 同一篇内容从多个来源进来时合并成一张卡，头部叠放来源图标。
- 读过的卡片每天淡一点；一周后收进「读过的」，两周没碰的收进「放了很久」。只收起，不删除，搜索永远找得到。

## 图标

- 24×24 线性图标，round cap 和 join，颜色跟随 `currentColor`。三档：S16 描边 2.0、M20 描边 1.8、L24 描边 1.65。
- 一个图标只表达一个意思：入口用网格，设置用齿轮，稍后读用眼镜，延后用时钟，提醒用铃铛，免打扰用划线铃铛，导航用 chevron。
- 不用 emoji，不用 icon font，不用品牌标志；来源用通用图标加来源名表示。

### 文字和图标只用一种

一个控件要么只写文字，要么只放图标，不要两样同时出现，表达同一个意思。

- **文字按钮不带图标**：「回复」「加入」「去原文」「在浏览器中授权」「放回桌面」只写字。不加 ↗ 外链箭头，也不加前置图标。
- **图标按钮不带文字**：工具栏、全局工具、关闭、全屏只放图标，含义写在中文 `aria-label` 里。
- **菜单项、设置分类、筛选胶囊、引导页选项**：只写文字。
- **允许同时出现的情况**：图标和文字说的是两件不同的事。比如卡片头部「来源类型图标 + 来源名」、附件「文件类型图标 + 文件名」、引用行「卡片类型图标 + 标题」。图标表示类型，文字是具体名称。
- **输入框**：前置的搜索放大镜可以和占位文字同时出现，它标的是输入框的类型，不是按钮的含义。
- 判断方法：遮住图标，文字是否已经把意思说全？说全了，图标就是重复，应该去掉。反过来，遮住文字也一样。
- `assets/Icons/` 的 64 个 SVG 由 `apps/web/atoms/icons.ts` 生成，和页面实际使用的一致；与设计画布第 13 块新图标集的逐个对照尚未完成。

## 使用组件

- 组件是原生 HTML 字符串函数（`window.Sill`）。先加载 tokens.css，再加载 `components/bundle.css`。
- 新增的 CardBlocks、StackCard、KeyPoints、ReadEndRing、SourceRow 目前是静态示例，直接用令牌变量写成，还没有进 bundle。
