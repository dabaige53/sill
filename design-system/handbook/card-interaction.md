# 卡片预览、叠放与时间

## 预览与叠放

- 抽屉打开后固定背景并保留滚动位置，关闭后还原。内容用原生惯性滚动，不显示滚动条但保留键盘滚动；触摸跟手不加过渡。到顶后继续下拉移动整张抽屉（见「下拉关闭」）；到底后开启「读完上推收起」时由读完圆片接管，关闭时只有轻微阻尼（最多 14px）。灰色把手是独立拖动区：上拖展开，下拖收起，拖过 160px 不论全屏与否直接关闭；取消触摸恢复原尺寸，松手才播放回位动效。
- 顶部显示来源、内容日期与结构化预计阅读时长，过长截断。预计时长统一显示「约 N 分钟阅读」，已有内容范围显示「当前内容约 N 分钟阅读」，缺失或清除时不显示。来源、发布方和作者按卡片类型合并显示，不把来源当成作者。标题下放标签，再进入摘要和正文。内容日期在卡面、预览和阅读页均显示「今天」「昨天」「10/18」，跨年带年份；只在来源行出现一次，不加「发布于」前缀。具体见[卡片日期](web-interaction.md#卡片日期)。来源备注只用于补充不同的信息，内容写入时避免重复出处和日期；界面保留已有备注，不自动解析或删除文字。个人备注仅来自个人状态 note，信息流卡片不显示；预览和放大阅读页均在正文末尾用同款轻边框区显示，并标记「备注」。卡片 meta 与文件 meta 不再使用，不推断成备注。沿用正文区现有段间距，不额外叠加顶部留白；读完手势的尾部空间放在信息区之后。两者均无值时不渲染信息区；内容时间信息不添加背景、边框或折叠按钮；个人备注使用上一条规定的边框。资讯没有发布时间时依次使用保存日期、卡片时间；其他类型缺失时不补造日期。完整时刻保留在日期提示中；收录、保存和更新时间不另设信息行，原始数据保留；业务专用备注保持原位置。
- 抽屉按实际内容决定高度；短内容不撑满屏幕，长内容初始最多占用可视高度减 64px，正文在抽屉内滚动。手机向下阅读时，外框连续扩展到全屏，正文保持字号和阅读位置；主屏幕 PWA 不显示放大按钮，沿用滚动扩展。顶部安全区和底部工具条须避开正文。
- 标签放在标题下面，用较小的非交互标签；来源头部承载来源、内容日期和预计阅读时长，来源备注在正文末尾。打开与关闭都有动效；

- 同一张卡在信息流和预览里用同一个头部。正文里不放色块按钮；只有「为什么看到」和交给助手这类文字链接留在内容末尾（[ADR 0037](../../docs/adr/0037-card-detail-toolbar.md)，`CardDetail` 画板）。
- 操作都在底部玻璃胶囊里，只用图标：左边是通用操作「收藏、标签、稍后读」，`ink`；一条竖线之后是这张卡片自己的操作，最多 3 个，`accent`。邮件「回复」；文章、视频、播客「去原文」；提醒和待办「在 Sill 内再提醒」、「忽略此提醒」。日程已显示「加入」时，顺序为「加入、在 Sill 内再提醒、忽略此提醒、下载日程」；没有显示「加入」时仍为「在 Sill 内再提醒、下载日程、忽略此提醒」。先排除不可用和被用户隐藏的操作，再取前三个，因此下载可在前面操作隐藏后补位（[ADR 0040](../../docs/adr/0040-event-reminder-priority.md)）。一边为空时不画竖线；全部隐藏时不显示胶囊。
- 名称写在 `aria-label`。触屏长按 0.45 秒在图标上方显示名称（`ink` 底、`card` 字），这次按下不执行；鼠标首次悬停 0.5 秒显示；提示出现后，800ms 内移到相邻工具立即显示名称，不重复入场。
- 手机六项操作的按钮尺寸与间距见[内容布局手册](content-layout.md#手机操作胶囊)。
- 提醒的「完成」是标题前的圆圈，和卡面同一个控件，只改 Sill；完成后再点恢复。胶囊里的「在 Sill 内再提醒」也只改 Sill，不改来源时间。
- 照片大图页在缩略图下放通用操作胶囊：收藏、标签、稍后读，遵守隐藏偏好，不增加专属操作。照片固定黑底，胶囊在两种主题下均复用现有深色变量。胶囊参与排版，不覆盖照片、缩略图或助手交接；保存或取消标签后回到原照片（[ADR 0041](../../docs/adr/0041-photo-shared-toolbar.md)）。
- 设置「卡片操作」每行在名称下方显示 muted 灰字示例：通用三项为所有卡片，回复为邮件，去原文为文章、视频等，加入和下载为日程，再提醒和忽略为待办、日程、提醒。复用现有 small 行样式；示例不改变开关名称、顺序、隐藏偏好或动作可用条件（[ADR 0042](../../docs/adr/0042-card-action-type-examples.md)）。
- 设置「桌面」页的「卡片操作」可以关掉任何一个操作（偏好 `hiddenActions`）。关掉只影响显示，功能和 MCP 不受影响。
- 胶囊在卡片内部底边上方，下面有滚动边缘。手机上正文最后一行到胶囊 26px，胶囊到底边 `max(8px, 安全区)`；读到底时内容、备注、标签和文字链接都在它上方完整露出。
- 关闭和全屏浮在来源行右侧：macOS 26 及以上使用原生玻璃圆片，Web 使用白色圆片，与来源行（发件人、来源名、日期）居中对齐，不占一条白带；标题占满宽度。没有来源行时对齐标题首行。往下读时和工具条一起收起，停下时回来，下面垫一层渐隐，不压正文。阅读页右上是退出全屏和关闭阅读的玻璃按钮组。
- 普通卡片详情的桌面左右内边距为 30px（`space-30` / `previewPaddingX`），预览与全屏一致；全屏内容占满剩余宽度，不另设居中正文宽度上限。资讯采用相同的 30px 左右内边距，不再设置 600px 正文宽度上限。手机保留现有窄屏内边距。
- 详情和阅读页里没有头像、设置或底栏。
- 提醒没有时间时，头部只写「提醒」，不显示 `meta` 等状态文字。关联卡下面列出了引用卡，头部不再写「来自 N 张卡片」。
- 在预览里打开引用卡时叠放：新卡盖在上面，下面那张露出的顶边只作层级提示，不接收操作。手机内嵌卡片继承当前抽屉高度或全屏状态；子卡展开后返回，父卡也保持全屏，不因内容长短改变外框。关闭当前卡返回上一张；详情打开期间，背景卡片不接收点击、焦点或拖动。
- Web 桌面与 Mac 不支持下拉关闭详情；手机保留。✕、Esc、手机下拉、点遮罩、读完上推、浏览器返回每次只关最上面一张，露出下面那张（[ADR 0046](../../docs/adr/0046-backdrop-closes-one-stacked-card.md)）。

## 量大与时间

- 同一来源一小时内超过 5 张，自动叠成一摞，像一副牌：一篇一张完整的卡，位置写在每张卡右上角（「2/6」）。左右翻看时移动的是整张卡，不是卡里的文字：最上面一张只平移跟手走，下一张从下面显露；松手过三分之一或快速一甩，上面那张整张飞出；往右拖是上一张从左边盖回来；不够就弹回。手指、鼠标拖动、触控板横扫、方向键都可以。卡在手里或飞出时压在旁边的卡上面。点按或回车才在原地展开整摞，拖动结束不算点按。
- 同一篇内容从多个来源进来时合并成一张卡，头部叠放来源图标。
- 读过或完成的卡片只改变颜色，始终保留在主页；时间流逝、阅读完成、任务完成、提醒完成或免打扰都不能自动收起卡片。只有明确归档才移出主页；保留已有真实归档状态。完成任务或提醒后保持当前顺序，后台保存、加载更多和切换分栏不重排；用户主动刷新或更换排序方式后再重新排序。
