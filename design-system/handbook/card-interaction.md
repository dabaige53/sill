## 预览与叠放

- 手机 Web/PWA 详情使用 Vaul：打开后固定背景并保留滚动位置，关闭后还原。打开直接到内容所需高度，正文用原生惯性滚动；正文到顶后下拉交给 Vaul 关闭或回位。使用 Vaul 原生把手拖动关闭；点击关闭按钮关闭详情。开启「读完上推收起」时，全屏正文底部仍由读完圆片接管。
- 手机详情按正文高度适配，至少 70dvh，长内容最多到顶部安全区下方 24px；底部留 12px 黑边，不设置中间停靠点，外层位移使用 Vaul；正文宽度与字号保持，底部工具栏保留在可见区域。PWA 不显示放大按钮。顶部安全区和底部工具条须避开正文。桌面预览仍按内容决定高度。
- 标签放在标题下面，用较小的非交互标签；来源头部承载来源、内容日期和预计阅读时长，来源备注在正文末尾。打开与关闭都有动效；

- 同一张卡在信息流和预览里用同一个头部。正文里不放色块按钮；只有「为什么看到」这类文字链接留在内容末尾；Codex 插件详情、全屏阅读、媒体与照片页不显示「附到对话」按钮或空占位（[ADR 0037](../../docs/adr/0037-card-detail-toolbar.md)，`CardDetail` 画板）。
- 名称写在 `aria-label`。触屏长按 0.45 秒在图标上方显示名称（`ink` 底、`card` 字），这次按下不执行；鼠标首次悬停 0.5 秒显示；提示出现后，800ms 内移到相邻工具立即显示名称，不重复入场。
- 点「标签」时，标签与备注以浮层叠在当前内容上：卡片详情、阅读页、照片、搜索页或主页都不切换、不重开。Web 桌面为居中窄面板，淡入淡出；手机为贴底面板，和卡片抽屉同样用 `dur-sheet`、`ease-sheet` 从底部滑入、滑出，并随键盘上移；下层保留内容、滚动位置和播放器，只多一层暗底。保存、✕、Esc、点暗处只关闭浮层，保存后下层详情原地显示新标签和备注；下层详情关闭时浮层一起关闭（[ADR 0090](../../docs/adr/0090-tag-layer-and-rounded-action-icons.md)）。
- 手机六项操作的按钮尺寸与间距见[内容布局手册](content-layout.md#手机操作胶囊)。
- 提醒的「完成」在卡面显示于标题前，在详情显示于标题右侧；两处是同一个控件，只改 Sill；完成后再点恢复。在提醒详情中完成或恢复时，保持当前抽屉、滚动位置和操作焦点，不自动关闭；由用户主动关闭。胶囊里的「在 Sill 内再提醒」也只改 Sill，不改来源时间。
- Web/PWA设置「桌面」页不提供「卡片操作」隐藏开关。旧`hiddenActions`字段仅为兼容保留，不影响Web/PWA动作显示；Mac尚待同步（[ADR 0076](../../docs/adr/0076-review-detail-ai-and-phone-search.md)）。
- 胶囊在卡片内部底边上方，下面有滚动边缘。手机上正文最后一行到胶囊 26px，胶囊到底边 `max(8px, 安全区)`；读到底时内容、备注、标签和文字链接都在它上方完整露出。
- 关闭和全屏浮在来源行右侧：macOS 26 及以上使用原生玻璃圆片，Web 使用白色圆片，与来源行（发件人、来源名、日期）居中对齐，不占一条白带；标题占满宽度。没有来源行时对齐标题首行。往下读时和工具条一起收起，停下时回来，下面垫一层渐隐，不压正文。阅读页右上是退出全屏和关闭阅读的玻璃按钮组。
- 普通卡片详情的桌面左右内边距为 30px（`space-30` / `previewPaddingX`），预览与全屏一致；全屏内容占满剩余宽度，不另设居中正文宽度上限。资讯采用相同的 30px 左右内边距，不设置 600px 正文宽度上限。手机保留现有窄屏内边距。
- 详情和阅读页里没有头像、设置或底栏。
- 提醒没有时间时，头部只写「提醒」，不显示 `meta` 等状态文字。关联卡下面列出了引用卡，头部不写「来自 N 张卡片」。
- 在预览里打开引用卡时叠放：新卡盖在上面，下面那张露出的顶边只作层级提示，不接收操作。手机内嵌卡片继承当前抽屉高度或全屏状态；子卡展开后返回，父卡也保持全屏，不因内容长短改变外框。关闭当前卡返回上一张；详情打开期间，背景卡片不接收点击、焦点或拖动。
- Web 桌面与 Mac 不支持下拉关闭详情；手机保留。✕、Esc、手机下拉、点遮罩、读完上推、浏览器返回每次只关最上面一张，露出下面那张（[ADR 0046](../../docs/adr/0046-backdrop-closes-one-stacked-card.md)）。

## 量大与时间

标签面板不显示卡片标题、操作提示或保存位置说明，保存区只有右侧「保存」，标签输入框避开右上角关闭按钮。手机打开面板时不聚焦、不弹键盘，点标签输入框才弹出，面板本身持有焦点、关闭按钮不显示焦点框；点候选标签或删除标签不改变键盘状态。备注始终是输入框，不做折叠：桌面在面板内直接输入；手机显示为一行输入框，有内容时显示前两行，没有时显示占位文字，点按后面板用 `dur-sheet`、`ease-sheet` 升到可见高度，备注页从右侧滑入并弹出键盘，「完成」带着草稿回到标签，「保存」一起写入。键盘弹出后面板使用实际可见高度，输入与候选内容在面板内滚动，保存区独立保留。增删标签时保留输入草稿、备注草稿、焦点与滚动位置。

邮件外链直接打开已保存的网页，不增加回复字段或邮箱路由。来源按钮使用普通 HTTPS 链接，独立网页交给系统处理，嵌入宿主使用已有 openLink。符合来源 App 规则的链接可以由系统打开对应 App，网页地址同时作为未安装时的访问入口。

PR 卡面与详情在编号后紧跟同一快照时间（「仓库 #编号 · 时间」），完整时间及含义放在提示中，不显示「记录于」前缀；右侧只放状态。长仓库名先省略，不挤掉编号和时间。正文保留已有内容，不由界面猜测并删除原标题或作者。

- 同一来源一小时内超过 5 张，自动叠成一摞，像一副牌：一篇一张完整的卡，位置写在每张卡右上角（「2/6」）。左右翻看时移动的是整张卡，不是卡里的文字：最上面一张只平移跟手走，下一张从下面显露；松手过三分之一或快速一甩，上面那张整张飞出；往右拖是上一张从左边盖回来；不够就弹回。手指、鼠标拖动、触控板横扫、方向键都可以。卡在手里或飞出时压在旁边的卡上面。点按或回车才在原地展开整摞，拖动结束不算点按。
- 同一篇内容从多个来源进来时合并成一张卡，头部叠放来源图标。
- 读过或完成的卡片只改变颜色，始终保留在主页。只有明确归档才移出主页；保留已有真实归档状态。完成任务或提醒后保持当前顺序，后台保存、加载更多和切换分栏不重排；用户主动刷新或更换排序方式后再重新排序。

Web 关联卡片行的悬停与按下不铺矩形底色、不加阴影；保留文字、分隔线、点击与键盘焦点提示。

手机关联卡片保留父抽屉，新卡片叠加其上；返回恢复原父层和滚动位置。手机触摸和鼠标按住拖动由 Vaul 接管，保留库默认滚动接管等待；读完上推保留。

手机抽屉与缩放后的背景共用 `sheet-radius`。背景圆角按 Vaul 的打开、拖动和松手进度变化，关闭回到无圆角，不使用库默认的 8px 与前层混搭。

电脑触控板双指与鼠标滚轮不拖动或关闭 Vaul 抽屉，保留正文滚动。手机触摸和鼠标按住把手／正文拖动使用 Vaul 原生位移、松手判断及回位；按钮关闭沿用原生退出动画。嵌套抽屉不覆盖 NestedRoot 的 onRelease，父层回位由库处理。

关闭详情后，鼠标和触屏不主动聚焦原卡片，并清除浏览器自动恢复到卡片内的焦点，不显示选中或焦点高亮；键盘返回保留焦点提示。
