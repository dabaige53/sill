# 内容布局

[返回设计手册](../README.md)。

## 间距与尺寸

- 卡片内边距 `card-padding` 18（手机 `card-padding-sm` 16），积木之间 `block-gap` 8，封面内缩 `cover-inset` 8。
- 信息流间距：手机 `gap-sm` 12、中等宽度 `gap-md`、桌面 `gap`；页边距对应 `margin-sm` 16、`margin-md`、`margin-lg`。
- 列数按 `col-ideal` 向下取整，并保证最小列宽 `col-min`；桌面不设四列上限，宽度足够时继续增加到五列、六列或更多。信息流列宽均分可用空间，两侧各留 12px，与顶栏对齐。
- macOS 新窗口默认宽 1512、高 760，标准密度下显示四列；已有窗口保留系统记录的尺寸，调整窗口后按可用宽度重新排列。
- 紧凑、标准、宽松的理想列宽分别为 280、340、400，取值见 `density`。桌面密度只改变列宽，标题、摘要、金句、速记和要点自然换行，卡片随内容增高，不限制行数；手机保留原截断规则。
- 卡面没有更多按钮，头部不为它预留空白。任务数量、进度、到期提示及发件人区域在悬停、聚焦、选中和菜单打开时保持位置与可用宽度不变。
- 待办与提醒的圆圈对齐文字首行中心，卡片、预览和阅读页使用同一规则；文字换行不改变圆圈位置。头像与两行元信息仍按整组居中。
- 归档列表的日期与恢复按钮共用位置，按两者较宽的内容预留空间；文件详情的名称与说明分别显示省略号。
- 所有可点击元素不小于 `hit-target`。例外：手机待办预览每项高 28，满足 WCAG 2.2 的 24 最小值；其中的圆圈向外扩到 44 宽。
- 资讯阅读：正文不限制最大宽度（`article-measure` none）；左右内边距 `article-gutter` 30（手机 `article-gutter-sm` 20），使用剩余可用宽度。段间距 16，标题下方 24，来源行下方 14，列表项间距 6，引用左侧 2px 细线、缩进 18。不缩放整页。
- 圆角：卡片 `card-radius` 22（手机 `card-radius-sm` 16）、封面 `cover-radius` 14、弹层 `sheet-radius` 28、面板 `panel-radius` 24、控件 `control-radius` 12、胶囊 `pill-radius` 999。CSS 变量与令牌同名，例如 `--cover-radius`。

## 内容排版偏好

设置的「外观」提供卡片与阅读两组排版选项。主题与卡片宽度保留；文字加重作用于卡片与阅读内容，导航、按钮和设置文字保持原尺寸。

| 选项 | 档位 | 取值 |
| --- | --- | --- |
| 卡片、阅读文字大小 | 小、标准、大 | 当前字号与行高的 0.94、1、1.12 倍；分别保存 |
| 卡片间距 | 紧凑、标准、宽松 | 当前断点间距的 0.75、1、1.25 倍 |
| 卡片内部留白 | 紧凑、标准、宽松 | 当前内边距与积木间距的 0.75、1、1.25 倍 |
| 阅读行段间距 | 紧凑、标准、宽松 | 行高为当前的 0.9、1、1.12 倍；段间距为 0.75、1、1.25 倍 |
| 阅读正文宽度 | 窄、标准、铺满 | 全屏阅读区域上限 640、800、无限制；窄窗口继续适应可用宽度 |
| 文字加重 | 标准、加重 | 正文 400→500，控件文字 500→600，标题 600→700；保留层级 |

数值维护于 `tokens/apple.json` 的 AppleMetrics：layoutTextSmall／Large、layoutSpaceCompact／Roomy、layoutLineCompact／Roomy、layoutReaderNarrow／Standard，Web 读取同一来源。默认文字、间距均为标准，正文宽度为铺满，旧数据缺少字段时采用默认值。

设置仅显示配置项，不放排版示例或说明段落；修改应用到实际卡片与阅读正文，并沿用工作区保存后的更新。恢复默认排版以一次偏好写入重置以上选项和卡片宽度，保留主题及其他设置。偏好沿用工作区保存与冲突检查，可由 MCP 的 preferences.patch 调整。字体家族、圆角、颜色、玻璃和动效不提供新的配置项。
