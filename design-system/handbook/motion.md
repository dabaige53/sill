# 动效

[返回设计手册](../README.md)。

## 共用规则

动效表达按压、空间位置和真实状态。Web 与 macOS 使用相同的操作含义；平台使用各自的绘制方式。键盘切换叠卡与打开、关闭菜单立即完成。

每个表面只由一个动画控制。新操作从当前绘制的位置和透明度接续，并取消旧动画；取消不能触发旧完成回调。退出结束后才清理表面。拖动期间直接跟手，每帧最多绘制一次，尺寸在开始时读取。松手回弹使用临界阻尼弹簧，接收释放速度，不缩放正文、不动画化宽高。

| 交互 | 唯一规则 |
| --- | --- |
| 按压卡片 | `dur-press` 120ms，缩至0.97 |
| 菜单 | `dur-menu` 180ms，从卡片右上角下方0.92倍浮出；关闭120ms，从当前状态淡出 |
| 桌面详情 | `dur-open` 220ms，上移10px淡入；`dur-close` 160ms，下移4px淡出 |
| 手机抽屉打开 | `ease-sheet`，`dur-sheet` 360ms，从底部升起，初始离顶64px |
| 内容下拉关闭 | 位移达到 `gesture-dismiss-distance` 110px，或最近100ms向下速度超过0.5px/ms且位移超过40px；松手提交 |
| 把手 | 上拉40px展开，短下拉40px收起；下拉160px关闭；取消恢复原尺寸 |
| 阅读右滑 | 位移超过屏宽30%，或最近100ms向右速度超过0.5px/ms且位移超过40px；松手提交 |
| 松手回弹 | 临界阻尼，角频率 `gesture-spring-frequency` 24/s；继承释放速度，当前位置可再次接管 |
| 卡片重排 | `layout` 220ms，只平移；宽度一次确定，文字不缩放 |
| 内容更新 | `fast` 淡入；连续更新接续当前透明度，不重复闪回全透明 |
| 工具条 | 下滚28px隐藏，上滚14px、停下650ms、到边缘或键盘聚焦恢复；隐藏180ms，出现220ms |

默认曲线 `ease` 为 `cubic-bezier(0.23,1,0.32,1)`；抽屉 `ease-sheet` 为 `cubic-bezier(0.32,0.72,0,1)`。参数来自设计变量，不在组件里维护另一组值。Mac叠卡整卡跟手，首尾阻尼不循环；松手沿用duration 0.5、bounce 0.2。

## 提交、取消与导航

- 下拉、右滑和读完上推在触摸移动时只预览结果，松手才提交；系统取消、多指打断恢复表面、遮罩和工具条，不刷新、不完成、不关闭。
- 触控板没有松手事件：达到阈值后停手或开始惯性才提交。普通滚动的惯性不发起新操作；关闭后的残余惯性不滚动主页。
- 读完上推：到底不显示提示，继续上推显示40px圆片和进度弧。达到120px只表示准备完成；松手后写入已读，蓝底白勾确认320ms，460ms后关闭当前层。未达标或取消则恢复原位。
- 关联详情的关闭按钮、Esc、遮罩、下拉和读完动作每次只退出最上层，恢复上一张卡片的阅读位置。普通全屏阅读退出后恢复主页。
- 打开后立即关闭、关闭中重开、回弹中重新拖动，都以最后一次操作为准。离场动画完成后关闭，不用固定延时猜测离场结束。旧面板回调不得关闭新面板。

## 其他组件

- 卡片菜单打开时卡片保持原位，菜单独立淡入；关闭后继续卡片原时间线。菜单靠近底栏时向上避让。首个鼠标提示等待500ms，同工具条连续提示立即显示，键盘提示立即显示。
- 仅首屏卡片上浮10px，前十张按30ms错开；滚动加载不播放入场。速记、归档恢复、筛选新增卡片从上方落下；移出卡片先停止接收操作，再淡出，其余卡片补位。
- 普通边缘滚动使用最多14px阻尼反馈，滚轮目标通过抽屉曲线连续过渡；触摸直接跟手。正文下拉关闭不叠加边缘反馈。
- 手机阅读滚动后展开至全屏；松手改变展开尺寸时一次确定高度，不过渡height、max-height或圆角。
- 下拉刷新由应用处理。圆环临时替换手机顶栏标志，达标后松手才请求；等待超过1秒先让卡片归位，圆环仍表示真实请求。成功短暂勾选，失败保留重试入口；完成后恢复标志。
- 搜索结果、图片翻页、多选条与状态提示使用短淡入；输入框、焦点和滚动位置保留。隐藏开始即停止接收操作，快速恢复取消旧退出。
- 加载短于 `delay-loading` 不显示加载态；骨架按真实高度；封面使用主色块后淡入，不动画化模糊半径。
- 播客尚无内置音频播放能力；播放和跳转不可用，提示前往来源收听。保留已有进度展示，不通过计时器模拟播放或写入已读。

项目不提供专门的无障碍设置或系统偏好适配，包括减少动态、减少透明度和增强对比度。保留正常键盘、焦点恢复、图标名称和原生控件语义。所有用户使用以上同一套动效规则。

已有存档中的旧偏好字段只作兼容读取，不产生界面效果；不修改历史迁移或用户存档。
