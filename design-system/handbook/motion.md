# 动效

[返回设计手册](../README.md)。

## 共用规则

动效表达按压、空间位置和真实状态。Web 与 macOS 使用相同的操作含义；平台使用各自的绘制方式。键盘切换叠卡与打开、关闭菜单立即完成。macOS 本轮对齐 Web，已有 reduceMotion 分支暂留；新增动效不增加该分支。

Web 自定义动效由 Motion 统一控制，CSS 表达静止状态；桌面搜索及底部 AI 输入胶囊材质层的悬停与聚焦反馈由 CSS opacity transition 单独控制（见网页交互手册），不与 Motion 共管该层；手机详情的 Vaul 动效与生命周期交给库自身管理。Vaul 背景的圆角变量列入库的过渡属性，时长、曲线和拖动时的即时更新仍由库控制，不另设一套 CSS 动画。Web桌面普通详情的边缘反馈交给浏览器原生滚动，不叠加Motion位移。每个表面只由一个动画控制。新操作从当前绘制的位置和透明度接续，并取消旧动画；取消不能触发旧完成回调。退出结束后才清理表面。拖动期间直接跟手，每帧最多绘制一次，尺寸在开始时读取。手机非 Vaul 表面如仍绑定自定义正文回位，使用motion.contentReboundSpring；首页刷新使用motion.pullRefresh，其他手势保留motion.edgeSpring，不互相覆盖。不缩放正文、不动画化宽高。

| 交互 | 唯一规则 |
| --- | --- |
| 按压卡片 | `dur-press` 120ms，缩至0.97 |
| 手机主页回顶 | `motion.homeReturn`：220ms 起，每屏增加 60ms，上限 500ms，`cubic-bezier(0.23,1,0.32,1)`；距离越远平均速度越快，不叠加模糊。300ms 内双击底部主页图标，到顶后交给已有刷新反馈；新输入中断时不执行待刷新动作 |
| Mac 卡片菜单（Web/PWA 已删除该菜单） | `dur-menu` 200ms，从卡片右上角下方0.95倍浮出；关闭 `dur-menu-close` 160ms，从当前状态淡出。Mac 右键时从指针处向右下浮出，靠近窗口右缘向左、靠近底部或 AI 框向上，离窗口边缘不小于 8；没有指针时（VoiceOver）从卡片锚点打开 |
| 桌面卡片详情 | 有可见来源卡片时，按位置和尺寸展开、收回；展开与收回用同一个弹簧 mass 1、stiffness 274、damping 30（`motion.cardSpring`）。无来源时保持 `dur-open` 280ms / `dur-close` 220ms 的10px淡入淡出 |
| 详情放大与缩小 | 从当前绘制的详情外框接续到全屏或预览尺寸，使用 `motion.cardSpring`；保留同一阅读层与返回关系，键盘即时完成 |
| 手机抽屉打开 | Vaul，`motion.phoneDrawer`：内容自适应（70dvh 起，最多接近满屏），底部黑边 12px，无中间停靠点，500ms、`cubic-bezier(0.32,0.72,0,1)`；保持不透明，遮罩同步，底页完整可视区域缩放与圆角联动 |
| 内容下拉关闭 | 位移达到 `gesture-dismiss-distance` 110px，或最近100ms向下速度超过0.5px/ms且位移超过40px；松手提交 |
| 资讯与媒体预览切换放大 | `motion.expandedSpring`：mass 1、stiffness 274、damping 27；正文不缩放，外框完成后内容与工具在目标位置以 detailFade 120ms 淡入，键盘即时。放大期间保留预览的遮罩，阅读页底色等外框铺满后再接替 |
| 手机详情把手 | Vaul Handle 控制下拉关闭和回位，不附加点击关闭行为 |
| 阅读右滑 | 位移超过屏宽30%，或最近100ms向右速度超过0.5px/ms且位移超过40px；松手提交 |
| 松手回弹 | Motion 弹簧；继承释放速度，当前位置可再次接管 |
| 详情下拉关闭 | 仅手机保留，Vaul 沿底部不透明滑出，遮罩同步；按钮也经同一退出路径，键盘即时关闭。Web 桌面与 Mac 不通过下拉关闭详情 |
| 卡片重排 | 桌面使用 `layout` 220ms，只平移；宽度一次确定，文字不缩放。手机 Web/PWA 直接排版，不播放重排位移 |
| 内容更新 | `fast` 淡入；连续更新接续当前透明度，不重复闪回全透明 |
| 工具条 | 下滚28px隐藏，上滚14px、停下450ms、到边缘或键盘聚焦恢复；隐藏 `dur-tuck` 240ms，Web桌面主页顶栏与详情顶部工具恢复 `dur-top-reveal` 560ms，其他工具恢复 `dur-reveal` 420ms；均用 `ease-reveal` |

默认曲线 `ease` 为 `cubic-bezier(0.23,1,0.32,1)`；抽屉 `ease-sheet` 为 `cubic-bezier(0.32,0.72,0,1)`。参数来自设计变量，不在组件里维护另一组值。Mac 叠卡只平移，不倾斜；Web/PWA 叠卡跟手倾斜并在离场时抛出，后卡补位；首尾没有下一张时保持原位，松手260ms平稳落定，不回弹。

## 实现要点

新增或修改动效时遵守以下做法。

- **磨砂玻璃不拆不藏。** 顶栏、导航胶囊、工具条等带模糊背景的表面，在页面切换时不用 `display: none`，也不反复隐藏再显示：重新出现的第一帧还没有模糊，会先露出底色，看起来像背景在加载。需要让开时，让新页面用更高层级盖住它（手机设置页盖住主页顶栏和导航），或只改透明度、不移除。
- **浮层不挤占所在行。** 建议列表等浮层出现时，不在所在行占位置，同行的其他元素（如 ⌘K 提示）位置不变。浮层的空容器和有内容的容器都不参与这一行的排版。
- **按住按键只算一次。** 系统按键重复（`KeyboardEvent.repeat`）不重复打开、聚焦或重绘；按住期间界面保持不动。
- **浮层内滚动不带动背后页面。** 浮层打开时，在输入行、输入行与浮层之间的空隙、浮层上滚动，背后页面都不动；浮层自己滚到头时拦下滚轮，并设 `overscroll-behavior: contain`。浮层以外照常滚动页面。
- **边缘归手势时，工具让开。** 某段边缘被手势占用时（开启「读完上推收起」且未读完时的最后 120px），随滚动出现的工具规则在这一段停用：到底和停顿都不叫回工具，往回滚照常出现。
- **滚轮手势按真实输入设计。** 鼠标滚轮一格一格滚，两次间隔常超过 40ms；触控板的力度也会忽大忽小。手势由主动发力开始后，后续同方向输入（包括惯性）都继续累计，停止输入后先保持一段时间（读完上推为 `pushHoldMs` 320ms）再回位。挡住惯性滑到边缘的条件只用于判断「开始」，不用于中途打断。
- **按钮关闭和手势关闭要比对。** 同一界面的 ✕、Esc 与手势关闭，要核对工具和背景在哪一帧回来；两条路径时机不同时，先确认用户看到的是哪一条，再统一。
- **多页面的同类元素共用一条规则。** 主页、AI、搜索、设置的页名等跨页面的同类元素，只写一份共用样式；改之前先量所有页面的实际位置与字号，不在各页各写一份。
- **计时规则用合成测试验证。** 间隔、停顿、回位时长，用合成测试推进时间来证明，并确认撤掉修复后测试会失败。浏览器面板隐藏时不出帧，不能拿来录动画。做法见[测试与验证](../../docs/implementation/testing.md#动效与计时)。

## 提交、取消与导航

- 下拉刷新、下拉关闭和右滑关闭在触摸移动时只预览结果，松手才提交；达标前系统取消、多指打断恢复表面、遮罩和工具条，不刷新、不完成、不关闭。
- Web 与 Mac 桌面鼠标在主页空白处按住下拉时，进度与内容逐帧跟手；停住不提交，达到阈值后松开左键才刷新。取消、窗口失焦或打开详情时回位；卡片拖拽、叠卡与按钮不进入刷新手势。按住鼠标时不使用滚动停顿计时提交；手机触摸规则不变。
- Web/PWA下拉刷新按下文「首页下拉刷新」处理；拉够只就绪，释放才请求，未达标、反向回到阈值内或打断只回位。pointer／touch使用真实释放事件，不套用wheel计时。
- 手机 Vaul 详情不绑定自写 wheel 下拉关闭，触控板双指与鼠标滚轮只滚动正文。其他仍绑定旧下拉手势的表面，以及独立的读完上推，在主动边缘操作达标时提交；上推立即写入已读和显示白勾，给予绘制机会后关闭。未达标wheel使用motion.wheelInput的40ms回位；读完上推例外：一旦在底部由主动发力开始，后续向下的wheel（鼠标逐格、力度起伏的触控板及其后续惯性）都继续累计，停止输入后保持 pushHoldMs 320ms 再回位；新序列间隔80ms，重新发力按超过1.25倍且增加2px判断。普通惯性抵达边缘不发起新操作；关闭保护仅处理同方向衰减尾段，40ms静默或新操作立即解除，最长240ms。Mac使用系统ended／momentum阶段。
- 读完上推：开启「读完上推收起」且尚未读完时，最后 120px 留给圆片：到底和在这段内停顿都不叫回工具胶囊与顶部工具，回滚 14px 照常出现；读完后到底恢复显示。到底继续主动上推显示40px圆片和进度弧，正文随上推距离60%移动，阈值120px。完成只一次，白勾不重新淡入，工具胶囊保持隐藏；wheel达标后进入关闭，touch达标后等真实松手。关闭从当前位移接续，不先回弹。Web/PWA背景列表更新统一延后到最终详情关闭后执行，不在关闭首帧前完整重绘；普通滚动到达底部的已读变化同样延后背景更新。
- 关联详情的关闭按钮、Esc、遮罩、下拉和读完动作每次只退出最上层，恢复上一张卡片的阅读位置。手机关联详情保持不透明，以 `dur-sheet` 和 `ease-sheet` 升起、滑出，不对整层淡入淡出。普通全屏阅读退出后恢复主页。
- 手机取消下拉或侧滑时，遮罩从当前深度在 `dur-sheet` 内恢复，抽屉同时回位，不立即跳回正常深度。手机阅读中的背景卡面更新延后到详情关闭后，已读状态仍立即保存。
- 打开后立即关闭、关闭中重开、回弹中重新拖动，都以最后一次操作为准。离场动画完成后关闭，不用固定延时猜测离场结束。旧面板回调不得关闭新面板。关闭动画被取消且仍停留在当前层时，解除禁止操作状态，恢复遮罩与工具。

## 正文边缘回位

Web桌面（宽度大于650px）html／body采用overscroll-behavior-y: auto，让页面边缘反馈交给浏览器。普通详情中，无读完上推圆环的sheet-scroll／reader-scroll使用overflow-y: scroll和overscroll-behavior-y: contain，保持滚动容器并阻止背景滚动；不绑定普通边缘wheel／touch拦截，不启动自定义正文位移或回位计时。原生效果由浏览器和系统决定，没有产品自定刚度、阻尼或时长。

手机仍绑定自定义边缘手势的非 Vaul 表面采用motion.contentReboundSpring：stiffness 600、damping 48、mass 1、restSpeed 2、restDelta 0.5。正文拉动幅度使用motion.edgeDrag的160／0.15阻力；保留现有布局、滚动视口和工具栏。Vaul 详情跳过这条绑定，不叠加普通正文回弹。

手机自定义回位的释放速度使用gesture-velocity-window 100ms内的可见位移，超过窗口没有新输入则归零；保持±750px/s上限与8ms最短样本间隔。松手从当前位移接续，不把停住前的速度再次加到内容上。wheel保留衰减释放和40ms静默回位，触摸使用真实释放；回位中重抓从当前绘制位置接上。出现读完上推圆片时，沿用独立的完成流程并关闭该容器原生回弹。手机根html／body仍为none，由自定义刷新和抽屉接手。见[ADR 0079](../../docs/adr/0079-content-edge-rebound.md)。

## 首页下拉刷新

- Web桌面普通滚动保留根auto的原生边缘反馈；明确进入下拉刷新时，wheel接手该序列并恢复main随动。body.is-pulling从拉动持续到卡片回位结束，期间根html／body暂为none，避免浏览器与Motion叠加位移。松手后按原刷新规则提交，卡片回位完成后恢复普通滚动的原生反馈。
- Web触控板刷新、鼠标按住空白拖动和PWA触摸／滚轮共用下列自定义位移、释放与反馈。圆环原UI、实际刷新请求与加载／完成展示规则共用；普通详情原生反馈保持独立。
- Web/PWA使用 `motion.pullRefresh`：内容位移为 `d × rubberDimension × rubber / (rubberDimension + rubber × d)`，rubberDimension 100（可见位移渐近上限100px）、rubber 0.7。内容和进度共用可见位移，threshold 64px才就绪，不再额外乘0.75，也不在80px处切换阻力。鼠标dragSlop为4px，启动后重设起点，触摸保持真实松手提交。
- 回位使用该参数的settle：stiffness 300、damping 34、mass 0.9、restDelta 0.1px、restSpeed 1px/s；保留向上释放速度，向下释放速度上限60px/s，不混用visualDuration。回位中再次拉动，从当前绘制位移反算输入基准。圆环保留原样式和标题区域锚点；无标题区域时沿用原回退位置，不迁移到卡片上方。
- wheel首个主动边缘事件只建立起点，后续增量完整累计后走同一阻力。wheel.decaySamples为3、decayRatio为0.5：连续3次衰减且幅度不大于本序列峰值50%时估计释放；否则以wheel.releaseIdleMs 80ms静默判断。单次减速不提交，重新发力重置衰减计数。该规则估计输入阶段，不等同于系统松手事件；惯性抵达顶部不能启动新下拉。
- 释放后内容立即回位，圆环单独表示刷新，不增加加载留白。motion.pullRefresh.feedback规定loadingMinMs 300ms、successHoldMs 400ms：先让加载旋转可见，再显示完成勾，最后以fast 140ms淡出；完成勾淡入期间不同时淡出整个圆环。请求立即开始，数据结果立即合入，展示计时不延后业务；实际请求未结束时继续加载，失败直接保留原位置重试，新下拉可中断已结束请求的反馈。按钮刷新保持内容原位，不复制演示布局或1200ms模拟请求；Sill始终可见。见[ADR 0078](../../docs/adr/0078-pull-refresh-resistance-and-release.md)。

## 其他组件

- 独立文字按钮、浅色按钮、会议入口和标签删除使用与主按钮相同的按压反馈：`dur-press` 120ms、`motion.pressScale` 0.97、默认 `ease` 曲线。任务与提醒只缩放圆圈，文字、点击区域和卡片保持原位；释放或取消时从当前位置恢复。操作不等待动画，禁用按钮不响应按压，键盘操作即时完成。筛选项与列表行保留原有变色反馈。

- 桌面卡片详情从来源位置展开，来源保留布局占位，关闭时重新读取来源位置。Web 使用 transform 和既有内容淡入规则。Mac 只移动并放大圆角外框：详情按最终尺寸布局一次，固定在外框左上角由外框裁剪露出，正文、原卡片外观、关闭与全屏圆片、底部胶囊和图标都不缩放；圆片与胶囊属于同一外框，随外框露出。原卡片外观与详情在几何进度 20%–75% 内交接，外框阴影随进度从卡片阴影过渡到详情阴影。Mac 关闭与 Web 相同，用展开的卡片弹簧收回，弹簧结束后交回真实卡片（[ADR 0062](../../docs/adr/0062-card-close-spring-and-read-end-release.md)）；关闭开始时胶囊与圆片用 `motion.detailFade` 120ms 先淡出，收回期间浮层不拦截点击，点另一张卡立即开始新的展开。来源不可见时淡出，快速反向操作保留当前过渡；键盘即时完成、手机与照片灯箱不变（[ADR 0058](../../docs/adr/0058-mac-card-reveal-transition.md)）。
- 桌面搜索框宽度随可用空间收缩。Web 固定宽 315px（`search-focused-width`），不播放聚焦或失焦伸缩，聚焦即显示卡片建议；Mac 伸缩尚待同步，见[网页交互](web-interaction.md#桌面顶栏与-ai-框)。输入立即显示，Mac 结果计算使用 `searchDelay` 180ms 合并连续输入；清空立即生效并取消旧计算。键盘聚焦即时完成。点击搜索框以外的任何位置即失去聚焦，点击照常作用于所点对象，搜索词与分栏标签保留。AI 输入框同样在点击框外时失去聚焦，草稿保留。
- AI 上下文卡片移除时用 `fast` 140ms 淡出，移除最后一张也一样。拖动的卡片堆松手后用 `fast` 淡出并缩到 0.95（`motion.menuScale`）。多选条与 AI 框/手机导航共享原底部位置：旧表面 fast 140ms 淡出并移动8px，随后新表面 dur-reveal 420ms、ease-reveal 淡入回位；退出开始即禁用操作，反向操作接续当前帧。
- Web 桌面分栏菜单鼠标打开180ms、关闭100ms，进入0.95至1、退出至0.98缩放，锚点位于分栏按钮；键盘即时完成。
- AI上下文引用在 fast 140ms 底部交接后，使用 motion.aiContext：进入位移500ms、淡入180ms；移除位移220ms、淡出140ms；其余条目补位280ms。Web位移4px、手机8px，ease-reveal，已有引用不重播，不改变导航时长。新加载封面在屏幕内且页面未被卡片抽屉盖住时以 `dur-reveal` 420ms、`ease-reveal` 淡入；屏幕外、抽屉下方加载的封面和缓存图片即时显示，已读透明度保持原值。
- Web/PWA 设置开关使用 `motion.webInteraction.toggleSpring`：visualDuration 0.3 秒、bounce 0.25；滑块平移20px，按压拉伸、支持拖动并在落点挤压，轨道与点击区域尺寸不变，不重播整页淡入。连续切换从当前绘制状态接续，键盘即时完成；媒体分段首次随面板显示，后续只让新旧文字140ms交叉淡入淡出，封面与渐变背景始终保持不透明度不变，未变化不重播。

- Web / PWA 取消单卡菜单和多选条右键菜单及其动画，保留普通分栏菜单。首个鼠标提示等待500ms，同工具条连续提示立即显示，键盘提示立即显示。
- 网页首屏卡片在数据排版后由整个卡片区以 `dur-reveal` 420ms、`ease-reveal` 一次淡入，不上浮、不逐张错峰；新加载的首屏封面同样淡入，缓存图片即时显示。滚动加载不播放入场；搜索输入更新结果时，留下的卡片保持位置与外观，只有新出现的卡片以同一时长与曲线淡入；后续归档恢复、筛选新增卡片保留既有到达反馈，移出卡片先停止接收操作再淡出，其余卡片补位。
- Web桌面普通详情按「正文边缘回位」使用浏览器原生反馈；手机非 Vaul 表面如仍绑定自定义边缘反馈，只移动滚动视口内的gesture-content，视口保持固定，阻力为motion.edgeDrag的160 × (1 − exp(−距离 × 0.15 / 160))，底部方向镜像。其释放使用motion.contentReboundSpring 600／48／1及最近100ms的px/s速度（限制±750）；同一属性只有一个控制者，面板替换或关闭时取消。Vaul 详情及存在读完上推圆片的容器不叠加普通边缘回弹。
- 手机向上滑动阅读时即开始展开至全屏，不等待松手或惯性停止；展开后外框占满当前可视区域。滚轮仍在停稳后展开。多指或系统取消后不再启动新的展开。内容按目标尺寸布局一次，外框以当前位置、可见高度与圆角裁剪接续，使用 `motion.expandedSpring`，由浏览器播放位移与裁剪，不逐帧改写 height 或 max-height。正文不缩放；安全区留白变化补偿阅读位置，顶部工具与把手接续当前位置，过渡期间暂停工具自动显隐。
- 阅读关闭手势只在方向明确后接管表面；普通点击不停止入场动画。播客详情固定横向位置，不通过整页右滑关闭；关闭按钮与下拉仍可使用。横向滚动的代码块、表格及媒体控件保留自身触摸操作，不发起阅读页关闭。连续触摸移动每帧最多绘制一次。
- Web/PWA下拉刷新由应用处理，规则见「首页下拉刷新」。手指按下时不读取尺寸，确认下拉后读取一次；圆环反馈至少300ms加载、400ms完成勾，不给真实请求或数据合入追加等待。
- 搜索与导航立即更新；照片翻页使用 `dur-deck` 260ms 按页吸附；多选条与状态提示使用短淡入；输入框、焦点和滚动位置保留。隐藏开始即停止接收操作，快速恢复取消旧退出。
- 后台加载短于 `delay-loading` 不显示加载态；骨架按真实高度；封面使用主色块后淡入，不动画化模糊半径。Web/PWA主动刷新圆环按motion.pullRefresh.feedback呈现；Mac现有反馈时长见「桌面阅读与刷新衔接」。
- Web/PWA 网页刷新时，主题在应用启动前确定，顶部栏和底部区域保持原位，不隐藏整个页面。首次数据读取短于 `delay-loading` 时，卡片区不显示占位；超过后以 `dur-reveal` 420ms、`ease-reveal` 淡入几张卡片形状的占位，占位以 1.6 秒周期在不透明度 1 与 0.55 之间缓慢呼吸，不可点击、不加文字。真实卡片在应用字号、间距并完成排版后，整个卡片区以 `dur-reveal` 420ms、`ease-reveal` 一次淡入，新加载的封面各自淡入；后台同步不重播首屏动画。云端首次会话检查返回前不显示登录入口；需要登录时占位保持到跳转登录页。下拉刷新沿用独立反馈流程。
- 视频详情使用来源平台的官方播放器；详情打开、放大或缩小的动效结束后才插入播放器框架，等待时显示封面，点播放会在播放器就绪后开始。播客详情是介绍页，不提供播放器，见[网页阅读](web-reading.md)。播放器的状态与进度来自实际播放，不用计时器模拟；阅读进度不能当作播放位置。无法播放时保留在来源打开。见 [ADR 0061](../../docs/adr/0061-in-app-media-playback-and-pr-cards.md)。
- 播客详情为介绍页：没有播放区收合、吸顶播放条、页签或文字稿跟随，打开与关闭沿用通用详情动效。
- 胶囊随滚动隐藏时轻移 20px 并在 `dur-tuck` 内淡出；恢复时在 `dur-reveal` 420ms 内轻移淡入（收起 `dur-tuck` 240ms），停止滚动同样过渡。隐藏开始就禁用点击和键盘焦点，软键盘出现时隐藏导航，不保留可点击残影。
- 离线提示和新内容/提醒数量提示在原位淡入淡出，轻移不超过 4px，不推移底部胶囊。隐藏开始即停止接收操作，动画结束才收起；快速恢复时取消旧退出动画，旧回调不能隐藏新提示。


保留正常键盘、焦点恢复、图标名称和原生控件语义。系统偏好分支的维护边界见[设计规范](../../docs/agent/DESIGN.md#跨端规则)。

已有存档中的旧偏好字段只作兼容读取，不产生界面效果；不修改历史迁移或用户存档。

## 桌面阅读与刷新衔接

- 阅读完成确认后等松手，再从当前位移直接关闭，不先单独回弹。保存失败只回位，不显示完成或关闭；页面离开后旧回调失效。
- Mac 不处理下拉关闭；侧滑移动整个详情表面，正文内部偏移只用于读完上拉和边缘阻尼。拖动时遮罩按关闭阈值渐淡至 30%，取消时与表面一起回位。
- Mac 主页在顶部下拉 48 后松手请求读取；不足阈值或取消则回位。刷新反馈最少显示 300ms，成功时内容先回位，勾选反馈保留 480ms 后原位淡出；慢请求 1 秒后释放内容偏移，失败保留可点击的重试入口。详情、设置、分栏菜单打开或拖动卡片时不启动主页刷新。
- Web 窗口尺寸变化启用已有的位置过渡与内容淡入；Mac 列数改变时过渡位置，卡片宽度改变时内容淡入。两端不缩放正文，保留当前 12px 外边距与列数规则。

## 桌面输入与动画协作

- 输入由当前最上层拥有：面板、阅读层、拖动、菜单、主页。打开面板暂停底层阅读手势，切换层后旧异步结果不得关闭新层。系统窗口和确认框优先于应用监听。
- 滚轮先处理结束、取消与惯性，再判断方向和位移；零位移结束也是有效结束。触控板以事件阶段收尾，普通鼠标才用 `gestureWheelRest` 120ms 超时。惯性隔离只拦截 momentum 事件，新主动滚动立即放行。
- 阅读完成反馈后直接收回；卡片收回使用动画完成回调卸载，工具胶囊保持隐藏。
- 玻璃容器默认只提供材质；内部按钮保留一套按压反馈。独立账户按钮使用原生交互玻璃，工具栏整体不随内部按钮点击一起缩放。
- 卡片测量缓存随子视图更新和列几何变化失效，不缓存跨内容变更的高度。窗口缩放不改变卡片字号和内部布局。


## Web 与 Mac 桌面卡片连续过渡

- Web 胶囊与卡片同一帧开始，沿卡片底边移动，保持底部间距；全屏层内对胶囊做反向缩放补偿，图标不被拉伸。Mac 胶囊在同一外框内随外框露出。过渡期间暂停滚动工具条的自动显隐，结束后恢复。
- 收回保持卡片外壳不透明。Web 在外壳内部，80ms 后开始用 140ms 淡入原卡片的展示副本（`motion.cardContentReturn`）；不是两张整卡同时变透明。副本在到达原位前已经可见，原卡片保持隐藏，到结束时同帧交回真实节点。
- 展示副本不可点击，不复制元素 ID 或卡片操作身份；取消时立即移除。来源不存在时沿用既有退出方式。
- 完成后的胶囊继续隐藏，不因轨迹动画恢复。手机同样保持正文当前位移，直接随抽屉滑出，不先回弹或恢复工具。
- Web 使用无交互的 DOM 副本；Mac 与真实卡片复用完整 CardFace 外观，来源和详情保持各自固定布局、不缩放，由进度驱动交接。底部渐隐、胶囊与关闭、全屏圆片置于同一圆角外框内，胶囊保留原生玻璃。真实窗口手感仍需体验确认。

桌面点击刷新或快捷键刷新不移动卡片；只有下拉操作保留内容跟手与松手回位。刷新按钮沿用按压反馈，加载、成功与失败图标使用 `fast` 原位交叉淡化；失败停留并可重试，忙碌时不重复请求。

Web 网页刷新时，Sill 与搜索栏所在顶部栏直接显示在原位，不播放首次入场。滚动触发的顶部栏收起与恢复保留。

Web桌面普通详情按「正文边缘回位」使用原生反馈；手机详情由 Vaul 统一接管停靠与下拉，停用该处旧普通回弹和自写 wheel 关闭。非 Vaul 表面仅在当前代码明确绑定时使用自定义边缘手势，不为统一效果重新接入。设置开关用真实`.toggle-knob`滑块承接可中断弹簧；头像与导航按压同用120ms／0.97。

网页首次数据加载不使用刷新手势反馈。顶部栏和底部区域保持原位；卡片区独立等待数据，超过 `delay-loading` 才淡入呼吸占位，真实卡片排版后整体一次淡入，新加载的封面各自淡入（[ADR 0089](../../docs/adr/0089-steady-content-arrival.md)）；后续同步不重播首屏，主动下拉刷新仍走独立反馈路径。

- 手势刷新：请求立即开始，释放后内容直接回位，不设置1秒内容悬停；圆环加载至少300ms、完成勾400ms后按fast 140ms退出，计时只控制反馈，不延后数据合入。新操作取消旧反馈与退出，Sill标题持续可见。工具栏停顿恢复450ms独立保留，完成与关闭带回工具时不走该等待；暂停期间清除累计滚动方向，不改变已保存的阅读位置。
- 点击任务与提醒：原节点更新圆圈、状态、计数及卡片完成色，详情不重建、不重新淡入；打开详情时的背景成员变化延后处理，提醒完成后抽屉保持打开。

### 工具栏共用节奏

Web/PWA 工具随滚动收起使用 `dur-tuck` 240ms。Web桌面顶栏独立恢复使用 `dur-top-reveal` 560ms；手机顶栏、底部轨道、AI 区和详情工具恢复使用 `dur-reveal` 420ms。恢复共用 `ease-reveal`。向下28px、回滚14px、停顿450ms的触发规则保持。关闭卡片带回主页工具仍跟随 `motion.cardSpring`，键盘立即完成；网页初次加载不播放顶栏入场。

## 状态之间的交接

- 任务勾选不重建详情、正文滚动与工具栏。收藏详情取消收藏时保持背景卡片，关闭详情后更新筛选列表。
- Web 文章/视频预览与全屏之间，使用与卡片展开相同的 cardTransform 和 cardSpring，放大与缩小均从切换前实际绘制位置变换到目标外框。正文按 detailContentDelay 100ms、detailFade 120ms 在运动中显示，目录同拍交接，工具沿用卡片进场与胶囊跟随；不再等待背景外框结束后另播正文淡入。视频在预览/全屏共用同一个媒体节点，不创建播放器副本。取消恢复透明度和操作能力。
- Web AI 使用 Anchored Collapse：气泡收到底部轨道中 AI 框的右端，展开从气泡右缘接回，并限制在轨道可用范围内；背景外壳以clip-path收窄或展开，文字/图标固定尺寸。motion.aiCollapse 收起260ms、展开300ms，cubic-bezier(0.32,0.72,0,1)，无过冲；旧内容100ms淡出，气泡图标在收起最后80ms出现，展开内容在最后120ms出现，各阶段并行。反向先读取当前裁切再取消旧动画；点击气泡时不提前结束仍在进行的收缩，只有开始实际拖动才结束原过渡。保留草稿、引用与原展开位置。
- 手机搜索点击/取消使用 motion.phoneSearch 编排：栏位移410ms、曲线(.2,.85,.22,1)；取消裁切280ms、透明200ms；头部透明200ms、上移12px/350ms；分类透明180ms、位移350ms；结果延迟130ms、上移14px/400ms；结果区内可见卡片随搜索栏逐张显示，每张错开40ms（最多7档），透明320ms、上移14px/400ms，卡片内封面不再单独淡入；筛选条透明200ms。标题、取消区和结果位移曲线(.2,.8,.2,1)，分类位移采用ease曲线。用transform与clip-path映射实际安全区，不缩放文字。点击（含首次点在输入框内）由应用以不滚动方式直接focus，并由系统显示键盘，键盘就位后页面不再追加上移；真实结果就绪后仅补足尚未经过的130ms，不为每次查询另加固定等待。Web顶栏仍为Combobox且不伸缩。

手机详情的 Vaul 外层是位置的唯一控制者，参数见 `motion.phoneDrawer`；不再绑定旧把手扩展、正文滚动扩展与普通边缘弹簧。Root / NestedRoot、Portal 和 Handle 使用原生生命周期；取消自定义普通正文回弹、wheel 关闭、入场暂停与退出计时器，读完上推优先。滚动接管保留库默认 100ms 等待，键盘避让与 body 处理使用默认行为。其他手机浮层沿用原规则。

Vaul 的 Content 与 Overlay 保留库的入场、退场和存在时间管理，不以 `forceMount`、禁用动画或自定义关闭位移覆盖。正文视口尺寸不随停靠点变化，只切换是否允许纵向滚动；释放采用库默认的速度停靠。背景容器包含完整页面工具，并在关闭后还原滚动位置。

- 手机搜索编辑期间隐藏底部胶囊，收起键盘后仍隐藏，取消搜索后恢复。输入框移动期间隐藏光标，完成后恢复；建议列表保留滚动能力但不显示滚动条。
- 标签输入采用 tag-input 参考（motion.tagInput）：回车或逗号（含全角）添加，粘贴含逗号或换行时拆成多个；手机键盘输入的逗号同样拆分。新标签弹入 spring visualDuration 0.25、bounce 0.15，自 0.9 缩放；手动输入的标签文字不动，只有底板弹入，× 延迟 60ms 以 searchIconSpring 出现。移除 150ms 淡出、缩至 0.9、模糊 2px，其余标签以 spring 0.25/bounce 0 滑到新位置。重复标签（不分大小写）不添加，原标签抖动 300ms。空输入时第一次退格选中最后一个标签（`ink` 底），第二次删除；继续输入、Esc 或失焦取消选中。× 点按不让输入框失焦。

## 章节目录与底部切换

- Web 桌面资讯目录放在正文右侧，当前章节以文字颜色和字重区分，不播放圆点移动或文字揭示动效。点击立即定位正文，滚动更新当前章节，短章节保留显式点击选择。首次显示、尺寸变化和键盘操作立即定位。
- 手机 Web/PWA 底部三项导航参考 [Segmented control](https://lab.xevrion.dev/lab/segmented-control)，采用 motion.segmentedControl：lead 0.18 秒、bounce 0；trail 0.36 秒、bounce 0.15。同一行图标的选中态副本按胶囊边缘裁切，背景保留 glass-press，图标为 ink。连续切换保留当前速度；首次显示、尺寸变化与键盘操作立即定位，页面切换不等待动画。
- 底部导航使用已有 Motion；按项目规则不新增减少动态效果分支，保留其他组件已有分支。

## Web/PWA 的 ui-lab 适配

按钮移出、取消和失焦均恢复；PWA 底部选中图标副本与普通图标同步点压。开关拉伸不与整控件缩放叠加。卡片展开与收回保留此次适配之前的实现，正文交接与返回卡面继续使用原有参数。下拉刷新保留此次适配之前的实现。叠卡只改变展示，前后导航与首尾边界保留。参数与完整决定见 [ADR 0082](../../docs/adr/0082-web-ui-lab-motion.md)。

开关时序对齐 ui-lab：按压拉伸 duration 0.2 秒、bounce 0；滑动与恢复 visualDuration 0.3 秒、bounce 0.25，并继承释放速度。点击立即启动一次滑动，设置重绘和松手不重复启动滑动；底色透明度与滑块共用进度。键盘仍遵循 Sill 即时响应规则。

手机 AI 对话输入框获得焦点时立即隐藏底部导航胶囊，不等待键盘高度变化；输入框失焦且键盘收起后恢复。
