# 动效

[返回设计手册](../README.md)。

## 共用规则

动效表达按压、空间位置和真实状态。Web 与 macOS 使用相同的操作含义；平台使用各自的绘制方式。键盘切换叠卡与打开、关闭菜单立即完成。macOS 本轮对齐 Web，已有 reduceMotion 分支暂留；新增动效不增加该分支。

Web 动效由 Motion 统一控制；CSS 只表达静止状态。每个表面只由一个动画控制。新操作从当前绘制的位置和透明度接续，并取消旧动画；取消不能触发旧完成回调。退出结束后才清理表面。拖动期间直接跟手，每帧最多绘制一次，尺寸在开始时读取。松手回位使用 mass 1、stiffness 600、damping 45 的弹簧，接收释放速度，不缩放正文、不动画化宽高。

| 交互 | 唯一规则 |
| --- | --- |
| 按压卡片 | `dur-press` 120ms，缩至0.97 |
| 菜单 | `dur-menu` 200ms，从卡片右上角下方0.95倍浮出；关闭 `dur-menu-close` 160ms，从当前状态淡出。Mac 右键时从指针处向右下浮出，靠近窗口右缘向左、靠近底部或 AI 框向上，离窗口边缘不小于 8；没有指针时（VoiceOver）与 Web 相同 |
| 桌面卡片详情 | 有可见来源卡片时，按位置和尺寸展开、收回；展开与收回用同一个弹簧 mass 1、stiffness 274、damping 30（`motion.cardSpring`）。无来源时保持 `dur-open` 280ms / `dur-close` 220ms 的10px淡入淡出 |
| 详情放大与缩小 | 从当前绘制的详情外框接续到全屏或预览尺寸，使用 `motion.cardSpring`；保留同一阅读层与返回关系，键盘即时完成 |
| 手机抽屉打开 | `ease-sheet`，`dur-sheet` 260ms，从底部升起，初始离顶64px；抽屉保持不透明，遮罩用同一时长从透明淡入 |
| 内容下拉关闭 | 位移达到 `gesture-dismiss-distance` 110px，或最近100ms向下速度超过0.5px/ms且位移超过40px；松手提交 |
| 资讯与媒体预览切换放大 | `motion.expandedSpring`：mass 1、stiffness 274、damping 27；正文不缩放，工具直接出现在目标位置，键盘即时。放大期间保留预览的遮罩，阅读页底色等外框铺满后再接替 |
| 把手 | 上拉40px展开，短下拉40px收起；下拉160px关闭；取消恢复原尺寸 |
| 阅读右滑 | 位移超过屏宽30%，或最近100ms向右速度超过0.5px/ms且位移超过40px；松手提交 |
| 松手回弹 | Motion 弹簧；继承释放速度，当前位置可再次接管 |
| 详情下拉关闭 | 仅手机保留，抽屉沿底部滑出260ms；关闭按钮与 Esc 同样用 `ease-sheet` 不透明滑出，遮罩同时淡出。Web 桌面与 Mac 不通过下拉关闭详情 |
| 卡片重排 | `layout` 220ms，只平移；宽度一次确定，文字不缩放 |
| 内容更新 | `fast` 淡入；连续更新接续当前透明度，不重复闪回全透明 |
| 工具条 | 下滚28px隐藏，上滚14px、停下650ms、到边缘或键盘聚焦恢复；隐藏 `dur-tuck` 240ms，出现 `dur-show` 320ms |

默认曲线 `ease` 为 `cubic-bezier(0.23,1,0.32,1)`；抽屉 `ease-sheet` 为 `cubic-bezier(0.32,0.72,0,1)`。参数来自设计变量，不在组件里维护另一组值。Web 与 Mac 叠卡只平移，不倾斜；首尾没有下一张时保持原位，松手260ms平稳落定，不回弹。

## 提交、取消与导航

- 下拉刷新、下拉关闭和右滑关闭在触摸移动时只预览结果，松手才提交；达标前系统取消、多指打断恢复表面、遮罩和工具条，不刷新、不完成、不关闭。
- Web 与 Mac 桌面鼠标在主页空白处按住下拉时，进度与内容逐帧跟手；停住不提交，达到阈值后松开左键才刷新。取消、窗口失焦或打开详情时回位；卡片拖拽、叠卡与按钮不进入刷新手势。按住鼠标时不使用滚动停顿计时提交；手机触摸规则不变。
- 触控板刷新和关闭手势在达到阈值后等待输入流停止才提交；读完上推在达到阈值时立即写入已读并显示白勾，关闭同样等松手或输入流停止。普通滚动的惯性不发起新操作；关闭后的残余惯性不滚动主页。
- 读完上推：到底不显示提示，继续上推显示40px圆片和进度弧，每帧最多更新一次；正文随上推距离的 60% 移动（`motion.finishTravel`，Mac `gestureFinishTravel`），留有阻力但跟得上手。达到120px立即写入已读、显示蓝底白勾，不等松手；白勾不再从透明重新加载。完成确认后工具胶囊持续隐藏，关闭期间不恢复；桌面完成确认后保持正文当前位移直接收回，不先单独回弹；白勾保持到松手：触摸抬起，或滚轮、触控板输入停止（Web 停顿 120ms 或增量开始衰减，Mac 收到结束或惯性阶段，鼠标滚轮停顿 `gestureWheelRest`）后关闭当前层；Web 在下一帧重绘信息流中的这张卡片，再下一帧开始关闭，重绘不与白勾或关闭的第一帧挤在一起；白勾不先单独淡出，随详情用同一个卡片弹簧收回（[ADR 0062](../../docs/adr/0062-card-close-spring-and-read-end-release.md)）；达标前取消恢复原位，达标后不重复提交或撤回完成。
- 关联详情的关闭按钮、Esc、遮罩、下拉和读完动作每次只退出最上层，恢复上一张卡片的阅读位置。手机关联详情保持不透明，以 `dur-sheet` 和 `ease-sheet` 升起、滑出，不对整层淡入淡出。普通全屏阅读退出后恢复主页。
- 手机取消下拉或侧滑时，遮罩从当前深度在 `dur-sheet` 内恢复，抽屉同时回位，不立即跳回正常深度。手机阅读中的背景卡面更新延后到详情关闭后，已读状态仍立即保存。
- 打开后立即关闭、关闭中重开、回弹中重新拖动，都以最后一次操作为准。离场动画完成后关闭，不用固定延时猜测离场结束。旧面板回调不得关闭新面板。关闭动画被取消且仍停留在当前层时，解除禁止操作状态，恢复遮罩与工具。

## 其他组件

- 独立文字按钮、浅色按钮、会议入口和标签删除使用与主按钮相同的按压反馈：`dur-press` 120ms、`motion.pressScale` 0.97、默认 `ease` 曲线。任务与提醒只缩放圆圈，文字、点击区域和卡片保持原位；释放或取消时从当前位置恢复。操作不等待动画，禁用按钮不响应按压，键盘操作即时完成。筛选项与列表行保留原有变色反馈。

- 桌面卡片详情从来源位置展开，来源保留布局占位，关闭时重新读取来源位置。Web 使用 transform 和既有内容淡入规则。Mac 只移动并放大圆角外框：详情按最终尺寸布局一次，固定在外框左上角由外框裁剪露出，正文、原卡片外观、关闭与全屏圆片、底部胶囊和图标都不缩放；圆片与胶囊属于同一外框，随外框露出。原卡片外观与详情在几何进度 20%–75% 内交接，外框阴影随进度从卡片阴影过渡到详情阴影。Mac 关闭与 Web 相同，用展开的卡片弹簧收回，弹簧结束后交回真实卡片（[ADR 0062](../../docs/adr/0062-card-close-spring-and-read-end-release.md)）；关闭开始时胶囊与圆片用 `motion.detailFade` 120ms 先淡出，收回期间浮层不拦截点击，点另一张卡立即开始新的展开。来源不可见时淡出，快速反向操作保留当前过渡；键盘即时完成、手机与照片灯箱不变（[ADR 0058](../../docs/adr/0058-mac-card-reveal-transition.md)）。
- 桌面搜索框宽度随可用空间收缩。聚焦时用 `dur-state` 220ms 伸长、失焦缩回，Web 只拉伸玻璃底，文字与光标不缩放，见[网页交互](web-interaction.md#桌面顶栏与-ai-框)。输入立即显示，Mac 结果计算使用 `searchDelay` 180ms 合并连续输入；清空立即生效并取消旧计算。键盘聚焦即时完成。点击搜索框以外的任何位置即失去聚焦，点击照常作用于所点对象，搜索词与分栏标签保留。AI 输入框同样在点击框外时失去聚焦，草稿保留。
- AI 上下文卡片移除时用 `fast` 140ms 淡出，移除最后一张也一样。拖动的卡片堆松手后用 `fast` 淡出并缩到 0.95（`motion.menuScale`）。多选开始时 AI 框与多选条在同一帧交换，AI 框不闪现。
- 桌面分栏菜单鼠标打开200ms、关闭160ms，透明度配合0.95至1缩放，锚点位于分栏按钮；键盘即时完成。
- AI上下文引用首次加入时140ms淡入并上移4px，移除时120ms淡出；已有引用不重播。新加载封面140ms淡入，缓存图片即时显示，已读透明度保持原值。
- 设置开关使用 `motion.toggleSpring`：visualDuration 0.2 秒、bounce 0.2；滑块平移20px并轻微回弹，底色同步过渡，尺寸不变，不重播整页淡入。连续切换从当前绘制状态接续，键盘即时完成；媒体分段首次随面板显示，后续只让新旧文字140ms交叉淡入淡出，封面与渐变背景始终保持不透明度不变，未变化不重播。

- 卡片菜单打开时卡片保持原位，菜单独立淡入；关闭后继续卡片原时间线。菜单靠近底栏时向上避让。首个鼠标提示等待500ms，同工具条连续提示立即显示，键盘提示立即显示。
- 仅首屏卡片上浮10px，前十张按30ms错开；滚动加载不播放入场。速记、归档恢复、筛选新增卡片从上方落下；移出卡片先停止接收操作，再淡出，其余卡片补位。
- 普通边缘滚动使用最多14px阻尼反馈，滚轮目标通过抽屉曲线连续过渡；触摸直接跟手。正文下拉关闭不叠加边缘反馈。
- 手机向上滑动阅读时即开始展开至全屏，不等待松手或惯性停止；展开后外框占满当前可视区域。滚轮仍在停稳后展开。多指或系统取消后不再启动新的展开。内容按目标尺寸布局一次，外框以当前位置、可见高度与圆角裁剪接续，使用 `motion.expandedSpring`，由浏览器播放位移与裁剪，不逐帧改写 height 或 max-height。正文不缩放；安全区留白变化补偿阅读位置，顶部工具与把手接续当前位置，过渡期间暂停工具自动显隐。
- 阅读关闭手势只在方向明确后接管表面；普通点击不停止入场动画。播客详情固定横向位置，不通过整页右滑关闭；关闭按钮与下拉仍可使用。横向滚动的代码块、表格及媒体控件保留自身触摸操作，不发起阅读页关闭。连续触摸移动每帧最多绘制一次。
- 下拉刷新由应用处理。手指按下时不读取尺寸，确认是下拉后读取一次。圆环临时替换手机顶栏标志，达标后松手才请求；等待超过1秒先让卡片归位，圆环仍表示真实请求。成功短暂勾选，失败保留重试入口；完成后恢复标志。
- 搜索与导航立即更新；图片翻页、多选条与状态提示使用短淡入；输入框、焦点和滚动位置保留。隐藏开始即停止接收操作，快速恢复取消旧退出。
- 后台加载短于 `delay-loading` 不显示加载态；主动刷新的反馈至少持续300ms；骨架按真实高度；封面使用主色块后淡入，不动画化模糊半径。
- 云端打开时，首次会话检查返回前不显示登录入口：短于 `delay-loading` 保持空白主页；超过后以 `fast` 淡入几张卡片形状的静止占位，不可点击、不加文字。返回后首屏卡片按首屏入场显示，不从上方落下；需要登录时占位保持到跳转登录页。
- 视频详情使用来源平台的官方播放器；详情打开、放大或缩小的动效结束后才插入播放器框架，等待时显示封面，点播放会在播放器就绪后开始。播客详情使用真实音频地址，提供播放与暂停、后退 15 秒、前进 30 秒、进度和倍速。卡面只显示播放标记，点按打开详情。播放器的状态与进度来自实际播放，不用计时器模拟；阅读进度不能当作播放位置。无法播放时保留在来源打开。见 [ADR 0061](../../docs/adr/0061-in-app-media-playback-and-pr-cards.md)。
- 播客预览向上滚动时，播放区收成顶部播放条，下面接文字稿；滑回顶部或点播放条回到播放区。大小播放区保留布局占位，在一个小播放条高度的滚动区间内连续交叉淡化；Motion 时间线由滚动位置直接控制，不等待定时动画追上。大播放器自然随页面滚走，不额外平移；小播放条从向上 `space-8` 的位置淡入，顶部底色与页签底色使用同一进度。页签始终保留相同间距与吸顶规则，不在切换时改变布局。反向滚动沿同一进度展开，不缩放正文、不移动文字稿；只有主要显示的一组控件接收操作。不显示「正在播放」标题。无音源时保留禁用控件，不显示无法播放的说明；真实音频加载或播放失败才显示错误。文字稿默认跟随播放，手动滚动后暂停跟随，点「跟随播放」恢复；当前段落与章节使用 `accent-soft`；播放进度变化只更新当前行，不重绘整份文字稿。关闭详情时暂停并保存位置；只有实际播放结束才自动标为已读，拖到结尾不算完成。
- 胶囊随滚动隐藏时轻移 20px 并在 `dur-tuck` 内淡出；恢复时在 `dur-show` 320ms 内轻移淡入（收起 `dur-tuck` 240ms），停止滚动同样过渡。隐藏开始就禁用点击和键盘焦点，软键盘出现时隐藏导航，不保留可点击残影。
- 离线提示和新内容/提醒数量提示在原位淡入淡出，轻移不超过 4px，不推移底部胶囊。隐藏开始即停止接收操作，动画结束才收起；快速恢复时取消旧退出动画，旧回调不能隐藏新提示。

播客吸顶区沿用封面的浅色底，背景铺满详情宽度，页签下沿以 `space-16` 淡出；不在播放条和页签后分别绘制白色卡片。小播放条距顶 `space-56`，页签紧随其后，不额外增加顶部内边距；播放进度条之外不加阴影横线。

项目不提供专门的无障碍设置或系统偏好适配，包括减少动态、减少透明度和增强对比度。保留正常键盘、焦点恢复、图标名称和原生控件语义。所有用户使用以上同一套动效规则。

已有存档中的旧偏好字段只作兼容读取，不产生界面效果；不修改历史迁移或用户存档。

## 桌面阅读与刷新衔接

- 阅读完成确认后等松手，再从当前位移直接关闭，不先单独回弹。保存失败只回位，不显示完成或关闭；页面离开后旧回调失效。
- Mac 不处理下拉关闭；侧滑移动整个详情表面，正文内部偏移只用于读完上拉和边缘阻尼。拖动时遮罩按关闭阈值渐淡至 30%，取消时与表面一起回位。
- Mac 主页在顶部下拉 48 后松手请求读取；不足阈值或取消则回位。刷新反馈最少显示 300ms，成功时内容先回位，勾选反馈保留 480ms 后原位淡出；慢请求 1 秒后释放内容偏移，失败保留可点击的重试入口。详情、设置、分栏菜单打开或拖动卡片时不启动主页刷新。
- Web 窗口尺寸变化启用已有的位置过渡与内容淡入；Mac 列数改变时过渡位置，卡片宽度改变时内容淡入。两端不缩放正文，保留当前 12px 外边距与列数规则。

## 桌面输入与动画协作

- 输入由当前最上层拥有：面板、阅读层、拖动、菜单、主页。打开面板暂停底层阅读手势，切换层后旧异步结果不得关闭新层。系统窗口和确认框优先于应用监听。
- 滚轮先处理结束、取消与惯性，再判断方向和位移；零位移结束也是有效结束。触控板以事件阶段收尾，普通鼠标才用 `gestureWheelRest` 120ms 超时。惯性隔离只拦截 momentum 事件，新主动滚动立即放行。
- 阅读完成反馈后直接收回；卡片收回使用动画完成回调卸载，工具胶囊保持隐藏。
- 玻璃容器默认只提供材质；内部按钮保留一套按压反馈。独立账户按钮使用原生交互玻璃，工具栏整体不随内部按钮点击一起缩放。
- 卡片测量缓存随子视图更新和列几何变化失效，不缓存跨内容变更的高度。窗口缩放不改变卡片字号和内部布局。


## Web 与 Mac 桌面卡片连续过渡

- Web 胶囊与卡片同一帧开始，沿卡片底边移动，保持底部间距；全屏层内对胶囊做反向缩放补偿，图标不被拉伸。Mac 胶囊在同一外框内随外框露出。过渡期间暂停滚动工具条的自动显隐，结束后恢复。
- 收回保持卡片外壳不透明。Web 在外壳内部，80ms 后开始用 140ms 淡入原卡片的展示副本（`motion.cardContentReturn`）；不是两张整卡同时变透明。副本在到达原位前已经可见，原卡片保持隐藏，到结束时同帧交回真实节点。
- 展示副本不可点击，不复制元素 ID 或卡片操作身份；取消时立即移除。来源不存在时沿用既有退出方式。
- 完成后的胶囊继续隐藏，不因轨迹动画恢复。手机同样保持正文当前位移，直接随抽屉滑出，不先回弹或恢复工具。
- Web 使用无交互的 DOM 副本；Mac 与真实卡片复用完整 CardFace 外观，来源和详情保持各自固定布局、不缩放，由进度驱动交接。底部渐隐、胶囊与关闭、全屏圆片置于同一圆角外框内，胶囊保留原生玻璃。真实窗口手感仍需体验确认。

桌面点击刷新或快捷键刷新不移动卡片；只有下拉操作保留内容跟手与松手回位。刷新按钮沿用按压反馈，加载、成功与失败图标使用 `fast` 原位交叉淡化；失败停留并可重试，忙碌时不重复请求。
