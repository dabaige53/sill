# 网页交互

[返回设计手册](../README.md) · [两端对照](interaction.md#两端对照)

## 网页（宽于 650px）

网页只有一个主界面：搜索不另开页面，AI 不另开页面，没有底部导航胶囊。卡片区按可用宽度自动增减列数，宽屏可显示五列、六列或更多，卡片用 A 字号（见[字体](foundation.md#字体)）。

桌面主页（Web 宽于 650、macOS）左右外边距为 12（`space-12` / `feedMargin`），导航与首末列卡片对齐。卡片区铺满可用宽度，不受内容最大宽度限制；保留列数判断与列间距，卡片宽度均分剩余空间。手机及搜索独立页面保持原布局。

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 顶栏 | 左：品牌图标、Sill、⌄；右：搜索栏、头像 | 四者高 40，同一中线 |
| 类型胶囊（只在有文字时） | 全部、资讯、消息…… | 高 32 |
| 卡片区 | 多列卡片，宽屏自动增加列数 | 列宽 280–380，理想 340 |
| AI 框 | +、输入、麦克风、发送 | 640×60，离底 28 |

### 桌面顶栏与 AI 框

**顶栏**

| 部分 | 数值 |
| --- | --- |
| 品牌图标 | 现有应用图标 `sill-icon`，40px，圆角 9 |
| 「Sill」 | 字号 34，字重 700，行高 40；与图标间距 10 |
| ⌄ 分栏按钮 | 20px `muted` 图标，点击区 36 |
| 搜索栏 | 高 40，圆角 20；静止时宽 280（`search-width`），聚焦伸长到 480（`search-focused-width`），失焦后有文字或标签时保持 360（`search-tagged-width`）；随窗口可用空间收缩 |
| 头像 | 40px 圆，点击区不小于 44 |
| 搜索栏和头像材质 | Web：低填色玻璃（`glass` 35% 加 `glass-filter`），1px `line-card` 内描边；macOS 26+：搜索栏为原生 clear 玻璃，头像为 regular 交互玻璃，旧系统为 Sill 玻璃；文字与图标不模糊；间距 8 |
| ⌘K 提示 | 13px `muted` 纯文字，不加框 |
| 对齐 | 四者同一中线；图标左缘对齐卡片区左缘，头像右缘对齐卡片区右缘。导航行高 64、可见控件高 40；导航行顶部至窗口顶部与导航行底部至首排卡片使用相同留白：Web 为 10（`space-10`），macOS 为 18（`topBarInset / 2`）。因此可见控件上下间距分别为 Web 22、macOS 30。桌面两侧留白均为 12px，品牌与账户分别对齐卡片区两侧 |

- Web 桌面与 macOS 顶栏固定在顶部，向下阅读时向上退出 `dur-tuck` 240ms，停顿、反向滚动或到达边缘时从上向下进入 420ms（`dur-reveal`），首次出现也一样；进入用 `ease-reveal` 曲线，减速均匀，全程可见移动，不回弹；收起用 `ease`。随卡片关闭恢复时，与卡片同一帧开始，用同一个卡片弹簧（`motion.cardSpring`），不延迟。位移包含顶部留白、导航行和模糊下沿 12px，保留布局占位。收起时不可点击或通过键盘聚焦；键盘触发立即显示。底部 AI 栏仍按原滚动规则收起；手机顶栏保持原有行为。
- 顶栏背景保留下面的色彩，向下渐进模糊至清晰，不铺异色实底。Web 用 `edge-blur-strong`、`edge-blur-mid`、`edge-blur-soft`（16、8、4px）三层 backdrop-filter 由上至下减弱，向下延伸 12px；不支持时回退 `canvas`。macOS 用附着在顶栏上的系统 regularMaterial，以渐变遮罩向下减弱；macOS 26 的 safeAreaBar 只保留布局作用，关闭独立的系统滚动边缘效果以免重叠。模糊层与控件共用同一位移动画，父层保持不透明，不单独播放各层透明度。
- 点「Sill」回到顶部。点头像打开设置弹窗。
- 顶栏品牌图形、搜索框、头像、状态和刷新按钮的可见外形统一为 40（`space-40`／`searchHeight`），点击区保留 44（`hitTarget`）。操作图标统一为 20（`space-20`），文字与图标按控件中线居中；Sill 字号仍为 34。
- 搜索栏聚焦时用 `dur-state` 220ms 伸长，失焦时缩回；Web 只拉伸玻璃底，文字与光标不缩放。不画聚焦边框与外圈，靠长度和光标表示正在输入；键盘聚焦即时完成。
- 有文字时，⌘K 提示换成清除按钮。

**分栏菜单**

| 菜单行 | 右侧 |
| --- | --- |
| ✓ 全部 | ⌘1 |
| 未读 | ⌘2 |
| 待办 | ⌘3 |
| 稍后读 | ⌘4 |
| 收藏 | ⌘5 |

- 默认收起，主页上不显示分栏行。点 ⌄ 在下方弹出菜单，宽 220，`dur-menu` 200ms，收起 `dur-menu-close` 160ms。当前项前有 ✓，快捷键为 `muted`。
- 选择后菜单关闭。选「全部」以外的项时，该项以 `ink` 底标签放进搜索栏，占位字改为「在未读里搜索」这类说法，卡片区只显示该分栏。选「全部」移除分栏标签。
- 每个分栏分别保留滚动位置，切回时回到原处。
- 菜单里的 ✓ 跟着搜索栏里的分栏标签走：删掉标签，✓ 回到「全部」。
- Esc 或点菜单外面：关闭菜单，不改变分栏。菜单打开时，上下方向键移动高亮，回车选择。

**搜索**

- 搜索栏在顶栏，不另开页面。⌘K / Ctrl K 聚焦搜索栏。
- 结果在卡片区原地显示，保持多列布局。有文字时，顶栏下方显示一行类型胶囊：全部、资讯、消息、笔记、待办、日程、媒体，只列出当前文字下有结果的类型（已选中的类型始终保留）。胶囊与手机搜索页同一组件，高 32，间距 8，左缘对齐卡片区。文字清空时这一行收起，类型选择同时取消，不在看不见时继续筛选。
- 输入 # 时，搜索栏正下方浮出列表，宽同搜索栏，不推开卡片：先「状态」（未读、收藏、稍后读），后「标签」（只列已有标签）；继续输入按名称过滤。已经是分栏标签或 # 标签的状态不再列出。方向键移动高亮，回车或点选后成为 `accent` 底的 # 标签，排在分栏标签后面，输入中的 # 片段从文字里去掉；末尾的 # 片段不参与文字匹配。搜索栏失去焦点时列表收起。
- 分栏标签、# 状态、# 标签、类型胶囊和文字同时生效。切换分栏保留文字、# 标签和类型选择。
- 输入法组词、命中词加粗与移动相同（见「搜索与键盘」）。
- 主页分栏与搜索共用一个状态：分栏就是搜索栏里的一个标签，可以接着输入文字，在该分栏里搜。
- 点标签上的 ×，或光标在标签后按删除键：移除标签，回到全部。
- 不显示结果数量，本地搜索不显示加载动画。新内容提示放在顶栏下方居中。

**底部 AI 框**

| 部分 | 数值 |
| --- | --- |
| 位置 | 底部居中，离底 28 |
| 尺寸 | 宽 640，高 `rail-row` 60，圆角 30 |
| 材质 | Web：清透玻璃 `glass` 加 `glass-filter`，带亮边和发丝线；macOS 26+ 为原生 regular 玻璃，不叠底色；AI 框、多选条和详情工具条三者相同 |
| 控件顺序 | +、输入、麦克风、发送 |
| 输入文字 | 16px |
| 控件 | 36×36，图标 20，不加底色 |
| 发送 | 32px 圆；不可发送时浅灰底、箭头用次级文字色，可发送时 `ink` 底 |

- 不显示主页 / AI / 搜索导航胶囊。控件和文字共用一条中线。
- 网页向下滚动时，顶栏与底部 AI 框一起收起；向上滚动、停止滚动或到达页面边缘时显示，两者同用 420ms（`dur-reveal`）与 `ease-reveal`，同时到位。搜索栏、AI 输入框聚焦或分栏菜单打开时保持显示；拖动卡片时显示 AI 框。
- 信息流不在最上面时，打开卡片详情、阅读页或照片，顶栏与底部 AI 框一起收起（`dur-tuck` 240ms），即使搜索栏有焦点也收起；停在最上面时保持显示。收起后，关闭卡片时与卡片同一帧开始回来，用同一个卡片弹簧，不延迟。Web 桌面与 macOS 相同，手机保持原规则。

**拖入卡片**

- 鼠标按住卡片即可拖动，也支持长按后拖动；触屏仍先长按，短滑保持滚动。拖动时显示卡片缩略图，原卡留在原处。

| 步骤 | 结果 |
| --- | --- |
| 开始拖动卡片 | AI 框显示 `accent` 描边和「松手，把卡片交给 AI」。拖动期间 AI 框放大到 1.02，并有 `accent` 圆环从框边向外扩 14 并淡出，每 1.2 秒一次；拖到框上放大到 1.05（`motion.aiDrop`）。按住选中但尚未移动时不算拖动，AI 框不出现 |
| 拖到 AI 框上松手 | 卡片成为框上方的上下文卡：`card` 底、细边、可点 × 移除 |
| 拖到别处松手 | 没有变化 |
| 连续拖入 | 可以放多张，按拖入顺序排列 |

- 原卡不移动，不改变状态。键盘用户用多选条的「交给 AI」代替拖动。

**会话与完整视图**（内置 AI 接入后启用）

| 行 | 从左到右 |
| --- | --- |
| 上排（高 44） | —（收起成一行）、运行状态、会话标题 ⌄、「另 N 个进行中」、⋮⋮ |
| 输入行（高 60） | +、输入、麦克风、发送 |

- 运行状态：运行中转圈，完成为 ✓。「另 N 个进行中」为 13px `muted`，只在其他会话也在运行时显示。
- 点标题向上弹出会话列表：新对话；进行中（每个带转圈）；历史（按时间倒序）。切换会话不打断其他会话。
- ⋮⋮ 菜单：「在完整视图中打开」「新对话」。
- 完整视图：居中面板，宽 1040，高为可视高度减 120；左侧 260 宽会话列表，右侧为当前对话。右上 ⤡ 或 Esc 回到底部一行。不加遮罩，卡片仍可拖入。

**多选**：多选条与 AI 框共用底部轨道，AI 框宽 640，多选条按按钮内容收窄；同高 60、同一位置、同一材质，一次只出现一样。

| 从左到右 | 图标 |
| --- | --- |
| 数量 | 数字 |
| 收藏 | bookmark |
| 稍后读 | glasses |
| 标签 | tag |
| 交给 AI | chat |
| 分隔线 | — |
| 取消 | x |

- 按钮 44 见方，整组居中。
- 「交给 AI」：把所选卡片放进 AI 框，退出多选，AI 框回来。退出多选后，AI 框原有输入和上下文卡保留。

### 网页键盘

| 按键 | 结果 |
| --- | --- |
| ⌘K / Ctrl K | 聚焦搜索栏 |
| ⌘1–⌘5 | 切换分栏：全部、未读、待办、稍后读、收藏 |
| Esc（菜单打开） | 关闭菜单 |
| Esc（搜索栏有文字） | 清除文字 |
| Esc（只剩标签） | 清除全部标签，回到全部 |
| Esc（搜索栏为空） | 搜索栏失去焦点并缩回 |
| 删除键（光标在最前） | 删除最后一个标签：先 # 标签，再 # 状态，最后分栏标签 |
| ↑ / ↓（# 列表打开） | 移动高亮 |
| 回车（# 列表打开） | 选中高亮项，变成 # 标签 |

Esc 每次只退一层，顺序为：菜单 → 文字 → 标签 → 焦点。「标签」一步清掉分栏标签和全部 # 标签，回到全部。

### 网页交互细节

| 操作 | 结果 |
| --- | --- |
| 悬停搜索栏、头像、⌄ | `dur-hover` 160ms 变化，只在支持悬停的设备上 |
| 点搜索栏 | 伸长到 480，显示光标，不画聚焦边框 |
| 点卡片区空白 | 搜索栏失焦并缩回，文字和标签保留 |
| 选分栏后输入文字 | 在该分栏里搜索 |
| 打开详情再关闭 | 回到原搜索条件和原滚动位置 |
| 窗口缩到 650px 及以下 | 改用移动布局：分栏回到胶囊行，导航胶囊回来，AI 框隐藏 |

### 网页状态

| 状态 | 表现 |
| --- | --- |
| 分栏或搜索没有结果 | 卡片区显示现有空状态，顶栏不变 |
| 拖动中 | AI 框 `accent` 描边加提示文字；松手后恢复 |
| 多选中 | AI 框隐藏，多选条在同一位置 |
| 内置 AI 未接入 | 发送和麦克风禁用；不显示运行状态、会话内容或回复，不伪造会话与结果 |
| 输入与上下文卡 | 只保留在当前页面会话中 |

### 设置弹窗

Web 桌面与 macOS 相同；手机是整页。画板 `MacChrome`。

| 部分 | 数值 |
| --- | --- |
| 打开方式 | 点头像；macOS 另有 ⌘, 与菜单「设置…」。不另开系统窗口 |
| 容器 | 窗口中央，宽 840（不超过窗口宽减 32）；分组区固定高 560（`settings-body-height`），切换分组不改变弹窗大小；内容更多时右侧滚动，窗口不够高时一起缩小；`canvas` 底，`sheet-radius` 28，`shadow-sheet`；其余部分盖 `dim` 遮罩 |
| 头部 | 「设置」34/700，字距 -0.025em；右侧 44 圆形关闭钮，`faint` 底，无描边、无阴影；最小高 60，上 16、左右 32 |
| 分组 | 左侧 200 宽，选中项为 `card` 底的浮起行；左右栏顶部留白同为 28；右侧分组标题 `panel-title` 22，内容区上下 28、左右 32 |
| 关闭 | Esc、点遮罩或关闭钮；焦点回到打开前的位置 |

设置的分组、内容、即时生效和失败回退保持不变。

设置现行画板为 [桌面设置](../boards/SettingsDesktop.dc.html)与[手机设置](../boards/SettingsMobile.dc.html)，由产品组件和样式生成。分组切换只用于查看，不执行保存、导出或删除。

### 卡片日期

- 同一个内容日期在卡面、预览和放大阅读页使用同一格式：今天、昨天、10/18；跨年显示 2025/10/18。资讯、笔记、视频、播客、照片、邮件等均沿用此规则。
- 按设备本地日历判断今天和昨天。只有日期的值保持原日期；带时区的时间先转换为本地时间。未来日期直接显示月日，不显示今天。
- 邮件发送时间和 PR 记录时间保留时分，例如「今天 09:30」；原值只有日期时不补 00:00。照片日期不添加时分。
- 日程时间、任务截止时间和汇总覆盖范围保留各自的业务格式。日期缺失时不补造；资讯沿用下面的发布日期、保存日期、卡片时间顺序。

## 资讯阅读

只用于资讯卡；预览与全屏分别遵循 `CardTypeDetails`、`CardTypeMobile`、`CardTypeReading`，Web 与 macOS 对齐。数值见[字体](foundation.md#字体)与[间距与尺寸](foundation.md#间距与尺寸)。

- 预览顺序：封面 → 来源 · 日期 · 阅读时长 → 标题 → 标签 → 正文 → 备注。标题区与正文之间不加通栏分隔线，保留原有留白。全屏把封面移到标题区之后。导语与列表属于正文，不额外插入卡面摘要。日期只在来源行出现一次，写「今天」「昨天」「10/18」，跨年加年份；取发布日期，没有时取保存日期，再没有时取卡片时间。
- 正文使用可用宽度，左右 30（手机 20），不限制最大宽度。预览浮层宽度不变，全屏正文随窗口扩展。
- 工具条、进度线、读完圆环、收起与关闭沿用原有规则。不加折叠区、属性侧栏或信息表。
- 其他类型的预览与阅读页不使用资讯阅读变量。

## 桌面阅读与操作细节

- 键盘打开搜索、记一笔及详情时立即显示并聚焦，关闭也立即响应；点击和触摸保留已有空间过渡。手机详情正文与抽屉同时出现，不再单独等待 200ms。
- 卡片内容块沿用 HTML 参考稿，来源、标题、摘要、清单、附件和关联内容之间统一间隔 8px。邮件附件使用 `surface` 底的静态标签，间隔 6px、内边距 6px 10px；没有链接时不添加点击操作。
- 桌面待办文字最多两行，圆圈与首行对齐。全部完成后保留原有清单结构和可恢复的勾选项，仅改变完成色，不压缩成完成横条。
- 建议卡显示两个关联预览；更多关联以“另有 N 项关联内容”说明，完整关联仍在详情查看。
- 短待办、提醒及短笔记预览保留较窄面板；普通卡片详情的桌面左右内边距为 30px，全屏时占满剩余宽度。资讯也采用相同内边距，不另设正文宽度上限。短内容末尾到工具条保持清晰分隔，不添加多余空白。
- macOS 搜索与 Web 使用相同分类入口与按需展开的状态、标签筛选；标签完整显示，各行可横向滚动。Toast 采用同一暂停规则。
- 桌面卡面不显示更多按钮，头部不预留按钮空位，日期与完成数量靠右对齐；右键或 Shift+F10 打开卡片菜单，VoiceOver 保留菜单动作。
- 资讯和邮件的纯文字摘要以 50–60 字为内容目标，桌面完整显示并自然增高，手机最多显示 4 行；正文依据不足时不凑字。已有要点版和展开叠卡沿用原规则，其他类型不变。
- 桌面详情工具栏与 AI 框、多选条使用同一种玻璃，按钮为 44，间距 4，胶囊高 60；两端沿用同组阴影。文字提示与圆形悬停底色保留。
- 指针（Web 与 macOS 一致）：可点击的按钮、链接、卡片和输入框里的标签、清除、移除按钮悬停显示手形；搜索框和 AI 框整个胶囊显示文字光标，点击胶囊空白处把光标放进输入框；禁用按钮（如未接通的 AI 加号、麦克风、发送）保持箭头。
- Mac 菜单栏提供「性能追踪」：开始、标记此刻、停止并导出。默认关闭，记录期间标题为「性能追踪 · 记录中」；不在卡片或阅读区新增悬浮入口。此入口是本机诊断工具，Web 不显示。

窄桌面仍在容纳两列最小宽度时保留两列；三列及以上才要求每列达到理想阅读宽度，避免小窗口退成过宽单列。

主页分栏滚动时保持可见。读完、完成提醒或勾选待办只更新状态，不改变当前信息流的成员、顺序、叠卡分组和卡片占位；任务预览保留当前行。切换分栏只应用筛选，保留卡片相对顺序。后台保存、内容更新、加载更多和返回主页不因完成状态重排；只有用户主动刷新或主动更换排序方式才重新排序。

## 移动浏览器基础行为

- 悬停反馈只在支持悬停且主指针精确时生效；按下与键盘焦点反馈独立保留。
- 应用与全屏阅读区域使用动态视口高度；Android 软键盘收起布局视口，iOS 继续使用现有 visualViewport 处理。
- 有触屏的设备上，输入字号至少 16px，避免聚焦时页面自动放大；保留用户缩放。16px 是浏览器输入保护阈值，不新增字号等级。
- 按钮禁止长按选中文字，正文和正文链接保留选择与系统菜单。轻点使用 manipulation，已有拖动区域保留自己的手势规则。
- 页面阻止浏览器纵向下拉刷新，内层滚动保留现有边界；横屏不自动放大文字。浏览器栏颜色跟随当前应用主题的 canvas。
- 这些是 Web 平台修复，不改变 macOS 的文案、状态或颜色角色；软键盘、安全区与主屏幕启动须在真机验收。
- PWA 触控与外壳：详情胶囊与底部导航的图标控件禁止文字选择和系统长按菜单。详情图标长按显示名称后，松手不执行动作；键盘聚焦时立即显示同一个名称提示。胶囊两端的名称提示向内侧展开，在 320px 宽度内完整可见。

独立工作台按系统深浅色选择状态栏底色：浅色 canvas 为 #f5f5f7，深色 canvas 为 #111113。登录页使用 card 底色，浅色 #ffffff、深色 #1c1c1f。manifest 保留现有 theme_color，不新增离线缓存。

主页隐藏浏览器根滚动条，不为右侧轨道预留空白；鼠标滚轮、触摸和键盘滚动保持可用。macOS 原生窗口不受此浏览器样式影响。
搜索结果、设置、AI 上下文、多选菜单和云端记一笔遵循同一隐藏轨道规则，仍可滚动到底；只隐藏滚动条，不使用 overflow: hidden 代替。

## 登录与授权

现行画板：[桌面登录](../boards/Login.dc.html)、[桌面授权](../boards/Authorization.dc.html)、[手机登录](../boards/LoginMobile.dc.html)、[手机授权](../boards/AuthorizationMobile.dc.html)。

- 登录内容宽度为 `auth-login-width` 352，授权为 `auth-consent-width` 400；窄屏按可用宽度收缩。两页采用白底、居中窄内容区与蓝色主按钮，不加外层厚卡片。品牌图标、连接图标、标题和状态说明居中；输入标签、账号信息和权限条目左对齐。
- 登录保留邮箱、密码、显示密码、忘记密码和邮件登录入口。标题下不加介绍句，不写“无需记住密码，用邮件中的链接继续”等重复说明，页脚不加标语。
- 邮件登录、重设密码和邮件发送后的状态沿用同一布局。只保留邮箱、必要状态和对应动作；不能用演示反馈表示真实邮件已发送或登录完成。
- 授权页显示申请应用、当前账号、逐项权限和内容范围；删除权限单独列出。应用名称、账号和权限按实际请求显示，不能固定使用画板中的示例值。
- 授权按钮为“取消”和“允许访问”；保留“可在「已授权客户端」中撤销”。取消不得授予权限；允许后的状态须以真实回执为准。
- 手机画板按 390 × 844 展示，与桌面共用页面和交互。手机缩小两侧留白，图标和标题保持居中；输入字号至少 16px，按钮高度至少 44px，内容超出屏幕时可纵向滚动。保持相同的顺序、文案和状态。macOS 对应登录与授权界面沿用同样的居中原则和权限表达。
- 原型页面只展示产品界面，不加顶部品牌栏、“设计预览”标识、页脚页面跳转或状态切换工具。画板之间从设计目录进入，状态通过页面原有操作触发。示例账号和必要的演示结果提示不进入产品页面；画板不提交账号、不发送邮件、不更改权限。

### 卡片详情内的导航与媒体

- 正文链接指向 Sill 内已有卡片时，在当前窗口打开该卡片，关闭后返回上一张；外部网址保持在来源打开。
- 播客上滑后，完整播放器切换为吸顶小播放器；完整播放区不与小播放器同时显示。小播放器与页签占据固定位置，文字稿从下方开始；滑回顶部或点标题恢复完整播放区。
- 卡面“审阅”有真实 PR 链接时打开该 PR；缺少链接时打开 Sill 中的 PR 详情，不禁用本地查看入口，不提交外部审阅。
