# 网页交互

[返回设计手册](../README.md) · [两端对照](interaction.md#两端对照)

## 网页（宽于 650px）

网页只有一个主界面：搜索不另开页面，AI 不另开页面，没有底部导航胶囊。卡片区按可用宽度自动增减列数，宽屏可显示五列、六列或更多，卡片用 A 字号（见[字体](foundation.md#字体)）。

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 顶栏 | 左：品牌图标、Sill、⌄；右：搜索栏、头像 | 四者高 40，同一中线 |
| 类型胶囊（只在有文字时） | 全部、资讯、消息…… | 高 32 |
| 卡片区 | 多列卡片，宽屏自动增加列数 | 列宽 280–380，理想 340 |
| AI 框 | +、输入、麦克风、发送 | 640×60，离底 28 |

### 桌面顶栏与 AI 框

**顶栏**

| 部分 | 数值 |
| --- | --- |
| 品牌图标 | 现有应用图标 `sill-icon`，40px，圆角 9 |
| 「Sill」 | 字号 34，字重 700，行高 40；与图标间距 10 |
| ⌄ 分栏按钮 | 20px `muted` 图标，点击区 36 |
| 搜索栏 | 高 40，圆角 20；宽 360，随窗口可用空间收缩，标签与聚焦不改变宽度 |
| 头像 | 40px 圆，点击区不小于 44 |
| 搜索栏和头像材质 | Web：`card` 底，1px `line-card` 内描边；macOS 26+：原生 Liquid Glass，旧系统为 Sill 玻璃；间距 8 |
| ⌘K 提示 | 13px `muted` 纯文字，不加框 |
| 对齐 | 四者同一中线；图标左缘对齐卡片区左缘，头像右缘对齐卡片区右缘。macOS 窗口控制区独占顶部 36，产品导航高 64，距首排卡片 20；桌面两侧留白均为 12px，品牌与账户分别对齐卡片区两侧 |

- Web 桌面与 macOS 顶栏位置固定，向下阅读时原位淡出，停顿、反向滚动或到达边缘时原位淡入；收起时不可点击或通过键盘聚焦，背景模糊随之隐藏。底部 AI 栏仍按原滚动规则收起；手机顶栏保持原有行为。
- 点「Sill」回到顶部。点头像打开设置弹窗。
- 顶栏品牌图形、搜索框、头像、状态和刷新按钮的可见外形统一为 40（`space-40`／`searchHeight`），点击区保留 44（`hitTarget`）。操作图标统一为 20（`space-20`），文字与图标按控件中线居中；Sill 字号仍为 34。
- 搜索栏聚焦只改变边框和光标，输入文字、增减标签与失焦都不改变宽度。
- 有文字时，⌘K 提示换成清除按钮。

**分栏菜单**

| 菜单行 | 右侧 |
| --- | --- |
| ✓ 全部 | ⌘1 |
| 未读 | ⌘2 |
| 待办 | ⌘3 |
| 稍后读 | ⌘4 |
| 收藏 | ⌘5 |

- 默认收起，主页上不显示分栏行。点 ⌄ 在下方弹出菜单，宽 220，`dur-menu` 180ms，收起 120ms。当前项前有 ✓，快捷键为 `muted`。
- 选择后菜单关闭。选「全部」以外的项时，该项以 `ink` 底标签放进搜索栏，占位字改为「在未读里搜索」这类说法，卡片区只显示该分栏。选「全部」移除分栏标签。
- 每个分栏分别保留滚动位置，切回时回到原处。
- 菜单里的 ✓ 跟着搜索栏里的分栏标签走：删掉标签，✓ 回到「全部」。
- Esc 或点菜单外面：关闭菜单，不改变分栏。菜单打开时，上下方向键移动高亮，回车选择。

**搜索**

- 搜索栏在顶栏，不另开页面。⌘K / Ctrl K 聚焦搜索栏。
- 结果在卡片区原地显示，保持多列布局。有文字且没有分类标签时，顶栏下方显示一行类型胶囊。
- 分类标签、# 条件、输入法组词、命中词加粗与移动相同（见「搜索与键盘」）。
- 主页分栏与搜索共用一个状态：分栏就是搜索栏里的一个标签，可以接着输入文字，在该分栏里搜。
- 点标签上的 ×，或光标在标签后按删除键：移除标签，回到全部。
- 不显示结果数量，本地搜索不显示加载动画。新内容提示放在顶栏下方居中。

**底部 AI 框**

| 部分 | 数值 |
| --- | --- |
| 位置 | 底部居中，离底 28 |
| 尺寸 | 宽 640，高 `rail-row` 60，圆角 30 |
| 材质 | `glass` |
| 控件顺序 | +、输入、麦克风、发送 |
| 输入文字 | 16px |
| 控件 | 36×36，图标 20，不加底色 |
| 发送 | 32px 圆；不可发送时浅灰底，可发送时 `ink` 底 |

- 不显示主页 / AI / 搜索导航胶囊。控件和文字共用一条中线。
- 网页向下滚动时，顶栏与底部 AI 框一起收起；向上滚动、停止滚动或到达页面边缘时显示。搜索栏、AI 输入框聚焦或分栏菜单打开时保持显示；拖动卡片时显示 AI 框。

**拖入卡片**

- 鼠标按住卡片即可拖动，也支持长按后拖动；触屏仍先长按，短滑保持滚动。拖动时显示卡片缩略图，原卡留在原处。

| 步骤 | 结果 |
| --- | --- |
| 开始拖动卡片 | AI 框显示 `accent` 描边和「松手，把卡片交给 AI」 |
| 拖到 AI 框上松手 | 卡片成为框上方的上下文卡：`card` 底、细边、可点 × 移除 |
| 拖到别处松手 | 没有变化 |
| 连续拖入 | 可以放多张，按拖入顺序排列 |

- 原卡不移动，不改变状态。键盘用户用多选条的「交给 AI」代替拖动。

**会话与完整视图**（内置 AI 接入后启用）

| 行 | 从左到右 |
| --- | --- |
| 上排（高 44） | —（收起成一行）、运行状态、会话标题 ⌄、「另 N 个进行中」、⋮⋮ |
| 输入行（高 60） | +、输入、麦克风、发送 |

- 运行状态：运行中转圈，完成为 ✓。「另 N 个进行中」为 13px `muted`，只在其他会话也在运行时显示。
- 点标题向上弹出会话列表：新对话；进行中（每个带转圈）；历史（按时间倒序）。切换会话不打断其他会话。
- ⋮⋮ 菜单：「在完整视图中打开」「新对话」。
- 完整视图：居中面板，宽 1040，高为可视高度减 120；左侧 260 宽会话列表，右侧为当前对话。右上 ⤡ 或 Esc 回到底部一行。不加遮罩，卡片仍可拖入。

**多选**：多选条与 AI 框共用底部轨道，AI 框宽 640，多选条按按钮内容收窄；同高 60、同一位置，一次只出现一样。

| 从左到右 | 图标 |
| --- | --- |
| 数量 | 数字 |
| 收藏 | bookmark |
| 稍后读 | glasses |
| 标签 | tag |
| 交给 AI | chat |
| 分隔线 | — |
| 取消 | x |

- 按钮 44 见方，整组居中。
- 「交给 AI」：把所选卡片放进 AI 框，退出多选，AI 框回来。退出多选后，AI 框原有输入和上下文卡保留。

### 网页键盘

| 按键 | 结果 |
| --- | --- |
| ⌘K / Ctrl K | 聚焦搜索栏 |
| ⌘1–⌘5 | 切换分栏：全部、未读、待办、稍后读、收藏 |
| Esc（菜单打开） | 关闭菜单 |
| Esc（搜索栏有文字） | 清除文字 |
| Esc（只剩标签） | 清除标签，回到全部 |
| Esc（搜索栏为空） | 搜索栏失去焦点，宽度保持不变 |
| 删除键（光标在最前） | 删除最后一个标签 |
| 回车（# 列表打开） | 选中高亮项，变成 # 标签 |

Esc 每次只退一层，顺序为：菜单 → 文字 → 标签 → 焦点。

### 网页交互细节

| 操作 | 结果 |
| --- | --- |
| 悬停搜索栏、头像、⌄ | `dur-hover` 160ms 变化，只在支持悬停的设备上 |
| 点搜索栏 | 宽度不变，显示光标和聚焦边框 |
| 点卡片区空白 | 搜索栏失焦，文字和标签保留，宽度保持不变 |
| 选分栏后输入文字 | 在该分栏里搜索 |
| 打开详情再关闭 | 回到原搜索条件和原滚动位置 |
| 窗口缩到 650px 及以下 | 改用移动布局：分栏回到胶囊行，导航胶囊回来，AI 框隐藏 |

### 网页状态

| 状态 | 表现 |
| --- | --- |
| 分栏或搜索没有结果 | 卡片区显示现有空状态，顶栏不变 |
| 拖动中 | AI 框 `accent` 描边加提示文字；松手后恢复 |
| 多选中 | AI 框隐藏，多选条在同一位置 |
| 内置 AI 未接入 | 发送和麦克风禁用；不显示运行状态、会话内容或回复，不伪造会话与结果 |
| 输入与上下文卡 | 只保留在当前页面会话中 |

### 设置弹窗

Web 桌面与 macOS 相同；手机是整页。画板 `MacChrome`。

| 部分 | 数值 |
| --- | --- |
| 打开方式 | 点头像；macOS 另有 ⌘, 与菜单「设置…」。不另开系统窗口 |
| 容器 | 窗口中央，宽 840（不超过窗口宽减 32）；分组区固定高 560（`settings-body-height`），切换分组不改变弹窗大小；内容更多时右侧滚动，窗口不够高时一起缩小；`canvas` 底，`sheet-radius` 28，`shadow-sheet`；其余部分盖 `dim` 遮罩 |
| 头部 | 「设置」34/700，字距 -0.025em；右侧 44 圆形关闭钮，`faint` 底，无描边、无阴影；最小高 60，上 16、左右 32 |
| 分组 | 左侧 200 宽，选中项为 `card` 底的浮起行；左右栏顶部留白同为 28；右侧分组标题 `panel-title` 22，内容区上下 28、左右 32 |
| 关闭 | Esc、点遮罩或关闭钮；焦点回到打开前的位置 |

设置的分组、内容、即时生效和失败回退保持不变。

设置现行画板为 [桌面设置](../boards/SettingsDesktop.dc.html)与[手机设置](../boards/SettingsMobile.dc.html)，由产品组件和样式生成。分组切换只用于查看，不执行保存、导出或删除。

### 资讯阅读

只用于资讯卡；预览浮层和全屏阅读页相同，Web 与 macOS 相同。画板 `ArticleReading`，数值见[字体](foundation.md#字体)与[间距与尺寸](foundation.md#间距与尺寸)。

- 顺序：来源 · 日期 · 阅读时长 → 标题 → 标签与出版信息 → 封面 → 导语与要点 → 正文 → 备注。日期只在来源行出现一次，写「今天」「昨天」「10/18」，跨年加年份；取发布日期，没有时取保存日期，再没有时取卡片时间。
- 正文使用可用宽度，左右 30（手机 20），不限制最大宽度。预览浮层宽度不变，全屏正文随窗口扩展。
- 工具条、进度线、读完圆环、收起与关闭沿用原有规则。不加折叠区、属性侧栏或信息表。
- 其他类型的预览与阅读页不使用资讯阅读变量。

## 桌面阅读与操作细节

- 键盘打开搜索、记一笔及详情时立即显示并聚焦，关闭也立即响应；点击和触摸保留已有空间过渡。手机详情正文与抽屉同时出现，不再单独等待 200ms。
- 卡片的来源与标题间隔 12px，标题与摘要间隔 6px；正文与清单、附件、关联内容之间使用 12px，保留手机现有密度。无可执行动作的邮件附件使用静态文件行，不做按钮外观。
- 桌面待办文字最多两行，圆圈与首行对齐。全部完成后保留原有清单结构和可恢复的勾选项，仅改变完成色，不压缩成完成横条。
- 建议卡显示两个关联预览；更多关联以“另有 N 项关联内容”说明，完整关联仍在详情查看。
- 短待办、提醒及短笔记预览保留较窄面板；普通卡片详情的桌面左右内边距为 30px，全屏时占满剩余宽度。资讯也采用相同内边距，不另设正文宽度上限。短内容末尾到工具条保持清晰分隔，不添加多余空白。
- macOS 搜索与 Web 使用相同分类入口与按需展开的状态、标签筛选；标签完整显示，各行可横向滚动。Toast 采用同一暂停规则。

窄桌面仍在容纳两列最小宽度时保留两列；三列及以上才要求每列达到理想阅读宽度，避免小窗口退成过宽单列。

主页分栏滚动时保持可见。读完、完成提醒或勾选待办只更新状态，不改变当前信息流的成员、顺序、叠卡分组和卡片占位；任务预览保留当前行。切换分栏或主动刷新后再应用最新筛选和排序。

## 移动浏览器基础行为

- 悬停反馈只在支持悬停且主指针精确时生效；按下与键盘焦点反馈独立保留。
- Web 桌面卡片的更多按钮隐藏时，顶部信息不预留按钮空位，日期与完成数量靠右对齐；悬停、键盘焦点或菜单打开时恢复空位。触摸设备沿用原有按钮位置。
- 应用与全屏阅读区域使用动态视口高度；Android 软键盘收起布局视口，iOS 继续使用现有 visualViewport 处理。
- 有触屏的设备上，输入字号至少 16px，避免聚焦时页面自动放大；保留用户缩放。16px 是浏览器输入保护阈值，不新增字号等级。
- 按钮禁止长按选中文字，正文和正文链接保留选择与系统菜单。轻点使用 manipulation，已有拖动区域保留自己的手势规则。
- 页面阻止浏览器纵向下拉刷新，内层滚动保留现有边界；横屏不自动放大文字。浏览器栏颜色跟随当前应用主题的 canvas。
- 这些是 Web 平台修复，不改变 macOS 的文案、状态或颜色角色；软键盘、安全区与主屏幕启动须在真机验收。
- PWA 触控与外壳：详情胶囊与底部导航的图标控件禁止文字选择和系统长按菜单。详情图标长按显示名称后，松手不执行动作；键盘聚焦时立即显示同一个名称提示。胶囊两端的名称提示向内侧展开，在 320px 宽度内完整可见。

独立工作台按系统深浅色选择状态栏底色：浅色 canvas 为 #f5f5f7，深色 canvas 为 #111113。登录页使用 card 底色，浅色 #ffffff、深色 #1c1c1f。manifest 保留现有 theme_color，不新增离线缓存。

主页隐藏浏览器根滚动条，不为右侧轨道预留空白；鼠标滚轮、触摸和键盘滚动保持可用。macOS 原生窗口不受此浏览器样式影响。
搜索结果、设置、AI 上下文、多选菜单和云端记一笔遵循同一隐藏轨道规则，仍可滚动到底；只隐藏滚动条，不使用 overflow: hidden 代替。

## 登录与授权

现行画板：[桌面登录](../boards/Login.dc.html)、[桌面授权](../boards/Authorization.dc.html)、[手机登录](../boards/LoginMobile.dc.html)、[手机授权](../boards/AuthorizationMobile.dc.html)。

- 登录内容宽度为 `auth-login-width` 352，授权为 `auth-consent-width` 400；窄屏按可用宽度收缩。两页采用白底、居中窄内容区与蓝色主按钮，不加外层厚卡片。品牌图标、连接图标、标题和状态说明居中；输入标签、账号信息和权限条目左对齐。
- 登录保留邮箱、密码、显示密码、忘记密码和邮件登录入口。标题下不加介绍句，不写“无需记住密码，用邮件中的链接继续”等重复说明，页脚不加标语。
- 邮件登录、重设密码和邮件发送后的状态沿用同一布局。只保留邮箱、必要状态和对应动作；不能用演示反馈表示真实邮件已发送或登录完成。
- 授权页显示申请应用、当前账号、逐项权限和内容范围；删除权限单独列出。应用名称、账号和权限按实际请求显示，不能固定使用画板中的示例值。
- 授权按钮为“取消”和“允许访问”；保留“可在「已授权客户端」中撤销”。取消不得授予权限；允许后的状态须以真实回执为准。
- 手机画板按 390 × 844 展示，与桌面共用页面和交互。手机缩小两侧留白，图标和标题保持居中；输入字号至少 16px，按钮高度至少 44px，内容超出屏幕时可纵向滚动。保持相同的顺序、文案和状态。macOS 对应登录与授权界面沿用同样的居中原则和权限表达。
- 原型页面只展示产品界面，不加顶部品牌栏、“设计预览”标识、页脚页面跳转或状态切换工具。画板之间从设计目录进入，状态通过页面原有操作触发。示例账号和必要的演示结果提示不进入产品页面；画板不提交账号、不发送邮件、不更改权限。

桌面详情工具栏使用 `glass-thick` 底色，按钮为 44，间距 4，胶囊高 60；两端沿用同组阴影。Mac 可点击工具按钮和顶部导航按钮悬停显示手形指针，禁用按钮保持箭头；文字提示与圆形悬停底色保留。

Mac 菜单栏提供「性能追踪」：开始、标记此刻、停止并导出。默认关闭，记录期间标题为「性能追踪 · 记录中」；不在卡片或阅读区新增悬浮入口。此入口是本机诊断工具，Web 不显示。

桌面主页（Web 宽度大于 650、macOS）左右外边距为 6，导航与首末列卡片对齐。卡片区铺满可用宽度，不受内容最大宽度限制；保留列数判断与列间距，卡片宽度均分剩余空间。手机及搜索独立页面保持原布局。

- 资讯和邮件的纯文字摘要以 50–60 字为内容目标，桌面完整显示并自然增高，手机最多显示 4 行；正文依据不足时不凑字。已有要点版和展开叠卡沿用原规则，其他类型不变。

桌面顶栏保留背景色彩，向下渐进模糊至清晰，不铺异色实底。Web 使用 16、8、4px 三层渐进 backdrop-filter，由上至下减弱，向下延伸 12px；控件位于模糊层上方。所有层与顶栏保持固定，不随滚动位移；顶栏父层保持不透明，控件层与三层背景模糊使用同一状态、时长和曲线原位淡出／淡入；收起动画结束后隐藏，恢复时同时显示并开始淡入。不对父层做透明度动画，以免隔断背景采样。不支持时回退 canvas；macOS 26 使用 safeAreaBar 与原生 soft 滚动边缘效果，旧系统使用渐变遮罩材质。搜索框独立采用通透玻璃：Mac 使用原生 clear，Web 使用低填色玻璃，文字与图标不模糊。AI 栏和多选栏保留原生 Liquid Glass 并增加底色（chromeGlassOpacity 0.94）。Web 底部操作栏使用 chrome-glass-filter 的 24px 模糊及较低饱和度。多选栏按按钮内容确定宽度，AI 发送不可用时用次级文字色保持箭头清晰，不改变功能状态。
