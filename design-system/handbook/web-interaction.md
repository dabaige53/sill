## 网页（宽于 650px）

网页只有一个主界面：搜索不另开页面，AI 不另开页面，没有底部导航胶囊。卡片区按可用宽度自动增减列数，宽屏可显示五列、六列或更多，卡片用 A 字号（见[字体](foundation.md#字体)）。

桌面主页（Web 宽于 650、macOS）左右外边距为 12（`space-12` / `feedMargin`），导航与首末列卡片对齐。卡片区铺满可用宽度，不受内容最大宽度限制；保留列数判断与列间距，卡片宽度均分剩余空间。手机及搜索独立页面保持原布局。

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 顶栏 | 左：品牌图标、Sill、⌄；右：搜索栏、头像 | 四者高 40，同一中线 |
| 类型胶囊（只在有文字时） | 全部、资讯、消息…… | 高 32 |
| 卡片区 | 多列卡片，宽屏自动增加列数 | 列宽 280–380，理想 340 |
| AI 框 | +、输入、麦克风、发送 | 640×60，离底 28 |

### 桌面顶栏与 AI 框

**顶栏**

| 部分 | 数值 |
| --- | --- |
| 品牌图标 | 现有应用图标 `sill-icon`，40px，圆角 9 |
| 「Sill」 | 字号 34，字重 700，行高 40；与图标间距 10 |
| ⌄ 分栏按钮 | 20px `muted` 图标，点击区 36 |
| 搜索栏 | 高 40，圆角 20；Web 固定宽 480（`search-focused-width`），随窗口可用空间收缩；macOS 保留原伸缩，待同步 |
| 头像 | 40px 圆，点击区不小于 44 |
| 搜索栏和头像材质 | Web：低填色玻璃（`glass` 35% 加 `glass-filter`），1px `line-card` 内描边；macOS 26+：搜索栏为原生 clear 玻璃，头像为 regular 交互玻璃，旧系统为 Sill 玻璃；文字与图标不模糊；间距 8 |
| ⌘K 提示 | 13px `muted` 纯文字，不加框 |
| 对齐 | 四者同一中线；图标左缘对齐卡片区左缘，头像右缘对齐卡片区右缘。导航行高 64、可见控件高 40；导航行顶部至窗口顶部与导航行底部至首排卡片使用相同留白：Web 为 10（`space-10`），macOS 为 18（`topBarInset / 2`）。因此可见控件上下间距分别为 Web 22、macOS 30。桌面两侧留白均为 12px，品牌与账户分别对齐卡片区两侧 |

- Web 桌面与 macOS 顶栏固定在顶部，向下阅读时向上退出 `dur-tuck` 240ms，停顿、反向滚动或到达边缘时从上向下进入 420ms（`dur-reveal`），网页初次加载保持原位；进入用 `ease-reveal` 曲线，减速均匀，全程可见移动，不回弹；收起用 `ease`。随卡片关闭恢复时，与卡片同一帧开始，用同一个卡片弹簧（`motion.cardSpring`），不延迟。位移包含顶部留白、导航行和模糊下沿 12px，保留布局占位。收起时不可点击或通过键盘聚焦；键盘触发立即显示。底部 AI 栏仍按原滚动规则收起；手机顶栏、底部轨道及详情工具恢复也使用同一 `dur-reveal` 与 `ease-reveal`。
- 顶栏背景保留下面的色彩，向下渐进模糊至清晰，不铺异色实底。Web 用 `edge-blur-strong`、`edge-blur-mid`、`edge-blur-soft`（16、8、4px）三层 backdrop-filter 由上至下减弱，向下延伸 12px；不支持时回退 `canvas`。macOS 用附着在顶栏上的系统 regularMaterial，以渐变遮罩向下减弱；macOS 26 的 safeAreaBar 只保留布局作用，关闭独立的系统滚动边缘效果以免重叠。模糊层与控件共用同一位移动画，父层保持不透明，不单独播放各层透明度。
- 点「Sill」回到顶部。点头像打开设置弹窗。
- 顶栏品牌图形、搜索框、头像、状态和刷新按钮的可见外形统一为 40（`space-40`／`searchHeight`），点击区保留 44（`hitTarget`）。操作图标统一为 20（`space-20`），文字与图标按控件中线居中；Sill 字号仍为 34。
- Web 搜索栏聚焦、失焦及条件变化不伸缩。搜索框获得焦点后直接显示本次页面会话的搜索历史与已有推荐标签，已有查询保留；继续输入文字后收起，输入 # 时显示条件列表。失焦保存非空搜索，最多 8 条，不写入卡片或账号数据。不画聚焦边框与外圈，光标表示正在输入。
- 有文字时，⌘K 提示换成清除按钮。
- Web 搜索采用 Combobox 候选交互：列表直接开关，行高 space-48；方向键、Home/End 移动候选，第一次 Esc 只关闭候选，之后沿用清空文字/条件的顺序。Tab 只接受用户已用方向键或指针明确指向的候选，单纯打开再离开不自动选择。保留原输入节点与查询。历史填入查询；条件标签仍放在框内，只有条件图标从列表移入目标图标位（motion.searchChoice：280ms，cubic-bezier(0.32,0.72,0,1)），文字与框体不缩放。前置搜索图标与条件图标采用 motion.searchIconSpring（0.3s、bounce 0），键盘选择即时；候选高亮共用一个背景，列表重新打开或筛选时直接定位。

**分栏菜单**

| 菜单行 | 右侧 |
| --- | --- |
| ✓ 全部 | ⌘1 |
| 未读 | ⌘2 |
| 待办 | ⌘3 |
| 稍后读 | ⌘4 |
| 收藏 | ⌘5 |

- 默认收起，主页上不显示分栏行。点 ⌄ 在下方弹出菜单，宽 220，`dur-menu` 200ms，收起 `dur-menu-close` 160ms。当前项前有 ✓，快捷键为 `muted`。
- 菜单行保留 `space-40` 点击高度；选中与悬停底色上下各内缩 `space-1`，相邻底色之间保留 2px 间隙。
- 选择后菜单关闭。选「全部」以外的项时，该项以 `ink` 底标签放进搜索栏，占位字改为「在未读里搜索」这类说法，卡片区只显示该分栏。选「全部」移除分栏标签。
- 每个分栏分别保留滚动位置，切回时回到原处。
- 菜单里的 ✓ 跟着搜索栏里的分栏标签走：删掉标签，✓ 回到「全部」。
- Esc 或点菜单外面：关闭菜单，不改变分栏。菜单打开时，上下方向键移动高亮，回车选择。

**搜索**

- 搜索栏在顶栏，不另开页面。⌘K / Ctrl K 聚焦搜索栏。
- 结果在卡片区原地显示，保持多列布局。有文字时，顶栏下方显示一行类型胶囊：全部、资讯、消息、笔记、待办、日程、媒体，只列出当前文字下有结果的类型（已选中的类型始终保留）。胶囊与手机搜索页同一组件，高 32，间距 8，左缘对齐卡片区。文字清空时这一行收起，类型选择同时取消，不在看不见时继续筛选。
- 输入 # 时，搜索栏正下方浮出列表，宽同搜索栏，不推开卡片：先「状态」（未读、收藏、稍后读），后「标签」（只列已有标签）；继续输入按名称过滤。已经是分栏标签或 # 标签的状态不再列出。方向键移动高亮，回车或点选后成为 `accent` 底的 # 标签，排在分栏标签后面，输入中的 # 片段从文字里去掉；末尾的 # 片段不参与文字匹配。搜索栏失去焦点时列表收起。
- 分栏标签、# 状态、# 标签、类型胶囊和文字同时生效。切换分栏保留文字、# 标签和类型选择。
- 输入法组词、命中词加粗与移动相同（见「搜索与键盘」）。
- 主页分栏与搜索共用一个状态：分栏就是搜索栏里的一个标签，可以接着输入文字，在该分栏里搜。
- 点标签上的 ×，或光标在标签后按删除键：移除标签，回到全部。
- 不显示结果数量，本地搜索不显示加载动画。新内容提示放在顶栏下方居中。

**拖入卡片**

- 鼠标按住卡片即可拖动，也支持长按后拖动；触屏仍先长按，短滑保持滚动。拖动时显示卡片缩略图，原卡留在原处。

| 步骤 | 结果 |
| --- | --- |
| 开始拖动卡片 | AI 框显示 `accent` 描边和「松手，把卡片交给 AI」。拖动期间 AI 框放大到 1.02，并有 `accent` 圆环从框边向外扩 14 并淡出，每 1.2 秒一次；拖到框上放大到 1.05（`motion.aiDrop`）。按住选中但尚未移动时不算拖动，AI 框不出现 |
| 拖到 AI 框上松手 | 卡片成为框上方的上下文卡：`card` 底、细边、可点 × 移除 |
| 拖到别处松手 | 没有变化 |
| 连续拖入 | 可以放多张，按拖入顺序排列 |

- 原卡不移动，不改变状态。键盘用户用多选条的「交给 AI」代替拖动。

**会话：一行、展开、完整**（内置 AI 接入后启用）：AI 框按需长高为展开面板和完整视图，规则见 [AI 对话](ai-conversation.md)。

**多选**：多选条与 AI 框共用底部轨道，AI 框宽 640，多选条按按钮内容收窄；同高 60、同一位置、同一材质，一次只出现一样。

| 从左到右 | 图标 |
| --- | --- |
| 数量 | 数字 |
| 收藏 | bookmark |
| 稍后读 | glasses |
| 标签 | tag |
| 交给 AI | chat |
| 分隔线 | — |
| 取消 | x |

- 按钮 44 见方，整组居中。全部选中卡片已收藏时，收藏按钮显示蓝色并执行批量取消；混合选择沿用全部收藏。Web/PWA 不提供多选条右键菜单。
- 「交给 AI」：把所选卡片放进 AI 框，退出多选，AI 框回来。退出多选后，AI 框原有输入和上下文卡保留。

### 网页键盘

| 按键 | 结果 |
| --- | --- |
| ⌘K / Ctrl K | 聚焦搜索栏 |
| ⌘1–⌘5 | 切换分栏：全部、未读、待办、稍后读、收藏 |
| Esc（菜单打开） | 关闭菜单 |
| Esc（搜索栏有文字） | 清除文字 |
| Esc（只剩标签） | 清除全部标签，回到全部 |
| Esc（搜索栏为空） | 搜索栏失去焦点并缩回 |
| 删除键（光标在最前） | 删除最后一个标签：先 # 标签，再 # 状态，最后分栏标签 |
| ↑ / ↓（# 列表打开） | 移动高亮 |
| 回车（# 列表打开） | 选中高亮项，变成 # 标签 |

Esc 每次只退一层，顺序为：菜单 → 文字 → 标签 → 焦点。「标签」一步清掉分栏标签和全部 # 标签，回到全部。

### 网页交互细节

| 操作 | 结果 |
| --- | --- |
| 悬停搜索栏、头像、⌄ | `dur-hover` 160ms 变化，只在支持悬停的设备上 |
| 点搜索栏 | 伸长到 480，显示光标，不画聚焦边框 |
| 点卡片区空白 | 搜索栏失焦并缩回，文字和标签保留 |
| 选分栏后输入文字 | 在该分栏里搜索 |
| 打开详情再关闭 | 回到原搜索条件和原滚动位置 |
| 窗口缩到 650px 及以下 | 改用移动布局：分栏回到胶囊行，导航胶囊回来，AI 框隐藏 |

### 网页状态

| 状态 | 表现 |
| --- | --- |
| 分栏或搜索没有结果 | 卡片区显示现有空状态，顶栏不变 |
| 拖动中 | AI 框 `accent` 描边加提示文字；松手后恢复 |
| 多选中 | AI 框隐藏，多选条在同一位置 |
| 内置 AI 未接入 | 发送和麦克风禁用；不显示会话按钮、运行状态、会话内容或回复，不伪造会话与结果 |
| 输入与上下文卡 | 只保留在当前页面会话中 |

### 设置弹窗

Web 桌面与 macOS 相同；手机是整页。画板 `MacChrome`。

| 部分 | 数值 |
| --- | --- |
| 打开方式 | 点头像；macOS 另有 ⌘, 与菜单「设置…」。不另开系统窗口 |
| 容器 | 窗口中央，宽 840（不超过窗口宽减 32）；分组区固定高 560（`settings-body-height`），切换分组不改变弹窗大小；内容更多时右侧滚动，窗口不够高时一起缩小；`canvas` 底，`sheet-radius` 28，`shadow-sheet`；其余部分盖 `dim` 遮罩 |
| 头部 | 「设置」34/700，字距 -0.025em；右侧 44 圆形关闭钮，`faint` 底，无描边、无阴影；最小高 60，上 16、左右 32 |
| 分组 | 左侧 200 宽，选中项为 `card` 底的浮起行；左右栏顶部留白同为 28；右侧分组标题 `panel-title` 22，内容区上下 28、左右 32 |
| 关闭 | Esc、点遮罩或关闭钮；焦点回到打开前的位置 |

设置的分组、内容、即时生效和失败回退保持不变。

设置现行画板为 [桌面设置](../boards/SettingsDesktop.dc.html)与[手机设置](../boards/SettingsMobile.dc.html)，由产品组件和样式生成。分组切换只用于查看，不执行保存、导出或删除。

### 卡片日期

- 同一个内容日期在卡面、预览和放大阅读页使用同一格式：今天、昨天、10/18；跨年显示 2025/10/18。资讯、笔记、视频、播客、照片、邮件等均沿用此规则。
- 按设备本地日历判断今天和昨天。只有日期的值保持原日期；带时区的时间先转换为本地时间。未来日期直接显示月日，不显示今天。
- 邮件发送时间和 PR 记录时间保留时分，例如「今天 09:30」；原值只有日期时不补 00:00。照片日期不添加时分。
- 日程时间、任务截止时间和汇总覆盖范围保留各自的业务格式。日期缺失时不补造；资讯沿用下面的发布日期、保存日期、卡片时间顺序。

### 卡片详情内的导航与媒体

见[导航与媒体规则](web-reading.md#卡片详情内的导航与媒体)。

批量收藏、稍后读和标签操作后保留多选与操作胶囊；操作完成不等于退出多选。实际拖动时，Web 主页显示已有 AI 框，手机和搜索把原胶囊切换成 AI 输入接收框；松手到目标后加入上下文，取消则恢复操作条，不增加发送请求。

手机搜索先展示分类浏览。点击搜索框时，上移到安全区下方，右侧显示文字「取消」，空框展示本次页面会话的搜索历史；点击直接聚焦输入框，由系统显示键盘。取消保存非空查询并恢复浏览，历史去重最多8条。筛选变化保留输入节点、光标和键盘，历史不写入卡片或账号。点击和取消按motion.phoneSearch编排：栏410ms、取消280/200ms、结果130ms延迟后200/400ms、底栏200/300ms；具体曲线及配合见动效手册。AI 折叠与底部交接遵循[动效](motion.md#状态之间的交接)。
