## 两端对照

窗口宽 650px 及以下用「移动」规则，宽于 650px 用「网页」规则。移动的决定见 [ADR 0048](../../docs/adr/0048-phone-top-row-and-search-tokens.md)，画板 `PhoneChrome`；网页的决定见 [ADR 0049](../../docs/adr/0049-web-top-search-and-ai-dock.md)，画板 `WebChrome`。

| 项目 | 移动（≤650px） | 网页（>650px） |
| --- | --- | --- |
| 顶部 | 每页一行：左侧页名 34/700，右侧 36px 圆钮 | 一条顶栏：品牌图标 + Sill + ⌄，右侧搜索栏 + 头像，统一 40 高 |
| 主页分栏 | 顶行下方一行实心胶囊，常驻 | 默认收起，从 ⌄ 菜单选，选中后成为搜索栏里的标签 |
| 搜索 | 独立页面：分类卡 → 结果页 | 顶栏里直接输入，结果在卡片区原地显示 |
| 搜索条件 | 分类标签（`ink`）+ # 标签（`accent`） | 相同 |
| 主页与搜索的状态 | 分别保存 | 共用一个状态 |
| 底部 | 导航胶囊「主页 / AI / 搜索」 | 只有 AI 框，没有导航胶囊 |
| AI | 独立页面，右上「历史」「新对话」 | 底部 AI 框，可拖入卡片，可展开成完整视图 |
| 多选条 | 与导航胶囊同一轨道，出现时胶囊隐藏 | 与 AI 框同一轨道，同宽同高，出现时 AI 框隐藏 |
| 设置入口 | 主页和搜索右上的头像，进入设置页 | 顶栏右侧的头像，打开居中设置弹窗（macOS 另有 ⌘,） |
| 内置 AI 未接入时 | 发送、语音、历史、新对话禁用 | 发送、麦克风禁用；不显示会话 |

两端共用：卡片组件与卡片动作（A 字号）、详情抽屉与阅读页（资讯卡用资讯阅读排版）、类型胶囊组件、分类与 # 标签规则、命中词加粗、输入法组词规则、Toast、记一笔与 N、R / T。

## 移动（650px 及以下）

三个页面：主页、AI、搜索。设置是从头像进入的页面，不是第四个导航项。详情和阅读仍是抽屉，不算页面。

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 顶行 | 页名 + 右侧圆钮 | 高 60 |
| 分栏（只在主页） | 全部、未读、待办、稍后读、收藏 | 高 44 |
| 卡片区 | 卡片，单列 | 页边距 16，卡片间距 12 |
| 导航胶囊 | 主页、AI、搜索 | 高 60，离底 16 + 安全区 |

### 手机主页

按 [Apple Music 主页](https://mobbin.com/screens/8c345080-d9bd-4ad5-a6c7-8e5b32445b20) 调整标题、头像和导航层级；卡片仍承载 Sill 的内容。

**顶行**：主页、AI、搜索三页相同。

| 部分 | 数值 |
| --- | --- |
| 高度 | 60 |
| 页名 | 「Sill」「AI」「搜索」，字号 34，字重 700，起点在页边距 16 |
| 右侧圆钮 | 36px 圆，点击区 44，与页名垂直居中 |
| 主页、搜索右侧 | 头像，进入设置；没有真实头像时用现有 person 图标，不虚构用户照片 |
| AI 右侧 | 「历史」（clock）和「新对话」（plus），间距 4，不放头像 |
| 底色 | `canvas` 加轻磨砂；内容滚到下方时保持清晰，不叠加厚玻璃或硬分隔线 |

- 点「Sill」：主页回到顶部，工具条出现。
- 下拉刷新时，刷新指示器在顶行正中，不遮住左侧页名。
- 搜索结果页不显示顶行。

**分栏**：顶行下方一行实心胶囊，与搜索结果的类型胶囊是同一组件。

| 部分 | 数值 |
| --- | --- |
| 行高 | 44 |
| 胶囊 | 高 32，全圆角，左右内边距 14，文字 14（`text-control`），间距 8 |
| 当前项 | `ink` 底，`card` 字，字重 600 |
| 其他项 | `card` 底，1px `line-card` 内描边，`ink` 字 |
| 选项 | 全部、未读、待办、稍后读、收藏 |

- 第一个胶囊与页边距 16 对齐。放不下时整行横滑，不压缩间距，不平分宽度。
- 切换分栏立即更新卡片区。每个分栏分别保留滚动位置，切回时回到原处。
- 分栏只作用于主页，不影响搜索。
- 读完、勾选待办等状态变化不改变当前列表的成员和顺序；切换分栏或刷新后再应用。

**卡片**

- 页边距 `margin-sm` 16，卡片间距 `gap-sm` 12，卡片圆角 `card-radius-sm` 16，内边距 `card-padding-sm` 16。标题、摘要与桌面同用 `card-title`、`summary`，摘要最多两行；已读只改变颜色。
- 页名、卡片左边线与第一个胶囊起点对齐。
- 保留原有卡片细节：文章 76px 缩略图；媒体与照片 2:1 大图；日程左侧时刻、右侧标题和时长；待办与提醒圆圈直接完成 Sill 内状态；附件占满整行。
- 新内容提示在分栏行下方；详情关闭后保留原阅读位置。

### 搜索与键盘

以 [Apple Music 顶部搜索栏](https://mobbin.com/screens/0fdc7e6a-e4aa-4c5a-8879-84396df1a589)、[分类网格](https://mobbin.com/screens/38013fe5-6e15-4038-9c0f-039bf66715c7)、[结果分类](https://mobbin.com/screens/6e9cc18e-6337-481f-91c5-d7ab3f09c247) 和 [搜索流程](https://mobbin.com/flows/aa6db5b1-4567-4ab8-9d57-c348a0e03f82) 为视觉依据。搜索栏始终在页面上方，不采用 Apple Music 的底部搜索栏；不复制音乐广告、播放器或系统状态栏。

**搜索首页**

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 顶行 | 「搜索」+ 头像 | 高 60 |
| 搜索栏 | 占位字「卡片、备注、来源」；`surface` 实底，胶囊圆角，无阴影 | 高 44，左右边距 16 |
| 分类卡 | 分类名称和已有内容封面，不加说明和数量 | 两列，16:10，间距 12，圆角 12，与搜索栏间距 16 |

- 页面底色为 `card` 实色。不显示筛选行，不显示虚构的「热门搜索」。
- 点分类卡：进入结果页，分类作为标签放进搜索栏。
- 输入文字并确认（输入法组词结束）：进入结果页。

**结果页**

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 搜索栏 + 关闭钮 | 分类标签、# 标签、文字依次排列 | 栏高 44，关闭钮 44 |
| 类型胶囊（只有文字时） | 全部、资讯、消息、笔记、待办、日程、媒体 | 高 32，间距 8 |
| 卡片区 | 结果卡片 | 同主页 |
| 导航胶囊 | 保留；搜索图标带 5px 小点 | 同主页 |

- 不显示顶行。点关闭回到搜索首页，清空本次条件。
- 分类标签：`ink` 底、`card` 字。结果只显示该分类，可以继续输入文字缩小范围。栏内有分类标签时不显示类型胶囊。
- 类型胶囊与主页分栏是同一组件；未选中项用 `surface` 底，无描边。没有结果的类型不显示。
- 左右滑动结果区切换类型，胶囊同步滚到可见位置。每个类型分别保留滚动位置。
- 搜索栏里有分类或 # 标签时，导航的搜索图标显示 5px 小点，不显示数量。

**# 条件**：取消「筛选」展开区，状态和标签改为在搜索栏输入 # 选择。

| 步骤 | 结果 |
| --- | --- |
| 在搜索栏输入 # | 搜索栏下方浮出列表，浮在结果上方，不推开结果 |
| 列表内容 | 先「状态」：未读、收藏、稍后读；后「标签」：只列已有标签，没有标签时不显示这一组 |
| 继续输入 | 按名称过滤列表 |
| 点选或按回车 | 条件变成 `accent` 底、白字的 # 标签，列表收起 |
| 点空白处或删掉 # | 列表收起，不加条件 |

- 分类标签、# 标签和文字可以同时存在，结果同时满足全部条件。
- 删除键从后往前逐个删除：先删文字，文字为空时删最后一个标签。标签多时在搜索栏内横滑，栏高不变。
- 状态只有未读、收藏、稍后读三项，不新增筛选能力。
- 命中词加粗，不加底色。不显示结果数量。输入法组词时不筛选，确认后更新；本地搜索不显示加载动画。
- 搜索和主页分别保存查询、条件及滚动位置。从搜索打开详情后，返回原查询与位置；浏览器前进后退遵循同样顺序。
- 软键盘只缩小可用内容区，不移动顶部搜索栏。

### 底部导航与反馈

**导航胶囊**

| 部分 | 数值 |
| --- | --- |
| 胶囊 | 居中，高 `rail-row` 60，每格 `nav-tab` 76，内边距 4 |
| 位置 | 离底 16 加安全区 |
| 图标 | 现有 Mono24 图标，居中，不显示文字；当前项 `ink`，其他 62% `ink` |
| 顺序 | 主页、AI、搜索，固定 |

- 切换立即更新，玻璃镜片换格，不拉伸，不弹跳。页面切换不播放整页过渡。导航常驻，搜索结果页也保留。
- 往下滚 28px 收起，往上滚 14px、停下 650ms、到顶或到底时回来。
- 软键盘出现时导航让开。

**AI 页**：参照 [X 的对话页](https://mobbin.com/screens/cc84d28a-3220-439b-ac7a-18f7778642e4)。

- 顶行左侧「AI」，右侧「历史」「新对话」。
- 输入框左右外边距 12，圆角 24，内边距 12。上排为 17px 输入；下排为附件、发送和语音。附件和语音高 32，发送为 24px 圆，语音为黑色胶囊。
- 输入框底色 `ai-composer`，控件浅底 `ai-control`。输入框跟随软键盘上沿，底部导航暂时隐藏。
- 已选卡片作为上下文卡显示在输入框上方。空白区域留白，不放引导句、功能说明或「输入不保存」等备注。

**设置**：从主页和搜索的头像进入，保留返回按钮、分组和现有轻操作。打开设置时不把导航镜片移到不存在的一格。记一笔仍在设置的「添加」组。

**多选**：多选条与导航胶囊在同一轨道。多选条出现时导航胶囊隐藏，退出多选后回来。动作为数量、收藏、稍后读、标签、交给 AI、取消。详情打开时背景工具条留在遮罩下，关闭后自然显露。

### 移动交互细节

| 操作 | 结果 |
| --- | --- |
| 点顶行「Sill」 | 主页回到顶部，工具条出现 |
| 点头像 | 进入设置；设置有返回按钮 |
| 点分栏胶囊 | 卡片区立即切换，回到该分栏上次的位置 |
| 横滑分栏行 | 只滚动胶囊行，不切换分栏 |
| 输入法组词中 | 不筛选；组词结束后更新 |
| 搜索结果里打开卡片，再关闭 | 回到原查询和原滚动位置 |
| 浏览器返回 | 先关最上面的抽屉，再回到上一个搜索状态 |
| 下拉主页 | 刷新；指示器在顶行正中 |
| 长按工具图标 0.45 秒 | 图标上方显示名称，这次按下不执行 |

### 移动状态

| 状态 | 表现 |
| --- | --- |
| 分栏没有卡片 | 显示现有空状态，不显示数量 |
| 搜索没有结果 | 显示现有空状态；不显示结果数量和加载动画 |
| 内置 AI 未接入 | 发送、语音、历史、新对话禁用；不伪造历史、会话或回复 |
| 输入内容 | 只保留在当前页面会话中 |

## 两端共用

- 键盘：N 记一笔，R 刷新，T 回到顶部；只在没有输入焦点时生效。下拉刷新保留。
- 任务完成、提醒操作、批量收藏与稍后读、归档与放回桌面、记一笔不弹成功提示，不提供弹窗撤销。必要的普通说明在可见且未被操作的累计 3.2 秒后淡出；页面不可见、窗口失焦、指针或键盘焦点进入时暂停。失败提示持续显示并可关闭。Toast 不遮挡当前操作。
- Web 本地同步失败时，搜索框左侧只保留一个琥珀色信息图标（手机位于顶栏），详情使用独立浮窗，不占信息流空间、不改变卡片布局，点击展开原因与操作，再次点击、点外部或按 Esc 收起。重试、导出使用现有图标，提供中文读屏名称和悬停提示；使用服务端版本保留文字及确认。草稿无法持久保存时自动展开提醒。窄屏操作换行；隐藏重复的「未连接」浮标，处理完成后恢复原有连接提示规则。
- macOS 的工作区错误在搜索框左侧收成同款信息图标，点击展开原因、刷新与关闭；收起后保留图标。写入结果未知时默认展开。刷新只重新读取，不重发写入；必要的普通提示沿用原有文字和计时。
- 卡片动作与多选动作保持原位置。设置与 AI 共用现有文案、颜色和尺寸角色，不新增后端能力。
- macOS 使用已确认的统一信息流、搜索、分栏菜单与 AI 框；视觉与动效对齐 Web，不改信息结构。会话、历史和完整视图在内置 AI 接入后启用。
- Esc 每次只关闭最上层：系统确认框、设置等弹窗、阅读详情、分栏菜单，最后才处理主页搜索。关闭上层保留底层的搜索文字、筛选与阅读位置。弹窗或详情打开时，主页搜索及分栏快捷键不生效。
- 普通点击或触摸关闭详情后，不显示标题的键盘焦点框；键盘操作仍保留 focus-visible，多选框不变。阅读到底当次滚动即更新状态，不等额外上推或动画；短文停留 1.2 秒后才算读完，隐藏页面、关闭或换卡后不计入。滚动监听不因首次内容较短而缺失。

## 预览与叠放

- 抽屉打开后固定背景并保留滚动位置，关闭后还原。内容用原生惯性滚动，不显示滚动条但保留键盘滚动；触摸跟手不加过渡。到顶后继续下拉移动整张抽屉（见「下拉关闭」）；到底后开启「读完上推收起」时由读完圆片接管，关闭时只有轻微阻尼（最多 14px）。灰色把手是独立拖动区：上拖展开，下拖收起，拖过 160px 不论全屏与否直接关闭；取消触摸恢复原尺寸，松手才播放回位动效。
- 顶部显示来源、内容日期与结构化预计阅读时长，过长截断。预计时长统一显示「约 N 分钟阅读」，已有内容范围显示「当前内容约 N 分钟阅读」，缺失或清除时不显示。来源、发布方和作者按卡片类型合并显示，不把来源当成作者。标题下放标签，再进入摘要和正文。内容日期在卡面、预览和阅读页均显示「今天」「昨天」「10/18」，跨年带年份；只在来源行出现一次，不加「发布于」前缀。具体见[卡片日期](web-interaction.md#卡片日期)。来源备注只用于补充不同的信息，内容写入时避免重复出处和日期；界面保留已有备注，不自动解析或删除文字。个人备注仅来自个人状态 note，信息流卡片不显示；预览和放大阅读页均在正文末尾用同款轻边框区显示，并标记「备注」。卡片 meta 与文件 meta 不再使用，不推断成备注。沿用正文区现有段间距，不额外叠加顶部留白；读完手势的尾部空间放在信息区之后。两者均无值时不渲染信息区；内容时间信息不添加背景、边框或折叠按钮；个人备注使用上一条规定的边框。资讯没有发布时间时依次使用保存日期、卡片时间；其他类型缺失时不补造日期。完整时刻保留在日期提示中；收录、保存和更新时间不另设信息行，原始数据保留；业务专用备注保持原位置。
- 抽屉按实际内容决定高度；短内容不撑满屏幕，长内容初始最多占用可视高度减 64px，正文在抽屉内滚动。手机向下阅读时自然扩展到全屏；主屏幕 PWA 不显示放大按钮，沿用滚动扩展。顶部安全区和底部工具条须避开正文。
- 标签放在标题下面，用较小的非交互标签；来源头部承载来源、内容日期和预计阅读时长，来源备注在正文末尾。打开与关闭都有动效；

- 同一张卡在信息流和预览里用同一个头部。正文里不放色块按钮；只有「为什么看到」和交给助手这类文字链接留在内容末尾（[ADR 0037](../../docs/adr/0037-card-detail-toolbar.md)，`CardDetail` 画板）。
- 操作都在底部玻璃胶囊里，只用图标：左边是通用操作「收藏、标签、稍后读」，`ink`；一条竖线之后是这张卡片自己的操作，最多 3 个，`accent`。邮件「回复」；文章、视频、播客「去原文」；提醒和待办「在 Sill 内再提醒」、「忽略此提醒」。日程已显示「加入」时，顺序为「加入、在 Sill 内再提醒、忽略此提醒、下载日程」；没有显示「加入」时仍为「在 Sill 内再提醒、下载日程、忽略此提醒」。先排除不可用和被用户隐藏的操作，再取前三个，因此下载可在前面操作隐藏后补位（[ADR 0040](../../docs/adr/0040-event-reminder-priority.md)）。一边为空时不画竖线；全部隐藏时不显示胶囊。
- 名称写在 `aria-label`。触屏长按 0.45 秒在图标上方显示名称（`ink` 底、`card` 字），这次按下不执行；鼠标首次悬停 0.5 秒显示；提示出现后，800ms 内移到相邻工具立即显示名称，不重复入场。
- 提醒的「完成」是标题前的圆圈，和卡面同一个控件，只改 Sill；完成后再点恢复。胶囊里的「在 Sill 内再提醒」也只改 Sill，不改来源时间。
- 照片大图页在缩略图下放通用操作胶囊：收藏、标签、稍后读，遵守隐藏偏好，不增加专属操作。照片固定黑底，胶囊在两种主题下均复用现有深色变量。胶囊参与排版，不覆盖照片、缩略图或助手交接；保存或取消标签后回到原照片（[ADR 0041](../../docs/adr/0041-photo-shared-toolbar.md)）。
- 设置「卡片操作」每行在名称下方显示 muted 灰字示例：通用三项为所有卡片，回复为邮件，去原文为文章、视频等，加入和下载为日程，再提醒和忽略为待办、日程、提醒。复用现有 small 行样式；示例不改变开关名称、顺序、隐藏偏好或动作可用条件（[ADR 0042](../../docs/adr/0042-card-action-type-examples.md)）。
- 设置「桌面」页的「卡片操作」可以关掉任何一个操作（偏好 `hiddenActions`）。关掉只影响显示，功能和 MCP 不受影响。
- 胶囊在卡片内部底边上方，下面有滚动边缘。手机上正文最后一行到胶囊 26px，胶囊到底边 `max(8px, 安全区)`；读到底时内容、备注、标签和文字链接都在它上方完整露出。
- 关闭和全屏浮在来源行右侧：macOS 26 及以上使用原生玻璃圆片，Web 使用白色圆片，与来源行（发件人、来源名、日期）居中对齐，不占一条白带；标题占满宽度。没有来源行时对齐标题首行。往下读时和工具条一起收起，停下时回来，下面垫一层渐隐，不压正文。阅读页右上是退出全屏和关闭阅读的玻璃按钮组。
- 普通卡片详情的桌面左右内边距为 30px（`space-30` / `previewPaddingX`），预览与全屏一致；全屏内容占满剩余宽度，不另设居中正文宽度上限。资讯采用相同的 30px 左右内边距，不再设置 600px 正文宽度上限。手机保留现有窄屏内边距。
- 详情和阅读页里没有头像、设置或底栏。
- 提醒没有时间时，头部只写「提醒」，不显示 `meta` 等状态文字。关联卡下面列出了引用卡，头部不再写「来自 N 张卡片」。
- 在预览里打开引用卡时叠放：新卡盖在上面，下面那张露出顶边，点顶边回到下面那张。
- Web 桌面与 Mac 不支持下拉关闭详情；手机保留。✕、Esc、手机下拉、点遮罩、读完上推、浏览器返回每次只关最上面一张，露出下面那张（[ADR 0046](../../docs/adr/0046-backdrop-closes-one-stacked-card.md)）。

## 量大与时间

- 同一来源一小时内超过 5 张，自动叠成一摞，像一副牌：一篇一张完整的卡，位置写在每张卡右上角（「2/6」）。左右翻看时移动的是整张卡，不是卡里的文字：最上面一张只平移跟手走，下一张从下面显露；松手过三分之一或快速一甩，上面那张整张飞出；往右拖是上一张从左边盖回来；不够就弹回。手指、鼠标拖动、触控板横扫、方向键都可以。卡在手里或飞出时压在旁边的卡上面。点按或回车才在原地展开整摞，拖动结束不算点按。
- 同一篇内容从多个来源进来时合并成一张卡，头部叠放来源图标。
- 读过或完成的卡片只改变颜色，始终保留在主页；时间流逝、阅读完成、任务完成、提醒完成或免打扰都不能自动收起卡片。只有明确归档才移出主页；保留已有真实归档状态。完成任务或提醒后保持当前顺序，后台保存、加载更多和切换分栏不重排；用户主动刷新或更换排序方式后再重新排序。
