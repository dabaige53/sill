# 页面与交互

[返回设计手册](../README.md)。

## 手机主页

2026-10-18 定稿，参考 X 的密度，仍然是卡片。间距、缩略图、日程排法和带标志的顶栏只在手机宽度生效；提醒卡、勾选圈和新内容提示的写法两端一致。2026-10-19 按 [ADR 0043](../../docs/adr/0043-desktop-home-filters.md) 给桌面补左上紧凑分栏，卡片密度仍不变。见设计画布 36 号画板和 [ADR 0036](../../docs/adr/0036-phone-home-density.md)。

- 间距：页边距 `margin-sm` 8，卡片间距 `gap-sm` 6，圆角 `card-radius-sm` 16，内边距 `card-padding-sm` 14。阴影保留，已读未读规则不变。
- 摘要最多 2 行。带人像的头部合成一行：20px 人像、名字 600 `ink`、「· 邮件 · 时间」`muted`。
- 文章封面改成右侧 `thumb` 76 见方的缩略图，圆角 `control-radius`；视频和照片保留大图，比例 2:1。
- 附件和引用条占满整行。
- 日程卡：开始时间放在左侧一列（`figure-route` 28，圆体），右侧上行写标题，下行写「至 结束时间 · 共 N 分钟」；参与者和「加入」在同一行，「加入」靠右。
- 提醒卡：头部写「提醒 · 来源名」，右侧写来源里的提醒时间；到点用 `alert`，未到点用 `muted`，不写「现在可以处理」等状态句。卡上没有按钮：圆圈就是「完成」，只改 Sill 里的状态。详情里的「完成」也是标题前的圆圈，「在 Sill 内再提醒」在底部胶囊里，不改来源里的时间（见「预览与叠放」）。
- 待办卡：每项高 28，圆圈 18；不写「另有 N 项」，头部右侧的「1/4」已说明总数。勾选只改 Sill 里的状态。
- 顶栏：状态栏下方是居中的 Sill 标志（点它回到顶部），下面一排分栏标签「全部 / 未读 / 待办 / 稍后读 / 收藏」。当前一格 `ink` 加粗，下方 3px `ink` 短线；其余 `muted`。「待办」包括待办和提醒。标签只筛主页，不改搜索的筛选。顶栏用 `frost` 磨砂底和 0.5px `line` 底线。
- 主页顶栏与分栏在滚动时保持可见；底部胶囊继续按「工具条收起」规则让开。
- 桌面宽度大于 650px 时显示同一组五个分栏，不显示手机标志。分栏宽度包住文字，与实际卡片列的左边对齐；桌面在顶部吸附，使用 canvas 底色，保持可操作。顶部 24px、标签高至少 44px、左右内边距 12px、间隔 8px、字号 14px，下方到卡片 16px；当前项沿用 ink、粗体与 28×3px 下划线。信息流仍使用原有最大宽度 1640px；增加列数前，每列须达到当前密度的理想阅读宽度。五个分栏分别保留滚动位置；重复点当前分栏不跳动。分栏只筛主页，不修改搜索或卡片。手机外观不变。此规则更新 ADR 0043 的随页滚动与间距约定。
- 新内容提示放在顶部：位于常驻标签下方，居中。最多三个来源类型图标，后面写「↑ N 项新内容」；提醒到点也算在内，铃铛排第一个。用 `glass` 白色玻璃，不用 `accent` 实底。点它把新内容放到最上面并回到顶部。

## 底部导航与反馈

2026-10-19 复核：用户比较三套状态表达后选择保留现状镜片，见 [ADR 0039](../../docs/adr/0039-keep-navigation-lens.md)。下列镜片、图标和页面切换规则继续有效，不再把 U3 列为未定设计。

- 底部只有一个导航胶囊，居中，四格：主页、搜索、AI、设置。当前一格用 `ink`，其余用 62% 的 `ink`，不用颜色区分。没有入口球、展开菜单，顶部不放头像或齿轮。
- 手机：胶囊不占满一行，按内容宽度居中（每格 60，共 248）；只有图标（24px），不写文字，名字只给读屏。每一格都是切换页面，不是弹窗：页面铺满胶囊后面的屏幕，没有把手、遮罩和通用关闭按钮，胶囊一直在（手机 AI 按 ADR 0045 保留原关闭按钮）；离开页面就点另一格，或按 Esc 回主页。从主页进入页面时整页 180ms 淡入；页面之间只淡入新内容，页面底色保持不透明，主页不会透出来。
- 桌面：图标在上、文字在下（10.5px）；AI、设置以面板打开，搜索使用独立页面。
- 胶囊只负责「去哪里」，不放对卡片的动作。收藏、备注与标签留在详情和阅读页的工具条里，批量动作留在多选菜单里。
- 主页：回到工作台；已经在工作台时滚回顶部。搜索：打开搜索。设置：格子里使用现有 Sill 线稿品牌标志 `sill`（窗台上的两张卡，复用 `assets/sill-line.svg` 的路径）；不使用头像、姓名首字或齿轮，不显示文字，保留「设置」无障碍名称，点开设置。图标沿用 Mono24 的描边、圆端点和 currentColor。
- AI：图标用对话气泡（`chat`）。拖入所选卡片后打开本地会话占位窗，展示卡片标题和短摘要。输入框可写临时文字，发送按钮禁用；明确说明尚未连接 AI、内容不发送、输入不保存。不生成回复、不调用模型或网络，也不改卡片状态。关闭后回到原页面与位置。读屏仍说明「AI，即将推出」。
- 本轮按用户结束指令保留 AI、设置整体、深色与阅读顶部现状；手机 AI 继续保留原关闭按钮，不实施已展示的去除候选。设置的卡片类型示例与搜索分行仍按已确认方案执行（ADR 0045）。
- 添加（记一笔）放进设置，是设置里单独的第一组「添加」，里面是同一个输入框。键盘 `N` 和首次打开页上的「记一笔」照旧直接打开记一笔面板。
- 镜片：当前一格上有一块透明的玻璃镜片（`glass-press` 底，上沿 `glass-edge` 高光）。换格时镜片用弹簧曲线 `ease-spring` 滑过去（`dur-lens` 300ms），途中横向拉长 5%、纵向压扁 3%，像一滴水移动，到位后回圆。手机上 AI、设置页面保留胶囊，镜片和页面同时换；搜索打开后隐藏胶囊，退出后恢复；桌面上点开搜索、AI、设置时，镜片和面板同时响应，底栏在 220ms 内淡出；面板关上后底栏回来，镜片再滑回主页。
- 尺寸：胶囊高 `rail-row` 60，每格 `nav-tab` 76 宽（手机 60）、4px 内边距；离底 28（手机 16 加安全区）。
- 刷新和回到顶部不放按钮：用下拉刷新，键盘 `R`、`T` 仍然可用；手机上点顶栏的 Sill 标志也回到顶部。搜索页正在筛选时，搜索图标右上角有一个 5px `ink` 小点，不显示数量；主页分栏标签已经显示当前一格，不算筛选。
- 轨道上方同一时间只放一样：「↑ 3」「未连接」提示居中浮在胶囊上方（手机上新内容提示移到顶部，见「手机主页」）；多选条和胶囊在同一行，手机宽度下多选条占满整行，胶囊暂时隐藏。
- 以后的助手功能放在 AI 这一格里，不再加新的悬浮按钮。
- 可撤销的 Toast 在可见且未被操作的累计 5.5 秒后淡出，普通说明累计 3.2 秒后淡出；页面不可见、窗口失去活动状态、指针停留或键盘焦点进入提示时暂停，恢复后继续剩余时间；替换和关闭取消旧计时。失败提示一直留着，带关闭按钮。Toast 在轨道上方一行，靠右，不叠在别的浮层上。
- 弹层打开、拖动卡片或键盘弹出时，轨道让开。手机上的 AI、设置是页面，胶囊留在原处；键盘弹出时让开。搜索页面始终隐藏胶囊，退出后恢复。

## 搜索与键盘

- 搜索和主页分别保存筛选、列表和滚动位置，搜索不改主页显示。两处复用同一卡片组件与卡片实体；阅读和完成状态共用。
- 从搜索打开卡片时，搜索结果留在抽屉下面。关闭详情返回原查询与滚动位置；退出搜索才回主页。浏览器前进与后退遵循同样顺序。

- 搜索筛选按「类型 / 状态 / 标签」分三行，左侧 28px 宽、12px muted 名称，条件与名称相隔 8px，条件区横滑；行间 8px、条件内边 2px、整体下边 4px。沿用原文字胶囊和筛选，标签为空时隐藏该行；每行是具名 group；筛选重绘保留各行横滑位置和焦点。保留查询、键盘顺序和详情返回，不改变主页（ADR 0044）。
- 搜索不显示数量：输入框里不写「26 张」，结果分组标题后不加数字。数量只交给读屏软件播报。
- 手机上搜索是一个页面：输入框在顶部安全区下方，筛选和结果依次向下排列；打开后隐藏底部导航胶囊。顶部关闭按钮或 Escape 退出后恢复胶囊。键盘弹出只缩小结果可滚动区域，不移动输入框。桌面搜索也使用独立页面，输入框在顶部，⌘K / Ctrl K 打开。
- 输入法拼写中（拼音或假名还没选字）不触发筛选，选字后再筛选，不闪出空结果。本地搜索不显示加载态。
- 键盘弹出时，记一笔、备注与标签这类要打字的弹层停在键盘上方，高度跟着可用空间变；底栏让开。

## 预览与叠放

- 抽屉打开后固定背景并保留滚动位置，关闭后还原。内容用原生惯性滚动，不显示滚动条但保留键盘滚动；触摸跟手不加过渡。到顶后继续下拉移动整张抽屉（见「下拉关闭」）；到底后开启「读完上推收起」时由读完圆片接管，关闭时只有轻微阻尼（最多 14px）。灰色把手是独立拖动区：上拖展开，下拖收起，拖过 160px 不论全屏与否直接关闭；取消触摸恢复原尺寸，松手才播放回位动效。
- 发布时间并入标题上方的来源行：「来源 · 10月1日」，跨年显示「来源 · 2025年10月1日」。没有发布时间不显示日期，不用收录或排序时间代替。来源名过长时截断，日期保持可见。完整时刻保留在日期提示中。收录、保存和更新时间不在阅读区展示；有值的来源备注在正文末尾用弱化文字完整展示，不添加面板、边框或折叠入口，业务专用备注保持原位置。原始数据保留。
- 抽屉按实际内容决定高度；短内容不撑满屏幕，长内容初始最多占用可视高度减 64px，正文在抽屉内滚动。手机向下阅读时自然扩展到全屏；主屏幕 PWA 不显示放大按钮，沿用滚动扩展。顶部安全区和底部工具条须避开正文。
- 标签放在标题下面，用较小的非交互标签；来源头部只承载来源名，发布时间并入来源行，其余来源元信息不在正文前展示。打开与关闭都有动效；

- 同一张卡在信息流和预览里用同一个头部。正文里不放色块按钮；只有「为什么看到」和交给助手这类文字链接留在内容末尾（2026-10-18，[ADR 0037](../../docs/adr/0037-card-detail-toolbar.md)，37 号画板）。
- 操作都在底部玻璃胶囊里，只用图标：左边是通用操作「收藏、标签、稍后读」，`ink`；一条竖线之后是这张卡片自己的操作，最多 3 个，`accent`。邮件「回复」；文章、视频、播客「去原文」；提醒和待办「在 Sill 内再提醒」、「忽略此提醒」。日程已显示「加入」时，顺序为「加入、在 Sill 内再提醒、忽略此提醒、下载日程」；没有显示「加入」时仍为「在 Sill 内再提醒、下载日程、忽略此提醒」。先排除不可用和被用户隐藏的操作，再取前三个，因此下载可在前面操作隐藏后补位（[ADR 0040](../../docs/adr/0040-event-reminder-priority.md)）。一边为空时不画竖线；全部隐藏时不显示胶囊。
- 名称写在 `aria-label`。触屏长按 0.45 秒在图标上方显示名称（`ink` 底、`card` 字），这次按下不执行；鼠标首次悬停 0.5 秒显示；提示出现后，800ms 内移到相邻工具立即显示名称，不重复入场。
- 提醒的「完成」是标题前的圆圈，和卡面同一个控件，只改 Sill；完成后再点恢复。胶囊里的「在 Sill 内再提醒」也只改 Sill，不改来源时间。
- 照片大图页在缩略图下放通用操作胶囊：收藏、标签、稍后读，遵守隐藏偏好，不增加专属操作。照片固定黑底，胶囊在两种主题下均复用现有深色变量。胶囊参与排版，不覆盖照片、缩略图或助手交接；保存或取消标签后回到原照片（[ADR 0041](../../docs/adr/0041-photo-shared-toolbar.md)）。
- 设置「卡片操作」每行在名称下方显示 muted 灰字示例：通用三项为所有卡片，回复为邮件，去原文为文章、视频等，加入和下载为日程，再提醒和忽略为待办、日程、提醒。复用现有 small 行样式；示例不改变开关名称、顺序、隐藏偏好或动作可用条件（[ADR 0042](../../docs/adr/0042-card-action-type-examples.md)）。
- 设置「桌面」页的「卡片操作」可以关掉任何一个操作（偏好 `hiddenActions`）。关掉只影响显示，功能和 MCP 不受影响。
- 胶囊在卡片内部底边上方，下面有滚动边缘。手机上正文最后一行到胶囊 26px，胶囊到底边 `max(8px, 安全区)`；读到底时内容、备注、标签和文字链接都在它上方完整露出。
- 关闭和全屏是浮在来源行右侧的白色圆片，与来源行（发件人、来源名、日期）居中对齐，不占一条白带；标题占满宽度。没有来源行时对齐标题首行。往下读时和工具条一起收起，停下时回来，下面垫一层渐隐，不压正文。阅读页右上是退出全屏和关闭阅读的玻璃按钮组。
- 详情和阅读页里没有头像、设置或底栏。
- 提醒没有时间时，头部只写「提醒」，不显示 `meta` 等状态文字。关联卡下面列出了引用卡，头部不再写「来自 N 张卡片」。
- 在预览里打开引用卡时叠放：新卡盖在上面，下面那张露出顶边，点顶边回到下面那张。
- ✕、Esc、下拉、点遮罩、读完上推、浏览器返回每次只关最上面一张，露出下面那张（[ADR 0046](../../docs/adr/0046-backdrop-closes-one-stacked-card.md)）。

## 量大与时间

- 同一来源一小时内超过 5 张，自动叠成一摞，像一副牌：一篇一张完整的卡，位置写在每张卡右上角（「2/6」）。左右翻看时移动的是整张卡，不是卡里的文字：最上面一张跟手走、带一点倾斜，下一张从下面浮起；松手过三分之一或快速一甩，上面那张整张飞出；往右拖是上一张从左边盖回来；不够就弹回。手指、鼠标拖动、触控板横扫、方向键都可以。卡在手里或飞出时压在旁边的卡上面。点按或回车才在原地展开整摞，拖动结束不算点按。
- 同一篇内容从多个来源进来时合并成一张卡，头部叠放来源图标。
- 读过或完成的卡片只改变颜色，始终保留在主页；时间流逝、阅读完成、任务完成、提醒完成或免打扰都不能自动收起卡片。只有明确归档才移出主页；保留已有真实归档状态。

## 桌面阅读与操作细节

2026-10-19 用户确认两轮审查优化；在仓库内更新规范与实现，不操作云端设计。

- 键盘打开搜索、记一笔及详情时立即显示并聚焦，关闭也立即响应；点击和触摸保留已有空间过渡。手机详情正文与抽屉同时出现，不再单独等待 200ms。
- 卡片的来源与标题间隔 12px，标题与摘要间隔 6px；正文与清单、附件、关联内容之间使用 12px，保留手机现有密度。无可执行动作的邮件附件使用静态文件行，不做按钮外观。
- 桌面待办文字最多两行，圆圈与首行对齐。全部完成后保留原有清单结构和可恢复的勾选项，仅改变完成色，不压缩成完成横条。
- 建议卡显示两个关联预览；更多关联以“另有 N 项关联内容”说明，完整关联仍在详情查看。
- 短待办、提醒及短笔记详情使用较窄宽度，长正文保留阅读宽度；短内容末尾到工具条保持清晰分隔，不添加多余空白。
- macOS 搜索与 Web 使用类型、状态、标签三个具名分组，标签不截断为前八项；各行可横向滚动。Toast 采用同一暂停规则。

窄桌面仍在容纳两列最小宽度时保留两列；三列及以上才要求每列达到理想阅读宽度，避免小窗口退成过宽单列。

主页分栏滚动时保持可见。读完、完成提醒或勾选待办只更新状态，不改变当前信息流的成员、顺序、叠卡分组和卡片占位；任务预览保留当前行。切换分栏或主动刷新后再应用最新筛选和排序。

## 移动浏览器基础行为

- 悬停反馈只在支持悬停且主指针精确时生效；按下与键盘焦点反馈独立保留。
- 应用与全屏阅读区域使用动态视口高度；Android 软键盘收起布局视口，iOS 继续使用现有 visualViewport 处理。
- 有触屏的设备上，输入字号至少 16px，避免聚焦时页面自动放大；保留用户缩放。16px 是浏览器输入保护阈值，不新增字号等级。
- 按钮禁止长按选中文字，正文和正文链接保留选择与系统菜单。轻点使用 manipulation，已有拖动区域保留自己的手势规则。
- 页面阻止浏览器纵向下拉刷新，内层滚动保留现有边界；横屏不自动放大文字。浏览器栏颜色跟随当前应用主题的 canvas。
- 这些是 Web 平台修复，不改变 macOS 的文案、状态或颜色角色；软键盘、安全区与主屏幕启动须在真机验收。
