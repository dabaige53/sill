## 两端对照

窗口宽 650px 及以下用「移动」规则，宽于 650px 用「网页」规则。移动的决定见 [ADR 0048](../../docs/adr/0048-phone-top-row-and-search-tokens.md)，画板为设计画布 44 号；网页的决定见 [ADR 0049](../../docs/adr/0049-web-top-search-and-ai-dock.md)，画板为设计画布 45 号。本节不新增设计变量。

| 项目 | 移动（≤650px） | 网页（>650px） |
| --- | --- | --- |
| 顶部 | 每页一行：左侧页名 34/700，右侧 36px 圆钮 | 一条顶栏：品牌图标 + Sill + ⌄，右侧搜索栏 + 头像，统一 40 高 |
| 主页分栏 | 顶行下方一行实心胶囊，常驻 | 默认收起，从 ⌄ 菜单选，选中后成为搜索栏里的标签 |
| 搜索 | 独立页面：分类卡 → 结果页 | 顶栏里直接输入，结果在卡片区原地显示 |
| 搜索条件 | 分类标签（`ink`）+ # 标签（`accent`） | 相同 |
| 主页与搜索的状态 | 分别保存 | 共用一个状态 |
| 底部 | 导航胶囊「主页 / AI / 搜索」 | 只有 AI 框，没有导航胶囊 |
| AI | 独立页面，右上「历史」「新对话」 | 底部 AI 框，可拖入卡片，可展开成完整视图 |
| 多选条 | 与导航胶囊同一轨道，出现时胶囊隐藏 | 与 AI 框同一轨道，同宽同高，出现时 AI 框隐藏 |
| 设置入口 | 主页和搜索右上的头像 | 顶栏右侧的头像 |
| 内置 AI 未接入时 | 发送、语音、历史、新对话禁用 | 发送、麦克风禁用；不显示会话 |

两端共用：卡片组件与卡片动作、详情抽屉与阅读页、类型胶囊组件、分类与 # 标签规则、命中词加粗、输入法组词规则、Toast、记一笔与 N、R / T。

## 移动（650px 及以下）

三个页面：主页、AI、搜索。设置是从头像进入的页面，不是第四个导航项。详情和阅读仍是抽屉，不算页面。

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 顶行 | 页名 + 右侧圆钮 | 高 60 |
| 分栏（只在主页） | 全部、未读、待办、稍后读、收藏 | 高 44 |
| 卡片区 | 卡片，单列 | 页边距 16，卡片间距 12 |
| 导航胶囊 | 主页、AI、搜索 | 高 60，离底 16 + 安全区 |

### 手机主页

2026-10-19 按用户选择的 [Apple Music 主页](https://mobbin.com/screens/8c345080-d9bd-4ad5-a6c7-8e5b32445b20) 调整标题、头像和导航层级；卡片仍承载 Sill 的内容。

**顶行**：主页、AI、搜索三页相同。

| 部分 | 数值 |
| --- | --- |
| 高度 | 60 |
| 页名 | 「Sill」「AI」「搜索」，字号 34，字重 700，起点在页边距 16 |
| 右侧圆钮 | 36px 圆，点击区 44，与页名垂直居中 |
| 主页、搜索右侧 | 头像，进入设置；没有真实头像时用现有 person 图标，不虚构用户照片 |
| AI 右侧 | 「历史」（clock）和「新对话」（plus），间距 4，不放头像 |
| 底色 | `canvas` 加轻磨砂；内容滚到下方时保持清晰，不叠加厚玻璃或硬分隔线 |

- 点「Sill」：主页回到顶部，工具条出现。
- 下拉刷新时，刷新指示器在顶行正中，不遮住左侧页名。
- 搜索结果页不显示顶行。

**分栏**：顶行下方一行实心胶囊，与搜索结果的类型胶囊是同一组件。

| 部分 | 数值 |
| --- | --- |
| 行高 | 44 |
| 胶囊 | 高 32，全圆角，左右内边距 14，文字 14（`text-control`），间距 8 |
| 当前项 | `ink` 底，`card` 字，字重 600 |
| 其他项 | `card` 底，1px `line-card` 内描边，`ink` 字 |
| 选项 | 全部、未读、待办、稍后读、收藏 |

- 第一个胶囊与页边距 16 对齐。放不下时整行横滑，不压缩间距，不平分宽度。
- 切换分栏立即更新卡片区。每个分栏分别保留滚动位置，切回时回到原处。
- 分栏只作用于主页，不影响搜索。
- 读完、勾选待办等状态变化不改变当前列表的成员和顺序；切换分栏或刷新后再应用。

**卡片**

- 页边距 `margin-sm` 16，卡片间距 `gap-sm` 12，卡片圆角 `card-radius-sm` 16，内边距 `card-padding-sm` 16。标题 17、摘要 15，摘要最多两行；已读只改变颜色。
- 页名、卡片左边线与第一个胶囊起点对齐。
- 保留原有卡片细节：文章 76px 缩略图；媒体与照片 2:1 大图；日程左侧时刻、右侧标题和时长；待办与提醒圆圈直接完成 Sill 内状态；附件占满整行。
- 新内容提示在分栏行下方；详情关闭后保留原阅读位置。

### 搜索与键盘

以 [Apple Music 顶部搜索栏](https://mobbin.com/screens/0fdc7e6a-e4aa-4c5a-8879-84396df1a589)、[分类网格](https://mobbin.com/screens/38013fe5-6e15-4038-9c0f-039bf66715c7)、[结果分类](https://mobbin.com/screens/6e9cc18e-6337-481f-91c5-d7ab3f09c247) 和 [搜索流程](https://mobbin.com/flows/aa6db5b1-4567-4ab8-9d57-c348a0e03f82) 为视觉依据。搜索栏始终在页面上方，不采用 Apple Music 的底部搜索栏；不复制音乐广告、播放器或系统状态栏。

**搜索首页**

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 顶行 | 「搜索」+ 头像 | 高 60 |
| 搜索栏 | 占位字「卡片、备注、来源」；`surface` 实底，胶囊圆角，无阴影 | 高 44，左右边距 16 |
| 分类卡 | 分类名称和已有内容封面，不加说明和数量 | 两列，16:10，间距 12，圆角 12，与搜索栏间距 16 |

- 页面底色为 `card` 实色。不显示筛选行，不显示虚构的「热门搜索」。
- 点分类卡：进入结果页，分类作为标签放进搜索栏。
- 输入文字并确认（输入法组词结束）：进入结果页。

**结果页**

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 搜索栏 + 关闭钮 | 分类标签、# 标签、文字依次排列 | 栏高 44，关闭钮 44 |
| 类型胶囊（只有文字时） | 全部、资讯、消息、笔记、待办、日程、媒体 | 高 32，间距 8 |
| 卡片区 | 结果卡片 | 同主页 |
| 导航胶囊 | 保留；搜索图标带 5px 小点 | 同主页 |

- 不显示顶行。点关闭回到搜索首页，清空本次条件。
- 分类标签：`ink` 底、`card` 字。结果只显示该分类，可以继续输入文字缩小范围。栏内有分类标签时不显示类型胶囊。
- 类型胶囊与主页分栏是同一组件；未选中项用 `surface` 底，无描边。没有结果的类型不显示。
- 左右滑动结果区切换类型，胶囊同步滚到可见位置。每个类型分别保留滚动位置。
- 搜索栏里有分类或 # 标签时，导航的搜索图标显示 5px 小点，不显示数量。

**# 条件**：取消「筛选」展开区，状态和标签改为在搜索栏输入 # 选择。

| 步骤 | 结果 |
| --- | --- |
| 在搜索栏输入 # | 搜索栏下方浮出列表，浮在结果上方，不推开结果 |
| 列表内容 | 先「状态」：未读、收藏、稍后读；后「标签」：只列已有标签，没有标签时不显示这一组 |
| 继续输入 | 按名称过滤列表 |
| 点选或按回车 | 条件变成 `accent` 底、白字的 # 标签，列表收起 |
| 点空白处或删掉 # | 列表收起，不加条件 |

- 分类标签、# 标签和文字可以同时存在，结果同时满足全部条件。
- 删除键从后往前逐个删除：先删文字，文字为空时删最后一个标签。标签多时在搜索栏内横滑，栏高不变。
- 状态只有未读、收藏、稍后读三项，不新增筛选能力。
- 命中词加粗，不加底色。不显示结果数量。输入法组词时不筛选，确认后更新；本地搜索不显示加载动画。
- 搜索和主页分别保存查询、条件及滚动位置。从搜索打开详情后，返回原查询与位置；浏览器前进后退遵循同样顺序。
- 软键盘只缩小可用内容区，不移动顶部搜索栏。

### 底部导航与反馈

**导航胶囊**

| 部分 | 数值 |
| --- | --- |
| 胶囊 | 居中，高 `rail-row` 60，每格 `nav-tab` 76，内边距 4 |
| 位置 | 离底 16 加安全区 |
| 图标 | 现有 Mono24 图标，居中，不显示文字；当前项 `ink`，其他 62% `ink` |
| 顺序 | 主页、AI、搜索，固定 |

- 切换立即更新，玻璃镜片换格，不拉伸，不弹跳。页面切换不播放整页过渡。导航常驻，搜索结果页也保留。
- 往下滚 28px 收起，往上滚 14px、停下 650ms、到顶或到底时回来。
- 软键盘出现时导航让开。

**AI 页**：参照 [X 的对话页](https://mobbin.com/screens/cc84d28a-3220-439b-ac7a-18f7778642e4)。

- 顶行左侧「AI」，右侧「历史」「新对话」。
- 输入框左右外边距 12，圆角 24，内边距 12。上排为 17px 输入；下排为附件、发送和语音。附件和语音高 32，发送为 24px 圆，语音为黑色胶囊。
- 输入框底色 `ai-composer`，控件浅底 `ai-control`。输入框跟随软键盘上沿，底部导航暂时隐藏。
- 已选卡片作为上下文卡显示在输入框上方。空白区域留白，不放引导句、功能说明或「输入不保存」等备注。

**设置**：从主页和搜索的头像进入，保留返回按钮、分组和现有轻操作。打开设置时不把导航镜片移到不存在的一格。记一笔仍在设置的「添加」组。

**多选**：多选条与导航胶囊在同一轨道。多选条出现时导航胶囊隐藏，退出多选后回来。动作为数量、收藏、稍后读、标签、交给 AI、取消。详情打开时背景工具条留在遮罩下，关闭后自然显露。

### 移动交互细节

| 操作 | 结果 |
| --- | --- |
| 点顶行「Sill」 | 主页回到顶部，工具条出现 |
| 点头像 | 进入设置；设置有返回按钮 |
| 点分栏胶囊 | 卡片区立即切换，回到该分栏上次的位置 |
| 横滑分栏行 | 只滚动胶囊行，不切换分栏 |
| 输入法组词中 | 不筛选；组词结束后更新 |
| 搜索结果里打开卡片，再关闭 | 回到原查询和原滚动位置 |
| 浏览器返回 | 先关最上面的抽屉，再回到上一个搜索状态 |
| 下拉主页 | 刷新；指示器在顶行正中 |
| 长按工具图标 0.45 秒 | 图标上方显示名称，这次按下不执行 |

### 移动状态

| 状态 | 表现 |
| --- | --- |
| 分栏没有卡片 | 显示现有空状态，不显示数量 |
| 搜索没有结果 | 显示现有空状态；不显示结果数量和加载动画 |
| 内置 AI 未接入 | 发送、语音、历史、新对话禁用；不伪造历史、会话或回复 |
| 输入内容 | 只保留在当前页面会话中 |

## 网页（宽于 650px）

网页只有一个主界面：搜索不另开页面，AI 不另开页面，没有底部导航胶囊。保持原有多列布局、列宽与卡片密度。

| 从上到下 | 内容 | 尺寸 |
| --- | --- | --- |
| 顶栏 | 左：品牌图标、Sill、⌄；右：搜索栏、头像 | 四者高 40，同一中线 |
| 类型胶囊（只在有文字时） | 全部、资讯、消息…… | 高 32 |
| 卡片区 | 多列卡片 | 同现有桌面 |
| AI 框 | +、输入、麦克风、发送 | 640×60，离底 28 |

### 桌面顶栏与 AI 框

**顶栏**

| 部分 | 数值 |
| --- | --- |
| 品牌图标 | 现有应用图标 `sill-icon`，40px，圆角 9 |
| 「Sill」 | 字号 34，字重 700，行高 40；与图标间距 10 |
| ⌄ 分栏按钮 | 20px `muted` 图标，点击区 36 |
| 搜索栏 | 高 40，圆角 20；宽 280，有标签时 360，聚焦时 480 |
| 头像 | 40px 圆，点击区不小于 44 |
| 搜索栏和头像材质 | `card` 底，1px `line-card` 内描边，间距 8 |
| ⌘K 提示 | 13px `muted` 纯文字，不加框 |
| 对齐 | 四者同一中线；图标左缘对齐卡片区左缘，头像右缘对齐卡片区右缘 |

- 点「Sill」回到顶部。点头像进入设置。
- 搜索栏宽度变化用 `dur-state` 220ms 和 `ease`，右缘固定，向左展开。
- 有文字时，⌘K 提示换成清除按钮。

**分栏菜单**

| 菜单行 | 右侧 |
| --- | --- |
| ✓ 全部 | ⌘1 |
| 未读 | ⌘2 |
| 待办 | ⌘3 |
| 稍后读 | ⌘4 |
| 收藏 | ⌘5 |

- 默认收起，主页上不显示分栏行。点 ⌄ 在下方弹出菜单，宽 220，`dur-menu` 180ms，收起 120ms。当前项前有 ✓，快捷键为 `muted`。
- 选择后菜单关闭。选「全部」以外的项时，该项以 `ink` 底标签放进搜索栏，占位字改为「在未读里搜索」这类说法，卡片区只显示该分栏。选「全部」移除分栏标签。
- 每个分栏分别保留滚动位置，切回时回到原处。
- 菜单里的 ✓ 跟着搜索栏里的分栏标签走：删掉标签，✓ 回到「全部」。
- Esc 或点菜单外面：关闭菜单，不改变分栏。菜单打开时，上下方向键移动高亮，回车选择。

**搜索**

- 搜索栏在顶栏，不另开页面。⌘K / Ctrl K 聚焦搜索栏。
- 结果在卡片区原地显示，保持多列布局。有文字且没有分类标签时，顶栏下方显示一行类型胶囊。
- 分类标签、# 条件、输入法组词、命中词加粗与移动相同（见「搜索与键盘」）。
- 主页分栏与搜索共用一个状态：分栏就是搜索栏里的一个标签，可以接着输入文字，在该分栏里搜。
- 点标签上的 ×，或光标在标签后按删除键：移除标签，回到全部。
- 不显示结果数量，本地搜索不显示加载动画。新内容提示放在顶栏下方居中。

**底部 AI 框**

| 部分 | 数值 |
| --- | --- |
| 位置 | 底部居中，离底 28 |
| 尺寸 | 宽 640，高 `rail-row` 60，圆角 30 |
| 材质 | `glass` |
| 控件顺序 | +、输入、麦克风、发送 |
| 输入文字 | 16px |
| 控件 | 36×36，图标 20，不加底色 |
| 发送 | 32px 圆；不可发送时浅灰底，可发送时 `ink` 底 |

- 不显示主页 / AI / 搜索导航胶囊。控件和文字共用一条中线。
- AI 框是输入框，往下滚动时不收起；聚焦时一直显示。

**拖入卡片**

| 步骤 | 结果 |
| --- | --- |
| 开始拖动卡片 | AI 框显示 `accent` 描边和「松手，把卡片交给 AI」 |
| 拖到 AI 框上松手 | 卡片成为框上方的上下文卡：`card` 底、细边、可点 × 移除 |
| 拖到别处松手 | 没有变化 |
| 连续拖入 | 可以放多张，按拖入顺序排列 |

- 原卡不移动，不改变状态。键盘用户用多选条的「交给 AI」代替拖动。

**会话与完整视图**（内置 AI 接入后启用）

| 行 | 从左到右 |
| --- | --- |
| 上排（高 44） | —（收起成一行）、运行状态、会话标题 ⌄、「另 N 个进行中」、⋮⋮ |
| 输入行（高 60） | +、输入、麦克风、发送 |

- 运行状态：运行中转圈，完成为 ✓。「另 N 个进行中」为 13px `muted`，只在其他会话也在运行时显示。
- 点标题向上弹出会话列表：新对话；进行中（每个带转圈）；历史（按时间倒序）。切换会话不打断其他会话。
- ⋮⋮ 菜单：「在完整视图中打开」「新对话」。
- 完整视图：居中面板，宽 1040，高为可视高度减 120；左侧 260 宽会话列表，右侧为当前对话。右上 ⤡ 或 Esc 回到底部一行。不加遮罩，卡片仍可拖入。

**多选**：多选条与 AI 框共用底部轨道，同宽 640、同高 60、同一位置，一次只出现一样。

| 从左到右 | 图标 |
| --- | --- |
| 数量 | 数字 |
| 收藏 | bookmark |
| 稍后读 | glasses |
| 标签 | tag |
| 交给 AI | chat |
| 分隔线 | — |
| 取消 | x |

- 按钮 44 见方，整组居中。
- 「交给 AI」：把所选卡片放进 AI 框，退出多选，AI 框回来。退出多选后，AI 框原有输入和上下文卡保留。

### 网页键盘

| 按键 | 结果 |
| --- | --- |
| ⌘K / Ctrl K | 聚焦搜索栏 |
| ⌘1–⌘5 | 切换分栏：全部、未读、待办、稍后读、收藏 |
| Esc（菜单打开） | 关闭菜单 |
| Esc（搜索栏有文字） | 清除文字 |
| Esc（只剩标签） | 清除标签，回到全部 |
| Esc（搜索栏为空） | 搜索栏失去焦点，宽度回到 280 |
| 删除键（光标在最前） | 删除最后一个标签 |
| 回车（# 列表打开） | 选中高亮项，变成 # 标签 |

Esc 每次只退一层，顺序为：菜单 → 文字 → 标签 → 焦点。

### 网页交互细节

| 操作 | 结果 |
| --- | --- |
| 悬停搜索栏、头像、⌄ | `dur-hover` 160ms 变化，只在支持悬停的设备上 |
| 点搜索栏 | 宽度展开到 480，显示光标 |
| 点卡片区空白 | 搜索栏失焦，文字和标签保留，宽度回到 280 或 360 |
| 选分栏后输入文字 | 在该分栏里搜索 |
| 打开详情再关闭 | 回到原搜索条件和原滚动位置 |
| 窗口缩到 650px 及以下 | 改用移动布局：分栏回到胶囊行，导航胶囊回来，AI 框隐藏 |

### 网页状态

| 状态 | 表现 |
| --- | --- |
| 分栏或搜索没有结果 | 卡片区显示现有空状态，顶栏不变 |
| 拖动中 | AI 框 `accent` 描边加提示文字；松手后恢复 |
| 多选中 | AI 框隐藏，多选条在同一位置 |
| 内置 AI 未接入 | 发送和麦克风禁用；不显示运行状态、会话内容或回复，不伪造会话与结果 |
| 输入与上下文卡 | 只保留在当前页面会话中 |

## 两端共用

- 键盘：N 记一笔，R 刷新，T 回到顶部；只在没有输入焦点时生效。下拉刷新保留。
- 可撤销 Toast 在可见且未被操作的累计 5.5 秒后淡出，普通说明累计 3.2 秒后淡出；页面不可见、窗口失焦、指针或键盘焦点进入时暂停。失败提示持续显示并可关闭。Toast 不遮挡当前操作。
- 卡片动作与多选动作保持原位置。设置与 AI 共用现有文案、颜色和尺寸角色，不新增后端能力。
- macOS 是否改成网页的顶栏、分栏菜单与 AI 框，待确认；确认前 macOS 保持现状。会话、历史和完整视图在内置 AI 接入后启用。

## 预览与叠放

- 抽屉打开后固定背景并保留滚动位置，关闭后还原。内容用原生惯性滚动，不显示滚动条但保留键盘滚动；触摸跟手不加过渡。到顶后继续下拉移动整张抽屉（见「下拉关闭」）；到底后开启「读完上推收起」时由读完圆片接管，关闭时只有轻微阻尼（最多 14px）。灰色把手是独立拖动区：上拖展开，下拖收起，拖过 160px 不论全屏与否直接关闭；取消触摸恢复原尺寸，松手才播放回位动效。
- 顶部只显示来源名，过长截断，不放日期。标题下依次放标签和日期，再进入摘要和正文。日期采用 [Medium 阅读页](https://mobbin.com/screens/9659e74b-ceec-4bb5-a80d-5e975a5bdb4e) 的简洁信息行：小灰字「10月1日」，跨年带年份，不加「发布于」前缀。来源备注只用于补充不同的信息，内容写入时避免重复出处和日期；界面保留已有备注，不自动解析或删除文字。备注保留在正文末尾，自然换行。沿用正文区现有段间距，不额外叠加顶部留白；读完手势的尾部空间放在信息区之后。两者均无值时不渲染信息区；不添加背景、边框或折叠按钮。没有发布时间不用收录或排序时间代替，完整时刻保留在日期提示中。收录、保存和更新时间不在阅读区展示，原始数据保留；业务专用备注保持原位置。
- 抽屉按实际内容决定高度；短内容不撑满屏幕，长内容初始最多占用可视高度减 64px，正文在抽屉内滚动。手机向下阅读时自然扩展到全屏；主屏幕 PWA 不显示放大按钮，沿用滚动扩展。顶部安全区和底部工具条须避开正文。
- 标签放在标题下面，用较小的非交互标签；来源头部只承载来源名，发布日期在标题与标签之后、正文之前，来源备注在正文末尾。打开与关闭都有动效；

- 同一张卡在信息流和预览里用同一个头部。正文里不放色块按钮；只有「为什么看到」和交给助手这类文字链接留在内容末尾（2026-10-18，[ADR 0037](../../docs/adr/0037-card-detail-toolbar.md)，37 号画板）。
- 操作都在底部玻璃胶囊里，只用图标：左边是通用操作「收藏、标签、稍后读」，`ink`；一条竖线之后是这张卡片自己的操作，最多 3 个，`accent`。邮件「回复」；文章、视频、播客「去原文」；提醒和待办「在 Sill 内再提醒」、「忽略此提醒」。日程已显示「加入」时，顺序为「加入、在 Sill 内再提醒、忽略此提醒、下载日程」；没有显示「加入」时仍为「在 Sill 内再提醒、下载日程、忽略此提醒」。先排除不可用和被用户隐藏的操作，再取前三个，因此下载可在前面操作隐藏后补位（[ADR 0040](../../docs/adr/0040-event-reminder-priority.md)）。一边为空时不画竖线；全部隐藏时不显示胶囊。
- 名称写在 `aria-label`。触屏长按 0.45 秒在图标上方显示名称（`ink` 底、`card` 字），这次按下不执行；鼠标首次悬停 0.5 秒显示；提示出现后，800ms 内移到相邻工具立即显示名称，不重复入场。
- 提醒的「完成」是标题前的圆圈，和卡面同一个控件，只改 Sill；完成后再点恢复。胶囊里的「在 Sill 内再提醒」也只改 Sill，不改来源时间。
- 照片大图页在缩略图下放通用操作胶囊：收藏、标签、稍后读，遵守隐藏偏好，不增加专属操作。照片固定黑底，胶囊在两种主题下均复用现有深色变量。胶囊参与排版，不覆盖照片、缩略图或助手交接；保存或取消标签后回到原照片（[ADR 0041](../../docs/adr/0041-photo-shared-toolbar.md)）。
- 设置「卡片操作」每行在名称下方显示 muted 灰字示例：通用三项为所有卡片，回复为邮件，去原文为文章、视频等，加入和下载为日程，再提醒和忽略为待办、日程、提醒。复用现有 small 行样式；示例不改变开关名称、顺序、隐藏偏好或动作可用条件（[ADR 0042](../../docs/adr/0042-card-action-type-examples.md)）。
- 设置「桌面」页的「卡片操作」可以关掉任何一个操作（偏好 `hiddenActions`）。关掉只影响显示，功能和 MCP 不受影响。
- 胶囊在卡片内部底边上方，下面有滚动边缘。手机上正文最后一行到胶囊 26px，胶囊到底边 `max(8px, 安全区)`；读到底时内容、备注、标签和文字链接都在它上方完整露出。
- 关闭和全屏是浮在来源行右侧的白色圆片，与来源行（发件人、来源名、日期）居中对齐，不占一条白带；标题占满宽度。没有来源行时对齐标题首行。往下读时和工具条一起收起，停下时回来，下面垫一层渐隐，不压正文。阅读页右上是退出全屏和关闭阅读的玻璃按钮组。
- 详情和阅读页里没有头像、设置或底栏。
- 提醒没有时间时，头部只写「提醒」，不显示 `meta` 等状态文字。关联卡下面列出了引用卡，头部不再写「来自 N 张卡片」。
- 在预览里打开引用卡时叠放：新卡盖在上面，下面那张露出顶边，点顶边回到下面那张。
- ✕、Esc、下拉、点遮罩、读完上推、浏览器返回每次只关最上面一张，露出下面那张（[ADR 0046](../../docs/adr/0046-backdrop-closes-one-stacked-card.md)）。

## 量大与时间

- 同一来源一小时内超过 5 张，自动叠成一摞，像一副牌：一篇一张完整的卡，位置写在每张卡右上角（「2/6」）。左右翻看时移动的是整张卡，不是卡里的文字：最上面一张跟手走、带一点倾斜，下一张从下面浮起；松手过三分之一或快速一甩，上面那张整张飞出；往右拖是上一张从左边盖回来；不够就弹回。手指、鼠标拖动、触控板横扫、方向键都可以。卡在手里或飞出时压在旁边的卡上面。点按或回车才在原地展开整摞，拖动结束不算点按。
- 同一篇内容从多个来源进来时合并成一张卡，头部叠放来源图标。
- 读过或完成的卡片只改变颜色，始终保留在主页；时间流逝、阅读完成、任务完成、提醒完成或免打扰都不能自动收起卡片。只有明确归档才移出主页；保留已有真实归档状态。

## 桌面阅读与操作细节

2026-10-19 用户确认两轮审查优化；在仓库内更新规范与实现，不操作云端设计。

- 键盘打开搜索、记一笔及详情时立即显示并聚焦，关闭也立即响应；点击和触摸保留已有空间过渡。手机详情正文与抽屉同时出现，不再单独等待 200ms。
- 卡片的来源与标题间隔 12px，标题与摘要间隔 6px；正文与清单、附件、关联内容之间使用 12px，保留手机现有密度。无可执行动作的邮件附件使用静态文件行，不做按钮外观。
- 桌面待办文字最多两行，圆圈与首行对齐。全部完成后保留原有清单结构和可恢复的勾选项，仅改变完成色，不压缩成完成横条。
- 建议卡显示两个关联预览；更多关联以“另有 N 项关联内容”说明，完整关联仍在详情查看。
- 短待办、提醒及短笔记详情使用较窄宽度，长正文保留阅读宽度；短内容末尾到工具条保持清晰分隔，不添加多余空白。
- macOS 搜索与 Web 使用相同分类入口与按需展开的状态、标签筛选；标签完整显示，各行可横向滚动。Toast 采用同一暂停规则。

窄桌面仍在容纳两列最小宽度时保留两列；三列及以上才要求每列达到理想阅读宽度，避免小窗口退成过宽单列。

主页分栏滚动时保持可见。读完、完成提醒或勾选待办只更新状态，不改变当前信息流的成员、顺序、叠卡分组和卡片占位；任务预览保留当前行。切换分栏或主动刷新后再应用最新筛选和排序。

## 移动浏览器基础行为

- 悬停反馈只在支持悬停且主指针精确时生效；按下与键盘焦点反馈独立保留。
- 应用与全屏阅读区域使用动态视口高度；Android 软键盘收起布局视口，iOS 继续使用现有 visualViewport 处理。
- 有触屏的设备上，输入字号至少 16px，避免聚焦时页面自动放大；保留用户缩放。16px 是浏览器输入保护阈值，不新增字号等级。
- 按钮禁止长按选中文字，正文和正文链接保留选择与系统菜单。轻点使用 manipulation，已有拖动区域保留自己的手势规则。
- 页面阻止浏览器纵向下拉刷新，内层滚动保留现有边界；横屏不自动放大文字。浏览器栏颜色跟随当前应用主题的 canvas。
- 这些是 Web 平台修复，不改变 macOS 的文案、状态或颜色角色；软键盘、安全区与主屏幕启动须在真机验收。

主页隐藏浏览器根滚动条，不为右侧轨道预留空白；鼠标滚轮、触摸和键盘滚动保持可用。macOS 原生窗口不受此浏览器样式影响。
搜索结果、设置、AI 上下文、多选菜单和云端记一笔遵循同一隐藏轨道规则，仍可滚动到底；只隐藏滚动条，不使用 overflow: hidden 代替。
