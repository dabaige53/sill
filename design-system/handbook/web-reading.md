## 资讯阅读

- 正文 Markdown 图片按原文位置显示，仅加载无内嵌凭据的 HTTPS 地址；保留说明文字、查询参数和重复图片。图片保持原比例并限制在正文宽度内，懒加载，有加载与失败提示。点击或键盘打开大图，关闭后保留原正文、焦点和滚动位置。原始 HTML 继续按文字显示，`images` 仍只负责原有封面与相册，不从正文收集图片再插到顶部。
- 原文操作只使用结构化 `url`，不从正文猜测出处。独立 Web/PWA 使用浏览器原生新标签链接，插件使用宿主 `openLink`，Mac 使用系统打开；缺少或不支持的链接禁用，宿主或系统拒绝时显示既有错误反馈。

只用于资讯卡；预览与全屏分别遵循 `CardTypeDetails`、`CardTypeMobile`、`CardTypeReading`。Web 与 macOS 的当前差异见[界面对账表](../../docs/implementation/design/ui-alignment.md)。数值见[字体](foundation.md#字体)与[间距与尺寸](foundation.md#间距与尺寸)。

- 预览顺序：封面 → 来源 · 日期 · 阅读时长 → 标题 → 标签 → 正文 → 备注。标题区与正文之间不加通栏分隔线，间距为 `rhythm-group` 24（见[纵向间距](content-layout.md#纵向间距)）。全屏把封面移到标题区之后。导语与列表属于正文，不额外插入卡面摘要。日期只在来源行出现一次，写「今天」「昨天」「10/18」，跨年加年份；取发布日期，没有时取保存日期，再没有时取卡片时间。
- 预览浮层宽度不变，左右 30（手机 20）。Web 资讯正文使用 shadcn Typeset 的段落、小标题、列表和引用间距，沿用原字体、字号、文字颜色与阅读偏好。桌面放大页内容区居中、最大宽 1200，内容区两侧再留窗口宽度的 5%（最小 24、最大 88）；正文内部边距保持不变。正文最大宽度为 `reader-measure` 920，桌面目录位于正文右侧，宽 `reader-outline-width` 160；正文与目录各自滚动。有标题时目录常显，不提供目录展开/收起按钮。目录只取正文 Markdown 的真实标题，不列「文章开头」；无标题时不显示目录。目录标题和条目沿用原来的 15px 字号，按 shadcn 目录的简洁列表呈现：普通项为 muted，当前位置用 ink 和中等字重，实际子标题缩进。Web 点击目录立即定位章节，不播放滚动过渡；手动滚动同步当前位置。手机预览不显示目录。
- 资讯和视频的预览保留底部操作胶囊；视频不提供放大入口；放大后操作直接显示在左上角，缩小与关闭在右上角。顶部占位 space-64，正文底部 space-24，不铺上下渐隐。阅读进度、读完圆环与既有轻操作保留。进度条与圆环随滚动逐帧更新；进度本身最多每 500ms 保存一次，关闭详情、切到后台或离开页面时补存；读完立即保存。视频播放器与正文上下排列。参见 [ADR 0065](../../docs/adr/0065-expanded-reading-layout.md)。
- 其他类型的预览与阅读页不使用资讯阅读变量。
- macOS 有正文的资讯、笔记、摘要和邮件均显示放大入口，不以内容高度限制。放大页左右留白45，正文与目录隐藏右侧滚动条，顶部阅读进度保留。预览和放大复用同一正文与原生滚动容器，切换不先清空正文；嵌套全屏的关闭只退出当前层。

## 桌面阅读与操作细节

- 键盘打开搜索及详情时立即显示并聚焦，关闭也立即响应；点击和触摸保留已有空间过渡。手机详情正文与抽屉同时出现，不再单独等待 200ms。
- 卡片内容块沿用 HTML 参考稿，来源、标题、摘要、清单、附件和关联内容之间统一间隔 8px。邮件卡面不显示附件，附件只在详情中复用文件列表；文件列表只在相邻项之间使用细分隔线和 8px 上下间距，列表上下不加线也不留额外间距；没有链接时不添加点击操作。
- 桌面待办文字最多两行，圆圈与首行对齐。全部完成后保留原有清单结构和可恢复的勾选项，仅改变完成色，不压缩成完成横条。
- 建议卡显示两个关联预览；更多关联以“另有 N 项关联内容”说明，完整关联仍在详情查看。
- 短待办、提醒及短笔记预览保留较窄面板；普通卡片详情的桌面左右内边距为 30px，全屏时占满剩余宽度。资讯预览采用相同内边距，放大页正文宽度和目录按「资讯阅读」。短内容末尾到工具条保持清晰分隔，不添加多余空白。
- macOS 搜索与 Web 使用相同分类入口与按需展开的状态、标签筛选；标签完整显示，各行可横向滚动。Toast 采用同一暂停规则。
- 桌面卡面不显示更多按钮，头部不预留按钮空位，日期与完成数量靠右对齐；Web 不提供单卡右键/更多菜单，也不提供多选条右键菜单；卡片详情和多选条的直接操作保留。Mac 仍有原菜单，差异见界面对账表。
- 资讯和邮件的纯文字摘要以 50–60 字为内容目标，桌面完整显示并自然增高，手机最多显示 4 行；正文依据不足时不凑字。已有要点版和展开叠卡沿用原规则，其他类型不变。
- 桌面预览工具栏与 AI 框、多选条使用同一种玻璃，按钮为 44，间距 4，胶囊高 60；两端沿用同组阴影。文字提示与圆形悬停底色保留。
- 指针（Web 与 macOS 一致）：可点击的按钮、链接、卡片和输入框里的标签、清除、移除按钮悬停显示手形；搜索框和 AI 框整个胶囊显示文字光标，点击胶囊空白处把光标放进输入框；禁用按钮（如未接通的 AI 加号、麦克风、发送）保持箭头。
- Mac 菜单栏提供「性能追踪」：开始、标记此刻、停止并导出。默认关闭，记录期间标题为「性能追踪 · 记录中」；不在卡片或阅读区新增悬浮入口。此入口是本机诊断工具，Web 不显示。

窄桌面仍在容纳两列最小宽度时保留两列；三列及以上才要求每列达到理想阅读宽度，避免小窗口退成过宽单列。

主页分栏滚动时保持可见。读完、完成提醒或勾选待办只更新状态，不改变当前信息流的成员、顺序、叠卡分组和卡片占位；任务预览保留当前行。切换分栏只应用筛选，保留卡片相对顺序。后台保存、内容更新、加载更多和返回主页不因完成状态重排；只有用户主动刷新或主动更换排序方式才重新排序。

## 移动浏览器基础行为

- 悬停反馈只在支持悬停且主指针精确时生效；按下与键盘焦点反馈独立保留。
- 应用与全屏阅读区域使用动态视口高度；Android 软键盘收起布局视口，iOS 继续使用现有 visualViewport 处理。
- 有触屏的设备上，输入字号至少 16px，避免聚焦时页面自动放大；保留用户缩放。16px 是浏览器输入保护阈值，不新增字号等级。
- 按钮禁止长按选中文字，正文和正文链接保留选择与系统菜单。轻点使用 manipulation，已有拖动区域保留自己的手势规则。
- 页面阻止浏览器纵向下拉刷新，内层滚动保留现有边界；横屏不自动放大文字。浏览器栏颜色跟随当前应用主题的 canvas。
- 这些是 Web 平台修复，不改变 macOS 的文案、状态或颜色角色；软键盘、安全区与主屏幕启动须在真机验收。
- PWA 触控与外壳：详情胶囊与底部导航的图标控件禁止文字选择和系统长按菜单。详情图标长按显示名称后，松手不执行动作；键盘聚焦时立即显示同一个名称提示。胶囊两端的名称提示向内侧展开，在 320px 宽度内完整可见。

独立工作台按系统深浅色选择状态栏底色：浅色 canvas 为 #f5f5f7，深色 canvas 为 #111113。登录页使用 card 底色，浅色 #ffffff、深色 #1c1c1f。manifest 保留现有 theme_color，不新增离线缓存。

主页隐藏浏览器根滚动条，不为右侧轨道预留空白；鼠标滚轮、触摸和键盘滚动保持可用。macOS 原生窗口不受此浏览器样式影响。
搜索结果、设置和 AI 上下文遵循同一隐藏轨道规则，仍可滚动到底；只隐藏滚动条，不使用 overflow: hidden 代替。

## 登录与授权

现行画板：[桌面登录](../boards/Login.dc.html)、[桌面授权](../boards/Authorization.dc.html)、[手机登录](../boards/LoginMobile.dc.html)、[手机授权](../boards/AuthorizationMobile.dc.html)。

- 登录内容宽度为 `auth-login-width` 352，授权为 `auth-consent-width` 400；窄屏按可用宽度收缩。两页采用白底、居中窄内容区与蓝色主按钮，不加外层厚卡片。品牌图标、连接图标、标题和状态说明居中；输入标签、账号信息和权限条目左对齐。
- 登录页使用 40 × 40 的应用图标和 `auth-title` 30/1.3 标题。Web/PWA 输入框高 56，标签在聚焦或已有内容时整体上移并缩小；字段间距 16，主按钮高 48。显示密码使用眼睛图标交叉淡化；等待真实请求时按钮保持宽度，显示加载图标与处理中说明；状态区预留高度，账号保留。Mac沿用56高字段及原生安全输入控件。当前 Web 与 Mac 只提供邮箱、密码、显示密码和「登录并继续」，不显示邮件登录或邮件重设密码入口。标题下不加介绍句，页脚不加标语；从插件进入时说明登录后继续本次授权。
- 当前未启用生产邮件登录，服务端默认拒绝发信请求。既有邮件回跳保留兼容，不作为现行登录入口；不能用演示反馈表示真实登录完成。
- 授权页显示申请应用、当前账号、逐项权限和内容范围；删除权限单独列出。应用名称、账号和权限按实际请求显示，不能固定使用画板中的示例值。
- 授权按钮为“取消”和“允许访问”；保留“可在「已授权客户端」中撤销”。取消不得授予权限；允许后的状态须以真实回执为准。
- 手机画板按 390 × 844 展示，与桌面共用页面和交互。手机登录表单在动态视口内垂直居中，上下至少留白 24px 并避开安全区；缩小两侧留白，图标和标题保持居中；输入字号至少 16px，按钮高度至少 44px，内容超出屏幕时可纵向滚动。保持相同的顺序、文案和状态。macOS 对应登录与授权界面沿用同样的居中原则和权限表达。
- 独立 Web 和手机 Web 未登录时进入 `/auth/login`，不在工作台另放一套邮件登录表单；已有未保存草稿时保留恢复入口。登录与授权画板从产品 HTML 和样式生成，仅替换演示回执，不提交真实请求。
- 原型页面只展示产品界面，不加顶部品牌栏、“设计预览”标识、页脚页面跳转或状态切换工具。画板之间从设计目录进入，状态通过页面原有操作触发。示例账号和必要的演示结果提示不进入产品页面；画板不提交账号、不发送邮件、不更改权限。

### 卡片详情内的导航与媒体

- 正文链接指向 Sill 内已有卡片时，在当前窗口打开该卡片，关闭后返回上一张；外部网址保持在来源打开。
- Web/PWA 播客为介绍页：封面、日期、标题、节目名、标签、收听记录、简介、只读章节、文字稿节选与信息表。无播放器、吸顶、页签、文字稿跟随、章节跳转及全屏入口。版式按 PR #72 原型：桌面详情宽 860，左右留白 80、顶部 40；封面 232 与日期、标题、节目行、标签并排，关闭与封面顶边对齐；手机封面整宽，关闭浮在封面右上角，上方不留空白。收听记录是上下分隔线之间的一行；正文最宽 640，简介不加标题，章节与信息为分隔线列表，文字稿标题下注「节选」并用衬线字体。没有封面图时画浅色封面，写节目名与标题。底部保留收藏、标签、稍后读、去原文和既有助手交接。收听记录只读取 `playbackPosition`，时长读取 `duration`；没有时长显示「时长未知」。记录由外部助手通过已有 MCP 写入并随工作区同步，页面不从阅读进度推算、不产生播放写入。macOS采用同一只读介绍结构，保留原生滚动。
- PR 详情头部只有来源、标题与标签。状态是信息行第一行（`pull` 图标）：状态文字用 `accent`，草稿和已关闭用 `muted`，后接「谁想把哪个分支合并到哪里」。检查、审阅人、改动、评论各占一行；没有数据的行不显示，不用「0/0」「—」占位。检查有明细时行尾显示展开箭头。
- PR 卡面按 CardTypeDetails 设计稿：来源行右侧为状态；标题、摘要之后一行左为分支、右为增删数与文件数，没有分支时这些计数从左开始，没有数据的项不占位；底部左为审阅人与检查（只显示勾号和通过数，如 1/1），右为「审阅」按钮。
- 卡面“审阅”有真实 PR 链接时打开该 PR；缺少链接时打开 Sill 中的 PR 详情，不禁用本地查看入口，不提交外部审阅。

### 照片轮播

Web/PWA 照片灯箱采用横向原生滚动与按页吸附（Scroll Snap），交互依据ui-lab Snap carousel公开源码；不称为Motion+源码复刻。照片占满一页，首尾不循环，背景和文字随明暗主题。触摸及触控板由浏览器处理滚动和惯性；鼠标按住拖动时暂停吸附，使用motion.photoCarousel最近80ms的位移估计速度，按280ms滑行距离选择落点；超过0.3px/ms的轻甩至少前进一页，停止后不保留旧速度。到达后恢复吸附，浏览器控制平滑滚动时长；前后按钮、缩略图和方向键共用照片索引，键盘立即定位。系统取消返回起始页，拖动后的click不触发其他动作，不缩放或拉伸照片。

桌面视频预览与播客一样宽 860，其他卡片预览仍为 760。视频仅使用预览页，播放器下方直接显示正文；播客仍为介绍页。资讯的预览与全屏过渡保持原有规则。

macOS 照片页的标题、图片区域与说明使用左右30的页边距，标题和关闭按钮顶部留白40；关闭按钮保持44点击范围。缩略图与说明左缘对齐，原生横向分页、图片比例及首尾边界保持。

## 章节目录

Web 资讯放大页使用上文「资讯阅读」的右侧目录。标题按相对最浅层级缩进，每级 12px、最多两级；当前位置以深色和中等字重表示。保留长标题换行，不使用章节比例分段、圆点或整行选中底色。点击及键盘定位立即完成。手机不显示目录。

视频只提供预览页：来源、标题、标签、播放器、正文依次排列。正文直接显示，不设置文字稿、章节或摘要页签，不提供 Sill 视频全屏页；官方播放器自身的控制保留。Web 与 Mac 使用相同规则。
