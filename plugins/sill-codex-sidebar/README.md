# Sill

新增的 Codex 侧边栏插件，与原有 Sill 产品插件并存，共享现有云端数据。

显示名为 Sill，安装身份 sill-codex-sidebar 保持不变。浅色使用 assets/sill-line.svg，深色使用 assets/sill-line-dark.svg。logo 和 composerIcon 均使用透明背景 SVG 线条图标，不使用带底色的整幅 PNG 作为侧边栏图标。

安装：`codex plugin add sill-codex-sidebar@quiet-glass-local`。重新打开 Codex 以加载更新；账号连接沿用正常授权入口。云端发布记录见 deploy/codex-sidebar-cloud/release.json。
