# Sill · Codex 侧边栏

额外的 Codex 插件，不替换原 Sill 产品插件。连接现有 Sill 云端 MCP 和已有 Codex OAuth 客户端，共享同一账号的数据；本机不运行服务。

安装：`codex plugin add sill-codex-sidebar@quiet-glass-local`

首次安装后重新打开 Codex，使插件工具和侧边栏入口加载。若显示未连接，在新插件的正常授权入口登录；不能把安装成功视为账号已连接。

侧边栏图标使用 `assets/sidebar-color.png`：沿用已选的彩色窗台品牌图标。浅色与深色模式均引用彩色 PNG，不再引用黑色单色 SVG。产品列表图标保持不变。
